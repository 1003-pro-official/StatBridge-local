# 원본 재현 및 수치 차이 해결 계획 (ai-assisted)

승인된 범위: 지급서비스 2개 표의 전체 범위 대조와 안전한 갱신, 앱의 자료 버전 근거 표시, 대표 원본 3건의 완전성 검증. 기존 변경은 보존하고 자동 머지하지 않는다.

1. 두 지급서비스 표를 동일 식별자·기간·분류로 대조한다. 원천 최종변경일을 확인하고 이전 CSV를 해시별 백업한 뒤 검증된 전체 자료만 원자적으로 교체한다.
2. 조회 결과마다 출처, UTC 조회시각, 원천 최종변경일, 관측치 SHA-256을 기록하고 기존 실행 근거 화면에 표시한다. 저장된 세션은 기존 데이터 스냅샷을 유지한다.
3. ESI 그림, 예금은행 금리표, 가계신용 잔액표의 원본 전체 계열·기간·계산·표현을 명세한다. 누락 또는 공표시점 자료 부재는 실패/미검증으로 남기고 응용형과 구분한다.
4. 갱신·무결성·자료 근거 전달을 회귀 검증하고 필수 Python 평가 및 프런트 빌드를 실행한다. 산출물에 실행 결과와 남은 제약을 기록한다.

완료 기준: 두 표의 전체 관측치가 갱신 응답과 일치하고 이전 자료를 복구할 수 있음; 자료 버전 근거가 출력까지 전달됨; 3개 원본의 재현 여부를 개별 근거로 판정함. 원본 전체와 같다는 표시는 수치·계산·표현 검증이 모두 통과할 때만 사용한다.
