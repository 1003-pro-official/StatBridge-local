# 한국은행 보고서 작성 지원을 위한 조사 확장과 재현 가능성

작성: 2026-10-19, ai-assisted. 대상은 한국은행 정기 간행물·보고서를 작성하는 직원이다. 담당자의 통계 정의·원문 검수를 완료한 자료로 표시하지 않는다.

## 1. 어디까지 조사하는 것이 적절한가

**핵심 보고서의 연도를 더 늘리기보다, 349개 통계표와 직접 연결되는 통계 공표자료를 먼저 넓히는 것을 추천한다.** 기존 조사는 핵심 보고서 5종·31개 판본의 추출물 4,027건이다. 종합 보고서에는 시장·해외·미시자료와 자체 분석이 함께 들어가므로, 같은 보고서의 판본을 추가해도 만들 수 있는 유형이 크게 늘지 않을 수 있다.

이번 조사는 2023-10-01~2026-10-19를 대상으로 했다. [통계 보도자료](https://www.bok.or.kr/portal/singl/newsData/list.do?menuNo=201264), [기타 보도자료](https://www.bok.or.kr/portal/singl/newsData/list.do?menuNo=201265), [기업경영분석 간행물](https://www.bok.or.kr/portal/singl/newsData/list.do?menuNo=200455)의 목록을 확인하고 자료군별 연도 내 최신판 및 개편 자료를 선정했다. 반기·분기 보도자료는 등록 연도 기준이며, 기업경영분석 정기 책자는 별도로 선정했다. 따라서 2025년에 등록된 2024년 기업경영분석 책자도 포함된다.

|---|---|---|---|
| 1 | 통화·유동성, 금융기관 금리, 가계신용, 산업별 대출 공표자료 | 통화금융통계 117개 | 잔액·유량, 신규취급액·잔액, 주체·상품별 동향 |

| 2 | 국내 지급결제동향·전자지급서비스 이용현황 | 지급결제통계 15개 | 월·분기 제공값의 집계 정의와 보고서 일평균의 동등성 확인 |

위 14개 통계군의 표 수 합계는 349개다. 무역지수·교역조건은 카탈로그상 수출입물가 조사군에 포함된다. 표 수는 현재 메타데이터의 조사명 기준이며 발간물 수나 재현 가능한 그림 수가 아니다.

[산업연관표](https://www.bok.or.kr/portal/bbs/P0001588/view.do?menuNo=200457&nttId=10087143&programType=new)처럼 한국은행이 작성하는 통계도 현재 목록에서 대응 표를 찾지 못하면 별도 미지원 대상으로 둔다. 지역본부 자료·해외사무소 자료·학술논문까지 무제한 확장하는 것은 이번 목적에서 우선순위가 낮다.

다음 조사에서는 자료군마다 최신판, 연도별 대표판, 기준년·산업분류·작성체계 변경판을 먼저 본다. 그 밖의 판본은 목록과 목차에서 새로운 계열 조합·가공·표현 유형을 찾았을 때만 추가한다. 단순히 문서 수를 늘리는 것을 완료 기준으로 삼지 않는다.

## 2. 무엇을 재현 가능하다고 판단했는가

허용 데이터의 기준은 **KOSIS 기관코드 301의 현재 지원 통계표 349개**다. 한국은행 작성 통계의 기초자료까지 모두 한국은행이 직접 조사해야 한다는 뜻은 아니다. 반대로 한국은행 보고서가 다른 기관 수치를 인용했다는 이유만으로 그 계열을 허용하지 않는다.

| 구분 | 판단 기준 |
|---|---|
| 전체 재현 | 원본의 모든 계열·기간·분류·단위·가공 정의를 충족하고 수치를 대조한 경우 |
| 부분 활용 | 원본의 일부 계열 또는 축약 기간을 사용하거나 지수 수준·다른 주기 제공값 등을 활용한 응용형 |
| 불가능 | 원본에 필요한 계열·분류·계산 재료가 지원 범위에 없는 것으로 확인된 경우 |
| 확인 대기 | 출처·통계 정의·원본 위치·시계열 개정 등 근거가 부족한 경우 |

데이터의 가능성과 앱의 성공은 별개다. [재현매핑](재현매핑.csv)에는 통계표·항목·분류 코드와 원본 PDF 물리 페이지를, [질의집](질의집.md)에는 실제 성공한 입력과 실패한 변형을 기록했다. 기대 조회조건은 사람이 작성한 조사 대상을 메타데이터에 대조해 만들었으며, 에이전트가 선택한 결과를 그대로 정답으로 삼지 않았다.

기존 4,027건은 제목 기반으로 전체 선별했다. 770건에 어휘상 통계표 후보가 있었고, 3,257건은 제목만으로 매핑하지 못했다. **770건은 재현 가능 판정이나 내용 정답률이 아니다.** 상세 출처·단위·분류·원본 수치 대조가 남아 있으며, 원래 결과물ID로 기존 마스터와 연결한다. 출처 불명 항목을 자동으로 한국은행 자료로 승격하지 않았다.

이번 질의 대상은 원본에서 일부 계열·기간을 선택한 응용형이다. 원본 전체의 수치·디자인까지 검증한 사례는 0건이다. 자료 범위를 넓히는 것만으로 해외 비교·미시분포·모형 전망·스트레스테스트 그림을 만들 수 있게 되는 것은 아니다.

## 3. 실제로 만들 수 있는 산출물과 해석

실행 성공한 질의는 [질의집의 바로 사용하기](질의집.md#실행-확인-질의-바로-사용하기)에서 선택한다. 추천 입력은 그래프와 표 각각 조회·출력·XLSX 내보내기를 확인한 쌍이다. 통계표 ID를 붙인 변형이 오히려 잘못 해석되는 사례가 있어, ID를 추가한 문장을 무조건 더 안전한 질의로 추천하지 않는다.

| 업무 | 산출물 유형 | 주의할 의미 |
|---|---|---|
| 경기 판단 | ESI 원계열·순환변동치, CCSI, 현재생활형편·생활형편전망, 경기판단·경기전망, 제조업 CBSI | 서로 다른 지수와 실적·설문 전망 구분 |
| 물가 동향 | 생산자물가지수, 원화 수출·수입물가지수, 기대인플레이션 | 지수·등락률·설문 기대치 구분 |
| 금융 여건 | 신규 수신금리, 가계대출금리, 대기업·중소기업 대출금리, 잔액 총대출금리 | 연%와 %p, 신규취급액과 잔액 구분 |
| 대외 거래 | 경상수지, 상품·서비스수지, 본원·이전소득수지, 수출물량, 교역조건 | 달러 금액과 지수, 국제수지와 통관 수출입 구분 |
| 내수·투자 | 실질 계절조정 민간소비와 설비투자 | 실질 수준과 성장률·성장기여도 구분 |
| 부채·자금흐름 | 가계신용·가계대출·판매신용, 대외금융자산, 대외채무, 가계의 현금·예금 운용 | 잔액과 거래 유량 구분 |
| 기업 분석 | 제조업 매출액증가율, 전산업 매출액영업이익률 | 연간 책자와 분기 표본의 모집단·산업분류 구분 |
| 지급결제 | PG·선불전자지급수단 이용금액, 계좌이체 금액 | 월·분기 제공값의 집계 정의와 반기 일평균의 동등성 확인; 두 지급서비스 표 전 범위 갱신·정합성 대조 완료; [후속 결과](해결결과.md) 참조 |

예를 들어 원본 「국제수지 주요 통계 추이」에서 상품수지·서비스수지만 선택해 2023~2025년 월별 선그래프와 표를 만들 수 있다. 이 결과를 원본의 모든 패널을 재현한 것으로 설명하지 않는다. 해석은 조회 수치에서 확인되는 수준·전기 대비 변화 등에 한정한다.

기본 검증은 빠른 출력의 서버 관측 요약을 사용했다. 로그인한 담당자가 보는 별도 보고서 해석 초안은 검수된 원문 인덱스와 문장 근거 검증이 추가로 필요하다. 실제 보고서의 원인·전망 문장을 이번 그래프의 숫자만으로 재작성했다고 주장하지 않는다.

## 4. 한계와 구체적인 보완 순서

|---|---|---|---|
| P0 | 지표를 여러 개 요청했는데 일부만 선택하거나, 표 ID를 붙이면 다른 분류를 선택하는 경우 | 기존 요청 검증에서 요청 계열별 표·분류·측정 개념을 다시 대조하고, 누락·대체 시 확인 질문으로 중단 | 이번 실패 질의와 동명 분류 사례를 회귀 입력으로 사용; 모든 기대 계열 일치 확인 |

| P0 | PG·선불전자지급수단의 지정 시점에서 로컬과 KOSIS 값이 다름 | 갱신 시각·출처·조회조건을 표시하고 재조회 선택 제공; 기존 저장 분석은 사용한 자료 버전 보존 | 같은 계열·단위·시점의 차이 원인을 확인하고 갱신 전후 표본 대조 |
| P1 | 제목·통계 작성기관만으로 같은 계열이라고 판단할 수 없음 | 보고서 계열과 표·항목·분류·단위·계절조정·명목/실질·산업분류를 잇는 검수 매핑 유지 | 원본 표본과 코드별 수치·각주 대조 |

| P2 | 관측값만으로 경제적 원인·전망을 확정할 수 없음 | 검수된 보고서 발췌의 페이지·발간일·분석 기간·근거 ID를 연결하고 담당자 검토 유지 | 문장별 원문 함의와 시점 누수 검수; 검수 전 자동 승인 금지 |

현재 앱에는 증감·증가율 표 열, 전년 대비 변환, 혼합 차트, 표 양식·내보내기, 원문 근거 기반 해석 경로가 이미 있다. 따라서 이를 전부 신규 기능으로 재개발하는 대신, 위 실제 실패와 통계 정의 차이를 먼저 해결한다. 초기 조사는 앱을 변경하지 않았으며, 후속 해결 작업에서는 실행 근거의 자료 버전 표시와 안전한 갱신 도구를 추가했다. 금리·가계신용 표 전체 셀 대조 결과와 ESI의 공표시점 제약은 [해결 결과](해결결과.md)를 따른다.

현재 349개 표로 부족한 해외·국내 기관 계열은 별도의 데이터 확장 과제다. 한국은행 통계의 추가 범위는 ECOS 연계를, 다른 기관 계열은 해당 기관의 공식 공급원을 검토하되, 이번 KOSIS 전용 질의집에 섞지 않는다. Bloomberg·미시자료·자체 추정·모형 결과가 필요한 원본은 별도로 표시하고 대체 수치를 생성하지 않는다.

## 5. 적합한 skill

| Skill | 추천 정도 | 이 작업에서의 용도 |
|---|---|---|
| `superpowers:brainstorming`, `writing-plans` | 권장 | 조사 목적·재현 기준·검증 범위를 먼저 확정 |
| `ponytail` | 권장 | 기존 수집기·메타데이터·API·렌더러를 재사용하고 앱 개발 범위를 늘리지 않음 |
| `verification-before-completion` | 필수적인 운영 방식 | 실행된 증거와 미실행을 구분하고 성공 주장 대조 |
| `systematic-debugging` | 실패 조사 때 권장 | 지표 누락·기간 파싱·자료 버전 차이의 원인 분리 |
| `requesting-code-review` | 검증 스크립트 작성 때 권장 | 기대 조건과 성공 판정 자체의 오류 검토 |
| `graphify` | 선택 | 발간물→그림/표→계열→통계표의 관계 탐색·추가 조사 후보 탐색 |
| `archify` | 선택 | 수집·매핑·검증 작업 흐름이나 출처 관계를 설명하는 다이어그램 |

[Graphify 공식 저장소](https://github.com/Graphify-Labs/graphify)는 코드·문서·PDF 등의 관계를 질의 가능한 그래프로 만드는 기능을 설명한다. 이 관계를 통계적 동일성이나 수치 검증의 근거로 승격하지 않는다. 이번에는 CSV·JSONL 매핑으로 진행했으며 Graphify 추가 설치나 프로젝트 전체 인덱싱을 하지 않았다. `archify`도 통계 시계열 그래프를 대신 그리는 도구가 아니다. 실제 수치 그래프에는 현재 프로젝트의 Plotly 출력을 사용한다.

`ouroboros`는 후속 기능 개발 범위를 별도 명세로 확정해 실행할 때 검토할 수 있다. 현재의 조사·질의집 작업에 자동 개발 루프를 추가할 필요는 없다.
