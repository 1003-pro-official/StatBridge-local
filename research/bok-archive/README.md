# 한국은행 핵심 법정 보고서 아카이브 (3년치)

`research/bok_download.py`로 한국은행 홈페이지에서 내려받은 원본 첨부파일 모음입니다.

- 수집일: 2026-10-01
- 기간: 최근 3년 (2023-10-01 이후 등록분)
- 대상: 핵심 법정 보고서 5종
  - `01-통화신용정책보고서` (연 4회)
  - `02-금융안정보고서` (연 2회)
  - `03-경제전망보고서` (연 4회)
  - `04-지급결제보고서` (연 1회)
  - `05-연차보고서` (연 1회)
- 규모: 264개 파일, 약 791MB (manifest 기준 첨부 링크 336건)

## 구조

```
bok-archive/
  <게시판>/<등록일>_<제목>/<첨부파일...>
  manifest.csv
```

`manifest.csv` 컬럼: 게시판, 제목, 등록일, 담당부서, 파일명, 파일URL, 저장경로, 바이트, 게시물URL
(첨부 링크 1건당 1행. 동일 파일을 가리키는 중복 링크도 포함)

## 출처·주의

- 출처: 한국은행 홈페이지 (bok.or.kr) 공개 자료. 저작권은 한국은행에 있습니다.
- 첨부파일에는 보고서 본문 PDF, 섹션별 PDF, 영문 Executive Summary, 그림 원본 데이터 `.xlsx`가 포함됩니다.
- 게시판에 따라 "파일이 존재하지 않습니다" 오류 응답은 자동 제외됩니다.

## 범위 확장

`bok_download.py`의 `BOARDS` 목록에 (라벨, menuNo)를 추가하면 다른 간행물도 받을 수 있습니다.
간행물 게시판은 `depth=200699`(간행물), 조사연구는 `201156`, 지역연구자료는 `201042`,
국외사무소자료는 `200080`을 부모 depth로 사용합니다.
