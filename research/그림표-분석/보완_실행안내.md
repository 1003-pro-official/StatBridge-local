# 기존 산출물 보완 실행

## 기본 실행

프로젝트 루트에서 `python research/그림표-분석/extract.py`를 실행합니다. 원본 백업·아카이브의 해시를 확인하고 로컬 문맥과 저장된 Codex 판단으로 결과를 재생합니다. API 키와 네트워크가 필요하지 않습니다.

- 특정 판본: `python research/그림표-분석/extract.py --report "통화신용정책보고서 2026년 3월"`
- 요청된 멱등·회귀 검증: `python research/그림표-분석/verify_enrichment.py`

## 보존해야 하는 입력

- `research/bok-archive/`: 원본 PDF·XLSX와 manifest.
- `백업/보완전_20261002/`: 보완 전 산출물과 해시 목록.
- `보완캐시/contexts.json`, PDF 색인, 표 구조: 원문 위치와 직접 번호 인용.
- `보완캐시/assistant_group_inputs.json`, `assistant_judgments/*.json`: 직접 읽은 제목·계열 입력과 목적·태그 판단.
- `보완캐시/assistant_vision_judgments.json`, `review_sheets/`, `vision_crops/`: PDF 영역별 시각 판단과 입력 이미지.
- `보완캐시/state.json`: 입력 해시와 백업 경로.

기본 재실행은 저장된 판단을 적용합니다. 모델을 새로 호출하거나 결과를 다시 작성하는 실행과 구분합니다. 새 원본이 들어오면 기존 판단의 문맥 해시가 달라질 수 있으므로 재검토가 필요합니다.

## 검수

`내용_검수대상.csv`에서 번호·종류·목적 미확인 항목과 원본 PDF 위치를 먼저 확인합니다. `PDF_페이지_검수.csv`에는 기존 문제 페이지와 추가 표 구조 검수 대상이 있습니다.

`검수대장.csv`의 `확정값`, `수정이유`를 작성하고 `검수상태`를 `확정`으로 바꾸면 재실행 때 반영됩니다. 자동값과 신뢰도는 골든셋 정답을 뜻하지 않습니다. 보존 대상으로 지정된 기존 출처·단위·데이터 형태의 수정은 회귀 검사에서 중단되므로 원문 근거를 확인하고 보존 규칙도 명시적으로 수정해야 합니다.

모듈은 `enrichment/rules.py`(규칙), `assistant.py`(현재 대화 직접 판단 캐시), `model.py`(선택적 외부 텍스트 호출), `vision.py`(렌더링·선택적 외부 비전 호출), `pipeline.py`(병합·출력)로 분리되어 있습니다. 이번 보완에는 외부 API 호출을 사용하지 않았습니다.
