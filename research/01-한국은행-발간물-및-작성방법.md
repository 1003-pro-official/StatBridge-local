# 한국은행 발간물 및 작성·분석 방법

- 주제: 한국은행이 발간하는 보고서·자료의 전체 목록과, 그 산출물을 작성·분석하는 방식
- 1차 출처: 한국은행 홈페이지(간행물·조사연구 메뉴, 각 보고서 상세페이지의 첨부파일 구성), ECOS 경제통계 개요, BOK 경제연구 논문목록, 한은 금요강좌 해설
- 수집일: 2026-10-01
- 성격: 공개 자료 기반 정리. 내부 전산·결재·모델 코드는 비공개이므로, 해당 부분은 **추정**으로 명시

> 이 문서는 한국은행 공개 자료에서 **확인되는 사실**과 **합리적 추정**을 구분해 정리한 참고자료입니다. 공식 견해가 아니며, 중요한 의사결정 전에는 한국은행 원문을 확인하십시오.

## 1. 발간물 전체 지도

한국은행 홈페이지의 「뉴스/자료 > 간행물·조사연구」 메뉴를 기준으로 정리한 분류입니다.

### 1.1 법정·정기 핵심 보고서

| 발간물 | 주기 | 근거·제출처 | 실제 목차 구성 |
|---|---|---|---|
| **통화신용정책보고서** | 연 4회 (3·6·9·12월) | 한국은행법 제96조①, 금융통화위원회 심의 후 **국회 제출** | 개요 → Ⅰ.통화신용정책 운영여건(세계경제·실물경제·물가·금융외환) → Ⅱ.운영 및 향후방향 → 참고 BOX |
| **금융안정보고서(FSR)** | 연 2회 (6·12월) | 한국은행법 제96조① | 개관·종합평가 → Ⅰ.금융안정 상황(가계·기업 신용 / 금융·자산시장 / 금융기관 / 대외부문 / 금융제도·정책) → Ⅱ.주요 현안 분석 → Ⅲ.심층 이슈 → 부록·용어해설 |
| **경제전망보고서 (Indigo Book)** | 연 4회 (2·5·8·11월) | 조사국·경제모형실 | Ⅰ.국내외 여건 및 전망(주요 여건 → 거시경제 전망 → 리스크 평가·시나리오) → Ⅱ.핵심이슈 → Ⅲ.중장기 심층연구 → 부록 |
| **지급결제보고서** | 연 1회 (4월) | 지급결제제도 운영·관리규정 제44조, 금융통화위원회 제출 | 개관 → Ⅰ.지급결제 환경 변화 → Ⅱ.정책대응 및 감시 → Ⅲ.동향 및 결제리스크 관리 → Ⅳ.향후 정책방향 → 부록·참고 |
| **연차보고서** | 연 1회 | 법정 결산·업무 총괄 성격 | 연중 통화정책·업무 전반 |

- **통화신용정책보고서**: 법은 연 2회 이상을 요구하나, 한국은행은 연 4회 작성해 국회에 제출.
- **경제전망보고서**: 소규모 개방경제 특성상 **조건부 전망**(주요 대외여건을 전제로 한 전망)으로 작성. 시장 전망분포·시나리오 분석과 다수의 BOX로 구성.
- **금융안정보고서**: 별도로 「금융안정 상황」 보고서(3·9월경)도 발간.

### 1.2 통계 간행물·자료

- **5대 국민경제통계**: 국민소득, 산업연관표, 자금순환표, 국제수지표, 국민대차대조표
- 정기 간행물: **국민계정**, **국민계정리뷰**, **기업경영분석**, **산업연관표**, **지역경제통계**, **단기금융시장 리뷰**
- **발간중지 간행물**: 조사통계월보, 해외경제 포커스
- 통계 공표는 IMF SDDS의 최상위 단계인 **확정일자 방식**으로 다음 연도 일정을 매년 12월 예고

### 1.3 조사연구물

- **BOK 이슈노트**(수시), **경제분석**(학술지), **BOK 경제연구**(working paper), **BOK 경제연구 INSIGHT**
- **국제경제이슈**, **금융안정 조사연구**, **지급결제 조사연구**, **통계연구**, **북한경제자료**

### 1.4 지역·국외 자료

- 지역: **지역경제보고서**, **주력산업 모니터링 보고서**, 지역경제동향·일지·통계, 조사연구자료
- 국외: 뉴욕·워싱턴·프랑크푸르트·동경·런던·북경·홍콩·상해 사무소 자료

### 1.5 단행본 및 부수 산출물

- **단행본**: 한국의 통화정책 / 한국의 금융시장 / 한국의 금융제도 / 한국의 거시건전성정책, 알기 쉬운 경제지표해설, 우리나라의 국민계정 등
- **부수 산출물**: 보도자료, 금융통화위원회 의사록·의결사항, 총재·금통위원 연설문, **영상보고서(자막)·카드뉴스**

## 2. 작성·분석 방법

### 2.1 산출물 파일 구성 (공개 첨부파일에서 확인)

정기 보고서는 거의 동일한 패턴으로 배포됩니다.

- **최종본 PDF**
- **그림 원본 데이터 `.xlsx`** (보고서에 실린 그림의 수치 데이터)
- **영문 Executive Summary** (FSR 등)
- **개관/요약을 본문과 분리**해 별도 PDF로 배포
- **부문별 담당자.pdf** (섹션별 집필 부서·연락처 명시)
- 보도자료는 `.hwpx`(한글) 또는 `.docx`(MS Word) + `.pdf`로 함께 배포 → **한컴오피스와 MS Word 혼용** 확인됨

### 2.2 집필·검증 프로세스

1. 담당 부서별 원고 작성 (부서는 3.1 참고)
2. **개요/한눈에 보기**를 먼저 확정 → 본문·BOX·부록 정합성 확보
3. 법정 보고서는 **금융통화위원회 심의** 후 **국회 제출**
4. 발간 시 **기자설명회** 개최 + **영상보고서·카드뉴스**로 멀티채널 배포

### 2.3 데이터 출처

- **ECOS(경제통계시스템)**: 한국은행 작성 통계 + 국내외 700여 기관 통계 서비스
- 법적 근거: 한국은행법 제86조(통계자료의 수집·작성), 통계법(승인통계, 자료제출 요구, 비밀 보호)
- 미시데이터: **가계금융·복지조사**(한은·국가데이터처·금감원 공동), **기업경영분석**(기업 재무제표)
- 심리지표: 기업경기조사(BSI), 소비자동향조사(CSI), 경제심리지수(ESI)
- 시장·해외 데이터: 시장금리·환율·유가 및 국제기관 데이터

### 2.4 분석 모형 (BOK 경제연구·공개 논문에서 확인)

- **거시계량경제모형**: BOK97, BOK04 등 연립방정식 체계
- **DSGE**: BOKDSGE 등 동태적 최적화 기반 모형
- **BVAR / VAR-GARCH**: 베이지안 VAR 경제전망, 변동성 분석
- **CGE**: 간접세 인하 등 정책 모의분석
- **Nowcasting**: 동적요인모형 + 딥러닝 결합(GDP 당분기 전망)
- **스트레스테스트·금융안정 분석**: 신용·유동성·대외부문 리스크 평가
- 전담 조직: **조사국 경제모형실**(Office of Economic Modeling and Policy Analysis)

### 2.5 사용 도구 (확인 / 추정 구분)

| 구분 | 도구 | 근거 |
|---|---|---|
| **확인** | 한컴오피스(한글·한셀) | 보도자료 `.hwp` / `.hwpx` 배포 |
| **확인** | MS Word | 일부 보도자료 `.docx` 배포 |
| **확인** | Excel | 그림 원본 데이터 `.xlsx` 배포 |
| **확인** | PDF | 최종 보고서 배포 형식 |
| **확인** | R / Python | ECOS OpenAPI 연계(CRAN `ecos` 패키지, PublicDataReader 등) |
| **추정** | EViews, Stata, MATLAB 등 계량 소프트웨어 | 중앙은행 관행 기반 추정, 내부 확인 불가 |
| **추정** | LaTeX | 학술성 연구보고서 일부 사용 추정 |

> 내부 전산·결재·편집 시스템과 실제 모델 운영 코드는 비공개이므로 확인 불가합니다.
