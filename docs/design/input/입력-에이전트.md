## 자연어 질의 입력 단계의 에이전트

이 단계에서 에이전트의 역할은 **사용자가 알고 싶은 내용을 편하게 표현하도록 돕는 것**입니다. 통계 용어를 몰라도 일상적인 문장으로 질문을 시작할 수 있어야 합니다.

여기서는 질의를 해석하거나 통계표를 고르지 않습니다. 사용자가 입력한 문장을 보존해 다음 단계인 `질의 해석 · Query Planning`에 전달하는 데 초점을 둡니다.

### 사용자와 에이전트의 진행 흐름

```
질의 입력 화면 표시
    ↓
사용자가 질문 작성
    ├─ 필요하면 예시나 입력 도움말 참고
    └─ 자유롭게 문장 작성
    ↓
사용자가 제출
    ↓
입력 원문을 보존해 질의 해석 단계로 전달
```

### 단계별 에이전트 행동

| 순간 | 에이전트 행동 | 구체적인 예 |
| --- | --- | --- |
| 입력 화면 진입 | 통계 용어를 몰라도 질문할 수 있음을 안내 | “평소 쓰는 표현으로 질문해도 됩니다.” |
| 입력 전 | 질문 예시를 보여줌 | “최근 5년 기준금리 추이를 보여줘”, “기준금리와 대출금리를 비교해줘” |
| 사용자가 작성 중 | 사용자가 도움을 요청하면 질문을 구체화할 선택 항목을 안내 | “기간이나 비교 대상을 추가하면 원하는 자료를 찾는 데 도움이 됩니다.” |
| 사용자가 짧거나 모호한 문장 제출 | 문장을 거절하거나 입력 단계에서 연속 질문을 하지 않고 그대로 접수 | “금리 알려줘”도 제출 가능 |
| 제출 직후 | 원문을 보존해 질의 해석 단계에 전달 | 질의 해석 단계에서 지표·기간·모호성을 분석 |

예시나 도움말은 작성 부담을 줄이기 위한 선택적 지원입니다. 사용자가 도움 없이 바로 질문할 수도 있어야 합니다.

### 입력 화면 구성

입력 화면에는 다음 요소가 적절합니다.

| 요소 | 목적 | 예시 |
| --- | --- | --- |
| 자유 입력창 | 원하는 내용을 제한 없이 입력 | “중소기업 대출 연체율이 최근 어떻게 변했어?” |
| 안내 문구 | 일상적인 표현도 허용됨을 알림 | “정확한 통계 용어를 몰라도 괜찮습니다.” |
| 예시 질의 | 요청을 어떻게 작성할지 참고 제공 | “최근 5년 기준금리와 M2 추이를 비교해줘” |
| 선택형 작성 도움 | 사용자가 원할 때 빠진 정보를 덧붙일 수 있도록 지원 | 기간, 비교 대상, 표/그래프 |
| 제출 버튼 | 작성한 질의를 해석 단계로 전달 | “질문하기” |

선택형 도움은 질의에 필수 조건을 강제로 요구하지 않습니다. 기간을 모르면 비워둔 채 제출할 수 있고, 비교 대상을 모르면 지표 하나만 입력해도 됩니다.

### 입력 단계의 범위

**에이전트가 하는 일**

- 자연어 입력을 허용하고 작성 예시를 제공
- 사용자가 요청할 때 질의를 구체화하는 데 도움
- 입력된 원문을 변형 없이 보존
- 질의를 제출하면 대화 맥락과 함께 다음 단계로 전달

**이 단계의 산출물**

```
{
  "original_query": "최근 금리 알려줘",
  "conversation_context": [],
  "submitted_at": "timestamp",
  "input_status": "submitted"
}
```

`original_query`는 사용자가 입력한 그대로 유지합니다. 정리된 지표 후보나 누락 조건, 확인 질문은 아직 이 단계의 산출물에 넣지 않습니다. 그것들은 다음 단계인 질의 해석에서 생성합니다.

### 입력 단계의 완료 조건

사용자가 질문을 제출하면 입력 단계는 완료됩니다. 예를 들어 “금리 알려줘”처럼 정보가 적더라도 제출할 수 있으며, 그 문장이 어떤 의미인지 확인할지는 다음 단계에서 판단합니다.

이렇게 하면 입력 단계의 경계가 분명해집니다. **입력 단계는 질문 작성을 돕고 원문을 전달하며, 제출된 질문의 의미와 조건을 분석하는 일은 질의 해석 단계에서 시작합니다.**
