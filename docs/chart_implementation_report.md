# 고급 통계 그래프 구현 결과

2026-10-12, ai-assisted. 적용 폴더: StatBridge-local1. 인접 StatBridge1은 수정하지 않았다. 기존 미커밋 지표 의미 검증·스티커 작업은 보존했으며 이 보고서는 이번 고급 그래프 확장을 설명한다.

## 구현 내용

제공된 경제전망·지급결제·통화신용정책·금융안정·지역경제 PDF의 실제 페이지를 읽고 12개 전문 템플릿을 구성했다. 흰 배경, 절제된 색, 단위·출처·각주, 다중 패널, 이중 축, 실제 제공된 구간의 음영을 적용한다. 한국은행 공식 제작물로 표시하지 않는다. 상세 출처와 직접 확인한 페이지는 `chart_templates.md`에 기록했다.

1. `advanced_chart_spec.py`: 16종 이름을 예약한 엄격한 ReportOptions, 12개 템플릿, 데이터 기반 추천, 의미·단위·구간 검사.
2. `advanced_chart_render.py`: 필수 8종과 추가 5종의 Plotly 출력, ECharts SVG 미리보기 옵션. 렌더러가 지원하지 않는 기능은 이유를 알린다.
3. `report_export.py`: 버전 명세 `statbridge.report/1`, 기존 명세 마이그레이션, 데이터 fingerprint 검증 복원, PNG/SVG/PDF 출력, 한글 폰트·이미지 유지.
4. `output_schema.py`, `research_chart_editing.py`, `output_agent.py`: `set_report` 명령, 기존 수정 상태와 Undo/Redo 연결, 일반 그래프 복원. 기본 출력·조회 흐름은 유지한다.
5. `chart_edit_agent.py`: HCX-007에 새 스키마·템플릿과 값 생성 금지 조건을 전달한다. 독립 파일 출력 요청은 클라이언트의 고정 경로로 처리한다.
6. `bridge_api.py`: `/api/report/templates`, `/recommend`, `/export`, 기존 편집 라우트의 직접 설정·명세 복원. 버전 충돌과 잘못된 명세는 적용하지 않는다.
7. `ReportPanel.tsx`, `ReportPreview.tsx`, CSS: 수정이 안의 템플릿·색·선·제목·폰트·범례·축·시계열 표시·출처·각주·해상도 설정, 저장·복원·미리보기.
8. `chart_data_transforms.py`: 실제 달력 주기에 따른 전년 대비 계산. 누락 관측과 0 분모를 조용히 잘못 계산하지 않는다.
9. 패키지/실행 CMD: Matplotlib, pypdf, ECharts 의존성과 기존 설치 상태 확인을 추가했다.
10. 공개 테스트·예시·벤치마크 스크립트와 설계·명세·템플릿·편집·검증·마이그레이션·결과 문서 7개를 추가했다.

## 검증

최종 기간 키와 혼합 주기 패널 수정 후 전체 테스트 728개와 하위 검사 355개가 305.96초에 통과했다. 고급 보고서 전용 테스트 21개(전체 실행에 포함)와 프론트 테스트 6개, 공개 v4.1 구조 validator, production build도 성공했다.

실제 KOSIS DT_181Y011의 분기 관측 24개를 조회해 보고서 명세와 PNG/SVG/PDF를 만들었다. 브라우저는 합성 QA 자료와 실제 편집·출력 API로 템플릿 적용, 재열기, 분기 라벨, ECharts SVG, PDF 다운로드와 “두 열의 다중 패널로 바꿔줘” 자연어 적용을 확인했다. 합성 자료를 실제 조회 결과로 제시하지 않는다. 12쪽 템플릿 PDF는 출력 후 PNG 렌더링으로 배치를 확인했다.

## 남은 범위와 사용 조건

- 점도표·수익률 곡선·금융 네트워크의 전용 데이터 어댑터는 구현하지 않았다. 선택 화면에서도 준비 중으로 표시한다.
- 전망 모형과 신뢰구간 추정은 제공하지 않는다. 표시 시작 기간과 실제 공급된 수치·구간만 사용한다.
- 사용자 데이터베이스의 영구 저장과 새로운 CSV 업로드 UI는 추가하지 않았다. 기존 조회 세션 및 명세 파일의 저장·복원을 사용한다. 서버 재시작 뒤에는 동일 원자료를 다시 조회해야 복원할 수 있다.
- 여러 종류 편집과 파일 출력을 하나의 자유문장으로 동시에 처리하는 흐름은 아직 지원하지 않는다. 편집 완료 후 별도 출력 요청을 사용한다.
- 모든 글꼴과 모든 기존 스타일의 세 렌더러 간 픽셀 일치, 모든 브라우저·기기 검증을 완료한 것은 아니다. 미지원 인쇄 스타일은 오류로 보존한다.
- 20,000관측의 구성에 25.417초가 측정되어 대규모 실시간 성능 최적화는 남아 있다. 수치 재현·성능·외부 제공자 검증의 한계는 `chart_quality_validation.md`를 따른다.

새 기능은 조회 결과에서 수정이를 열고 **보고서 차트 · 인쇄 설정**을 펼쳐 사용한다. 필수 메타데이터를 제공한 뒤 설정을 적용하고 PNG/SVG/PDF/JSON을 저장한다. 기존 스티커와 그림판은 기존 경로로 계속 사용한다. 잘못된 요청은 기존 결과를 유지한다.
