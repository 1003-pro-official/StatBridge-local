StatBridge의 공개 개발용 기자 질의 v2.1 골든셋을 이용해 질의 상태 판정, 통계표·계열 선택, 실제 KOSIS 조회, 후속 대화 맥락, 운영 지표와 답변 품질을 나누어 평가했다. 사용자가 검토·승인한 200문항 골든셋의 SHA-256은 `b350188a76ba1e31739b8cc56b8512b84f90f479380e86fcbf04d181ccc32563`이다. 결과를 한 개의 종합 정확도로 합치지 않고 측정 경로와 분모를 함께 기록한다.

### 후속 대화 맥락

사용자가 승인한 보충 대화 30건(기간 변경 10건, 조건 추가·변경 10건, 비교·정정 10건)을 `execute=false`로 평가했다. 최종 계획은 30/30건에서 기대 조건과 완전히 일치했고, 명시 조건 161/161개(100%)를 보존했다. 핵심 조건 누락은 0건으로 후속 맥락 관문을 통과했다. 이 결과는 계획 상태 보존을 확인한 것으로, 후속 대화에서의 실제 KOSIS 수치 조회·HTTP·인증은 측정하지 않았다.

## 정성 평가

### 검수 결과

저장된 실제 API 응답 표본 30건을 사용해 승인 골드와 대조했다. 표본은 `resolved` 13건, `no_match` 10건, `need_clarification` 7건으로 구성하고 역질문 사례 7건을 모두 포함했다. 점수는 각 항목 5점 만점이다.


| 검수 항목       | 평균     | 관찰                                            |
| ----------- | ------: | --------------------------------------------- |
| 질의 의도 충실도   | 5.00/5 | 평가 표본에서 요청 의도와 처리 방향이 일치했다.                   |
| 통계표·계열 적합성  | 4.77/5 | 표본의 조회 결과는 승인 골드의 표·계열·조건과 부합했다.              |
| 불확실성·역질문 처리 | 4.67/5 | 모호한 요청에는 선택지를 제시하고, 미지원 요청은 조회하지 않았다.         |
| 답변 명료성      | 4.60/5 | 전체 평균은 기준 이상이지만 일부 미지원 안내에서 다음 행동이 구체적이지 않았다. |


심각한 1점 평가는 없었다. 다만 이 결과는 AI 단독 1차 검수이므로 사용자 피드백이나 2인 독립 정성 검수의 대체 자료가 아니다. 사용자는 2인 검수를 추후 진행하기로 했다.

### 개선점과 회고

- **미지원 안내를 구체화한다.** 신용등급별 부도율과 역외 원화결제시스템 일정 요청은 지원하지 않는 이유와 다음 단계 안내가 포괄적이어서 명료성 3점을 받았다. 지원 범위를 명확히 설명하고, 실제로 존재하는 대체 통계나 공식 출처가 확인되는 경우에만 이를 안내할 필요가 있다.
- **후보 검색과 최종 선택을 분리해 개선한다.** 오프라인 Recall@5가 52.9%여서 규칙 검색만으로는 정답 후보를 충분히 회수하지 못하는 사례가 있다. 검색 계층 진단과 전체 API의 표·계열 선택 결과를 별도로 추적해야 한다.
- **평가 근거를 계속 보존한다.** 점수에는 골든셋 버전, 데이터 스냅샷, 실행 범위와 분모를 함께 기록한다. 서로 다른 골드·채점 정책의 과거 수치를 최신 결과와 합산하지 않는다.
- **릴리스 판정은 보류한다.** 기본 탐색·값 비교와 후속 계획 보존은 기준을 통과했지만, 요청 비용 비교 근거와 2인 독립 검수가 없다. 실제 조회 지연시간은 DNS 장애로 중단된 초기 시도와 이후 완료된 전체 실행을 구분해 해석해야 한다.

따라서 본 평가는 공개 v2.1 개발용 골든셋 기준의 회귀·진단 성과를 보여 주지만, 실제 사용자 만족도나 최대 처리 용량, 비용 효율, 전체 릴리스 적합성을 입증하지 않는다. 종합 릴리스 판정은 **보류**한다.
