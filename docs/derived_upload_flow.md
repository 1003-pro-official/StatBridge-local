# 파생지표 자료 보완과 호출 절감 (ai-assisted)

## 사용자 흐름

1. 만들고 싶은 지표·기간·그래프를 자연어로 요청합니다.
2. 원자료 확인 결과에서 예정 계산법, 필요한 입력, API 확보·미확보, 입수처를 확인합니다.
3. 미확보 자료가 있으면 상단 **파일 업로드 공간 열기** 또는 하단 **부족 자료 파일 연결하기**를 누릅니다.
4. 자료별 CSV·JSON·TSV·XLSX 파일을 연결합니다. 파일 선택, 드래그, 텍스트 붙여넣기를 지원합니다.
5. 두 기간 비교라면 기간 기준, 파일의 실제 호가 방향, 가로축 이름, 평균 대상을 저장합니다.
6. **파생지표 계산하기**를 누르면 검증된 계산 트리로 그래프와 표를 생성합니다. 계산 근거에서 적용 산식·관측값·파일 출처·해시를 확인합니다.

계산 조건 질문은 정상 안내입니다. 실제 미확보 입력이 없는 경우 빈 업로드 화면을 열지 않습니다. 업로드 작업은 계정별로 저장하고, 앱을 다시 열면 **자료 연결 이어가기**에서 복원합니다. 기존 계정·보관 분석을 덮어쓰지 않습니다.

## 파일 계약과 계산법

파일 하나는 시계열 하나입니다. 필드는 `period,value,unit,frequency,source`입니다. 일별 시점은 `YYYYMMDD`, 주기는 `D`이며 최대 2MB·6,000행입니다. JSON은 객체 배열, XLSX는 동일한 첫 행을 가진 단일 시트입니다. 수식·매크로·외부 링크는 실행하지 않습니다. 빈 값, 중복 날짜, 잘못된 주기·단위는 거부합니다.

두 기간의 국가별 비교는 현재 일별 파일을 사용합니다. 특정일 비교는 해당 날짜의 관측값이 필요합니다. 월평균 기준은 시작 월과 종료 월의 제공기관 관측값 전체를 넣고 각각 평균한 후 변화율을 계산합니다. 휴일을 채우지 않습니다. 서버가 제공기관의 휴일 달력이나 부분 파일의 완전성을 보증하지 않으므로 원자료와 대조하고 확인해야 합니다. 월별 파일만으로 일별 비교를 해결할 수 있다고 안내하지 않습니다.

- 직접 변화율: `(종료값 / 시작값 - 1) * 100`
- 역방향 변화율: `(시작값 / 종료값 - 1) * 100`
- 원자료가 자국통화/USD이면 역방향, USD/자국통화이면 직접 변화율을 적용해 달러 대비 통화가치 상승을 양수로 통일합니다. 여기서 `/`는 관측 단위이며 금융상품 티커가 아닙니다.
- DXY는 원지수의 직접 변화율입니다. 선물이나 무역가중지수로 대체하지 않습니다.
- 평균선은 사용자가 선택한 대상의 변화율 산술평균입니다. 선택한 노드와 계산값을 근거에 저장합니다.

`period_change`는 구조화된 허용 연산입니다. 입력 하나, 2~4개 기간, 날짜·평균 기준·방향만 허용하며 Python 코드나 임의 수식을 실행하지 않습니다. GPT가 만든 DAG는 계정 소유 파일 ID, 원래 기간, 입력 순서, 방향, 평균 구성과 독립 대조합니다. 기존 깊이·관측 수·작업량·메모리 제한도 적용합니다. 그래프·표는 기존 OutputAgent/ChartSpec을 사용합니다.

## GPT 호출 정책

| 단계 | 최초 요청 | 동일 조건 반복 |
|---|---:|---:|
| 실제 메타데이터에 근거한 미확보 안내 | 1회 | 캐시 적중 시 0회 |
| 파일 연결·형식 검증·설정 저장 | 0회 | 0회 |
| 기간 비교 DAG 설계와 의미 검토 | 2회 | 검증 계획 적중 시 0회 |
| 수치 계산·기본 그래프/표 출력 | 0회 | 0회 |

미확보 안내 캐시는 정확히 같은 질문·실제 API 스냅샷 SHA에 묶고 최대 24시간·32개로 제한합니다. 관측값 확보 결과, 모델/API 장애, 미확인 후보는 이 캐시에 저장하지 않습니다. API 스냅샷 자체의 유효성 확인을 먼저 수행합니다.

계획 캐시는 해당 계정의 작업 안에서만 사용합니다. 질문·설정·파일 SHA·실제 단위·주기·카탈로그 버전이 모두 일치해야 하며, 재사용 때도 구조·출처·설정·수치 검증은 다시 합니다. 파일이나 설정이 바뀌면 최초 의미 검토까지 다시 수행합니다. 모델 응답 실패를 성공 계획으로 캐시하지 않습니다.

입력 검증과 미확보 확인을 마친 기간 비교는 같은 통계표를 반복 검색하지 않습니다. 계획·검토에 필요한 ID·단위·검증된 계약만 전달하며 실제 관측값을 모델에 보내지 않습니다. 호출별 토큰과 단계·시간, 계획 캐시 적중을 계산 근거에 기록합니다. 일반 조회와 기존 단일 시계열 계산 경로는 유지합니다.

## 출처 제한

자동 API 호출은 승인된 349개 한국은행 KOSIS 표에 제한합니다. 외부 기관 링크는 사용자가 자료를 입수하는 안내이며 자동 허용 출처 확장이 아닙니다. 사용자 파일은 별도 출처로 표시합니다. 업로드 파일이 실제 제공기관에서 내려받은 정확한 원본인지 서버가 인증한 것으로 표현하지 않습니다.
