## 기업 및 프로젝트 소개

### 1. 기업명

클라비

(원문 첨부 이미지: 기업 로고)

### 2. 기업 소개

생성형 AI 및 클라우드 전문기업으로, 생성형 AI 솔루션, AI Agent, AI SaaS 서비스를 기반으로 공공·산업 전반의 데이터 기반 업무 혁신과 디지털 전환을 지원하고 있습니다.
또한, NCP를 비롯한 멀티·하이브리드 클라우드 환경에 대한 통합 MSP 서비스를 제공합니다.

## 제공 리소스

프로젝트 수행을 위해 아래와 같은 리소스를 제공합니다.

### 1. AI 모델

생성형 AI를 활용한 프로젝트를 원활하게 수행할 수 있도록 NCP AI Service API Key를 제공합니다.

제공 모델

- HCX-DASH-001
- HCX-DASH-002
- HCX-003
- HCX-005
- HCX-007
- Re-ranking Model
- RAG Reasoning Model
- Embedding Model v1
- Embedding Model v2

> ※ 위 모델(HCX 등)은 클라비에서 제공하는 리소스이며, 프로젝트 진행 중 특정 기능 구현에 더 적합하다고 판단되는 경우 Claude API 등 다른 LLM을 자유롭게 선택·병행하여 사용하실 수 있습니다. 다만 제공 모델 외 사용에 따른 비용 및 API Key 발급·관리는 팀에서 자체적으로 진행해야 합니다.

### 2. 데이터 및 연계 리소스

프로젝트별 제공되는 데이터와 연계 리소스가 다르며, 자세한 내용은 각 프로젝트 소개 페이지를 참고하시기 바랍니다.

## 활용 시 주의사항

### 1. API Key 및 인증 정보 관리

프로젝트 수행을 위해 제공되는 API Key(HCX 등) 및 관련 인증 정보는 프로젝트 수행 목적으로만 사용해야 합니다. 다음과 같은 행위는 금지됩니다.

- 외부 공유
- 공개 저장소(GitHub 등) 업로드
- 제3자 제공
- 프로젝트 목적 외 활용

### 2. 데이터 활용

프로젝트에서 활용하는 공개 데이터 및 제공되는 데이터셋

데이터 자체에 대한 별도의 보안 제약은 없으며, 프로젝트 목적에 맞게 자유롭게 활용할 수 있습니다.

### 3. 프로젝트 결과물 활용

프로젝트 수행 과정에서 작성한 결과물은 자유롭게 활용할 수 있습니다. 예를 들어,

- GitHub Repository
- 포트폴리오
- 기술 블로그
- 발표 자료

등으로 자유롭게 활용할 수 있습니다.

## 멘토링 안내

보다 효과적인 멘토링을 위해 아래 사항을 권장합니다.

### 1. 프로젝트 진행 내용 공유

멘토가 프로젝트 진행 상황을 이해할 수 있도록 아래 자료를 공유해 주세요.

- GitHub Repository
- 프로젝트 문서(Notion 등)
- 회의 내용
- 작업 진행 현황

프로젝트를 진행한 과정과 의사결정 내용을 함께 기록하면 멘토링 과정에서 보다 구체적인 피드백을 받을 수 있습니다.

### 2. 사전 질문 준비

멘토링 전에는 궁금한 내용을 미리 정리하여 전달해 주세요. 예를 들어,

- 현재 고민하고 있는 문제
- 구현하면서 막힌 부분
- 기술 선택에 대한 고민
- 설계 방향에 대한 질문

등을 정리해 오시면 제한된 멘토링 시간을 보다 효율적으로 활용할 수 있습니다. 가능하다면 멘토링 하루 전에 질문을 전달하는 것을 권장합니다.

### 3. 프로젝트를 수행하며 고려해 보면 좋은 점

프로젝트에서는 단순히 기능을 구현하는 것보다 문제를 해결하는 서비스를 만드는 과정을 중요하게 생각합니다. 프로젝트를 진행하면서 다음과 같은 부분을 함께 고민해 보시기 바랍니다.

- 사용자가 실제로 해결하고자 하는 문제는 무엇인가?
- AI는 어떤 부분에서 가장 효과적으로 활용될 수 있는가?
- 생성된 결과를 어떻게 신뢰할 수 있도록 만들 것인가?
- 사용자와 AI가 자연스럽게 상호작용하려면 어떤 구조가 적절한가?
- 왜 이러한 구조와 기술을 선택했는지 설명할 수 있는가?

열정과 적극성, 그리고 스스로 문제를 해결하려는 태도는 프로젝트를 수행하는 과정에서 매우 중요한 요소입니다. 정답을 찾기보다 다양한 방법을 시도하고, 그 과정에서 얻은 경험과 근거를 팀원 및 멘토와 적극적으로 공유해 보시기 바랍니다.
