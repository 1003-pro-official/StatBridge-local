## 안내 (원문 붙임1 도입부)

국가통계포털(KOSIS)의 다양한 통계와 설명 등에 대한 편의성 제고를 위해 KOSIS와 인공지능(AI)를 연계할 수 있는 개방형 표준 프로토콜(MCP) 시범서비스를 활용하여 시스템을 개발 중에 있습니다.
현재 서비스를 위해서는 활용하는 AI 특성에 따라 기본적인 설정이 필요합니다.
이 설명서는 ➊ 클로드앤트로픽, ➋ 앤티그래비티구글, ➌ 챗지피티오픈AI 순으로 설정 방법이 구성되어 있습니다.
이용에 참고하시기 바랍니다.

> ※ (참고사항) 구글의 앤티그래비티(AntiGravity), 오픈AI의 ChatGPT에서도 활용이 가능하나, 현재 기준 엔트로픽(Anthropic)의 클로드(Claude) AI와 연계하여 사용하실 때 최적의 결과를 얻으실 수 있습니다.

> **주의** — 본 서비스는 국가통계포털(KOSIS) 데이터를 기반으로 한 시범서비스입니다. 생성형 AI의 특성상 답변에 오류나 부정확한 내용이 포함될 수 있으므로, 중요한 의사결정 전에는 반드시 KOSIS 원자료를 확인하시기 바랍니다. 또한, 본 서비스의 통계 분석·해석 결과는 국가데이터처의 공식 입장이 아닌 참고용이니 활용 시 유의하시기 바랍니다. 감사합니다.

## 1. 클로드(Claude) AI — MCP 설정 방법 (Anthropic)

1. 클로드 웹 또는 앱 초기 화면에서 **Google로 계속하기** 또는 **이메일로 계속하기**로 로그인 (최초 이용 시 회원가입 필요)
2. 클로드 웹 또는 앱 로그인 후 왼쪽 아래 아이콘을 눌러 나온 메뉴 중 **[설정]** 클릭
3. 설정 창에서 **[커넥터]** - **[맞춤 설정]** 클릭
4. 맞춤 설정 화면에서 **[+]** 더하기 표시 클릭
5. **[커스텀 커넥터 추가]** 클릭
6. 커스텀 커넥터 추가 창에 입력 후 **[추가]** 버튼 클릭
   - **[이름]**: 자유롭게 입력 (예시: `kosismcp`)
   - **[원격 MCP 서버 URL]**: `https://kosismcp2026.vercel.app/api/mcp`
7. **승인 필요** 클릭 → **항상 허용**으로 변경
8. ← (뒤로 가기) 클릭
9. 채팅창에 KOSIS와 관련하여 자유롭게 질문
   - 예시: "2020년부터 2025년까지 소비자물가 알려줘"

## 2. 앤티그래비티(AntiGravity) AI — MCP 설정 방법 (Google, Gemini)

1. (PC에서) 검색 포털에 "앤티그래비티"로 검색(`https://antigravity.google`)하여 이동
2. **Download for Windows** 클릭
3. **Continue with Google** 클릭하여 로그인 (최초 이용 시 별도로 구글 가입 후 사용 가능)
4. **Sign In** 클릭하여 로그인
5. 로그인 후 구글 정책 동의사항 체크하고 **Next** 클릭
6. 컬러 테마 선택
7. 앤티그래비티 설정 파일에 내용 추가 필요
   - Windows 키 클릭 → `cmd` 입력하여 명령 프롬프트 앱 실행
   - 아래 명령어 실행 (config 폴더 생성, 이미 있으면 생략)

     ```
     mkdir $env:USERPROFILE\.gemini\config -Force
     ```

   - 아래 명령어 실행 (메모장에서 `mcp_config.json` 파일 열기)

     ```
     notepad $env:USERPROFILE\.gemini\config\mcp_config.json
     ```

   - 메모장에 아래 내용을 추가하여 붙여넣고 저장한 뒤 닫기

     ```json
     {
       "mcpServers": {
         "kosismcp2026": {
           "url": "https://kosismcp2026.vercel.app/api/mcp",
           "serverURL": "https://kosismcp2026.vercel.app/api/mcp",
           "timeout": 30000,
           "trust": true
         }
       }
     }
     ```

8. 앤티그래비티 채팅창에서 KOSIS 관련하여 자유롭게 질문 (일반적 질문도 가능합니다!)
9. 질문-답변 예시 (원본 화면 캡처 — 본 문서에는 텍스트 없음)

## 3. 챗GPT(ChatGPT) AI — MCP 설정 방법 (OpenAI)

> OpenAI의 ChatGPT 서비스 정책 변경에 따라, KOSIS MCP 연계 기능은 **챗GPT(ChatGPT) 유료 계정에서만** 이용할 수 있음을 알려드리니 참고하시기 바랍니다.

1. PC에서 ChatGPT 서비스 접속 및 로그인 (`https://chatgpt.com`, 최초 이용 시 회원가입 필요)
2. 구글, 애플, 휴대전화번호 등 로그인 가능한 방법으로 로그인
3. 왼쪽 하단의 아이콘 클릭
4. 팝업으로 뜬 메뉴 중 **[보안 및 로그인]** - **개발자 모드 켜기**
5. 개발자 모드 켠 다음 **[플러그인]** - **플러그인 둘러보기** 클릭
6. 플러그인 검색 창 옆의 **[+]** 클릭
7. 이름(자유롭게), 설명(자유롭게), 연결(`https://kosismcp2026.vercel.app/api/mcp` 입력), 인증(인증 없음), V(내용을 이해했으며 계속 진행하실 원합니다) 체크 → **만들기** 클릭
8. **연결하기** 클릭
9. `kosismcp2026`이 설정된 것을 확인 후 x 눌러 설정 창 끄기
10. 메인 채팅창에서 **[+]** → `kosismcp2026` 선택
11. `kosismcp2026` 선택 후 자유롭게 질문 (아래는 예시 — 원본 화면 캡처)
