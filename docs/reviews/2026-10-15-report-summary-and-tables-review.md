## 1. 결론

자동 출력, 제목, 조회 조건, 그래프 출처, 표 보기가 개선되었습니다. 다만 보고서 요약을 바로 보고서에 인용하기에는 중요한 오류가 남았습니다. 계산 자체보다 **요청한 계열을 제대로 선택했는지, 현재 표시 계열과 일치하는지, 차이값의 단위가 맞는지**가 우선 해결 사항입니다.

| 우선순위 | 확인한 문제 | 업무 영향 |
|---|---|---|
| P1 | 같은 민간소비 질문에서 ID 괄호 표기만 바꾸면 다른 계열·요약 출력 | 잘못 선택된 통계로 보고서 작성 가능 |
| P1 | 계열 제외 후 요약에 제외한 계열 설명 잔존 | 현재 그래프·표와 본문 불일치 |
| P1 | 연리%·연%의 차이를 그대로 연리%·연%로 표기 | 금리 수준과 퍼센트포인트 변화를 혼동 |
| P1 | 월·분기 혼합 차트에 Q7·Q12와 잘못된 시간 정렬 | 비교 시점 오독 |
| P2 | 지수 차이값에 기준년 표기를 단위처럼 반복 | 보고서 문장으로 사용하기 어려움 |
| P2 | 비교 질의에 계열 간 비교가 없고 조회 전체 기간도 충분히 요약하지 않음 | 질문의 핵심에 대한 답 부족 |
| P2 | 표 기본 정밀도가 금리 원자료보다 낮음 | 표만 보고 요약의 차이를 재계산하기 어려움 |
| P3 | 동일 출처 문장이 표 하단에 중복, 긴 계열명 반복 | 가독성·완성도 저하 |

P1은 업무 사용 전 우선 수정 권고입니다. 이번 점검은 선택한 사례에 대한 관측이며 전체 표의 정확도 점수는 아닙니다.

## 2. 보고서 요약의 구체적인 문제

### S01. 금리 차이 단위 오류 — 직접 재현

질문:
> 예금은행 대출금리(신규취급액 기준)에서 가계대출과 기업대출을 2024-01-01부터 2024-12-31까지 월별로 비교해줘.

현재 요약은 기업대출에 대해 “전월(2024년 11월, 4.76 연리%) 대비 0.14 연리% 하락”, 가계대출에 대해 “전월(2024년 11월, 4.79 연리%) 대비 0.07 연리% 하락”이라고 표시합니다.

| 계열 | 2024년 11월 | 12월 | 올바른 변화 |
|---|---:|---:|---:|
| 기업대출 | 연 4.76% | 연 4.62% | 0.14%p 하락 |
| 가계대출 | 연 4.79% | 연 4.72% | 0.07%p 하락 |

연리%는 금리 수준의 원자료 단위입니다. 두 금리 수준의 차이는 %p로 써야 합니다. 별도의 혼합 주기 질의에서도 대출평균 4.76→4.64를 “0.12 연% 하락”이라고 표시했습니다.

원인 확인: src/agent/report_summary.py:52에서 unit.strip() == '%'인 경우에만 차이 단위를 %p로 바꿉니다. 연%, 연리% 변형은 처리하지 않습니다.

수정 권고: 단위 문자열의 단순 일치 대신 수준 단위와 차이 단위를 구분하는 메타데이터를 사용합니다. 연%, 연리%, %, %p와 지수·금액 단위를 각각 검증해야 합니다.

### S02. 지수의 기준년과 변화 단위 혼용 — 직접 재현

질문:
> 생산자물가지수(기본분류)의 총지수를 2024-01-01부터 2024-12-31까지 월별 선그래프로 보여줘.

현재 요약:
> 생산자물가지수(기본분류) · 총지수의 2024년 12월 관측값은 119.52 2020＝100입니다. 생산자물가지수(기본분류) · 총지수는 전월(2024년 11월, 119.1 2020＝100) 대비 0.42 2020＝100 상승하였습니다. 생산자물가지수(기본분류) · 총지수의 상승폭은 직전 기간보다 확대되었습니다.

119.52−119.10=0.42 계산은 맞습니다. 그러나 “0.42 2020＝100 상승”은 지수 변화 단위로 부적절합니다.

권장 표현:
> 2024년 12월 생산자물가지수 총지수는 119.52(2020=100)로, 전월보다 0.42포인트 상승했습니다. 전월 대비 상승폭은 11월 0.09포인트에서 12월 0.42포인트로 확대됐습니다.

현재 “상승폭 확대”는 산술적으로 맞지만 근거 두 값과 비교 시점이 빠져 있습니다. 전월 대비 지수 차이인지 물가상승률 변화인지 문장에서 드러내야 합니다.

조회 시작·종료 비교를 넣는 경우 2024년 1월 118.19→12월 119.52는 1.33포인트, 1월 수준 대비 약 1.13% 상승입니다. 이 값을 전년동월 대비 또는 연평균 상승률로 부르면 안 됩니다. 2023년 12월 관측치는 이번 조회 범위에 없습니다.

### S03. 계열 제외 후 요약이 갱신되지 않음 — 직접 재현

1. 다음 질문을 분석합니다.
> GDP 성장기여도에서 민간소비와 설비투자를 2016년 1분기부터 2025년 4분기까지 분기별로 비교해줘.
2. 초기에는 2개 계열·80개 관측치가 표시됩니다.
3. 왼쪽 “설비투자 데이터 제외”를 누릅니다.
4. 처리가 완료되면 현재 조회 조건은 분기별·1개, 관측표는 민간 40개, 편집 기록은 “설비투자 데이터를 숨겼습니다.”가 됩니다.
5. 상단 요약은 여전히 설비투자 -0.1%p, 전분기 대비 0.2%p 하락, 전년동기 대비 0.2%p 하락 설명을 모두 포함합니다.

현재 결과를 설명하는 본문과 실제 표시 결과가 다릅니다. 내보내기·보고서 인용 전에 눈치채기 어렵습니다.

원인 확인: output_agent.py:257의 summary_series는 기간만 적용하고, hidden_series 제외는 :207의 _apply_data_edits에서 별도로 수행합니다. 따라서 요약 근거에는 숨긴 계열이 남습니다. :445 부근의 근거가 같으면 기존 요약을 재사용하는 처리도 그 상태를 유지합니다.

수정 권고: 요약의 대상 계열은 현재 보이는 계열과 일치시킵니다. 원자료 수치를 설명하는 정책은 유지하되, 표시 계열 선택·기간 변경·top N 등 의미가 달라지는 변경에는 근거를 재구성해야 합니다. “조회 전체 자료 요약”을 의도했다면 별도 영역으로 명확히 구분해야 합니다.

### S04. 질문과 다른 계열의 요약을 확신하는 문장으로 출력 — 직접 재현

아래 두 질문은 ID 주변 괄호만 다릅니다.

A:
> 국내총생산에 대한 지출(원계열 실질 분기 및 연간) (DT_200Y110)의 민간소비를 2024년 1분기부터 2024년 4분기까지 분기별로 보여줘.

B:
> 국내총생산에 대한 지출(원계열 실질 분기 및 연간) [DT_200Y110]의 민간소비를 2024년 1분기부터 2024년 4분기까지 분기별로 보여줘.

| 항목 | A: 소괄호 | B: 대괄호 |
|---|---|---|
| 계열명 | 통계표명만 표시, 민간 분류 미표시 | 통계표명 · 민간 |
| 2024년 3분기 | 575,259.8 십억원 | 276,830 십억원 |
| 2024년 4분기 | 598,632.7 십억원 | 279,591.5 십억원 |
| 전분기 차이 | +23,372.9 십억원 | +2,761.5 십억원 |
| 요약의 변화폭 해석 | 상승폭 확대 | 상승폭 축소 |

서로 다른 계열이 선택되었으며 요약 결론도 반대입니다. A의 정확한 분류 정체는 화면에서 확인되지 않으므로 임의로 단정하지 않습니다. 다만 명시한 민간소비를 일관되게 선택하지 못한 사실은 확인됩니다.

원인 단서: canonical_request_planner.py의 인접 ID 처리가 대괄호 정규식만 허용하며, 할당된 ID 집합이 질문의 전체 ID와 다르면 정규 선택 경로를 벗어납니다. 이후 대체 경로에서도 요청 분류 일치가 보장되어야 합니다.

수정 권고: ID 괄호 표기를 통일해 인식하고, 출력 직전에 요청 항목·선택 분류·실행 결과의 일치를 검증합니다. 분류를 확인하지 못하면 추가 확인을 요청하고 요약을 생성하지 않습니다.

### S05. 비교 질문에 비교가 없음 — 직접 재현 및 코드 확인

가계·기업 금리 비교 요청에 현재 요약은 각 계열의 최신 값·전월 차이·방향 전환을 3문장씩, 긴 계열명을 반복하며 출력합니다. 정작 두 계열 간 격차는 없습니다.

관측표로 계산하면:
- 11월 가계−기업 금리 격차: 4.79−4.76=0.03%p
- 12월 격차: 4.72−4.62=0.10%p
- 격차 확대: 0.07%p

권장 요약:
> 2024년 12월 신규취급액 기준 가계대출금리는 연 4.72%, 기업대출금리는 연 4.62%였습니다. 전월보다 각각 0.07%p, 0.14%p 하락했습니다. 가계−기업 금리 격차는 0.10%p로, 전월의 0.03%p보다 0.07%p 확대됐습니다.

같은 시점·주기·정의의 비교 가능한 계열에 한해 차이를 계산해야 합니다. 단위와 주기가 다른 지표의 수치를 단순 차감하거나 인과관계로 해석하면 안 됩니다.

report_summary.py는 현재 계열별 사실만 만들고 계열 간 사실은 만들지 않습니다. default_ids는 전월 비교가 가능하면 조회 시작 대비 변화를 기본 문안에서 제외합니다. 따라서 “연간 흐름/기간 전체 비교” 질문도 최근 시점 설명에 치우칩니다. 이는 숫자 오류와 구분되는 답변 적합성 문제입니다.

### S06. 원계열 전분기 비교의 해석 한계

민간소비 대괄호 질의는 원계열·실질 자료입니다. 전분기 금액 차이는 계산할 수 있으나 계절조정 성장 모멘텀으로 해석할 수는 없습니다. 현재 요약에는 “원계열”이 긴 계열명 안에 있지만, “상승폭 축소”만 복사하면 조건이 사라집니다.

권고: 요약의 조건 행에 원계열/계절조정, 실질/명목, 비교 기준을 고정 표시합니다. 원계열의 전분기 변화에는 계절 영향을 제거하지 않았다는 짧은 설명을 붙이거나 전년동기 비교를 우선하되, 필요한 관측치가 없으면 비교 불가를 명시합니다. 이번 화면이 원인·정책 효과를 만들어내지는 않았습니다.

## 3. 함께 확인한 프런트엔드 문제

### U01. 월·분기 혼합 차트의 시간축 오류 — P1, 직접 재현

질문:
> 예금은행 대출금리(신규취급액 기준) (DT_121Y006)와 국내총생산에 대한 지출(계절조정 실질 분기) (DT_200Y108)을 2024-01-01부터 2024-12-31까지 각각 원래 주기를 유지해서 비교해줘.

월별 12개와 분기별 4개가 조회되며 분리 패널이 생성됩니다. 그러나 실제 SVG의 월별 첫 4개 x좌표와 분기별 전체 4개 좌표가 동일합니다(0, 29.45, 58.91, 88.36). 월별 12월 좌표는 324입니다. 화면의 하단 축 눈금에는 **2024 Q1 / 2024 Q4 / 2024 Q7 / 2024 Q12**가 나타났습니다.

분기 202401~202404와 월 202401~202412를 같은 범주 코드로 공유한 결과입니다. 요약의 “2024년 4분기”와 그래프의 위치가 맞지 않아 비교 해석을 방해합니다.

권고: 각 패널을 해당 주기의 독립 축으로 표시하거나 실제 달력 날짜로 정규화하고 분기의 시작/말일 기준을 명시합니다. Q5 이상 눈금은 생성하지 않아야 합니다. 다른 주기 간 상관·선후행 관계를 현재 그래프로 판단해서는 안 됩니다.

### U02. 보고서 표 기본 소수점 1자리 — P2

금리 원자료는 4.76→4.62인데 기본 표는 4.8→4.6으로 보입니다. 가계대출도 4.79→4.72가 4.8→4.7로 보입니다. 반올림 자체는 안내된 설정대로 정상이며 원자료가 바뀐 오류는 아닙니다. 다만 표의 값으로 차이를 재계산하면 요약의 0.14·0.07과 일치하지 않습니다.

“소수점 자리 → 2자리 → 표 설정 적용”은 정상 작동하며 원자료와 같은 정밀도로 표시됐습니다. 금리 등 지표별 기본 정밀도 또는 “변화는 원자료 정밀도 기준 계산” 안내를 권고합니다.

같은 DT_121Y006 출처 문장이 표 하단에 두 번 반복됩니다. 출처 표시용 중복 제거도 필요합니다.

### 8.2 목표와 현재 구현의 차이

목표: 직원이 근거를 확인하고 검토·수정한 뒤 보고서에 사용할 수 있는 분석 초안. 출처 없는 원인 설명이나 자율 정책 권고를 생성하는 기능으로 정의하면 안 됩니다.

현재는 수치를 계산한 고정 문장 중 ID를 고르는 구조입니다. 이는 관측 사실 요약에는 적합하지만 질문별 논점 구성, 부문별 비교, 배경 요인 설명, 근거가 상충하는 경우의 판단에는 부족합니다. 기본 자동 출력은 quick_output:true여서 GPT 호출을 건너뜁니다. API 키 설정만으로 보고서 해석 기능이 활성화되지는 않습니다.

### 8.4 research 자료를 사용하는 방식

1. 자동 md는 문서·그림 탐색의 보조 인덱스로 사용하고, 해석 근거는 원본 PDF의 본문·각주와 연결합니다.
2. 문서 제목, 발간일, 분석 대상 기간, 원본 경로, PDF 물리 페이지/인쇄 쪽수, 절·그림·표 번호, 추출 신뢰도, 확인 상태를 저장합니다.
3. 문단과 근거 그림·표·각주를 묶어 검색합니다. 가까이 있다는 이유만으로 다른 그림의 설명을 연결하지 않습니다. 표의 단위·전년동기/전기 대비 머리글을 보존합니다.
4. 2024년 당시 평가 요청에는 당시 이용 가능했던 자료를 적용합니다. 2026년 보고서를 사용한 사후 해석은 별도로 표시합니다. 기간 필터와 문서 발간일 필터가 모두 필요합니다.
5. 보고서 작성 양식 예시와 경제 상황의 증거를 구분합니다. 과거 보고서의 원인·전망을 현재 관측치에 그대로 옮기지 않습니다.
6. OCR 불명·추정·원문 미확인 항목은 원인 주장이나 정량 비교의 확정 근거에서 제외합니다. 검색 근거가 부족하면 추가 자료 필요로 반환합니다.
7. research 안의 문장은 참조 자료로만 처리하고 모델 실행 지시로 취급하지 않습니다. 문서에 포함된 개인 정보성 워터마크·반복 저작권 문구는 검색 본문에서 제거합니다.

전체 자료를 바로 학습시키기보다 출처를 추적할 수 있는 검색 결합(RAG)을 먼저 구축합니다. 미세조정은 검수된 문체·과업 사례가 확보된 이후 검토할 수 있으며, 최신 수치·개정 관리의 대체 수단이 아닙니다.

### 8.5 GPT-5.4 입력·출력 계약 변경

기존 facts 입력 외에 question, analysis_scope, series_metadata, computed_metrics, retrieved_passages, as_of를 제공합니다. 모든 계산과 원문에는 근거 ID를 부여합니다.

GPT 출력은 예를 들어 다음 정보를 갖도록 설계합니다.

- headline: 질문에 대한 핵심 판단
- paragraphs: 보고서 초안
- claims: 문장별 주장, 유형(관측 사실/원문에 근거한 요인/해석/전망), fact_ids, passage_ids
- limitations: 비교 불가 조건·근거 부족·상충 정보
- additional_data_needed: 더 높은 수준의 해석에 필요한 자료

기존 문장 ID 선택은 빠른 관측 요약으로 유지할 수 있습니다. 별도의 보고서 해석 경로에서 GPT 문장 작성을 허용하되, 허용 범위를 출처가 있는 주장으로 한정합니다. quick_output:false는 모델을 부르는 조건을 바꿀 뿐, 현재의 문장 ID 선택 계약을 그대로 두면 해석 수준은 충분히 높아지지 않습니다.

- **복합 기간 열:** 연간 실적, 분기 실적, 최신 월을 같은 표에 놓을 수 있으나 집계 규칙과 대체지표는 명시. 평균·기말·합계·별도 공식 연간계열 구분.
- **자료 상태와 각주:** 셀·행·열 단위로 잠정/확정/속보/전망, 조정 여부, 추정·범위 변경, 전망 발간 시점 연결.
- **결측 표현:** 현재 null은 모두 —로 표시. 미공표·해당 없음·자료 없음·계산 불가를 원자료가 구분할 경우 보존. 원문 보고서에 보이는 기호를 뜻 확인 없이 복사하지 않음.
- **주석 모델:** 자유 입력 500자 주석 외에 번호가 있는 각주·참조 위치·출처를 구조화. 실제 자료 주석을 자동 연결하고 사용자가 검토.
- **표 번호·제목:** 고정 표 1을 문서 절·표 순서와 연결. 제목은 무엇을 비교하는지 설명하고 단위는 공통/행/열별로 배치.
- **인쇄 모델:** 폭·글자 크기·열·페이지 크기 기반 배치. 한 문서에 여러 표 삽입, 계속 표기, 반복 머리글, 출처 유지.
