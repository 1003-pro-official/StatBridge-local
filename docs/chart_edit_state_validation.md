# 현재 그래프 편집 상태 검증

2026-10-12, ai-assisted.

## 단일 상태와 결함 수정

서버의 `ChartSpec`과 `editVersion`이 편집의 정본이다. 자연어·수동 속성·그림 직접 선택은 모두 `/api/output/edit`를 사용한다. 화면의 선택 항목·아직 입력 중인 글자·임시 그림은 UI 상태이며 정본 복제본이 아니다.

- 기존에는 수정마다 결과를 새 페이지 이력에 추가하고 위로 스크롤했다. 편집은 현재 이력을 교체하며 스크롤을 유지한다.
- 별도 수정 챗봇의 성공 후 닫힘을 상시 입력창에 적용하지 않는다. 같은 세션의 대화는 재진입 후에도 보존한다.
- 클라이언트는 수정 요청을 직렬화하고 실행 시점의 최신 버전을 사용한다. 서버도 잠금 아래 이전 객체와 버전을 검사한다. 오래된 요청은 409로 거절한다.
- 저장 설정의 DPI·명시적 데이터 스타일처럼 현재 모양이 같아도 이후 출력·디자인에 의미가 있는 상태 변경을 허용한다. 이를 화면 변화로 거짓 보고하지 않고 설정 저장으로 알린다. 상태 자체가 같은 요청은 무변경으로 거절한다.
- 데이터 색과 `series_styles.color/dash`가 충돌해 반복 변경이 안 보이던 문제를 고쳤다. 최신 색·선 명령이 이전 개별 오버라이드를 대체하고 범례와 실제 선의 색을 일치시킨다.
- 원본 복원은 사용자 선택이며 취소 가능한 별도 편집이다. 저장된 최초 스냅샷을 사용한다. 재편집의 전제 조건이 아니다.

## 검증 시나리오

자동 단위 테스트: 제목 → 색 → 기간 강조 → 기준선 → 범례 → 디자인 → 설명 → 선 굵기 → 격자 → 부제의 10회 연속 편집을 수행했다. 단계마다 데이터 표가 같음을 확인하고 제목·색·강조·기준선·설명의 공존과 JSON 복원 후 추가 편집을 검사한다.

HTTP 테스트: 개별 제목 취소가 최신 색을 유지하는지, Undo가 그 취소를 되돌리는지, 최초 상태 복원과 오래된 버전 거절을 검사한다. 데이터 추가·교체·Undo의 표 식별자·값 보존을 검사한다. 메모리에서 세션을 제거한 뒤 저장 파일로 복원하고 재편집한다. 저장 자료를 변조하면 무결성 검증이 실패한다.

실제 API: KOSIS DT_181Y011, 2020~2025 분기 24개로 6개 디자인과 10회 연속 편집, Undo/Redo, JSON 저장·복원·추가 편집을 수행했다. 자연어 제목·기간 강조·강조 색·불투명도·선 색 변경까지 검증한다. 실제 실행 회차·응답 시간·실패·최종 상태는 `evaluation_runs/chart_workspace_live`와 `chart_e2e_evidence.md`를 따른다.

브라우저: 같은 항목의 제목·선·축·설명·강조 선택, 반복 수동 편집과 자연어 편집, Undo/Redo, 저장 및 재열기 증거를 별도로 기록한다. API 테스트의 성공을 브라우저 검증으로 대체하지 않는다.

## 저장과 통계 정확성

데이터 편집과 표현 편집은 구분한다. 스타일 작업은 원자료 값·단위·표 식별자·출처·기준시점을 변경하지 않는다. 표시 변환은 기록하며 원자료는 남긴다. 다른 표를 추가·교체할 때는 실제 조회 결과와 요청 일치 검증이 필요하다. JSON은 현재 자료와 fingerprint·표시 값·중복 메타데이터가 일치해야 복원된다. 서버 디스크 저장도 자료 fingerprint를 검사한다.

최근 20개의 Undo/Redo와 최초 상태를 보존한다. 서버 파일은 64MB(압축 전), JSON 파일은 8MB 제한이다. 서버 저장을 하지 않은 임시 세션은 서버 재시작으로 만료될 수 있다. 외부 제공자 오류·모호한 지시·미지원 스타일·잘못된 자료는 실패로 보고하고 기존 결과를 유지한다.
