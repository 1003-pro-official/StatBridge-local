**우선 판단:** 저장된 CSV의 **형식**은 깨끗하다. 문제는 **의미의 모호함**이다. 표 이름만으로 정답을 확정하기 어렵고, 단위·최신성·수록 범위를 CSV 안에서 확인할 수 없는 표가 있다. 검색은 표 이름과 분류 경로로 후보를 찾고, 최종 선택 전에 항목·분류·단위·주기·수록 기간을 확인해야 한다. 이름 변형 15그룹은 골든셋 후보이며, 같은 지표 또는 서로 대체 가능한 표라는 판정은 아니다.

## 2. 분석 범위와 방법

- 출처: [한국은행 표 카탈로그](../../data/kosis/hankook_tables.json)의 2026-09-14 수집본과 `data/tables/`의 로컬 CSV. 전체 [통계표 목록](한국은행-통계표-목록.md)에 표 ID별 수집 여부와 기간이 있다.
- 근거: 모든 코드 셀이 오류 없이 실행된 [EDA 노트북](../../notebooks/01_data_eda.ipynb)의 저장된 출력(`eda-03`, `eda-07`~`eda-13`). 이번 보고서 작성 과정에서 KOSIS API를 다시 호출하지 않았다.
- 방법: CSV별 행 수, `ITM_ID`와 `C1`~`C4`의 고유값 수, `UNIT_NM`, `PRD_SE`·`PRD_DE`, `LST_CHN_DE`를 집계했다. 중복 후보는 `주기 + 수록 시점 + 항목 ID + 파일에 존재하는 분류 코드`가 같은 행으로 정의했다.
- 한계: 수록 시점은 원본 코드를 그대로 비교했다. 행 수는 고유 시점이나 지표 수가 아니며, 수치의 통계적 정확성·현재 API 제공 상태는 검증하지 않았다.

## 4. QC: 데이터 품질 점검

### 4.1 형식 무결성 — 이상 0건

| 점검 항목 | 건수 |
|---|---:|
| CSV 미수집 표 | 2 |
| 빈 CSV | 0 |
| 파일명과 `TBL_ID`가 다른 행 | 0 |
| 동일 조회 키 중복 행 | 0 |
| `ITM_ID`가 빈 행 | 0 |
| 주기 또는 수록 시점이 빈 행 | 0 |
| `DT` 값이 빈 행 | 0 |
| `DT` 값이 숫자로 변환되지 않는 행 | 0 |
| `UNIT_NM` 열은 있으나 값이 빈 행 | 0 |
| 분류 코드(`C1`~`C4`)가 빈 행 | 0 |

CSV 미수집 2개는 모두 자금순환표의 `DT_284Y001`(잔액표), `DT_284Y002`(거래표)다. 위 정의로 표시되는 **점검 후보 표는 0건**이며, 숫자로 변환되지 않는 `DT` 값 예시도 없다(`eda-11`).

### 4.2 완전성 — CSV만으로 채울 수 없는 메타정보

| 분류 차원 라벨 공백 | 1개 표 | `DT_404Y017`은 `C1` 라벨(`C1_OBJ_NM`)이 비어 있다. 이 표에 한해 분류 라벨을 코드로만 표시할 수 있다. |

### 4.3 구조 일관성

- 헤더가 8종이므로 컬럼 위치 기반 파싱은 안전하지 않다. 항상 헤더 이름으로 접근해야 한다.
- 분류 차원은 1~4개이므로 "조회 키"를 표마다 동적으로 구성해야 한다(`PRD_SE + PRD_DE + ITM_ID + 존재하는 C1~C4`).
- `UNIT_NM` 열 유무가 4개 차원 조합과 독립적으로 나타나, 차원 수만으로 스키마를 추정할 수 없다.

### 4.4 최신성·수록 범위 이상 후보

표 ID 체계가 두 세대로 갈린다. 같은 지표가 구·신 코드에 나뉘어 있고 수록 범위가 다르다.

| 구분 | 수록 종료 | 최종 수정일 | 예시 표 |
|---|---|---|---|
| 구 코드 세대 | 2004.09 | 2025-12-30 | DT_101Y001~019, DT_102Y101~104, DT_111Y001~004, DT_112Y001~002 |
| 신 코드 세대 | 2026.07~2026.08 | 2026-09-20 | DT_161Y001~017, DT_171Y001~004, DT_172Y001~002 |

`DT_101Y001`과 `DT_161Y007`은 이름이 같고 수록 기간이 일부 겹친다. 또한 `DT_404Y017`(생산자물가지수-총지수 1910~1964)은 최종 수정일이 2024-05-14로, 대부분 표의 2026-09-20과 다르다. 이는 표가 정지·이관되었을 가능성을 보여주는 **후보**이며, 원본 통계표 정의를 확인하기 전에는 오류로 확정하지 않는다.

## 6. 검증하지 않은 것

- 원본 KOSIS 통계표 정의와 수치를 대조하지 않았으므로, 값의 정확성·집계 일관성을 보장하지 않는다.
- `DT` 값이 숫자로 변환된다는 사실은 단위·계열·집계 방식이 올바르다는 검증이 아니다.
- 시점(`PRD_DE`)은 원본 코드를 그대로 두고 최소·최대만 비교했다. 사전순 비교이므로 연도·차수 코드 체계가 다른 표를 섞어 해석하지 않는다.
- 행 수는 고유 시점이나 지표 수가 아니며, 표 간 우열이나 사용자 질문 빈도를 뜻하지 않는다.
- 최신 API 제공 상태와 두 세대 코드 표의 공식 이관 여부는 확인하지 않았다.
