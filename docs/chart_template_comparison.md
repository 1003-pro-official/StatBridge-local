# 그래프 디자인 비교

2026-10-12, ai-assisted. 기존 12개 고급 차트 구성은 유지하며 화면용 디자인 6종을 별도로 추가했다. 차트 구성은 데이터·배치 유형이고 디자인은 표현 속성이다. 제공되지 않은 전망값·구간·위험 시점을 만들지 않는다.

각 디자인은 흰 배경, 한글 대체 글꼴, 가운데 제목, 정의된 글자·선·격자·범례·여백을 적용한다. 기존 제목·부제·기간 강조·설명·원자료는 보존한다. 직접 지정한 데이터 색·선 스타일은 디자인의 기본값보다 우선한다. 디자인 선택은 해당 디자인에 정의된 공통 표현 속성을 갱신하는 명시적 동작이다.

이전 문제는 기존 템플릿이 주로 차트 구조를 지정하고, 이미 저장된 스타일과 기본값의 구분이 불명확했던 데 있었다. `chart_designs.py`에서 디자인 기본값을 정의하고 현재 명세에 적용하며, 개별 데이터 오버라이드는 렌더링 시 합성한다. 별도의 화면 설정 복제본을 저장하지 않는다. 데이터 색 설정과 시리즈 스타일 색이 충돌하던 문제도 최신 명령이 우선하도록 수정했다.

미리보기는 현재 첫 데이터로 그린 간략 SVG이며 실제 수치를 사용한다. 실제 중앙 그래프는 Plotly로 렌더링한다. 단순 예시 선만 그린 화면을 완료 결과로 제시하지 않는다.

## 검증과 이미지

자동 테스트는 6종의 글자·색·선·격자 렌더링 서명을 비교하고 서로 다름을 확인한다. 매 단계의 데이터 표를 원자료 기반 표와 비교한다. 실제 KOSIS DT_181Y011의 24개 분기 값으로 적용한 API 증거는 `evaluation_runs/chart_workspace_live/evidence.json`에 기록한다.

브라우저 비교 스크린샷은 `evaluation_runs/chart_workspace_browser/design-report.png`, `design-stability.png`, `design-outlook.png`, `design-slides.png`, `design-academic.png`, `design-explore.png`다. 최신 최종 프레임 재검증 여부와 결과는 `chart_e2e_evidence.md`에 기록한다. 생성 이미지·실행 로그는 Git에서 제외하며 같은 로컬 체크아웃에서 확인한다.

Plotly·Matplotlib·ECharts가 모든 스타일을 픽셀 단위로 동일하게 보여 주는 것은 아니다. Matplotlib의 선 유형·마커·색·글자·격자와 기존 지원 제한을 검사한다. ECharts의 바이올린·저장 이미지·위치 주석 등 미지원 구성은 명시한다. 팬 차트는 실제 공급된 경계가 필요하며 3종 예약 유형(점도표·수익률 곡선·금융 네트워크)은 실행 미지원이다.
