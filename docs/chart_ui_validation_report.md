## 주요 수정

현재 서버 버전이 편집의 기준이 되도록 요청을 순서대로 처리하고, 오래된 버전과 다른 세션 응답을 거절했다. 디자인의 기본값과 사용자 개별 스타일을 합성하여 최신 선 색이 실제 그래프·범례와 일치하도록 했다. 모양이 같아도 DPI나 명시적 설정이 바뀐 요청은 상태 변경으로 저장한다. 상태가 실제로 같은 요청만 무변경으로 처리한다.

외부 모델의 빈 명령 응답으로 명확한 기간 강조가 실패하는 사례를 재현했다. 단독 제목·분기 범위 강조·최근 강조 색/투명도·명확한 시리즈 색 지시는 현재 데이터와 ID를 검증하는 제한된 해석기로 처리한다. 복합·모호한 요청은 기존 HCX-007 해석 및 전체 지시 검증을 유지한다. 이 경로는 모델 응답에 `validated-text`로 표시하여 실제 HCX 호출과 구분한다. 429와 일부 일시적 오류에는 최대 두 번 재시도하며 실패 시 기존 상태와 입력을 보존한다.

가로·세로 격자 제거를 각각 연결하고, 내보내기에서 visible=False와 색상 인자가 함께 전달되어 격자가 재활성화되던 오류를 수정했다. 제목/축 SVG의 클릭을 막던 포인터 설정도 브라우저에서 확인 후 고쳤다. 모바일 입력창의 CSS 우선순위를 수정해 실제 고정 위치를 확인했다.

## 지원 한계

Undo/Redo는 최근 20개 이력이다. 저장은 현재 자료의 스냅샷이며 최신 통계 재조회가 아니다. 서버 압축 전 64MB, JSON 가져오기 8MB 제한이다. 미지원 벡터 차트 종류·비선형 선 스타일·일부 데이터 좌표 장식은 오류 이유를 표시하고 조용히 다른 출력으로 바꾸지 않는다. 기존 Plotly 화면 PNG 다운로드는 유지한다. 외부 모델 호출 지연과 요청량 제한 때문에 자연어 편집의 즉시 응답을 보장하지 않는다.
