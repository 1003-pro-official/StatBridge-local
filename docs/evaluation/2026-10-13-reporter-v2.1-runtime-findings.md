## D. 지원 불가 요청을 다른 표로 대체 (최우선)

사용자가 요청한 개념이 카탈로그에 없는데, 거절하지 않고 **다른 표를 조회해 그 데이터를 보여준다.**

| 문항 | 요청(카탈로그에 없음) | 실제 선택 |
|---|---|---|
| `REPORTER30-V2.1-052` | 취약차주 비중 | `DT_121Y010` 고정·변동금리대출 비중 |
| `REPORTER30-V2.1-170` | 유로지역 경제심리지수(ESI) | `DT_513Y001` 한국 경제심리지수 |
| `REPORTER30-V2.1-171` | 미국·유로 일반인 기대인플레이션율 | `DT_511Y003` 한국 기대인플레이션율 |

- 규모: **도달 71건 중 13건이 골드와 다른 표를 조회**(조회 계약 `tables_match` 실패), `no_match` 골드 60건 중 **14건이 조회를 시도**했다.
- 왜 문제인가: 사용자에게 **다른 질문의 데이터를 조용히** 보여준다. v2 원본의 "미지원 지표를 다른 지표로 대체하지 않는다" 원칙이 새 유형에서 뚫렸다.
- 재현: `evaluate_execution.py`의 `tables_match`·`not_executed` 체크와 `diagnostic` 참고.

## B. 이미 명시한 조건을 되묻는 역질문 (31건)

사용자가 조건을 문장에 적었는데도 다시 묻는다.

- 예: `REPORTER30-V2.1-037` "…**신규취급액 기준**으로 비교" → 런타임이 `comparison:0:interest_basis`("어떤 기준의 금리를 원하시나요?")를 띄움
- 실제 뜬 역질문 분포: `comparison:0:table` 8, `canonical_table:*` 8, `loan_type` 5, `comparison:0:interest_basis` 3, `rate_type` 4, 기타 3
- 영향: 31건이 조회 단계까지 가지 못한다.

## C. 카탈로그에 없는 요청에 역질문 (11건)

거절해야 할 요청(예: `051` 주요국 국채금리, `097` 고정이하여신비율)에 "어떤 표를 원하시나요"로 되묻는다. 사용자가 답해도 데이터가 없으므로 거절이 맞다.

## A. 기자식 표현 라우팅 공백 (36건)

응답: `지원 데이터에서 찾지 못한 지표: <계열명>`. 계열은 카탈로그·KOSIS에 실재한다.

- 예: `088` "상호금융 수신 잔액" → `DT_111Y007`에 존재
- 예: 기업재무(연간) 16건 — "전산업 기업의 부채비율", "제조업 기업의 재고자산회전율"
- 주기 A 문항 18건이 전부 실패한 것도 같은 원인(기업재무 표 라우팅)이며, 주기 처리 자체의 문제는 아니다.
- 주의: 이 36건은 **문구가 지나치게 간접적인지** 사람 검수가 필요하다. 기자가 실제로 쓸 문장이면 코드가 목표로 삼아야 하고, 아니면 골든셋 문구를 완화한다(현재는 유지).
