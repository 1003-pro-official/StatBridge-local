자연어 질의부터 통계표 탐색까지는 **단계별 정확도와 전체 성공률을 따로 측정**하는 것이 좋습니다. 최종 통계표를 잘 찾았더라도, 사용자 의도를 잘못 해석한 것인지 후보 검색이 실패한 것인지 알 수 있어야 하기 때문입니다.

## 단계별 평가

| 단계 | 평가 질문 | 주요 지표 |
| --- | --- | --- |
| 자연어 질의 입력 | 사용자가 질문을 무리 없이 제출했고, 입력한 원문이 그대로 보존됐는가? | 제출 성공률, 입력 원문 보존율, 입력 중 이탈률, 완료 시간 |
| 의도·조건 추출 | 에이전트가 사용 목적과 지표·기간·대상·비교 조건을 제대로 뽑았는가? | 의도 분류 정확도, 슬롯별 정밀도·재현율·F1, 핵심 슬롯 완전 일치율 |
| 통계 개념 후보 구성 | 사용자의 표현을 통계표 탐색에 쓸 개념 후보로 잘 연결했는가? | 정답 개념 Recall@k, 후보 순위 MRR/NDCG, 근거 없는 후보 비율 |
| 모호성 관리·역질문 | 확인이 필요할 때 질문했고, 확인하지 않아도 될 때는 불필요하게 묻지 않았는가? | 필요한 질문 탐지율, 불필요한 질문률, 놓친 모호성률, 답변 후 해석 해결률 |
| 도구 실행계획 | 표 탐색과 메타정보 확인에 필요한 도구를 적절한 순서로 계획했는가? | 계획 유효율, 필수 도구 누락률, 불필요한 도구 호출률, 예상 분기 적합도 |
| 통계표 탐색 | 요청에 맞는 표를 후보로 찾고, 표가 없거나 후보가 여러 개인 경우 올바르게 판단했는가? | 정답 표 Recall@k, Top-1 정확도, 후보 순위 MRR/NDCG, 무결과 판별 정확도, 복수 표 집합 정확도 |

### 지표의 의미

- **Recall@k**: 정답 표나 개념이 상위 `k`개 후보 안에 들어 있는 요청의 비율입니다.
- **Top-1 정확도**: 가장 먼저 제시한 표가 정답인 비율입니다.
- **무결과 판별 정확도**: 적합한 표가 없을 때 없다고 판단하고, 있을 때 후보를 찾는 능력입니다.
- **핵심 슬롯 완전 일치율**: 지표·기간·비교 대상 등 결과를 바꾸는 조건을 모두 정확히 추출한 비율입니다.
- **필요한 질문 탐지율**: 정답 판단을 위해 사용자 확인이 필요한 질의에서 실제로 질문한 비율입니다.
- **불필요한 질문률**: 기본값이나 탐색으로 처리할 수 있는 사안에 확인을 요청한 비율입니다.

## 골든셋은 어떻게 구성하나요?

각 테스트 질의마다 기대 결과를 미리 기록한 골든셋이 필요합니다. 표 ID는 제공된 한국은행 카탈로그의 표 ID를 기준으로 지정하고, 실제 표가 여러 개 정답일 수 있는 질의는 허용 표 집합으로 관리합니다.

골든셋에는 다음 유형을 포함하는 것이 좋습니다.

- 표 이름과 가까운 공식 용어 질의
- 일상 표현이나 별칭을 사용한 질의
- 지표·대상·기간·주기를 함께 지정한 질의
- 여러 표를 비교해야 하는 질의
- 해석이 갈려서 역질문이 필요한 질의
- 표가 없거나 현재 범위에서 지원할 수 없는 질의

각 질의의 정답 레코드에는 원문, 의도, 슬롯, 개념 후보, 질문 필요 여부, 허용되는 정답 표 ID, 기대 상태를 기록합니다. 예를 들어 “금리 알려줘”에는 하나의 정답 표를 지정하기보다, **모호성 때문에 질문해야 한다**는 기대 결과와 허용 가능한 질문 선택지를 기록합니다.

## 두 종류의 평가를 함께 합니다

1. **단계별 평가**
    
    각 컴포넌트가 맞는 결과를 냈는지 측정합니다. 테스트 단계에 정답 슬롯이나 정답 개념을 직접 넣어 주면 해당 컴포넌트 자체의 성능을 볼 수 있습니다.
    
2. **End-to-End 평가**
    
    실제 사용자 질의부터 통계표 후보와 최종 상태까지 이어서 실행합니다. 사용자가 답해야 하는 질의에서는 역질문과 답변 과정도 포함합니다.
    

두 결과를 비교하면 오류 위치를 분리할 수 있습니다. 예를 들어 정답 개념을 입력했을 때 표 탐색은 성공하지만 실제 질의에서는 실패한다면, 탐색기보다 앞 단계의 조건 추출이나 개념 후보 구성이 원인일 가능성이 큽니다.

## 초기 성공 기준

처음부터 하나의 종합 점수로 판단하기보다는, 다음을 우선 확인하는 편이 좋습니다.

- 결과를 크게 바꾸는 지표·기간·비교 조건의 추출 오류
- 적합 표가 있는데도 후보에 넣지 못한 경우
- 표가 없는데 있는 것처럼 진행한 경우
- 질문해야 할 모호성을 확인하지 않은 경우
- 필요 없는 질문 때문에 흐름이 자주 중단되는 경우

특히 통계표 탐색에서는 Top-1 정확도만 보지 않는 게 중요합니다. 정답 표를 상위 후보로 찾아도 에이전트가 다른 표를 최종 선택할 수 있고, 반대로 여러 표가 모두 조건에 맞는 질의도 있기 때문입니다. **후보 재현율, 최종 선택, 무결과 판별, 역질문 판단을 각각 측정**해야 실패 원인을 알 수 있습니다.
