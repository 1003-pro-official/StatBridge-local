# StatBridge v2.2 평가셋(120문항)과 승인 정책 변경

2026-11-03 정리 · ai-assisted · 공개 개발 평가 · 사람의 최종 승인 아님

2026-10-30에 확정한 v2.2 평가셋과 그 기준 변경을 기록한다. 원본 묶음은 `StatBridge_EvalSet_v2.2_AIReviewed_20261030.zip`이며, 질문·정답·기준·검토 문서는 [`eval/min-e2e/v2.2/`](../../eval/min-e2e/v2.2/)에 있다. 예측·점수·관측·화면 캡처와 내장 evidence ZIP은 Git에 넣지 않았다.

## 범위

| 구분 | 내용 |

`v2.2`는 새 제품 실행이 아니라 **기존 120문항 증거를 새 기준으로 재판정한 결과**다. 실행 이력은 [최소 E2E 평가 이력](../../docs/evaluation/min-e2e-history/README.md)의 v2·v2.1 문서를 따른다.

## 승인 정책 변경

최종 사람 승인 절차를 **평가 통과 조건에서 제거**했다. 승인 여부를 조작하거나 일괄 승인한 것이 아니라, 판정을 세 가지로 분리했다.

| 판정 | 뜻 |
|---|---|
| PASS | 규칙과 근거가 충족됨 |
| FAIL | 명백한 불일치 |
| EVIDENCE_GAP | 판정에 필요한 증거가 없음 |

- CQ 의미 검토는 AI가 직접 수행하고 검토 주체·원시 응답 해시·이유를 남겼다(`CQ_review_actor: ai_model`).
- 기존 사람 이미지 판정 18건은 증거로 보존했다(`human_visual_decisions_preserved: 18`).
- AI 판정은 사람의 승인으로 표시하지 않는다.

## 주요 판정

### CQ21-08 — 답변 전 실행 금지 실패

기간 확인 질문 자체는 맞았지만, 실제 응답 observability에 `statistics.execute completed`가 남아 있었다. 이전 관측기가 `bool(output)`만으로 실행 여부를 판단해 놓쳤고, 이번에 trace까지 확인해 FAIL로 정정했다. **출력 그래프가 없다는 것과 데이터 실행이 없었다는 것은 다르다.**

### CQ21-16 — 최신월 동결 증거 공백

원계열 E1000만 202401~202609로 표시되어 가용 종료월 202609와 일치하고 202610을 채우지 않았다. 다만 원래 계약이 요구한 **예측 전 독립 최신월 동결 기록**이 없어 최신성 부분만 EVIDENCE_GAP으로 둔다. 과거 기록을 지금 만들어 채우지 않는다.

### D23 — 요약 지표명 결함 (Judge 오류 설명 철회)

| 월 | 원시 금리차 B−A (%p) | 당월·직전월 평균 (%p) |
|---|---:|---:|
| 2025-01 | 1.57 | 선행월 |
| 2025-02 | 1.55 | 1.56 |
| 2025-03 | 1.68 | 1.615 |
| 2025-04 | 1.64 | 1.66 |
| 2025-05 | 1.62 | 1.63 |
| 2025-06 | 1.66 | 1.64 |

계산은 5개 표시 월 모두 독립 Decimal 검산과 일치했다. 그러나 실제 요약은 2개월 평균을 "금리차의 당월"로 명명했다. 표·제목·계획은 평균이므로 **요약 지표명이 잘못된 제품 결함**이다.

앞선 보고서의 "Judge가 평균을 당월로 바꿨다"는 설명은 철회한다. 실제 응답과 Judge 입력은 바이트 해시로 연결되고 원문도 동일했다. 원래 RAGAS 점수 0.25와 평균 0.952586은 그대로 보존하며, 이번 직접 판정을 표준 RAGAS 재호출 결과로 가장하지 않는다.
