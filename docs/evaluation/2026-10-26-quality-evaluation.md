## 목적과 실행 범위

개발 완료 전 현재 버전의 결함과 검증 한계를 확인했다. 제품 코드와 기존 정답을 수정하지 않고 최초 관측, 하네스 호환 실행, 환경 보정 재실행을 분리했다. 다른 평가 계열의 점수를 합산하지 않는다.

- 평가 대상 커밋: `ef02d2471c5d928f7de1382b2dd5c9db82322e9d`.
- 실제 입력과 적용 지점: [평가 질의 목록](2026-10-26-evaluation-queries.md).
- 실모델 구성요소: 파일럿 8건, 본평가 40건(파생 계획 12·보고서 12·자연어 편집 8·지원 범위 8), 대표 3건의 추가 반복 6회.
- 별도 실험: 공개 Golden v2 dev/test 72건 오프라인 진단, 실제 KOSIS 조회·파생 수치 검산, 한 개 대표 브라우저 업무 흐름, 전체 회귀·빌드.
- 공개 자료만 사용했다. 비공개 평가 저장소·holdout 정답은 열거나 반입하지 않았다.

새 40문항은 개발 진단용이며 사람 승인 골든셋이나 사전 등록된 벤치마크가 아니다. 보고서·편집은 합성 관측값을 사용했으며, 실제 KOSIS 수치와 브라우저 결과는 별도 기록했다. 주제 변형과 반복 실행을 독립적인 통계 주제 수로 세지 않는다. 40문항 전체를 웹 화면에서 실행한 것은 아니다.

## 모델·환경

강한 모델은 `gpt-6.1-sol`, 텍스트 모델은 `gpt-6-luna`를 평가 프로세스에 명시했다. 실제 Responses 응답의 `model` 필드에서 두 ID를 확인했다. 날짜가 고정된 모델 스냅샷 평가는 아니다.

코드상 강한 모델은 파생 계획·의미 검토·보고서·편집에, 텍스트 모델은 폴백이 있는 요약 근거 선택·스타일 제안에 배정된다. 이번 입력 중 규칙이나 폴백으로 끝난 경로는 모델 성공으로 간주하지 않는다. 평가 클론의 로컬 설정에는 이전 모델 값이 남아 있어 프로세스 환경변수로 지정했으며 실제 설정 파일이나 사용 중인 서버는 변경하지 않았다.

원자료는 별도 공급된 CSV 349개다. 클론의 `data/tables` 연결에서 Windows 접근 오류가 발생해 정상 공급 폴더를 평가 프로세스의 `STATBRIDGE_TABLES_DIR`로 지정했다. 공개 출처 검증도 원본 프로젝트의 동일한 공개 연구 자료 경로로 연결했다. 연결 변경과 원자료 복사는 하지 않았다. 계정은 별도 테스트 DB를 사용했다.

## 주요 발견과 수정 우선순위

### 1. 높음: 보고서의 수준값 질문 충실성

본평가 `report-01/02/04`는 특정 월의 수준을 물었지만 변화폭을 답했다. 합성 자료의 3월 가계 금리는 4.9%, 기업 금리는 4.6%, 2월 가계 금리는 5.0%인데 요청한 값을 본문에 제시하지 않았다. `report-03`은 보유한 1월 수준을 묻는데 비교 기준 자료가 없다고 안내했다. `report-12`는 원래 값과 계산식을 요청했지만 일반식만 답했다.

이 5건은 요구 충족 실패라는 AI 잠정 판정이다. 나머지 7건은 변화폭·순위·격차 또는 자료 부족·인과/전망 제한에서 대체로 요청과 맞았다. 정성 검수 전 공식 7/12 성능으로 발표하지 않는다. `report-01`은 동일 입력 총 3회 모두 수준 대신 변화폭을 답했다.

수정 시 수준 조회, 시점 간 변화, 계열 간 격차를 구분하고 필요한 원래 값을 답변에 포함해야 한다. 잘못된 사실과 맞는 숫자로 다른 질문에 답하는 문제를 분리한다.

### 2. 높음: 단위 미확정으로 인한 계산 가용성

경제심리지수 원계열 파생 계획 6건은 생성됐으나 실제 API 단위를 확정하지 못해 계산이 중단됐다. 기본 조회·표·내보내기에서는 단위 위치가 빈 괄호로 표시됐다. 단위를 임의로 넣지 않는 차단은 보호 장치이며, 공식 정의를 확인해 지원 가능 계열을 보완하는 일은 별도 개선이다.

### 3. 중간~높음: 평균 요청의 의미 확인과 반복 일관성

`derived-12`의 두 금리 단순 산술평균은 최초에 각 계열의 월별 12개월 이동평균으로 해석됐다. 추가 2회는 사용자가 지정한 기간 변경 검증 오류로 중단됐다. 평균 축이 모호해 정답을 확정하지 않았다. 월별 두 계열 평균인지 각 계열의 기간 평균인지 확인하는 역질문이 필요한 사례로 검토한다.

### 4. 중간: 기업명 표현과 지원 정책 안내

회사·개인 원자료 문구는 규칙으로 제한됐다. 파일럿의 삼성전자 매출액 혼합 요청은 파일 보완을 제안했고 본평가의 구체화된 요청은 원자료를 찾지 못했다며 제한했다. 서로 다른 입력이므로 확률적 불안정성으로 단정하지 않는다. 명시적 기업명에서도 회사 자료 지원 정책을 일관되게 안내하는지 추가 확인한다.

### 5. 중간: 평가 환경·내보내기 추적성

원자료 경로, 평가기 인증·세션 호환을 제품 결함과 분리해야 한다. 별도 UI 서버의 첫 빌드는 API 기본 주소가 다른 서버를 가리켜 로그인 연결이 실패했고 `VITE_API_BASE_URL=/api` 재빌드 후 같은 출처에서 확인했다. PDF·XLSX에는 기관·표명이 있지만 항목·분류 식별자까지 바로 추적하기 어렵다. 그래프 PNG에는 로컬 자료와 표 ID가 표시됐다.

## 강점과 브라우저 관측

지원하는 자연어 편집 7건에서 제목·범례·색·점선·막대 전환과 원자료 보존을 확인했다. 관측값을 999로 바꾸고 실제 출처를 지우라는 1건은 거부했다. 기대된 거부를 실행 예외라는 이유만으로 실패 처리하지 않는다. 제목+범례 복합 편집은 총 3회 모두 적용됐다.

외부 전용 자료, 회사·개인 원자료, 무근거 예측·인과 단정, 임의 보간·코드 실행 요청에서 계산 완료를 만들어 내지 않았다. 이 소수 요청이 전면적인 보안 통과를 뜻하지는 않는다.

브라우저는 한 대표 흐름에서 로그인 → 경제심리지수 12개월 조회 → 표 전환 → CSV/XLSX/PDF → 그래프 SVG/PNG → 자연어 제목 편집 → 저장 → 새로고침 → 보관함 복원을 확인했다. 여러 확인 지점이 있으며 12개 독립 업무나 사용자 시험이 아니다. 새로고침 시 현재 화면은 자동 복원되지 않았지만 명시적으로 저장한 분석의 제목·기간·12개 관측·편집 기록은 수동 복원됐다. UI는 자동 임시 보관을 하지 않는다고 안내한다.

확대보기 조작은 도구 관측이 불명확해 성공·제품 실패 모두 판정하지 않았다. 초기 다운로드 이벤트가 이전 파일과 섞인 관측은 제외하고 최종 파일 형식·내용을 검사했다.

## 비용과 사람 검토

실제 OpenAI 호출은 파일럿 12회+본평가 73회+추가 반복 16회, 총 101회다. 모든 호출의 사용량을 관측했다. 표준 토큰 가격과 보수적인 입력 요율을 적용한 추정 상한은 약 **1.6031달러**다. 실제 청구액과 남은 크레딧은 조회하지 않았다. 브라우저 제목 변경은 현재 규칙 경로로 처리돼 평가용 모델 transport의 추가 호출 기록이 없었다. KOSIS 호출은 OpenAI 비용에 포함하지 않는다.

가격 근거: [Sol 모델](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Luna 모델](https://developers.openai.com/api/docs/models/gpt-6-luna). cached/cache-write 토큰을 포함한 원장은 로컬 실행 자료로 보존하고 이 PR에는 포함하지 않는다.

정성 기준은 [기존 REVIEW.md](../../eval/statbridge-e2e/v1/REVIEW.md)의 사실성·요구 충족·명료성·출처/한계·시각화·대화/복구 0/1/2 기준을 사용했다. 이 기준을 빌려도 다른 평가 계열의 점수를 합치지 않는다. 로컬에 40건의 관측 해시·AI 메모·빈 사람 평가 필드를 준비했다. 사람 승인은 모두 false다. 팀원은 보고서 5건, 평균 사례, 단위 차단 6건과 정상 표본을 우선 확인하고, 0점·치명 오류·불일치는 두 번째 검수자가 확인한다.

## 재현과 공개 경계

아래는 평가 대상 버전의 기본 검증이다. Windows 명령은 별도 공급된 원자료 폴더를 `STATBRIDGE_TABLES_DIR`에 지정하고, 테스트용 계정 DB를 사용하며, 외부 공급자 키와 Langfuse 내보내기를 자식 프로세스에서 비활성화한 환경에서 실행한다. 키 값은 명령행·문서·출력에 넣지 않는다.

```powershell
$env:PYTHONPATH = 'src/backend;src/agent;tests'
# STATBRIDGE_TABLES_DIR: 검증된 공급 CSV 폴더, STATBRIDGE_AUTH_DB: 별도 테스트 DB
.venv/Scripts/python.exe -m pytest -q tests eval/table-discovery/v4.1/tests
.venv/Scripts/python.exe -m pytest -q tests/test_search_stack.py
.venv/Scripts/python.exe eval/table-discovery/v4.1/scripts/validate_v41.py
Push-Location src/agent/frontend
$env:VITE_API_BASE_URL = '/api'
pnpm build
Pop-Location
```

POSIX 표준 검증 명령은 [CONTRIBUTING.md](../../CONTRIBUTING.md#5-검증과-완료-정의dod)를 따른다. 공개 Golden v2의 검증·실행 명령은 [해당 README](../../eval/statbridge-golden/v2/README.md)에 있다. 기존 실행기를 그대로 실행하면 인증/세션 호환 문제를 다시 만날 수 있다.

이번 실모델·브라우저·경로 매핑 검증은 로컬 평가 래퍼를 사용했다. 실행 래퍼·원장·관측·해시·내보내기 파일은 Git에서 제외된 로컬 평가 폴더에 보존했다. **이 PR만 clone해 동일한 실모델 101회 실행을 그대로 재생할 수 있는 공개 실행기를 제공하는 것은 아니다.** 질의 목록은 공개하지만 프롬프트·모델 출력·평가 결과 JSON·계정 DB·원자료·개인 절대 경로·로컬 파일 링크·생성 이미지는 게시하지 않는다. 재현 지원 시 검수자가 접근 가능한 별도 로컬 자료와 실행 정책을 확인해야 한다.

## 미검증과 후속 작업

사람 정답·해석 승인, 블라인드 최종 평가, 실제 NCP/JEV/벡터 검색 성능, 12개 독립 브라우저 업무, 파일 보완·서버 재시작 복구, 동시 사용자 부하, 실환경 계정 격리 공격, 모바일·키보드·스크린리더 전수 평가가 남았다. 기존 회귀 실행을 실서비스 공격 시험으로 대신하지 않는다.
