### 원인과 조치

1. **HTTP 테스트 대기: 실행 환경의 Windows 로컬 소켓 제한.** Python `socket.socketpair()`를 3초 제한으로 최소 재현했습니다. 제한 실행에서는 `socket.py`의 `accept()`에서 TimeoutError가 발생했고, 로컬 소켓이 허용된 실행에서는 즉시 성공했습니다. 같은 환경에서 이전에 멈춘 차트 전환 HTTP 테스트도 정상 종료했습니다. OS/Python 전역 설정이나 제품의 이벤트 루프를 임의 변경하지 않았습니다.
2. **전체 실행으로 발견한 배치 회귀 1건.** 원자료만 요청하는 확정된 조회 계획에도 `comparison_modes(..., self.resolver.tables)`를 무조건 실행했습니다. 초기화를 생략해 MCP 실행을 독립 검증하는 테스트에서 불필요한 resolver 의존성 때문에 execution error가 발생했습니다. 원자료 모드는 바로 배치 조회하며, 명시적인 증가율·차이 요청만 표별 계산 범위를 판별하도록 수정했습니다. 이는 실제 사용자 질의가 모두 실패했다는 의미는 아닙니다. 별도 계산이 없는 요청의 카탈로그 재탐색을 제거한 변경입니다.
