## 1. 정량 평가 지표

| 단계 | 지표와 계산 방법 | 초기 통과선 |
| --- | --- | --- |
| **A. 자연어 질의와 대화 맥락** | **원문 보존율** = 다음 단계에 원문이 정확히 전달된 질의 수 ÷ 제출된 전체 질의 수. **맥락 전달 정확도** = 골든셋에서 이어받아야 할 조건을 모두, 그리고 새로 언급되지 않은 조건은 변경 없이 전달한 질의 수 ÷ 맥락 의존 질의 수 | 원문 보존율 **100%**. 맥락 전달 정확도 **100%** |
| **B. 의도·조건 추출** | **의도 Macro-F1** = 각 의도 유형별 F1의 평균. **슬롯 정확도** = 지표·기간·대상·비교 조건별로 예측값이 정답과 일치한 수 ÷ 평가 대상 슬롯 수. 값이 없는 슬롯은 `미지정`이 정답. **핵심 슬롯 완전 일치율** = 핵심 슬롯 전체가 맞은 질의 수 ÷ 전체 질의 수 | 의도 Macro-F1 **0.90 이상**. 슬롯 정확도 **0.90 이상**. 완전 일치율 **0.85 이상** |
| **C. 통계 개념 정규화** | **개념 Recall@5** = 허용 개념 후보 중 하나 이상이 상위 5개에 포함된 질의 수 ÷ 개념 후보 평가 질의 수. **근거 유효율** = 후보와 연결된 표 이름·경로·용어 사전 근거가 실제로 존재하는 후보 수 ÷ 전체 출력 후보 수 | Recall@5 **0.95 이상**. 근거 유효율 **0.95 이상** |
| **D. 모호성·충돌 점검** | **필요 질문 재현율** = 골든셋상 질문이 필요한데 실제 질문한 질의 수 ÷ 질문이 필요한 전체 질의 수. **질문 정밀도** = 실제 질문한 질의 중 질문이 필요했던 수 ÷ 실제 질문한 전체 질의 수. **불필요 질문률** = 질문이 불필요한데 질문한 질의 수 ÷ 질문이 불필요한 전체 질의 수 | 재현율 **0.95 이상**. 정밀도 **0.85 이상**. 불필요 질문률 **0.15 이하** |
| **E. 사용자 확인** | **답변 반영 정확도** = 사용자가 선택·입력한 조건을 정확히 Query Plan에 반영한 답변 수 ÷ 확인 답변 수. **확인 완료율** = 답변 후 모든 필수 모호성이 해소된 사례 수 ÷ 답변을 받은 사례 수. **질문 수** = 확인을 완료하는 데 든 질문 수의 중앙값 | 반영 정확도 **0.95 이상**. 완료율 **0.90 이상**. 질문 중앙값 **2 이하** |
| **F. 데이터 전략 수립** | **전략 유형 정확도** = 단일 지표, 복수 지표, 계산 필요, 지원 범위 밖 등 골든셋의 전략 유형과 일치한 질의 수 ÷ 전체 전략 평가 질의 수. **필수 점검 포함률** = 골든셋에서 요구한 주기·단위·기간·계열 검사를 모두 계획에 넣은 질의 수 ÷ 해당 점검이 필요한 질의 수 | 전략 유형 정확도 **0.90 이상**. 필수 점검 포함률 **0.95 이상** |
| **G. 도구 실행계획 작성** | **필수 도구 포함률** = 계획에 필요한 모든 도구가 포함된 질의 수 ÷ 도구 계획 평가 질의 수. **순서 적합률** = 필요한 선후 관계를 모두 지킨 계획 수 ÷ 계획 수. **미허용 도구율** = 정의되지 않은 도구가 포함된 계획 수 ÷ 전체 계획 수 | 필수 도구 포함률 **0.98 이상**. 순서 적합률 **1.00**. 미허용 도구율 **0%** |
| **H. 계획 검증** | **무효 계획 차단율** = 오류 계획 중 검증기가 거부한 수 ÷ 골든셋의 무효 계획 수. **유효 계획 통과율** = 유효 계획 중 검증기가 통과시킨 수 ÷ 골든셋의 유효 계획 수. 스키마 오류·잘못된 도구·필수 인자 누락·잘못된 단계 순서를 각각 별도 집계 | 무효 계획 차단율 **1.00**. 유효 계획 통과율 **0.98 이상** |
| **I. 통계표 탐색으로 전달** | **전달 필드 완전율** = 원문·조건·사용자 선택·검색어·계획 상태·카탈로그 버전이 모두 전달된 질의 수 ÷ 전체 전달 질의 수. **조건 일치율** = 전달된 조건이 최종 검증된 Query Plan과 일치하는 수 ÷ 전달 조건 수 | 필드 완전율 **1.00**. 조건 일치율 **1.00** |

표 탐색 자체는 I의 다음 단계이므로 별도 지표를 둡니다.

| 탐색 결과 지표 | 계산 방법 | 초기 통과선 |
| --- | --- | --- |
| **표 Recall@5** | 골든셋의 허용 표 ID 중 하나 이상이 상위 5개 후보에 포함된 질의 비율 | **0.95 이상** |
| **Top-1 정확도** | 1순위 표가 허용 표 ID인 질의 비율 | **0.85 이상** |
| **무결과 F1** | 적합한 표가 없는 질의를 정확히 `NO_MATCH`로 판정한 정밀도·재현율 조화평균 | **0.90 이상** |
| **복수 표 집합 재현율** | 골든셋에 지정된 필수 표 중 탐색 결과에 포함된 표의 비율 | **0.95 이상** |

## 2. 정성 평가 지표

정성 평가는 동일한 1–5점 척도를 사용하되, 단계별 판단 기준을 고정합니다. 아래 표의 1·3·5점은 채점 예시이며, 2점과 4점은 인접한 기준 사이로 채점합니다.

| 단계 | 평가 항목 | 1점 | 3점 | 5점 |
| --- | --- | --- | --- | --- |
| **A. 입력** | 입력 편의·안내 적절성 | 질문을 어떻게 써야 할지 모르겠거나 통계 용어를 요구함 | 예시가 있으나 사용자의 질문 유형과 잘 맞지 않음 | 일상어로도 질문할 수 있음을 알리고 관련 예시를 간결하게 제공 |
| **B. 해석** | 의도 충실성·추정 절제 | 사용자의 의도나 핵심 조건을 잘못 바꿈 | 주요 의도는 맞지만 한 조건의 의미가 불분명하거나 과하게 추정됨 | 핵심 의도를 정확히 반영하고 불명확한 조건은 미지정으로 보존 |
| **C. 개념 후보** | 통계적 타당성·근거성 | 카탈로그나 사전 근거가 없는 개념을 제시 | 관련 후보는 찾았지만 후보 간 구분 또는 근거가 약함 | 후보가 카탈로그·사전 근거와 연결되고 구분 기준도 명확 |
| **D. 모호성 판단** | 질문 필요성·질문 품질 | 중요한 모호성을 놓치거나 무관한 질문을 함 | 필요한 점은 물었지만 질문 이유나 구분이 불분명 | 결과를 바꾸는 쟁점만 정확히 짚고 질문 이유가 설명됨 |
| **E. 사용자 확인** | 선택의 명확성·응답 반영 | 선택지가 겹치거나 답변을 계획에 반영하지 않음 | 선택은 가능하나 차이 설명 또는 자유 입력이 부족 | 선택지가 서로 구분되고, 추천 이유와 직접 입력이 제공되며 답이 정확히 반영됨 |
| **F. 데이터 전략** | 계획의 통계적 타당성 | 필요한 주기·단위·기간 검사를 누락 | 주요 검사는 있으나 일부 병합 위험을 놓침 | 필요한 메타정보와 정합성 위험을 빠짐없이 계획 |
| **G. 도구 계획** | 실행 가능성·효율성 | 정의되지 않은 도구 또는 실행 불가능한 순서 | 실행 가능하지만 중복 호출이나 목적 설명 누락이 있음 | 각 도구의 목적과 순서가 분명하고 필요한 호출만 포함 |
| **H. 계획 검증** | 차단·오류 설명 품질 | 무효 계획을 통과시키거나 원인을 숨김 | 계획은 차단하지만 다음 조치가 불명확 | 오류를 차단하고 원인과 수정할 필드를 구체적으로 표시 |
| **I. 전달** | 추적 가능성·다음 단계 활용성 | 다음 단계가 질의를 재구성해야 할 정도로 정보가 부족 | 핵심 조건은 있지만 근거나 버전 등 일부 정보가 빠짐 | 조건·후보 근거·사용자 선택·카탈로그 버전이 함께 전달됨 |

정성 점수는 두 명이 독립 채점하는 것을 권합니다. 채점자 간 점수 차이가 2점 이상이면 근거를 검토해 조정하고, 특정 항목에서 반복적으로 의견이 갈리면 해당 채점 기준을 먼저 고칩니다. 종합 시에는 **단계별 평균 점수와 1점 응답 비율을 함께** 보고, 평균이 높아도 핵심 단계에서 1점 사례가 반복되면 통과시키지 않는 것이 좋습니다.

## 3. 골든셋과 비교 실행 규칙

공정한 도구 비교를 위해 다음 조건을 고정합니다.

- 같은 질의 원문과 대화 맥락
- 같은 허용 개념·표 ID 집합과 기대 질문 라벨
- 같은 카탈로그 스냅샷과 메타정보 기준일
- 같은 검색 대상 텍스트(표 이름·경로·용어 사전)
- 같은 상위 후보 수 `k`
- 같은 LLM 프롬프트·JSON 스키마·온도 설정
- 같은 도구 목록과 실행 순서 제약

결과는 모델 하나의 종합 점수로만 정리하지 말고, 예를 들어 `HCX-007: 슬롯 F1 / 질문 재현율 / 계획 유효율 / 지연시간 / 비용`처럼 **성능표를 단계별로** 작성합니다.

## 4. 최종 통과 판정

권장 판정 방식은 다음과 같습니다.

1. **필수 안전·정합 조건:** 원문·사용자 선택 보존, 무허용 도구 차단, 계획 검증은 100% 기준으로 둡니다.
2. **정량 기준:** 각 단계의 초기 통과선을 적용합니다.
3. **정성 기준:** 단계별 평균이 4점 이상이고, 핵심 항목에서 반복적인 1점 응답이 없어야 합니다.
4. **비용·속도 비교:** 정확도와 정성 품질을 통과한 후보끼리 API 비용과 응답시간을 비교합니다.

특히 모델·임베딩·리랭커 비교에서는 **단계별 정답률을 먼저 통과 기준으로 삼고, 정성 점수와 비용·지연시간으로 최종 선택**하는 방식이 오류 원인을 가장 잘 드러냅니다.
