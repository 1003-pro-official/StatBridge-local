## 1주 차에 먼저 합의할 것

1. **골든셋 형식:** 질문마다 `질문 / 유형 / 정답 표 ID / 항목·기간 / 기대 결과 / 출처 / 채점 기준`을 기록한다.
2. **파트 간 데이터 형식:** Backend가 `표 ID / 시점 / 값 / 단위 / 사용한 항목 / 가공 방식`을 전달하고 Agent가 이를 결과에 표시한다.
3. **수치의 기준:** 최종 표·그래프의 수치는 KOSIS Open API 응답을 기준으로 한다. 수집된 CSV는 탐색·개발용으로 활용한다.
4. **현재 수집 범위:** 목록 349개 중 CSV는 347개다. `DT_284Y001`, `DT_284Y002`는 누락 표로 표시하고 평가 문항을 만들 때 구분한다.

## 평가 운영 원칙

- 검색, 조회·병합, 시각화·설명, 전체 흐름을 나누어 측정한다.
- 표를 찾지 못하는 질문에서는 근거 없는 수치를 제시하지 않는지도 평가한다.
- 5주 차에 평가 문항을 고정하고, 6주 차 개선 전후에 같은 문항을 사용한다.
- 매주 하나의 공통 질의로 세 파트의 연결 상태를 확인한다.
