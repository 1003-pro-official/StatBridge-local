샘플과 픽셀 단위로 동일하거나 원래 수치를 재현했다고 주장하지 않는다. 벤치마크 예제 파일의 모든 수치·구간·이벤트는 합성이고 실제 한국은행 통계와 구분한다.

## 유형별 지원

필수 8종은 Plotly, ECharts 변환, Matplotlib 인쇄 경로를 구현했다. 팬은 제공된 경계가 필수이고, 기여도는 자료 의미 확인, 이중 축은 역할 지정, 회귀는 동일 시점 3쌍 이상·서로 다른 X가 필요하다. 원래 워터폴 수준 값을 차분해 표시하며 원자료 수준도 문서에 유지한다.

확장: 히트맵·바이올린·누적 영역·시나리오·버블 구현. 바이올린은 ECharts에 조용히 박스로 대체하지 않고 미지원 안내한다. 점도표·수익률 곡선·금융 네트워크는 16유형 스키마에 예약했지만 전용 투표자·만기·관계 데이터 어댑터가 없어 생성은 거부한다. 계열 숫자만으로 임의 네트워크나 금리 만기를 만들어내지 않는다.
