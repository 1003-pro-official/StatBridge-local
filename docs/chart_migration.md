# 기존 기능 호환과 마이그레이션

Plotly, 기존 14종 그래프, 기존 API 요청·응답의 필수 필드를 유지한다. ChartSpec에 `report`가 없거나 null이면 기존 렌더러를 그대로 사용한다. ReportOptions는 `set_report` 또는 직접 report 입력으로만 활성화한다. 초기 검색·조회·기간 확인·출력 선택은 기존 흐름이다.

새 출력에는 선택적으로 `reportDocument`, `echartsOption` 또는 `echartsUnavailable`이 추가된다. 기존 클라이언트는 이를 무시할 수 있다. 기존 그림판·메모·이모티콘은 주 Plotly 차트에 남는다. 직접 보고서 설정에도 현재 버전의 미적용 이모티콘을 전달한다.

명세 JSON은 같은 관측 자료를 다시 조회한 세션에 복원할 수 있다. 현재 자료와 표 참조·출처·버전·값이 다르면 거부한다. 서버 재시작 후 편집 세션 자체는 없어지므로 다시 조회하고 JSON을 복원해야 한다. 사용자 데이터베이스·로그인별 서버 저장소·CSV 임의 업로드는 이번에 추가하지 않았다.

명시적 일반 차트 종류 변경은 보고서 모드를 해제한다. “일반 그래프 복원”도 같은 역할이며 undo로 보고서 상태를 다시 가져올 수 있다. 다른 엔진에서 구현하지 않은 위치 스타일은 오류/미지원 안내로 처리하고 축·이미지를 조용히 삭제해서 출력하지 않는다.

Windows 런처는 Matplotlib/pypdf와 ECharts를 검사해 기존 설치에서도 누락 의존성을 설치한다. Python 의존성은 `src/backend/requirements.txt`, 프런트 잠금은 pnpm-lock.yaml에 기록한다. 파일 출력은 한국어 시스템 폰트가 필요하며 폰트 원본은 배포하지 않는다.

전년 대비 표시 변환은 이제 확인된 주기의 **전년 동일 시점**에 맞춘다. 월/분기 코드가 같아 보이는 경우 주기 메타데이터로 구분하고, 결측 전년·분모 0은 계산하지 않는다. 원자료를 0으로 채우지 않는다. 이전 관측 대비 증가율과 누적 합계는 별도의 기존 변환으로 남는다.
