# 부족 자료 안내와 다중 형식 업로드 · ai-assisted

## 구할 곳 안내

2026-10-19 공식 사이트를 확인해 KOSIS, 한국은행 ECOS, 공공데이터포털의 고정된 공식 URL만 안내합니다. 모델이 만든 URL이나 임의 외부 API로 연결하지 않습니다. 일반 통계에는 자료명 검색어와 항목·지역·기간·주기·단위·기준연도를 확인할 체크리스트를 표시합니다. 링크는 **공식 사이트 검색 후보**이며 해당 지표·기간의 파일 제공을 검증했다는 뜻이 아닙니다.

- KOSIS: <https://kosis.kr/>. 조회표에서 파일을 받을 수 있습니다. [공식 다운로드 안내](https://mgmk.kosis.kr/civilComplaint/kosisGuideIndex.do?q_no=5).
- 한국은행 ECOS: <https://ecos.bok.or.kr/>. 경제·금융 통계의 검색 후보로 안내합니다.
- 공공데이터포털: <https://www.data.go.kr/>. 공공 파일데이터의 검색 후보로 안내합니다.
- 가상·합성 지수: 공식 다운로드 URL이 있는 것처럼 안내하지 않습니다. 사용자가 지정한 시험값과 산정 기준을 직접 준비하도록 설명합니다.
- 사내·개인 자료: 회계 장부·원가 관리 등 보유 원자료에서 확인하도록 안내합니다.

KOSIS는 [OpenAPI 안내](https://sso.kosis.kr/serviceInfo/openAPIGuide.do)에서 JSON 등 여러 제공 형태를 설명합니다. 제공기관이 지원하는 형식과 이 앱이 받는 파일 구조는 다릅니다. 현재 앱은 아래 구조로 정리된 파일을 받습니다. API 조회 범위는 기존 한국은행 승인 349개 표 그대로입니다. 외부 자료는 사용자가 명시적으로 업로드한 별도 자료로 표시합니다.

## 지원 파일과 양식

| 형식 | 입력 구조 | 빈 양식 |
|---|---|---|
| CSV | UTF-8, 첫 행은 필드명 | 제공 |
| JSON | 필수 필드 5개를 가진 관측값 객체의 배열 | 제공 |
| TSV | UTF-8, 탭으로 구분, 첫 행은 필드명 | 제공 |
| XLSX | 시트 하나, 첫 행은 필드명, 이후 관측값 | CSV를 엑셀에서 열어 XLSX로 저장 |

필수 필드는 `period,value,unit,frequency,source`입니다. JSON 필드 순서는 자유지만 다른 필드는 허용하지 않습니다. CSV/TSV/XLSX는 열 순서를 유지합니다. 일별 시점은 `20230102`, 주기는 `D`이며 월별은 `202301`/`M`입니다. Q/S/Y는 기존 시점 규칙을 따릅니다. 최대 12개 입력과 12개 출력 계열을 지원합니다. 일별 시차·이동평균은 달력일 기준이며 휴일·결측을 채우지 않습니다. 전년비는 전년 같은 월일을 사용하고 전년에 대응 날짜가 없는 2월 29일은 결측 처리합니다. 단위와 출처는 모든 관측값에 필요합니다. 제목·주석·병합 셀이 있는 제공기관 원본은 양식으로 정리해 주세요. 빈 값은 임의로 채우지 않습니다.

파일당 원본 2MB, 시계열당 6,000행, 한 가지 단위·주기 조건을 유지합니다. 업로드는 원본 바이트를 전달해 SHA-256을 계산하며 원본 확장자로 불변 저장합니다. 기존 CSV 텍스트 업로드 계약도 호환됩니다. 텍스트 붙여넣기는 선택한 CSV/JSON/TSV 형식을 사용합니다. `encoding=base64`는 파일 바이트, `utf8`은 붙여넣기 텍스트입니다. API content 길이는 base64 전송 여유를 포함하지만 원본 2MB 제한은 별도 적용합니다.

XLSX는 읽기 전용 파서로 열며 수식을 계산하지 않습니다. 수식·오류 셀·매크로·외부 링크·XML 엔터티·암호화 파일·과도한 행/열·압축 해제 8MB 초과·ZIP 항목 128개 초과를 차단합니다. 값으로 저장한 파일을 사용해 주세요. PDF·이미지·HWP·DOCX·구형 XLS는 지원하지 않습니다. 신뢰할 수 없는 문서에서 숫자를 추측해 계산에 넣지 않습니다.

## 화면

중복 오류 안내를 제거하고 준비된 API 자료, 필요한 자료의 조건, 구할 곳, 양식 다운로드, 파일 드롭/선택, 연결 완료 상태와 계산 버튼을 구분했습니다. 긴 모델 설명과 자세한 입력 규칙은 접어서 확인합니다. 작은 화면에서는 업로드 영역을 한 열로 배치합니다. 사용자 파일·API 출처와 이전 계산의 불변 근거는 기존 흐름을 유지합니다.

검증 결과와 실행 범위는 `eval/derived_files_v8_results.json`에 기록합니다. 이전 v7 모델 평가 결과를 이번 UI/파일 변경 이후의 300건 모델 평가로 재표기하지 않습니다.
