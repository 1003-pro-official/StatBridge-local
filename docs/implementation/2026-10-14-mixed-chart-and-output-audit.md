# 2026-10-14 그래프·표 출력/편집 점검 및 혼합 차트 확장 (ai-assisted)

## 구현
두 폴더의 스냅샷 그래프, 첨부 표 스타일 팩 6종, 화면 편집 → 저장/복원 → 파일 내보내기 경로를 확인했습니다.

차트 종류 선택기에 시간축 혼합 7종(선·막대, 선·영역, 막대·영역, 선·막대·영역, 선·누적 막대, 영역·누적 막대, 선·영역·누적 막대)을 추가했습니다. 지표별 선/막대/영역을 따로 지정할 수 있습니다. 같은 주기, 지표별 2개 이상 관측값, 최대 두 단위에 한해 표시합니다. 누적 막대는 동일 단위·동일 시점 및 막대 두 계열 이상이 필요합니다. 초기 모양은 지표 순서에 따라 지정하며 이후 변경할 수 있습니다.

실제 같은 시점 관측쌍 3개 이상이고 X값에 변동이 있는 두 지표에는 산점도·회귀선도 주 메뉴에서 제공합니다. 기존 팬 차트(실제 구간 자료 필요), 관측점 표시 설정은 고급 편집/선 스타일에서 유지합니다. 원·도넛·트리맵을 시간축 차트와 임의로 겹치는 기능은 제공하지 않습니다.

새 STYLE_EDIT 명령 set_series_chart_types는 params.types={조회된 지표 이름: line/bar/area}로 모양을 일괄 지정합니다. 조회되지 않은 이름, 다른 종류, 잘못된 전달 구조는 거부합니다. 10개 이상 지표도 4~5개 명령으로 처리해 기존 12개 명령 제한을 넘지 않습니다. 조회값·단위·주기는 바꾸지 않습니다.

## 발견 및 보완
- UI에 없던 혼합 선택기와 지표별 선택을 연결했습니다.
- 영역 혼합이 벡터 인쇄에서 거부되거나 보고서 표현에서 모양을 잃는 경로를 수정했습니다. ECharts도 area를 line+areaStyle로 표현합니다.
- 인쇄에서 여러 막대가 겹치지 않도록 같은 축의 막대만 나란히/누적 배치합니다. 선·영역은 누적 합계에 넣지 않습니다.
- 누적 막대의 최신값 레이블은 누적 상단에 배치하되 실제 해당 지표의 관측값을 표시합니다.
- 보고서 이중축을 일반 선·막대로 바꿀 때 오른쪽 축 연결을 유지합니다. 누적 혼합에서 일반 막대로 바꾸면 나란히 배치로 되돌립니다. 같은 누적 막대를 다시 지정하는 요청은 기존처럼 변경 없음으로 처리합니다.
- 표 양식 추가 전 저장 JSON도 default 양식/빈 강조 목록으로 복원됩니다. 실제 수치/출처 불일치나 임의 필드는 계속 거부합니다.
