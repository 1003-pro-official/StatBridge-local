# 추천 질문·메뉴·PNG 다운로드 수정 (ai-assisted)

추천 버튼은 기간(2020-01~2025-12), 실제 표 이름 및 분류가 포함된 완전한 질문을 입력합니다. 현재 예시는 결제통화 수입 비중(호주, 달러, 비중), 생산자물가지수(기본분류, 총지수), 예금은행 대출금리(신규취급액 기준, 대출평균), 국제수지(경상수지)입니다. 두 실행 서버의 네 예시 모두 추가 분류 질문 없이 한 계열을 조회하고 그래프 종류 선택 단계로 진행했습니다. 조회 결과를 미리 만들어 넣지 않으며 기존 UI → Agent → MCP 조회 흐름을 사용합니다. 같은 분석 화면으로 이동하던 자연어 질의 메뉴를 제거했습니다.

워크스페이스 PNG는 서버 인쇄 렌더러 대신 현재 응답의 Plotly 명세 전체를 임시 렌더링해 저장합니다. 제목·범례·축·자동 하단 설명을 보존하며 화면용 SVG의 일부만 복사하지 않습니다. 원·도넛·트리맵도 동일 경로를 사용합니다. PNG 생성용 DOM은 성공/실패 후 정리하고, 파일 링크의 객체 URL은 다음 출력이나 그래프 변경/화면 종료 때 해제합니다. 다운로드용 링크를 DOM에 연결하여 클릭하며 진행 상태·완료 링크·오류는 워크스페이스 상단에 표시합니다. 브라우저가 자동 다운로드를 막아도 사용자는 완료 링크로 직접 저장할 수 있습니다. 채팅의 단독 출력 요청도 동일한 함수를 사용합니다. SVG/PDF/JSON의 기존 서버 경로는 유지합니다.

검증: 두 프런트엔드 타입 검사·빌드 및 Node 73개 통과. 전체 백엔드 회귀 local1 875개, StatBridge1 866개 및 각각 355 subtests 통과. 공개 평가 자료 검증도 양쪽 통과했습니다. 브라우저에서 중복 메뉴 제거, 추천 질문 입력/실데이터 조회, local1과 StatBridge1의 PNG 다운로드 파일 생성을 확인했습니다. 한 계열/네 계열 선 그래프와 원/도넛/트리맵 PNG 파일을 내려받아 바이너리 무결성을 확인하고, 선·원 그래프의 실제 이미지를 검사했습니다. 모든 차트 종류·편집 조합의 실물 출력 전수 검사는 포함하지 않습니다.

새 의존성이나 CMD 변경은 필요하지 않습니다. 설정·API 키·계정·저장 그래프는 폴더 간 복사하지 않았습니다.
