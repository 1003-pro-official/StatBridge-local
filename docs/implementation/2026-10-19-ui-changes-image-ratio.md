# 2026-10-19 UI와 이미지 비율 변경 정리

이 문서는 오늘 요청에 따라 반영한 화면과 관련 동작을 정리한다. ai-assisted 작업이며 사람의 코드 검토 전이다. 기존 기능 브랜치에서 작업했으며 커밋·푸시·머지는 하지 않았다.

[기존 UI 변경 정리](2026-10-19-ui-changes.md)를 바탕으로 그래프와 보고서 이미지의 기본 비율, 크기 조절, 저장 시 비율 유지 내용을 추가한 문서다. 원본의 검증·배포 기록은 당시 실행 기록으로 보존하며, 이번 작성에서 다시 확인한 결과는 별도로 구분한다.

## 상단 도구와 편집 단축키

- 분석 작업 상단에는 **파일 내보내기**만 남겼다.
- 실행 흐름, 되돌리기, 다시 실행, 분석 저장, 분석 설정 버튼과 실행 근거 모달 진입점을 제거했다.
- **Ctrl+Z**는 그래프 편집을 되돌리고 **Ctrl+Y**는 취소한 편집을 다시 적용한다. 기존 서버 편집 이력을 사용하므로 데이터·기간·스타일 복원이 함께 동작한다.
- 입력창·텍스트 영역·편집 가능한 텍스트에서는 브라우저의 텍스트 되돌리기를 유지한다. 다른 영역이나 모달에서 단축키를 가로채지 않는다.
- 수정·파일 생성 중이거나 해당 이력이 없으면 이력 변경을 실행하지 않는다. 키를 길게 누르거나 응답 전에 반복 입력해도 요청이 중복 실행되지 않는다.
- 계정별 대화 보관과 파일 내보내기는 유지한다. 고급 그림판의 편집 도움말과 세부 편집 기능도 유지한다.

## 속성 창 정리

표시 값 · 전년동기 비교, 차트와 디자인, 축 설정, 막대 간격, 제목 · 범례, 선 · 데이터 색상, 눈금 · 격자, 기간 강조, 주석 등의 속성을 접고 펼칠 수 있는 그룹으로 정리했다. 기본은 접힌 상태이며, 그래프의 제목·선·축·주석을 선택하면 해당 속성을 펼쳐 이동한다. 일반 재렌더링에서는 사용자가 펼친 상태와 입력값을 유지한다.

`속성을 선택해 편집하세요` 안내 배너와 버튼의 `간행물형` 문구를 제거했다. 관측 요약 아래의 `문장별 수치·계산 근거 확인` 펼침 영역도 제거했다.

## 원자료와 전년동기 비교 그래프

`2020=100`인 지수 수준과 전년동기 대비 증감률(%)을 구분하는 표시 값 선택을 추가했다. 전년동기 대비는 `(현재 값 ÷ 전년 같은 기간 값 - 1) × 100`으로 계산한다. 필요한 전년도 자료는 같은 통계표·항목·분류로 MCP에서 조회한다. 비교값이 없거나 0이면 계산하지 않으며 이미 증감률인 자료를 다시 변환하지 않는다.

**전년동기 막대그래프**는 연한 파란 막대, 양쪽 동일한 세로축 눈금, 상단 단위, 간결한 월 표시를 적용한다. 연간 점선은 같은 계열의 당해·전년 공표 연간지수가 있고 표시 기간에 한 해 전체가 있을 때만 계산한다. 월별 지수의 단순 평균이나 간행물 수치로 대신하지 않는다.

PNG는 화면 형식을 반영하며 CSV는 계산된 표시 값으로 내보낸다. 편집 이력을 이동하면 전년도 비교 자료도 함께 복원한다. 일반적인 `추이` 질문은 원자료 의미를 유지한다.

## 참고 그래프 이미지로 수정

- 이미지 편집 요청은 본문 수신까지 최대 180초를 기다리도록 일반 조회의 20초 제한과 분리했다. 분석 중 진행 안내를 표시하며 실패하면 요청 문장과 첨부 파일을 유지한다.
- 참고 이미지의 형식과 현재 실제 데이터를 함께 사용한다. 이미지에서 읽은 숫자를 관측값으로 복사하지 않는다.
- 참고 범례가 같은 통계 계열군의 세부 품목을 명시하면 정식 카탈로그 분류를 찾아 MCP 원자료를 조회한다. 수출/수입, 물량/금액/가격을 구분하고 누락 품목을 총지수로 대신하지 않는다.
- 여러 선의 색·점선·빈 원형 관측점, 내부 범례, 양쪽 축, 상단 단위, 기간 강조와 내부 주석을 적용할 수 있도록 보완했다. 데이터와 형식을 함께 적용하고 되돌릴 수 있다.
- 참조 이미지와 현재 그래프의 계열 수가 다른데 선 색만 바꾸고 완료했다고 처리하던 경우를 보완했다. 다만 이미지의 모든 장식과 공표되지 않은 전망값까지 자동 재현하는 기능은 아니다.

## 관측 요약과 보고서 초안

**근거를 연결한 보고서 초안**을 **보고서 초안**으로 바꿨다. 현재 그래프와 그 아래 간략한 설명·출처가 들어간다. 설명의 근거와 작성 기준은 별도 접기 영역으로 정리했다.

사용자가 제공한 2026년 8월 경제전망보고서의 한국은행 단독 출처 그래프 설명을 참고하여 최근 흐름·주요 수치·비교를 중심으로 짧게 작성하도록 했다. 과거 보고서의 원인 해석·전망을 현재 자료에 옮기지 않는다. 초안은 현재 표시 기간·숨긴 계열·증감률 변환을 반영하고, 원자료 관측 요약과 구분한다.

수치와 설명 후보는 서버가 계산한다. GPT-5.4는 검증된 설명의 ID를 선택하며 자유롭게 관측값·원인·전망을 만들지 않는다. 모델 호출이 실패하거나 잘못된 응답이면 동일한 근거의 기본 설명을 사용한다. 이미지 수정은 별도의 이미지 분석 경로를 사용한다.

보고서 생성에는 API와 그래프 PNG 생성을 포함한 제한 시간을 두었다. 작성 중 그래프 버전이 바뀌면 오래된 결과를 적용하지 않는다. 재생성에 실패하면 이전에 완성된 미리보기를 유지한다.

## PDF 저장과 이미지 비율

기존의 **인쇄 · PDF 저장**은 브라우저 인쇄창만 열었다. 이를 **HTML 저장**, **PDF 저장**, **인쇄**로 분리했다. PDF 저장은 실제 A4 PDF를 바로 다운로드한다.

현재 그래프 PNG와 서버가 보관한 초안 설명을 합치며 저장할 때 모델이나 KOSIS를 다시 호출하지 않는다. 로그인 소유권·편집 버전·초안 ID를 확인한다. 이미지 가로세로 비율을 유지하고 긴 설명은 다음 페이지에 이어진다. HTML에서도 최대 너비와 자동 높이로 비율을 유지한다.

이전 PDF 검증에서는 PNG 1400×634의 비율과 PDF 안의 배치 비율이 모두 2.208202로 일치했다. 한국어 제목·출처·설명을 포함한 1쪽 PDF를 렌더링해 확인한 당시 기록이며, 이후 적용한 전년동기 출판용 그래프의 기본 크기는 아래와 같다.

### 기본 그래프 비율과 저장 크기

- 전년동기 출판용 막대그래프의 기본 크기를 **715×662px**, 가로:세로 약 **1.08:1**로 맞췄다. 화면·PNG·보고서 초안에서 같은 비율을 사용한다.
- 브라우저 창이나 그래프 패널의 너비가 바뀌어도 출판용 그래프의 이미지 비율을 창 비율로 바꾸지 않는다. 화면에는 사용 가능한 너비에 맞춰 축소해 표시한다.
- 일반 그래프는 현재 표시된 그래프의 가로세로 비율을 보고서 이미지에 반영한다. 보고서 이미지를 일괄적으로 너비 1400px에 맞춰 늘리지 않는다.
- 과거에 저장한 전년동기 출판용 그래프에 너비 정보가 없고 기존 520px 높이만 남아 있으면 기본 비율로 보정한다. 사용자가 너비와 높이를 명시한 그래프는 해당 설정을 유지한다.

### 보고서 그래프 크기 조절

보고서 초안을 작성한 뒤 **보고서 그래프 크기**에서 너비와 높이를 입력하고 **크기 적용**을 누르면 이미지를 다시 생성한다.

| 항목 | 동작 |
|---|---|
| 너비 | 400~2400px 범위의 정수 |
| 높이 | 280~10000px 범위의 정수 |
| 비율 유지 | 기본으로 켜져 있다. 너비 또는 높이를 바꾸면 반대쪽 크기를 원래 비율에 맞춰 계산한다. |
| 비율 유지 해제 | 너비와 높이를 각각 지정할 수 있다. |
| 원래 크기 | 초안을 처음 생성했을 때의 크기로 되돌린다. |

지원 범위에 맞춰 자동으로 크기를 조절해야 할 때는 두 축을 같은 배율로 조정한다. 한쪽 축만 잘라 비율이 달라지는 것을 방지하며, 픽셀 정수 반올림에 따른 차이는 있을 수 있다. 범위를 벗어나는 직접 입력은 적용 전에 안내한다.

### 미리보기와 파일 저장

- 초안 미리보기, 저장 HTML, 인쇄, PDF에 적용한 이미지 크기와 비율을 전달한다. 문서나 용지 너비에 맞춰 이미지를 축소해도 비율을 유지한다.
- HTML 이미지에 실제 너비·높이를 기록하고 `width:auto`, `height:auto`, `max-width:100%`, `object-fit:contain`으로 표시한다.
- PDF 저장 요청에는 `image_width`, `image_height`를 함께 보내며 서버가 PNG의 실제 픽셀 크기와 대조한다. 두 항목을 생략한 기존 요청은 초안의 원래 비율로 검증한다.
- 이미지 크기를 바꾸는 동안 그래프가 수정되면 이전 버전의 결과를 반영하지 않는다.

## 경상수지 조회 기간 오류

첫 질문의 검증된 조회 계획이 기간 선택 후 재전송되는 과정에서 다른 표 이름 조건으로 확장되어 일치 검사를 실패하던 문제를 수정했다. 같은 질문의 기존 계획을 다시 검증해 유지한다. 명시한 원계열·계절조정·표 ID 조건과 위조된 분류 값도 검사한다.

실제 KOSIS에서 `경상수지 원계열`은 `DT_301Y013`으로 선택되고 기간 재입력 후 출력 설정 단계로 진행했다. 간행물 그림의 연간 복합 그래프와 2026·2027년 전망치까지 월별 관측값만으로 재현되는 것은 아니다.
