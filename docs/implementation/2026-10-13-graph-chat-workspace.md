# 그래프 대화 워크스페이스 (2026-10-13, ai-assisted)

## 사용자 흐름

데이터와 모든 그래프 편집 제어를 왼쪽 패널에 모았습니다. 중앙은 그래프이며 오른쪽은 대화 말풍선, 편집 기록, 참고 파일 및 전송 입력창입니다. 모바일에서는 그래프와 제어, 채팅을 세로로 배치합니다.

- 사용자가 채팅하지 않고 제목, 색, 데이터, 기간, 보고서 설정 등을 바꾸어도 성공한 실제 편집 결과를 대화 기록에 남깁니다. 되돌리기/다시 실행도 기록합니다.
- 대화는 그래프 편집 세션별, 로그인 계정별로 브라우저에 저장하며 새로고침 후에도 표시됩니다. 전체 기록을 표시하고 모델에는 최근 40개 메시지와 최신 차트 상태를 제공합니다. 이전 요청을 다시 실행하지 않는 서버 규칙을 유지합니다.
- 새 채팅 시작 또는 다른 그래프의 조회 결과 전환 시 이전 대화 저장/삭제/취소를 선택합니다. 조회 실패는 이전 그래프와 대화를 유지합니다.
- 저장한 그래프 대화 목록에서 다시 열거나 삭제할 수 있습니다. 새 대화에는 이전 그래프의 대화 맥락을 보내지 않습니다.
- 대화 저장 시 현재 그래프도 기존 서버 저장 API로 저장합니다. 기존 서버 계정 저장 한도 5개를 유지합니다. 서버 저장이 실패해도 브라우저 대화와 그래프 사본은 보존하고 안내합니다.
- 대화 자체는 해당 브라우저의 계정별 저장입니다. 다른 PC와 동기화되지 않습니다. 서버 세션을 복원할 수 없으면 저장 사본과 대화만 표시하며 새 조회를 안내합니다.
- 대화 삭제는 대화와 브라우저 사본에 적용됩니다. 별도로 저장한 서버 그래프는 내 저장 그래프에서 관리합니다.
- 저장 공간 부족 시 기록은 메모리에 유지하고 저장 실패를 알립니다. 파일/이미지의 base64는 대화 저장에 포함하지 않습니다.
- 오래된 저장 대화를 다시 열어도 더 최근의 활성 대화 기록을 덮어쓰지 않습니다. 늦은 복원 응답이 새 그래프/새 채팅을 덮어쓰지 않도록 세션을 확인합니다.

## 자연어 편집의 실제 오류 수정

실제 OpenAI 요청에서 HTTP 400, input에 JSON 단어가 필요하다는 응답을 재현했습니다. Responses JSON 모드 요청의 input_text에도 명시적인 JSON 출력 지시를 추가했습니다. 모델/API 키는 변경하지 않았습니다.
공식 근거: https://developers.openai.com/api/docs/guides/structured-outputs#json-mode
이후 실제 UI 자연어 제목 변경과 대화의 후속 범례 변경이 성공했습니다.
