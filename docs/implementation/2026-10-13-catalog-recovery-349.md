# 2026-10-13 카탈로그 전체 검색·복구 화면 개선 (ai-assisted)

local1과 StatBridge1의 349개 지원 표에 공통 검색·분류 검증을 적용했습니다. 사용자의 실패 요청을 실제 사전·카탈로그·API 응답에서 재현하고 수정했습니다.

## 변경

- 공통 이름 뒤에 나열한 기준을 정본 표 이름에서 복원합니다. 특정 결제통화 ID를 코드에 고정하지 않습니다. 영문 대소문자, 공백, 구두점과 기준 사이의 쉼표·슬래시·접속사를 처리합니다.
- 같은 이름·기준에 여러 ID가 있으면 임의로 선택하지 않습니다. 기존 표 ID 선택 경로로 돌려보냅니다. 요청의 추가 지표를 버리거나 다른 지표로 바꾸지 않습니다.
- 지원되지 않는 명시적 지표를 비교 요청의 첫 지표에서 중단하지 않고 함께 안내합니다. 기준금리와 소비자물가지수는 현재 지원 사전에 없으며 생산자물가나 대출금리로 대체하지 않습니다.
- 정본 표 선택 시 근거 없는 첫 분류 값으로 실행하지 않습니다. 확인된 대표·전체 분류가 없으면 해당 표에서 실제로 필요한 분류 이름과 선택지를 안내합니다. 새 `need_details` 응답은 찾은 표와 원래 기간을 보존하며 데이터 호출을 대기합니다.
- 카탈로그의 분류 이름·개수·코드 목록을 실제 조회 가능한 사전 코드에 맞춥니다. 메타데이터의 상위 분류 수와 선택 가능한 분류 수를 섞어 표시하던 문제를 수정했습니다.
- 복구 작업을 미지원 지표, 잘못된 기간, 연결·권한 오류, 입력 오류로 구분합니다. 미지원 지표에는 질문 수정과 지원 표 탐색만 표시하고, 기간 수정과 재시도는 해당 문제에서만 제공합니다.
- 실행 전후 검증 실패에도 완전한 응답 형태와 조회 기간을 반환합니다. 불완전한 과거 응답에 기간이 없어도 복구 화면이 중단되지 않도록 방어합니다.
- 버튼은 파란색 강조·밝은 테두리·동일한 모서리·포커스·비활성 표현으로 통일합니다. 통계표 선택은 검색 가능한 카드와 분류 확인 화면으로 변경했습니다. 분류 확인 중에는 기존 네 표를 하나의 표로 바꾸지 않습니다.

## 검증

- 공개 사전의 349개 표를 정식 이름과 명시적 ID로 조회해 모두 해당 ID로 해석되는 것을 확인했습니다.
- 카탈로그 349개 표의 모든 분류에서 표시 개수, 표시 이름, 선택 코드와 기본값의 일치를 검사했습니다.
- 카탈로그에서 생성한 공통 이름 변형을 검사하여 공백·영문·구두점으로 인한 누락과 동명 표 오선택을 확인했습니다.
- 전체 회귀: local1 794개 / StatBridge1 785개, 각 355개 subtest 통과. 이후 추가된 실행 검증 실패 응답 및 전체 이름 변형 검사는 관련 모듈 전체를 다시 실행해 두 폴더 각각 39개 통과를 확인했습니다.
- 프런트엔드: 두 폴더 모두 타입 검사·빌드 및 71개 Node 테스트 통과. 공개 v4.1 검사도 통과했습니다.
- 두 CMD 실행 경로로 API/UI를 재시작했고, 브라우저에서 두 질문의 안내와 검색 카드·분류 목록을 확인했습니다.
- 두 실제 API에서 분류를 명시한 결제통화 요청은 2020-01-01~2025-12-31 기간, 네 표·네 계열·288개 월별 관측값을 반환했습니다. 검증용 분류는 국가별 ‘달러 (호주)’, 지역별 ‘달러 (중국)’, 표시 기준 ‘금액’이며 원래 요청에 임의로 덧붙이지 않습니다.

349개 표의 모든 기간·분류 조합에 대한 외부 KOSIS 호출을 전수 검증한 결과는 아닙니다. 전체 검사 범위는 표 해석·카탈로그 계약·분류 선택·복구 경로이며, 수치 호출은 위 네 표를 실제 서버에서 별도로 확인했습니다. 키·계정·저장 그래프·CSV·환경 파일은 복사하지 않았고 새 의존성이나 CMD 변경은 필요하지 않았습니다.
