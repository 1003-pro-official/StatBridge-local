# 2026-10-12 StatBridge 작업 정리

이 문서는 오늘 local1에서 진행한 화면 이식, 그래프 편집 워크스페이스, 로그인과 계정별 저장, 렌더링 안정화, StatBridge1 동기화를 정리한다. ai-assisted 작업이며 PR은 사람의 검토 후 반영한다. 오늘 작업 전부터 남아 있던 측정 개념 보호와 스티커 위치 보존 변경도 이번 제출에 포함되므로 별도로 구분한다.

## 1. 화면 및 통합 편집

StatBridge3의 상단 내비게이션과 전문적인 남색·파란색 화면을 local1에 이식했다. 원본 StatBridge3는 수정하지 않았다. 데이터 선택, 중앙 그래프, 오른쪽 속성, 하단 자연어 입력을 하나의 워크스페이스로 연결했다. 자연어와 수동 편집은 같은 현재 그래프 상태를 사용한다.

차트 종류·디자인·제목·축·범례·선 색상·선 두께·선 모양·관측점 표시를 편집할 수 있다. 기간 강조, 기준선·설명, 보고서 출력, 이모티콘 배치도 같은 편집 세션에 연결한다. Undo/Redo, 저장 후 재편집, PNG·SVG·PDF 출력과 고급 보고서 명세 관련 모듈을 추가했다. 이전 저장 명세를 읽기 위한 마이그레이션을 포함한다.

자연어 텍스트에서 명확한 변경은 검증 가능한 편집 명령으로 처리하고 복잡한 변경은 기존 모델 경로로 연결한다. 모델이 없는 상황의 제한과 실제 외부 호출 검증은 개별 검증 문서에 구분했다. 데이터 예시는 계열별 5개를 유지했다.

상세: [화면 이식](2026-10-12-statbridge3-ui-transplant.md), [워크스페이스](../chart_workspace_ux.md), [편집 명령](../chart_edit_commands.md), [고급 그래프 구조](../advanced_chart_architecture.md).

## 2. 그래프 깨짐과 입력 오류

작은 그래프 영역에 제목·부제·긴 범례와 인쇄용 여백이 몰리면서 그래프가 잘리고 자연어 입력을 덮는 문제를 수정했다. 화면용 제목·범례는 줄바꿈 가능한 별도 영역에 두고 중앙 그래프 높이를 확보했다. 작은 창에서는 페이지 스크롤로 출력과 입력을 모두 볼 수 있게 했다.

Plotly 갱신과 resize를 순서대로 처리한다. 이전 비동기 렌더링이 최신 상태를 덮지 않도록 하고, 편집마다 purge하던 동작을 제거했다. 이벤트와 마운트 해제 시 자원도 정리한다.

숫자 입력은 입력 도중 바로 적용하지 않고 Enter 또는 blur 시 검증한다. 빈 값과 허용 범위를 벗어난 값은 기존 값으로 복구한다. 관측점을 끄면 점 없는 실선을 사용할 수 있고 템플릿 변경 후에도 선택을 유지한다. 디자인 API 실패 이유와 재시도도 표시한다.

실제 두 KOSIS 계열에서 여섯 디자인, 주석 적용, 차트 종류와 선 모양을 바꾸는 10회 연속 편집을 확인했다. 1360×650 브라우저에서 제목·범례·그래프·대화가 겹치지 않는 것도 확인했다. 모든 기기와 임의로 긴 제목에 대한 전수 검증을 뜻하지 않는다.

상세: [렌더링 안정화](../chart_render_stability.md), [화면 검증](../chart_ui_validation_report.md).

## 3. 로그인 및 계정별 저장

기존 체크아웃에서 이식 가능한 인증 코드를 확인하지 못해 local1에 새 로그인·회원가입을 구현했다. 회원가입은 아이디, 이름, 이메일, 비밀번호와 확인 값을 검증한다. 사용자가 요청한 로컬 테스트 계정 test1·test2·test3의 비밀번호는 1234다. 일반 가입은 별도의 비밀번호 길이 규칙을 적용한다.

비밀번호는 salt와 scrypt로 저장한다. 서버 세션 토큰은 무작위이며 DB에는 해시만 보관한다. HttpOnly·SameSite 쿠키를 사용하고 HTTPS에서는 Secure를 적용한다. 로그인부터 12시간 절대 만료이며 서버와 화면 모두 만료 후 재로그인을 요구한다. 로그아웃은 세션을 폐기한다.

계정별 그래프 저장은 최대 5개다. 같은 그래프 재저장은 슬롯을 갱신하고 여섯 번째 새 그래프는 거절한다. 사용자별 저장 경로와 서버 소유권 검사로 다른 계정의 조회·편집·저장·삭제·내보내기를 차단한다. 브라우저 기록도 계정별로 분리한다. 실제 API에서 타 계정 접근 404, 동시 저장 5개 제한, 재시작 후 저장 그래프 재편집을 확인했다.

회원·세션 DB와 저장 그래프는 로컬 캐시에만 보관하며 Git에 포함하지 않는다. 이메일 소유 확인, 비밀번호 재설정, 소셜 로그인, 인터넷 배포 환경의 보안 감사는 구현·검증 범위 밖이다.

상세: [인증 검증](../account_auth_validation.md).

## 4. 148종 이미지 정리

운영 스티커 148종을 제거하고 실제 한국은행 보고서에서 확인한 상승·하락 표기를 참고한 투명 배경 화살표 2종으로 교체했다. 한국은행 공식 배포 이미지 또는 공식 이모티콘 세트로 표시하지 않는다. 위치·크기·각도·투명도 편집을 유지한다. 삭제된 이미지의 이전 식별자는 저장 명세 마이그레이션에서만 처리하며 다른 그래프 설정과 값을 보존한다.

참고 출처와 실제 검증은 [렌더링 안정화 문서](../chart_render_stability.md)에 기록했다. 원본 보고서 PDF 전체는 게시하지 않는다.

## 5. 두 로컬 폴더 동기화

최신 local1을 기준으로 StatBridge1/StatBridge-official의 공통 소스·문서·실행 스크립트를 맞췄다. 공통 파일 748개를 바이트와 SHA-256으로 비교했다. 각 폴더의 API 키·회원 DB·저장 그래프는 독립적으로 보존했다. 기존 파일은 StatBridge1 내부 백업에 보관했다.

루트 START/STOP CMD는 정본 scripts/windows 실행 스크립트에 위임한다. local1은 UI 5173/API 8000, StatBridge1은 UI 5174/API 8001을 사용한다. 동시 실행 시 세션 충돌을 막기 위해 쿠키 이름도 분리한다. Python 환경과 벡터 인덱스는 StatBridge1의 기존 자원을 사용하며 부족한 의존성을 설치했다.

두 실제 루트 CMD가 정상 실행됐다. 로그인, 349개 카탈로그, 디자인 6종, 주석 2종이 같았다. 실제 DT_181Y011의 2021–2025년 관측값 20개와 데이터 해시가 같았다. 임시 검증 서버는 종료하고 두 기본 서버를 유지했다.

이 PR에는 local1의 코드만 들어간다. StatBridge1의 포트별 루트 래퍼와 로컬 환경 연결은 별도 폴더에서 적용한 변경이며 저장소 밖의 상태다. 개인 경로, 환경, 계정 파일을 Git으로 동기화하지 않는다.

상세: [폴더 동기화 검증](../folder_sync_validation.md).

## 7. 검증과 공개 경계

렌더링 패치 이후 local1 전체 회귀는 748개와 하위 검사 355개가 통과했다. 동기화된 StatBridge1의 최초 전체 회귀에서는 747개와 하위 검사 355개가 통과하고, 새 CMD 바로가기를 금지하던 구조 검사 1개가 실패했다. 검사 목적을 유지하여 허용된 START/STOP 별칭만 정본 스크립트에 위임하는지 확인하도록 변경했고 구조 검사 2개가 통과했다. 임시 SQLite 정리 시 Windows 파일 점유 경고 1건이 있었다.
