# 그래프·표 편집 반영 및 보관 캐시 점검 (ai-assisted)

## 변경

- 브라우저 `statbridge.saved-chats.archive`를 더 이상 쓰거나 읽어 합치지 않는다. 계정별 기존 보존 캐시는 정리하고 최신 5개 외 대화 캐시도 제거한다.
- 미저장 대화는 메모리에만 유지하며 명시적으로 보관한 분석의 대화만 브라우저에 저장한다.
- 새 질문·새 채팅·페이지 재접속·다른 분석 열기에서 자동으로 분석 스냅샷을 저장하지 않는다. `statbridge.workspace.current`도 저장하지 않는다. 명시적 분석 저장과 계정 저장은 유지한다.
- 보관함의 '이전 기록' 영역과 서버 `olderItems` 병합을 제거한다.
- 행·열·최근 시점 수·표 항목 변경 시 이전 축에 묶인 병합·서식 범위·참조 행렬·맞춤 배치를 초기화한다. 전체 기본 글꼴과 격자선 설정은 유지한다. 이전 표는 편집 이력에 남아 Ctrl+Z로 원래 서식까지 복구된다. 초기화 동작은 UI에 명시한다.
- 자동 반영 콜백의 false 반환을 오류로 표시하고, 적용이 끝난 뒤 설정 패널이 서버 상태와 동기화되도록 완료 상태를 전달한다. 표·축·막대 간격·보고서·주석 기호 패널을 점검했다.

## 점검 범위

| 편집 영역 | 자동 검증 | 이번 직접 UI 확인 |
|---|---|---|
| 보관함 | 계정 분리, 5개 상한, 기존 overflow 삭제 | 두 앱에서 이전 기록 영역 없음 |
| 행·열 전환 | 첨부 기반 3종 표 × 양방향, 원본 불변 | 두 앱에서 시점 행 전환, local1 역전환과 Ctrl+Z |
| 셀 | 병합·분할, 원자료 불변, 모든 테두리, 텍스트, 수치 표시 | 색·굵게·기울임·밑줄·소수점·정렬·병합·분할·굵은 파선 |
| 표 양식·상세 설정 | 6종 양식, 머리글·행 그룹·참조 행렬·계산 열·각주·내보내기 회귀 | 본 작업의 UI 검증은 위 셀 항목 중심 |
| 그래프 | 선·점·구간·축·주석·기준선·도형·색·레이아웃·이중축·보고서·이력 회귀 | 제목, 선↔막대 렌더링, 범례 위치 |
| 안전성 | 실패 원본 보존, 버전 충돌, 소유권, 원자료 불변 | 기간 변경 실패 재현 후 보완 검증 |

자동 회귀는 실제 렌더링/파일 계약을 검증하지만 브라우저에서 모든 버튼과 모든 조합을 클릭한 전수 E2E와는 다르다. 자연어·참고 파일의 실제 GPT 품질 재평가는 이번 점검에 포함하지 않는다. UI 점검은 구조화된 편집으로 진행한다.

## 검증 결과

- 전체 공개 회귀: 96파일, 2,025 PASS + 하위 검사 355 PASS, FAIL 0 / SKIPPED 0. 모델 키 비활성, 실행 중 Python 소스·테스트 해시 불변. 이 결과는 기간·항목 변경 추가 보완 직전 스냅샷이다.
- 최종 기간·항목 보완 후 관련 회귀: local1 162 PASS / FAIL 0 / SKIPPED 0. 이 중 신규 배치·선택 변경 12건. StatBridge1 신규 12건도 독립 PASS.
- 최종 프런트엔드: 두 폴더 각각 179 PASS / FAIL 0 / SKIPPED 0. 두 폴더 TypeScript + Vite 빌드 성공. 기존 대형 청크 경고는 남아 있다.
- 공개 카탈로그 validator PASS. 비공개 평가 자료는 사용하지 않았다.
- 사용자/계정 저장 그래프 DB 해시: local1 사용자5·그래프9, StatBridge1 사용자4·그래프5 모두 기존 기준선과 일치. .env 해시도 일치.
- 직접 UI: 두 앱 보관함에서 이전 기록 없음, 양쪽 시점 행 전환, local1 반대 전환과 Ctrl+Z로 색·테두리 복구 확인. 셀 색·굵게·기울임·밑줄·정렬·소수점·병합·분할·3px 파선 확인. 그래프 제목, 막대 SVG trace, 6px 점선 SVG path, 축 제목 SVG 확인.
- 실제 UI에서 최근 시점 축소 실패를 재현했고, 기간·항목 변경 시 기존 위치 설정을 정리하도록 추가 패치했다. 최종 실제 UI에서 서식이 있는 표를 최근 4개 분기로 축소한 뒤 4행·2열로 전환했고 오류 메시지 0건을 확인했다. 증거: `.venv/cache/edit-apply-audit-20261019/final-transposed-table.png` 및 `final-evidence.json`.
- 전체 2,025건을 최종 추가 보완 후 다시 실행한 것은 아니다. 최종 보완은 관련 162건으로 재검증했다. 브라우저의 모든 조작·모든 값 조합을 전부 클릭했다고 보고하지 않는다.

실행 로그는 각 프로젝트 `.venv/cache/edit-apply-audit-20261019/`에 있으며 공개 소스와 분리한다. 저장 분석을 덮어쓰는 저장 버튼은 UI 점검 중 누르지 않았다.
