# 작은 화면의 그래프 본문 잘림 수정 (2026-10-16)

## 재현 및 원인

사용자의 가계신용 잔액+전년동기 증가율 질의에서 업권별 분기 표를 선택했습니다. 1366×625 브라우저 콘텐츠 화면에서 중앙 패널 267px, 그래프 스크롤/프레임 141px, 제목 78px, 범례 40px였습니다. 실제 Plotly 본문은 아래로 밀렸으나 layout containment와 고정 높이 프레임 때문에 스크롤 부모의 scrollHeight도 141px에 머물러 선·막대에 접근하지 못했습니다. 조회 데이터는 두 계열 모두 존재했습니다.

## 변경

한 개·두 개의 계열도 기존 확장형 차트 배치를 사용하고 그래프 본문에 최소 420px을 확보했습니다. 데스크톱에서는 문서 높이를 늘려 페이지 스크롤로 전체 그래프를 볼 수 있고, 모바일에서는 실제 콘텐츠 높이를 내부 스크롤에 반영합니다. 기존 다계열·분리 패널 배치와 원자료 수치·축 설정은 유지합니다. API나 서버 계산 변경은 없습니다.

- 두 폴더 같은 소스·회귀 테스트 반영.
