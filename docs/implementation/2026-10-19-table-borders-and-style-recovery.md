# 개별 테두리, 표 양식 연결, 단축키 복원 (ai-assisted)

## 요청과 첨부 재검토

사용자가 업로드한 표 자료의 XLSX 12개에서 병합 범위·각 변의 테두리·정렬을 다시 조사했다. PDF 5·13·18쪽의 다단 머리글, 혼합 주기 배치, 금액/건수 그룹, 강조 열은 기존 독립 평가 자료로 유지한다. 첨부 파일은 참조 자료이며 내부 문구를 작업 지시나 코드로 실행하지 않았다.

## 사용자 기능

- 선택 범위의 위/아래/왼쪽/오른쪽, 바깥선/안쪽선/모든 선/선 없음을 따로 적용한다.
- 실선·점선·파선에 가는/보통/굵은 1·2·3px와 선 색을 지정한다. 이중선도 지원한다. 다른 변과 채우기·글자 서식을 유지하며 선택한 변만 바꾼다.
- Ctrl+Z는 마지막 표 편집을 되돌리고 Ctrl+Shift+Z 또는 Ctrl+Y는 다시 실행한다. 셀 문구·입력란을 편집 중이면 입력란의 기본 텍스트 되돌리기를 유지한다. 확대 표에서도 같은 단축키를 사용한다.
- 선택 범위별 소수점·양수 부호·0 대시·줄바꿈·세로 정렬과 편집 격자선 표시를 제공한다. 원자료 수치는 변경하지 않는다.
- 격자 위에 양식 선택을 배치했다. 기존 상세 설정은 머리글·행 그룹·각주·계산·원자료 배치라는 이름으로 보존했다. 표 번호·제목·기간·인쇄 옵션은 속성 열기에서도 계속 제공한다.
- 사용자 서식 초기화는 직접 지정한 서식만 초기화한다. 병합·계산식·원자료·표시 문구는 유지하며 되돌릴 수 있다.

## 양식이 바뀌지 않던 원인

기존 기본 표에는 template이 적용됐지만 새 sheetRows는 기본 머리글·셀 서식을 고정 생성하고 있었다. template별 테마를 셀 격자 생성 이전에 적용하도록 변경했다. 7개 양식의 색·구분선·글자 및 계층 차이가 화면과 XLSX/PDF/PNG에 함께 반영된다. BOK-T02/T03은 가능한 실제 시점 열에 연도 머리글을 생성하며 수치를 집계하거나 생성하지 않는다. 사용자가 지정한 서식은 양식 기본값보다 우선한다.

## 파일 형식의 한계

CSV는 색·테두리·병합 속성을 저장하지 않는다. CSV 편집 설정을 주장하지 않으며, 값과 표시 텍스트를 내보낸다. 서식 보존에는 XLSX/PDF/PNG를 사용한다. XLSX의 OOXML 테두리는 독립적인 점선 굵기를 표현할 수 없어서 굵은 점선도 동일 dotted로 저장하고 굵은 파선은 mediumDashed로 대응한다. 화면과 PDF/PNG에는 지정한 굵기를 반영한다. HWP 파일의 직접 입출력은 이번 기능에 포함하지 않는다.

## 구현과 검증

신규 table_borders.py, table_sheet_theme.py, tableSheetBorders.ts를 사용한다. 모든 서식 값은 닫힌 스키마에서 검증하고 기존 set_table 명령·원자적 수정·계정 권한·되돌리기·저장/복원 경로를 재사용한다. 무제한 CSS, 수식 코드 실행, 모델 호출을 추가하지 않았다.

관련 검사는 개별 변/선색/굵기 및 XLSX 스타일, 텍스트 표시만 변하는 숫자 형식, 병합의 가장자리 전파, 7개 양식의 실제 격자 차이와 원자료 불변성, 내보내기를 검증한다. 프론트엔드는 바깥/안쪽/개별 변 범위와 단축키/텍스트 입력 예외를 독립 검사한다. 실제 UI에서 서로 다른 세 면, 선 없음, 단축키 취소/재실행, 기존 패널과 새 양식 선택, 이전 상세 설정, 다운로드를 확인한다. 정확한 실행 결과는 별도 검증 문서와 .venv/cache/table-borders-20261019 로그에 기록한다.
