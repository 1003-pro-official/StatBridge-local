# 2026-10-06 출력·수정 에이전트 통합

## 범위와 출처

`statbridge2/StatBridge-local/TODAY_CHANGES_2026-10-06.md`에 기록된 팀원 작업과 `StatBridge1/StatBridge-official`의 현재 출력·수정 기능을 공식 저장소 레이아웃에 통합했다. ZIP 추출 시각을 작업 시각으로 간주하지 않고 실제 코드 차이와 작업 기록을 비교했다. 통합 기준은 upstream `main`의 `b75b1a5`이다.

- 팀원 작업: 경상수지의 경상·상품·서비스·본원소득·이전소득 5개 검증된 구성항목 계획, 월별 날짜 좌표, 표시한 구간의 색 변경, 비교 그래프 가독성 보완.
- StatBridge1 작업: 독립 수정 에이전트, 부분 편집·수정 안전성, 정확한 표명/복합 질의 매칭, 텍스트 기간 처리, 데이터별 그래프 지원 조건, 모든 그래프의 정보 표시와 유형 전환, 그림판 편집, 최신 캐릭터 UI.
- 포터블 `statbridge_agent.py`의 런타임 코드는 공식 `agent_runtime.py`에 반영했다. 동명의 기존 패키지는 유지했다. 데이터·MCP·실행 경로는 `data/processed`, `data/tables`, `src/backend`, `scripts/windows`를 유지한다.
- 루트 실행 스크립트, 가상환경, 원자료, 벡터 DB, 평가 초안/결과, 미리보기 HTML, 임시 파일은 가져오지 않았다. 공개 평가 파일도 이번 기능 통합에 불필요한 초안은 제외했다. 비공개 평가 자료는 열람하지 않았다.

## 입력과 출력

정확한 표명, 명시적인 표 ID, 측정 개념, 신규취급액/잔액 등의 조건을 구분한다. 복합 질의의 원래 요청을 보존하고 다른 표의 수식어가 현재 표로 전파되지 않도록 한다. 조회 결과와 요청이 일치하지 않으면 다른 표로 그래프를 그리지 않고 확인을 요구한다. 이 규칙이 모든 자연어 표현의 완벽한 이해를 보장하지는 않는다.

텍스트의 기간을 확인한 경우 날짜 재선택 대신 `periodSelection`으로 확인 내용을 반환한다. 제공 범위를 벗어난 기간은 실제 제공 범위와 조정 여부를 안내하며 값을 만들어 내지 않는다.

13개 그래프 유형의 지원 여부는 실제 계열 수·공통 관측 시점·단위·값 조건으로 판단한다. 지원되지 않는 유형도 별도로 표시하고 부족한 조건을 설명한다. 사용자의 combined 선택을 몰래 separate로 변경하지 않는다. 단위가 다른 시계열의 단일 축 비교는 차단하며 별도 그래프 또는 명시적으로 지원되는 보조축이 필요하다. 산점도는 두 축의 지표/단위와 시점을, 원·도넛은 계열명·값·기준 시점을 표시한다.

모델이 없는 계열명을 제안하면 자동 스타일 제안만 제거하고 실제 데이터와 사용자가 선택한 그래프 유형을 유지하며 경고한다. 사용자가 명시적으로 없는 계열의 편집을 요청한 경우에는 거부한다. 월별 좌표는 ISO 날짜로 변환하되 원래 기간 ID는 선택용 customdata에 보존한다. 분기 ID는 월로 변환하지 않는다.

## 수정 에이전트와 UI

`ChartEditAgent`는 HCX-007 어댑터를 사용한다. 모델 경계를 분리해 이후 이미지 지원 모델을 연결할 수 있지만 현재 HCX-007은 이미지/손글씨를 읽지 않는다. 구조화된 선택 위치·기간·계열·설명과 텍스트를 해석한다. 출력 에이전트가 명령 검증과 실제 Plotly 렌더링을 담당한다.

- 선분/관측 구간, 점, 막대 등 대상과 범위를 검증하고 전체 계열로 조용히 확대하지 않는다.
- 색/점선/두께/마커, 계열 표시, 축/범례/배치, 주석/도형 등의 허용된 구조화 편집을 지원한다. 허용 범위를 벗어난 명령과 모호한 대상은 기존 그래프를 유지한다.
- 단독 그래프 유형 변경과 단순한 명시 색 변경은 검증된 규칙으로 처리한다. 복합·부정 문장은 이 단순 경로로 오인하지 않는다.
- 펜·화살표·사각형·텍스트 표시, 선택·이동·크기 변경을 지원한다. 표시 종류와 수정 안내는 일반 사용자가 이해할 수 있는 한국어로 제공한다.
- 여러 표시의 설명을 편집 요청으로 연결한다. 반복 텍스트 삽입을 방지하고 실패 시 표시와 기존 출력은 유지한다.
- 세션은 상한이 있고 수정 버전, 실행 취소/다시 적용을 제공한다. 세션은 메모리 기반이므로 서버 재시작 때 사라진다.
- 최신 투명 캐릭터 GIF를 플로팅 버튼·챗봇에 사용한다. 버튼은 이름 배지 없이 표시하며 드래그·위치 저장·화면 경계 보정·키보드 이동을 지원한다. 편집 안내에는 동일 캐릭터 PNG를 사용한다.

팀원의 구형 `mark` 요청 필드를 추가하지 않고 최신 `visual` 계약으로 해당 구간 색 변경을 통합했다. README와 프런트 `api/types.ts`에 계약 확장을 함께 반영했다. 기존 catalog 응답 필드 및 API 키 없는 로컬 CSV 사용 동작은 유지했다.

## 캐릭터 에셋 재생성

`public/sujeongi/`의 동작 GIF 9개와 안내 PNG는 UI에서 사용하는 정적 에셋이다. 원본 스프라이트는 별도 공급하며 저장소에 원본 개인 파일이나 미리보기 결과를 넣지 않았다. `tools/build_sujeongi_gifs.py`, `tools/build_sujeongi_transparent.py`는 원본 경로와 출력 경로를 인자로 받는다. 투명 변환 도구에는 별도 Pillow/numpy/scipy 및 Windows 맑은 고딕 글꼴이 필요하며 앱의 실행 의존성은 아니다. 재생성 출력은 저장소 밖에서 확인한 뒤 앱에 필요한 에셋만 반영한다.

원본의 8개 포즈를 정렬·왕복 재생한 애니메이션이며 새로운 중간 동작을 생성한 것은 아니다. GIF 투명도는 이진이고 원본 의상의 프레임 번호가 남아 있다.
