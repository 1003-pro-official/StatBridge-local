# 2026년 10월 20일 변경사항

작성일: 2026-10-20, 한국 시간 기준. ai-assisted 변경 기록이다.

이 문서는 오늘 이 대화에서 변경하거나 직접 확인한 내용을 정리한다. 작업 시작 전에 존재하던 다른 미커밋 변경을 오늘 새로 구현한 것으로 분류하지 않는다. `statbridge4.zip`은 이 문서와 현재 작업 폴더의 소스·문서를 포함하는 배포용 스냅샷이다. 커밋·푸시·PR 제출·머지는 수행하지 않았다.

## 1. 여수신 금리 조회 누락 수정

- ‘여수신 금리’를 대출금리와 수신금리 두 지표로 해석하도록 수정했다.
- ‘여수신금리’, ‘여·수신 금리’, ‘여/수신 금리’ 표기도 처리한다.
- 같은 질문 절에 지정한 은행 구분, 신규취급액·잔액 기준, 기간을 두 조회에 유지한다.
- 한쪽 금리가 누락된 조회 계획은 완료로 처리하지 않는다.
- 처음에는 코드 수정만 적용되어 기존 서버가 수정 전 코드를 계속 사용했다. 실행 중인 프로젝트 서버를 재시작하여 수정 내용을 실제 서비스에 반영했다.

관련 파일: `src/agent/agent_runtime.py`, `src/agent/request_match_guard.py`, `src/agent/stat_dictionary/stat_language_resolver.py`, `tests/test_combined_bank_rates.py`.

## 2. 현재 자료에 질문하기 답변 개선

사용자가 제공한 Word 예시의 ‘핵심 수치 → 비교·대조 → 확인 가능한 해석’ 구성을 반영했다. 예시의 숫자를 실제 관측값으로 복사하지 않는다.

- 질문 해석 프롬프트에 금리, 대출 구성, 물가, 성장, 기업, 지급결제 등을 다루는 퓨샷 예시를 추가했다.
- LLM은 기존 계열 중 분석 대상, 분석 유형, 비교 시점을 선택한다. 관측값 계산과 최종 답변 문장 작성은 서버가 담당한다.
- 질문 해석 단계에는 계열명, 정식 표 이름, 단위, 주기, 수록 시점 등 메타데이터를 전달한다. 관측값 자체는 전달하지 않는다.
- 여러 수치 문장을 보고서 형식의 한 문단으로 연결한다.
- 대출·수신금리의 변화 속도를 비교할 때 두 금리 차이의 변화도 계산한다.
- 같은 연이율을 뜻하는 `연%`와 `연리%`는 비교 시 호환하고, 근거에는 원래 단위를 보존한다. 월이율을 연이율로 환산하지는 않는다.
- 물음표, 줄바꿈, 세미콜론으로 나눈 질문을 최대 네 개까지 독립적으로 처리한다.
- 일부 질문만 답할 수 있으면 `partially_answered`와 질문별 `sections`를 반환한다. 예를 들어 금리 비교는 답변하고, 대출액 구성 분석에 필요한 자료가 없으면 해당 질문에만 부족한 자료를 안내한다.
- 모델이 질문과 다른 금리 계열을 선택하면 이를 그대로 사용하지 않는다. 해석이 유효하지 않을 때는 지원되는 명확한 질문에 한해 규칙 기반 처리를 사용한다.
- 전체와 구성 항목의 합계가 비교 두 시점에서 일치하는지 확인하고, 가장 큰 변화폭이 동률이면 특정 한 항목만 주도했다고 서술하지 않는다.
- 계산 결과와 원자료를 fact ID로 연결한다. 원인·정책효과·공식 전망은 별도 근거 없이 생성하지 않는다.

관련 파일: `src/agent/statistical_question.py`, `src/agent/bridge_api.py`, `src/agent/frontend/src/StatisticalQuestion.tsx`, `tests/test_question_examples.py`, `tests/test_statistical_question.py`.

## 3. 답변과 요약의 계열명 간소화

질문 답변, 기본 관측 요약, 보고서 설명에서 계열명을 간결하게 표시하도록 공통 처리했다.

- 계열명 안의 괄호 주석과 중첩 괄호 주석을 생략한다.
- 표 ID, 각주 번호, 가운데점 뒤의 반복 항목을 본문 이름에서 생략한다.
- 예를 들어 긴 대출금리 항목명은 ‘예금은행 대출금리’, 수신금리 항목명은 ‘예금은행 수신금리’로 표시한다.
- 이름을 짧게 표시하는 처리와 통계 선택·계산을 분리했다. 원래 계열명, 표 ID, 단위, 관측값은 계산 및 출처 근거에 보존한다.
- 이 처리는 계열명에 붙은 부가 설명을 대상으로 한다. 비교 시점과 수치처럼 문장에 필요한 정보는 별도로 유지한다.

관련 파일: `src/agent/narrative_labels.py`, `src/agent/statistical_question.py`, `src/agent/report_summary.py`, `src/agent/report_caption.py`, `tests/test_narrative_labels.py`.

## 4. UI 변경

### 하단 예시 질문 영역 제거

화면 맨 아래의 ‘다른 질문도 탐색해보세요’ 문구와 예시 질문 버튼 네 개를 제거했다. 질문 입력과 분석 기능은 유지한다.

관련 파일: `src/agent/frontend/src/App.tsx`.

### 처음 그래프 설명 토글 추가

- 질문 답변 아래에 ‘처음 그래프 설명 보기’를 추가했다.
- 질문 답변이 표시된 뒤에도 토글을 펼쳐 기존 그래프 설명을 볼 수 있다.
- 기본 상태는 접힘이며, 다시 클릭하면 접을 수 있다.
- 처음 설명과 질문 답변을 함께 확인할 수 있도록 했다. 질문 답변으로 원래 설명 데이터를 덮어쓰지 않는다.

관련 파일: `src/agent/frontend/src/StatisticalQuestion.tsx`, `src/agent/frontend/src/StatisticalQuestion.css`.

## 5. 설명 생성 기준 정리

| 구분 | 자료 기준 | 문장 구성 |
|---|---|---|
| 처음 그래프 설명 | 현재 계열·기간의 변환 전 원자료 | 최신 수준, 전월·전분기 변화, 전년동기 비교 또는 관측된 흐름 |
| 질문 답변 | 현재 표시 계열·기간에 해당하는 변환 전 원자료 | 질문에 필요한 계산과 비교를 수행한 뒤 문장으로 연결 |
| 보고서 설명 | 현재 그래프에 표시된 자료 | 최신 수준과 주요 변화 한 가지를 선택하여 짧게 작성 |

보고서 설명은 처음 설명을 그대로 복사하지 않고 별도로 생성한다. 그래프를 증감률 등으로 변환했다면 보고서 설명은 표시된 변환값을 기준으로 한다. 질문 답변은 보고서 설명을 자동으로 교체하지 않는다.

## 6. 실행과 실제 동작 확인

- 프로젝트의 등록된 프로세스인지 확인하는 기존 Windows 런처로 Agent, MCP, 프런트엔드를 실행·재시작했다.
- API는 `http://127.0.0.1:8000`, UI는 `http://127.0.0.1:5173`을 사용한다.
- API health와 UI의 HTTP 200 응답을 확인했다.
- 실제 로컬 API에서 기본 테스트 계정으로 대출·수신금리 조회, 그래프 출력, 질문 답변까지 연결하여 확인했다.
- 2025년 1~3월 조회의 두 계열 출처가 모두 KOSIS API임을 확인했다. 두 선이 생성되고, 금리 비교 답변과 구성 자료 부족 안내가 질문별로 분리되었다.
- 계열명 간소화 이후에도 실제 조회의 기본 요약과 질문 답변에서 표 ID·반복 항목·각주가 본문 이름에 남지 않는지 확인했다.
- 프런트엔드만 수정한 하단 영역 제거와 토글 추가는 개발 서버의 수정 모듈 응답에서도 확인했다. 해당 UI 변경에 서버 전체 재시작은 필요하지 않았다.

```powershell

```

```powershell

```

남은 확인 범위:

- 계열명 간소화와 마지막 UI 변경 이후 전체 Python 회귀 검증을 다시 실행하지 않았다. 해당 변경은 표시 문구와 UI 동작을 대상으로 하여 관련 테스트 및 빌드로 확인했다.
- 토글은 빌드와 개발 서버 모듈 반영까지 확인했으며 실제 브라우저에서 직접 클릭하는 검증은 수행하지 않았다.
- 원자료 CSV 전수 조회, 모든 지표 조합, 모든 질문 유형을 실제 외부 API로 확인한 것은 아니다.
- `statbridge4.zip`을 새 PC에 풀어 의존성을 설치하고 시작하는 검증은 이번 작업에 포함하지 않는다.
- 이 Markdown 작성과 패키징을 위해 기능 테스트 전체를 다시 실행하지 않는다. 압축 파일은 파일 목록, 포함 제외 정책, CRC와 파일 해시를 별도로 점검한다.

## 8. statbridge4.zip 구성과 실행

압축 파일은 프로젝트의 `output/statbridge4.zip`에 생성한다. ZIP의 최상위 폴더는 `StatBridge-local/`이다. 이 문서와 현재 소스, 테스트, 공개 메타데이터, 설정 예시, 실행 스크립트를 포함한다. 미커밋 상태의 소스 변경도 현재 내용으로 포함하므로 Git 커밋만을 내보낸 패키지가 아니다.

다음 항목은 제외한다.

- 실제 `.env`, API 키, 인증서·개인 키 등 비밀 파일. 값이 없는 설정 예시는 포함한다.
- `.git`, 별도 워크트리, 에이전트 설정·스크래치와 임시 파일.
- `.venv` 등 가상환경, `node_modules`, 빌드 산출물과 캐시.
- 원자료 CSV, 벡터 DB, 계정·세션 DB, 저장 그래프, 사용자 업로드와 실행 중 생성된 자료.
- 예측·평가 실행 결과, 로컬 검증 로그, 출력물과 기존 압축 파일.
- 비공개 평가 자료와 정답 파일. 해당 자료를 패키징 입력으로 열거나 복사하지 않는다.

압축을 푼 뒤 `StatBridge-local/START_STATBRIDGE.cmd`를 실행한다. 다른 PC에서는 실행 환경과 API 키를 새로 준비해야 한다. 로컬 CSV 조회가 필요하면 별도 공급 원자료가 필요하다. 자세한 설치 안내는 루트 `README.md`를 따른다.

사람의 검토와 승인 없이 이 변경을 main에 머지하지 않는다.
