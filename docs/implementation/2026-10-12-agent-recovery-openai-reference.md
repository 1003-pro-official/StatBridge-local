# 역질문 복구·GPT-5.4·참고 그래프 업로드

ai-assisted. local1 작업이며 StatBridge1은 이번 변경 대상이 아니다.

## 오류 후 이어가기

조회에서 표가 없거나 데이터·연결에 문제가 있으면 기존 결과를 실패 응답으로 덮지 않는다. 기존 그래프와 입력을 유지하고 같은 요청 재시도, 질문 보완, 기간 선택, 실제 카탈로그의 다른 표 선택, 저장 그래프 재열기를 제공한다. 다른 표를 고르는 것은 사용자의 명시적 선택이며 인접 표를 자동으로 대신 조회하지 않는다. 지원되지 않는 표의 요청 기간과 확정 조건도 실패 응답에 보존한다. 표를 바꾸면 해당 표에 맞지 않는 이전 분류 코드를 자동으로 복사하지 않는다.

출력 오류는 기존 조회 세션·출력 설정을 유지한다. 수정 오류는 서버의 후보 상태를 커밋하지 않는다. 수정창에는 질문과 함께 제목·범례·축·강조·현재 실제 계열 선택, 추가 설명, 같은 수정 재시도 기능을 제공한다. 선택과 설명으로 보완한 요청도 같은 현재 그래프 세션을 사용한다. 변경하지 못한 부분을 성공으로 표시하거나 데이터 값을 추측하지 않는다.

API의 400/409/422/429/502/503/504 오류에는 기존 detail 외에 recovery 질문과 선택지를 추가했다. 인증·소유권 실패의 상태 코드와 접근 차단은 유지한다. 복수 항목 설정과 단계별 역질문의 실패에서도 확정한 앞 단계를 초기화하지 않는다.

## 모델과 키

사용자가 확정한 공식 API 모델명은 `gpt-5.4`다. 출력 설명·출력 명세와 자연어/참고 이미지 수정에 OpenAI Responses API를 연결했다. 조회의 HCX-003 분류와 NCP 임베딩/검색 설정은 유지한다. `STATBRIDGE_OUTPUT_PROVIDER=ncp`로 기존 제공자 경로를 명시적으로 선택할 수 있다.

키 입력 파일은 **StatBridge-local1 루트 `.env`**다. 빈 설정 항목을 준비했으며 실제 키는 넣지 않았다.

```dotenv
STATBRIDGE_OUTPUT_PROVIDER=openai
OPENAI_API_KEY=여기에_OpenAI_API_키_입력
OPENAI_CHART_MODEL=gpt-5.4
OPENAI_CHART_TIMEOUT=90
```

키를 입력한 뒤 루트 START_STATBRIDGE.cmd로 재시작한다. 프런트엔드 VITE 변수나 대화창에 키를 넣지 않는다. .env는 Git에 포함하지 않는다. 서버에서만 Authorization 헤더를 만들고 응답의 원문 오류·키를 화면에 노출하지 않는다. Responses 호출에는 store=false를 사용한다. OpenAI 계정의 모델 사용 권한과 API 요금은 사용자의 설정에 따른다.

공식 근거: [GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4), [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), [이미지 입력](https://developers.openai.com/api/docs/guides/images-vision), [PDF 입력](https://developers.openai.com/api/docs/guides/file-inputs).

## 참고 파일

수정 입력창의 참고 그래프 업로드에서 PNG/JPG/WebP/PDF 최대 3개를 첨부한다. 파일 하나당 최대 4MB, 이미지 최대 1600만 화소, PDF는 암호 없는 1~5쪽을 허용한다. 확장자나 MIME만 믿지 않고 실제 내용도 검사한다. 첨부를 제거하거나 바꿀 수 있으며 실패 후에도 첨부와 요청은 유지된다.

사용자가 전송하면 참고 파일을 OpenAI에 보낸다고 화면에 표시한다. 이미지는 input_image, PDF는 input_file로 전달하며 base64를 텍스트 지시로 위장하지 않는다. 현재 실제 통계 자료의 값·시점·계열을 유지하면서 참고 형식의 색상·배치·축·주석·차트 종류를 해석한다. 파일 내부 지시문은 자료로 취급한다. 필요한 데이터 차원이나 수정 정보가 없으면 확인 질문을 반환한다. 모델이 작성한 실행 코드나 임의 통계 수치를 실행하지 않고 기존 편집 스키마와 렌더러에서 검증한다.

## 설명

그래프 위 설명은 220자 이내 2문장 보고서 문체를 요청하도록 바꿨다. 확인한 시작·끝·최솟값·최댓값을 근거로 하며 원인·전망·정책 효과를 추측하지 않는다. 분기와 월을 구분한다. 모델 연결이 없거나 실패하면 실제 시작·끝 수치에 기반한 보고서 문체의 규칙 요약을 사용한다.

## 검증

- 최종 전체 회귀: **756 passed, 355 subtests passed**, 324.49초.
- 집중 계약·편집 검사: 20개 통과. 이후 전체 회귀에도 포함했다.
- TypeScript와 프런트엔드 build 성공. 기존 번들 크기 경고는 유지된다.
- 모의 Responses 전송 검사: gpt-5.4/store=false/input_image, 이미지 base64의 텍스트 제외, 적용 후 원자료·관측값 유지.
- 손상·위장 파일과 중첩 입력 우회 거절, 없는 표의 기간·조건 유지, 타 계정 참고 파일 편집 요청 404.
- 실제 HTTP 테스트: 확인 질문 반환 후 같은 그래프에서 보완된 제목 수정 성공, 실패 시 상태 불변.
- 실제 브라우저: 없는 지표 요청 → 기존 그래프 유지 → 실제 카탈로그 DT_181Y011 선택 → 기간 보완 → KOSIS 관측값 24개 조회 → 출력.
- 실제 브라우저: 정상 JPEG 첨부·미리보기·자연어 전송 → 키 미설정 안내 → 요청·첨부·그래프 유지. 잘못된 MIME의 파일도 서버에서 거절되는 것을 확인했다.

OpenAI 키가 아직 비어 있으므로 **실제 GPT-5.4 응답과 참고 그래프 모방 품질은 검증 전**이다. 모의 전송/편집 검증을 실제 모델 성공으로 주장하지 않는다. 만료된 서버 편집 세션의 자동 영구 복원을 뜻하지 않으며 계정 저장 그래프 재열기를 제공한다. 새 파일로 통계 자료 자체를 추출·대체하는 기능은 이번 참고 형식 편집의 범위 밖이다.

로그와 화면 증거는 Git에서 제외한 .venv/cache/agentic-* 경로에 보관한다.

### 전체 회귀 이후 최종 보완 검증

추론 토큰 예산·단위 조사와 요약 기본 표시 및 복구 안내 정리 후 집중 검사 **42 passed**(17.21초), Node 검사 **9 passed**, 타입/빌드, 공개 v4.1 validator를 다시 확인했다. 이 보완까지 포함한 전체 회귀를 추가 실행한 결과로 소급하지 않는다. 새 모델 키 미설정 오류 뒤 같은 그래프의 확정된 제목 수정을 실제 브라우저에서 완료했고 이전 오류 안내가 없어짐을 확인했다. 재시작 후 저장 그래프에서 이어가기와 현재 GPT-5.4 이미지 지원 메타데이터도 실행 API에서 확인했다. 마지막 집중 계약 검사 한 차례에서 기존 Windows 임시 SQLite 정리 경고가 발생했지만 테스트는 통과했다.
