# 2026-10-14 참고 그래프 편집과 읽기 쉬운 변경 기록

빈 질문의 분석 버튼에 적용되던 wait 커서를 기본 커서로 바꿨습니다. 실제 요청 중의 진행 표시와 버튼 잠금은 유지합니다. 서버 편집 설명과 브라우저의 이전 기록 표시를 한국어로 정리했습니다. `markers False`는 `관측점 표시를 껐습니다.`, `dash solid`는 `선 모양: 실선`으로 표시합니다. 사용자 입력과 저장된 원본 대화는 바꾸지 않습니다.

local1과 StatBridge1/StatBridge-official에 같은 기능 코드·테스트·진단 하네스를 적용했습니다. 포트·쿠키·키·계정·저장 그래프는 각 폴더 설정을 유지합니다. 이번 작업에서 커밋·푸시는 실행하지 않았습니다.

## 실제 이미지 입력에서 발견하고 수정한 문제

- `이렇게 그려줘`와 참고 파일을 함께 보냈는데도 변경 요소를 고르라는 일반적인 질문을 반복했습니다. 전체 시각 형식 요청으로 처리하도록 지시를 명확히 했습니다.
- 모델이 불필요한 `params: null` 또는 `value: ""`를 반환해 유효한 스타일 설정이 거부됐습니다. 사용하지 않는 필드만 제한적으로 정규화합니다. 잘못된 자료형·충돌한 파라미터는 계속 거부합니다.
- 모델이 패널 구조를 읽어도 테마 적용 뒤 한 축에 합쳐지는 경우가 있었습니다. 이미지에서 판독한 종류·영역 수·열 수를 별도 구조 필드로 검증하고 배치를 마지막에 적용합니다. 실제 Plotly 축 쌍 개수를 검사합니다.
- 패널에서 일반 그래프로 복귀해도 보고서 패널 설정이 남았습니다. 결합 배치로 바꾸면 보고서의 패널 상태도 해제합니다.
- 긴 제목·위쪽 범례·패널 제목이 겹쳤습니다. 각각의 공간을 확보하고 실제 그림 영역의 최소 높이를 유지합니다. 명시적으로 지정한 제목 위치는 보존합니다.
- `연%`와 `연리%`가 같은 축에서 비교되지 않았습니다. 연간 금리 축 비교에서만 같은 단위로 판정합니다. 원자료 단위 문자열·일반 `%`·`%p`와 합산 적합성은 바꾸지 않습니다.

참고 파일은 스타일 참고이며 통계 근거를 대체하지 않습니다. 일반적인 형식 요청에서 이미지의 제목·기간·단위·수치·축 범위·전망·장기평균을 복사하는 명령을 거부합니다. 현재 조회 관측값과 이름을 유지합니다. 이미지에서 자료를 추출해 새 통계 계열을 만드는 기능은 이번 변경에 포함하지 않습니다.

## 한국은행 공개 그래프 진단

출처는 [경제전망보고서 2026년 5월](https://www.bok.or.kr/portal/bbs/P0002359/view.do?menuNo=200066&nttId=10098209) PDF 28쪽 그림 1.18 국제유가·그림 1.19 호르무즈 통항 선박수와 [금융안정보고서 2026년 6월](https://www.bok.or.kr/portal/bbs/P0000593/view.do?menuNo=200068&nttId=11062197) PDF 22쪽 그림 I-1-6 가계대출 연체율입니다. PDF 페이지 렌더를 직접 확인한 뒤 해당 그림을 PNG로 잘라 첨부했습니다.

`eval/chart-reference/v1/cases.json`은 공개 출처·쪽·크롭 좌표·현재 카탈로그 조회 조건을 기록합니다. 준비/평가 방법은 [하네스 안내](../../eval/chart-reference/v1/README.md)에 있습니다. 원 PDF·PNG·모델 응답·원행·계정 DB·평가 결과는 `.venv/cache`에만 남깁니다.

현재 KOSIS 조회 데이터는 선 사례 2계열 48개 관측값, 누적 막대 사례 5계열 120개, 패널 사례 3계열 72개입니다. 누적 막대는 호주 수입 결제통화 중 선택한 5계열 부분집합이며 전체 통화 합계라고 해석하면 안 됩니다. 패널은 실제 현재 계열을 한 영역씩 나눕니다. 원본 은행 그룹·각 그룹의 여러 곡선·장기평균을 생성하거나 복사하지 않았으므로 원본과 같은 통계 내용·곡선·픽셀 재현이 아닙니다.

실제 설정된 GPT-5.4 이미지 입력 모델을 사용했습니다. 격리 계정의 실제 `/api/query` → `/api/output` → `/api/output/edit` 경로를 호출하며 관측값·지표·단위·주기를 비교하고 원행 SHA-256을 별도로 검증합니다. 파일 업로드는 브라우저에서도 실제로 수행했습니다. 모델 내부 추론은 수집하지 않습니다.

| 실행 | local1 | StatBridge1 | 판정 범위 |
|---|---|---|---|
| 구조 검증 실행 | 3/3 | 3/3 | 기본 종류·실제 축/영역 수·관측값/원행 보존 |
| 제목 배치 보완 뒤 반복 | 2/3 | 3/3 | local1 패널은 불필요한 그룹 선택 질문으로 복귀, 기존 출력/데이터 보존 |
| 그룹 질문 지시 보완 뒤 local1 패널 재검증 | 1/1 | 미실행 | 실제 3개 축 영역, 데이터 보존 |

성공한 호출만 모아 전체 성공률로 제시하지 않습니다. 반복 호출에서도 모델 응답이 달라질 수 있습니다. 마지막 세 사례 반복의 local1 응답 시간은 21.766/22.750/22.781초, StatBridge1은 25.032/24.375/21.516초이며, local1 패널 재검증은 23.641초였습니다. 각 사례는 해석·검토 모델 요청 2회를 사용했습니다. 이전 호출에서는 110초도 관측했으므로 수초 내 완료를 보장하지 않습니다.

자동 판정과 외관 판정을 분리했습니다. 초기 판정은 보고서 종류를 패널 성공으로 오인했으나 화면에서는 세 선이 한 축에 겹쳤습니다. 그 실행의 패널 성공은 인정하지 않고 실제 축 개수 검사로 수정했습니다. 최종 렌더러로 기존 실제 모델 명령·조회 계열을 재렌더해 제목/범례 간격과 세 패널을 화면에서 확인했습니다. 이 재렌더는 새 모델 호출이 아닙니다. 원본과 완전히 같은 그룹 구조·범례·축 배치를 지원하는지는 추가 자료/그룹 어댑터와 더 넓은 사례 평가가 필요합니다. `visual_review=pending`은 외관 통과 점수가 아닙니다.

- 앞선 중간 전체 Python 테스트: 939 passed, 355 subtests passed. 마지막 구조 바인딩·제목 배치 변경 이후 전체 테스트를 다시 실행한 결과가 아니며, 이후 변경은 위 최종 영향 테스트와 실제 모델 호출로 검증했습니다.

- 골드셋 200문항 평가는 이번 VLM 진단과 별개이며 이번 작업에서 재실행하지 않았습니다.

API 키·기존 계정·저장 그래프를 복사하지 않았습니다. 실제 모델 호출에는 각 폴더에 이미 설정된 서버 키를 사용했으며 키를 출력하지 않았습니다. 기존 계정과 저장 그래프는 하네스 평가에 사용하지 않았습니다. 테스트 계정 DB는 별도 출력 경로에 격리했습니다. 캡처·일회성 비교 페이지·원응답은 공개 코드 변경에 포함하지 않습니다.
