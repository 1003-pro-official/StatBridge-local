# 그래프 종류 선택 복구 · 미사용 UI 정리 (2026-10-21)

ai-assisted. local1과 StatBridge1에 적용했다.

## 변경

- 그래프 종류 선택이 접힌 ‘차트와 디자인’ 안에 있어 찾기 어려웠다. 왼쪽 속성의 ‘그래프 편집’ 바로 아래에 항상 보이는 ‘그래프 변경’ 영역으로 옮겼다. 기존 선택기를 재사용하여 중복 메뉴를 만들지 않았다.
- 서버가 현재 자료에 허용한 차트만 선택할 수 있다. 혼합·이중축·회귀 선택과 기존 검증 편집 명령을 유지한다. 차트 종류는 기존 set_chart_type 경로로 즉시 반영한다.
- 요청한 ‘문장별 수치·계산 근거 확인’과 관측 요약 안내 UI를 제거했다. SummaryEvidence.tsx와 import·호출을 삭제했다. 파생지표 계산 근거와 Langfuse 실행 로그, 보고서 작성 기능은 유지한다.
- TypeScript 전체 소스에 noUnusedLocals/noUnusedParameters를 적용하여 미사용 import·상태·인자와 연결되지 않는 onEvidence 전달을 정리했다. 표 복사·조회 복원·그림 표시·이미지 지원의 실제 동작은 유지한다.
- src/main.tsx에서 정적 import/export 및 리터럴 dynamic import를 따라간 의존성 점검에서 남은 고립 TS/TSX 모듈은 없었다(d.ts 제외). 공용 CSS 중 파생 계산 근거가 쓰는 스타일은 보존하고 삭제한 컴포넌트만 사용하던 article 스타일은 제거했다.
- 점검용 임시 스크립트도 제거했다. 작업 기록·테스트·수동 평가 도구는 실행 또는 기록 용도가 있으므로 단순히 앱 시작점에서 호출되지 않는다는 이유로 지우지 않았다. 이 점검은 모든 Python 동적 로딩·외부 수동 진입점의 불사용을 증명하는 전역 분석이 아니다.

## 검증

- 두 폴더 빌드 PASS. 미사용 지역 선언·인자 검사 0건. 기존 큰 번들 경고는 남아 있다.
- 두 폴더 프런트엔드 Node 221 PASS, 0 FAIL.
- 실제 UI 5173/5174에서 동일한 예금은행 대출·수신금리 2025년 1~3월 자료로 선 → 막대 → 선 왕복 변경을 확인했다. 각 상태에서 2개 실제 Plotly trace를 확인했고, 주요 데이터 표의 조회 수치는 전후 완전히 동일했다.
- 차트 선택기는 접힌 details 밖에 있으며, 관측 요약 안내와 문장별 근거 버튼은 DOM에 0개이다.
- 삭제한 모듈의 정적 참조가 남지 않음을 확인했다. 프런트엔드만 변경하여 백엔드 전체 Python 검사는 이번 작업에서 반복하지 않았다.
- src/tests/tools/scripts/docs 비교에서 프로젝트별 frontend/.env 이외 차이가 없음을 확인했다. 포트·환경·계정·저장 분석·원자료는 동기화 대상에서 제외한다.


최종 루트 설정 포함 비교는 681개 파일이며 차이는 START_STATBRIDGE.cmd 하나이다. StatBridge1의 API 8001/UI 5174·별도 쿠키 설정이므로 의도적으로 유지했다. 환경파일은 비교·복사 대상에서 제외했다. 계정·저장 분석도 local1 users=5/graphs=9, StatBridge1 users=4/graphs=5로 전후 동일하다.
