# 좌우 축 편집과 축 제목 위치

- 계열별 좌/우 Y축 선택. 왼쪽 계열이 모두 없어지는 연결은 차단합니다. 오른쪽 계열을 해제하면 보조축 설정도 정리합니다. 보고서 모드의 right_axis와 일반 보조축 상태를 함께 갱신합니다.
- X/왼쪽 Y/오른쪽 Y축을 골라 제목, 위치(0~100%), 눈금에서 추가 간격(0~80px), Y축별 범위를 편집합니다. 기본값 복원과 편집 이력을 사용합니다. 기존 축 제목 빠른 입력은 이 제어로 통합했습니다.
- Plotly와 벡터 인쇄에 제목 위치를 반영합니다. 반응형 실제 화면에서도 제목을 별도 설명으로 오분류하지 않고 그래프 영역에 유지합니다.
- 오른쪽 막대가 왼쪽 선을 가리지 않도록 그림의 축 레이어와 인쇄 순서를 조정했습니다.
- 이미지 구조 연결은 기존 보조축을 무조건 추가하던 방식을 수정하여 판독한 축 연결로 교체합니다. 이미지 계열 수를 현재 데이터 수에 맞춰 복제하지 않도록 명시했습니다. 이미지의 수치/단위/축 범위를 기존 데이터에 복사하지 않는 기존 정책을 유지합니다.

검증: 관련 Python 28개와 참고 정책/편집 설명 20개, 프런트엔드 111개 통과. 실제 WorkspaceProperties와 PlotlyRenderer를 Playwright로 실행하여 세 축 제목 표시 및 오른쪽 축 편집 명령을 확인했습니다. 로그인된 전체 세션을 재촬영한 것은 아닙니다.

사용자 허용 후 1.png와 합성 잔액/증가율 자료를 설정된 OpenAI API로 전달하여 실제 이미지 편집 경로를 실행했습니다. 결과는 잔액=line/왼쪽, 증가율=bar/오른쪽이며 관측값은 보존되었습니다. 이는 이미지 1개의 검증이며 모든 이미지 인식 정확도를 보장하지 않습니다. 실제 통계 재조회와 수치 대조는 실행하지 않았습니다. 원본 이미지·API 응답은 커밋 대상에 포함하지 않았습니다.

최종 확장 회귀: 기존 편집/보고서/새 이중축/참고 정책 85개 통과(56.87초). 두 폴더 최종 빌드와 서버 헬스 확인 완료. 기본값 복원 시 기존 x_axis_label/y_axis_label 저장 값도 선택 축에 한해 초기화합니다.
