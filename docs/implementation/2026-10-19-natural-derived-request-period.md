## 변경 이유와 범위
사용자가 API·파일 요청 문구를 덧붙이지 않아도 일반적인 파생지표 계산 요청을 처리합니다. `2023년 1월부터 4월까지 … 2020=100`에서 기준연도를 종료연도로 읽던 오류를 수정했습니다. 생략된 연도·월·분기의 경계를 달력으로 검증하고, 여러 비교기간은 임의로 합치지 않습니다. 잘못된 날짜와 역전 기간은 계속 거부합니다.

비율·차이·합계·곱셈·가중평균·실질화·비교 등의 복수 입력 요청은 공통 원자료 확보 확인을 사용합니다. 단순 단일계열 변화율에는 불필요한 선행 확인을 추가하지 않습니다. 확인한 항목·분류는 독립 재검증 후 계획에 재사용하고 경제적 의미 검토는 유지합니다. 검색 한도 소진을 데이터 부재로 단정하던 경로도 실제 API 확인으로 보완했습니다. 기존 편집은 검증된 이전 DAG를 이어갑니다.

API 자료와 부족 자료가 함께 있고 확인 질문이 없으면 파일 연결을 자동으로 엽니다. 모호한 계산 조건은 오류 대신 확인 질문으로 안내합니다. 전부 외부 자료인 요청, 회사·개인 자료 요청에 대한 기존 지원 제한은 유지합니다.
