## 표 계산과 출력

`TableOptions.comparison`으로 전기 차이·전년동기 차이·조회 시작 대비 차이/증가율을 선택합니다. 계산 셀에는 산식·단위·원 관측치를 남깁니다. 기준 시점이 없으면 결측이며, 증가율 기준값이 0 이하이면 자동 계산하지 않습니다. 서로 다른 주기 자료를 합산하지 않습니다. 지표를 행으로 놓을 때만 계산 열을 제공합니다.

`/api/table/export`는 현재 화면의 표 문서 스냅샷을 사용합니다. CSV는 표시 반올림 값, Excel은 원래 수치와 표시 형식을 함께 저장합니다. PDF/PNG에는 같은 번호·제목·출처·주석을 적용합니다.

## 근거 연결 보고서 초안

- 기본 `quick_output:true` 관측 요약은 유지합니다. 별도 버튼에서 `/api/report/interpret`를 호출하며 로그인 소유권·요청 전후 revision을 확인합니다.
- 질문, 표시 범위, 계열 메타데이터, 서버 계산 사실, 검수 발췌, 해석 기준일을 전달합니다. 모델 문장은 문장별 fact/passage ID와 연결합니다.
- 현재 표시 계열의 최신 사실과 비교 요청의 격차 근거가 누락되면 검증을 통과하지 못합니다. PDF의 과거 숫자를 현재 관측값으로 쓰는 경로는 허용하지 않습니다.
- 발간일/분석 기간 필터를 모두 적용합니다. 기본 기준일은 조회 종료일이며 이후 기준일을 지정하면 사후 해석으로 표시합니다.
- 공식 요인·전망은 모델이 원문 구절 번호를 선택합니다. 서버가 실제 원문 구절과 발간일·쪽수·적용 기간을 붙여 출력합니다. 원문 분석 기간을 벗어난 적용은 거부합니다.
- 잘못된 JSON·숫자·인용 계약은 최대 한 번만 교정합니다. 여전히 검증되지 않거나 공급자 호출이 실패하면 서버 관측 문장으로 대체합니다. 브라우저 대기는 20초로 제한됩니다. 서버의 외부 요청 강제 취소를 보장하지는 않습니다.
- 담당자 검토 대기 상태를 유지합니다. 자동 검증은 원문 함의를 완전히 판정하는 장치가 아닙니다.
