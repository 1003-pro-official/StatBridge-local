# CCSI 공식 정의에 근거한 단위 보완 및 재평가

2026-10-22 · ai-assisted. 기존 계정·분석·원자료·평가 정답을 유지하고, 단위가 비어 있던 소비자심리지수의 계산용 단위 메타데이터만 근거와 함께 보완했다.

## 실제 원자료·공식 정의 확인

구성된 키로 KOSIS `statisticsParameterData.do`를 실제 호출했다. 기관 301, 표 `DT_511Y002`, 항목 `13103134688999`, 월별 주기 M, 분류 `objL1=13102134688CSI_CD.FME`, `objL2=13102134688CSI_CLF_CD.99988`을 지정했다. 2023년 1월~2025년 12월의 관측 36개를 HTTP 200으로 받았고, 실제 분류명은 소비자심리지수·전체였다. 관측 36개에는 `UNIT_NM` 키가 없었다.

같은 표의 KOSIS `statisticsData.do?method=getMeta&type=ITM`도 HTTP 200으로 항목·분류 66개를 받았으며 단위를 제공하지 않았다. 따라서 KOSIS가 단위 ‘지수’를 반환했다고 기록하지 않는다. 키와 키가 포함된 요청 URL은 로그에 저장하지 않았다.

한국은행 [2025년 12월 소비자동향조사 결과](https://www.bok.or.kr/portal/bbs/B0000501/view.do?menuNo=200690&nttId=10095310)의 [PDF 원문](https://www.bok.or.kr/fileSrc/portal/56590ec4ef374f519035e1983f8dc74f/2/705f67aaf5754453812dc43d323720b5.pdf)을 실제 내려받아 부록 2 ‘소비자심리지수 개요’(PDF 9쪽, 인쇄면 8/8쪽)를 확인했다. CCSI는 여섯 구성지수를 표준화해 합성하고 장기평균 100, 장기표준편차 10으로 조정한 지수이다. 이 공식 산출 정의를 근거로 계산용 단위를 **지수**로 분류했다. %, %p 또는 2020=100으로 분류하지 않았다.

문서 SHA-256: `d6de3f90e0162dd7ff02f6f2a171dca4a81cc9f2705c233811f39926604785eb`.

## 적용 방법과 제한

`src/agent/verified_source_units.py`에 검증된 단위 메타데이터를 추가했다. 아래 조건이 모두 맞을 때만 적용한다.

- 기관·표·항목·주기·두 분류가 위 CCSI 전국 전체 계열과 정확히 일치한다.
- 응답은 성공한 KOSIS API 자료이고, 각 행의 기관·항목·표·분류·주기가 요청과 일치한다.
- 모든 행의 원래 단위가 미제공·빈 문자열이다. 이미 있는 단위는 덮어쓰지 않으며 혼합 단위도 허용하지 않는다.
- 다른 CSI 구성지수·분류·기관·사용자 파일에는 적용하지 않는다.

`source_series()`는 API 행을 수정하지 않고 검증된 계산용 단위를 사용한다. `DerivedIndicatorRuntime`은 영수증의 `unit_resolutions` 및 공개 근거의 `sourceSelections[].unitResolution`에 공식 출처·정의·문서 해시·원래 API 단위 미제공 상태를 기록한다. 영수증의 원자료 `UNIT_NM`은 계속 미제공 상태로 보존한다. 단위 정책 변경은 검증된 계획 캐시의 정책 해시에 포함되어 과거 계획 재사용을 무효화한다.

CCSI는 표준화한 지수이므로 `(당월/전월−1)×100`은 지수값에 적용한 상대 변화율이다. 소비심리 자체가 그 비율만큼 증가했다거나 한국은행이 발표한 공식 증감률이라는 뜻은 아니다. 이 제한을 계산 근거에 함께 기록했다. 지수값의 단순 차이와 상대 변화율도 구분한다.

## 재평가

v1.1의 질문·고정 자료·정답을 수정하지 않고, 남아 있던 소비자심리지수 문항 1개만 local1과 StatBridge1에서 실제 Sol 모델·인증 API 경로로 다시 실행했다. 두 프로젝트 모두 계산 완료 및 v1.1 정량 검산을 충족했다. 기관·단위·경제학적 의미 검증을 해제하지 않았다.

다른 113개의 기존 관측을 재사용한 합산 결과는 양쪽 각각 **정량 충족·정성 검토 대기 114개, 실패 0개, 원래 제외 6개**이다. 120개 전체를 새로 실행한 결과나 사람 정성 검수 완료 점수는 아니다. 이번 모델 호출은 각 3회, 합계 6회이며 응답 모델은 `gpt-6.1-sol`이다. local1 입력/출력 토큰은 15,734/525, StatBridge1은 15,748/551이다. 실제 청구 금액은 조회하지 않았다.

실제 KOSIS에서 이번에 받은 36개 값도 별도로 재계산하여 전월 값이 있는 35개 상대 변화율을 Decimal 독립 산식과 허용 오차 0.000001로 비교했고 모두 일치했다. 첫 달의 과거 값은 채워 넣지 않았다. 라이브 값은 개편·표준화에 따른 빈티지 차이가 있을 수 있어 고정 평가 정답과 섞지 않았다. 원응답을 보존한 것도 확인했다.

## 회귀·동기화·보존

양쪽 각각 전체 테스트 2,287개와 하위 검사 355개가 통과했다. 최종 수집 목록과 8개 실행 그룹의 모듈을 대조하여 누락·중복을 확인했다. TypeScript/Vite 빌드와 공개 v4.1 검증(`50/70/30`)도 양쪽에서 통과했다.

합성 자료 테스트는 정확한 계열 범위, 다른 분류·기관·주기·단위 위조 차단, 원응답 불변, 단위가 있는 응답 보존, 빈·혼합·잘못된 단위, 기록 사본 변조 방지, 계산 영수증의 원단위와 보완 근거 분리를 확인한다.

수정 코드·테스트·문서를 양쪽 폴더에 동일하게 반영했다. 각 환경의 `.env`, 포트·쿠키, 계정 DB와 저장 분석은 복사하거나 삭제하지 않았다. 전후 읽기 전용 감사에서 사용자·분석·연결 자료·저장 파일·환경 설정의 해시와 개수가 일치함을 확인한다.

원본 HTTP 응답, PDF, 추출된 부록, 모델 사용량, 영수증, 전후 감사는 local1의 Git 무시 경로 `.venv/cache/ccsi-unit-evidence-20261022`에 보존한다. `verify_results.py`가 고정 자료 재채점과 라이브 독립 검산을 수행하며, `final-summary.json`, `live-verification.json`에 결과를 나누어 기록했다. 실제 키·원자료 숫자·평가 정답·사용자 자료는 공개 코드나 문서에 복사하지 않았다.
