# 첫 화면 초기화와 상단 대화 버튼 정리 (2026-10-13, ai-assisted)

- 로고와 분석 홈은 현재 그래프/입력/오류/선택 상태를 비우고 첫 화면 상단으로 이동합니다.
- 새로고침 및 새 페이지 진입 시 그래프를 자동으로 복원하지 않습니다. 브라우저의 이전 스크롤 위치도 복원하지 않습니다.
- 이전 그래프의 대화는 브라우저 계정별 대화 목록에 보관합니다. 저장한 대화를 명시적으로 열면 그래프와 기록을 다시 확인할 수 있습니다.
- 가운데 편집 항목 검색 입력칸을 제거했습니다. 제목·축·계열 선택은 그래프와 왼쪽 설정에서 그대로 가능합니다.
- 채팅의 기호 추천 메뉴를 제거했습니다. 왼쪽 그림판의 별도 기호/이모티콘 편집 기능은 유지합니다.
- 별도 상단 줄에 있던 대화 관리 버튼을 기관형 헤더 안으로 이동했습니다. 데스크톱은 둥근 아이콘·텍스트 버튼, 모바일은 접근 가능한 이름을 가진 아이콘 버튼입니다.

검증: 두 폴더 TypeScript/Vite 빌드 및 Node 테스트 각 67개 통과. 실제 브라우저에서 저장 그래프 열기, 로고 클릭으로 결과/질의 초기화, 그래프 표시 중 새로고침 후 초기 화면 복귀와 불필요한 검색/기호 메뉴 제거를 확인했습니다. 이번 수정은 프런트엔드에 한정하며 전체 Python 검사는 재실행하지 않았습니다.
