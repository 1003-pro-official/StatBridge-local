# 2026-10-14 — 탐색 선택지와 결과별 내보내기 정리

## 변경 내용

- 복합 질문의 금리 역질문을 지표별 확정 조건으로 처리합니다. 첫 금리 기준을 전체 질문에 적용한 뒤 같은 기준을 다시 묻던 경로를 수정했습니다. 기존에 명확한 통계표·항목을 선택하던 카탈로그 경로는 유지합니다.
- 비교 요청의 선택지에는 현재 서비스에서 지원하는 표 중, 앞서 선택한 표와 원자료 제공 기간 및 텍스트의 명시 기간이 겹치는 표만 표시합니다. 예: `대출금리와 생산자 물가를 비교해줘` → 잔액 → 생산자물가 기본/특수/품목별 3개. 1910~1964년 총지수는 제외합니다. 명시적으로 과거 자료를 탐색하는 카탈로그 자체를 삭제하지 않습니다.
- 그래프 설정 화면에서도 사용할 수 없는 종류와 합치기 선택 버튼을 표시하지 않습니다. 데이터가 합쳐질 수 없는 이유와 계열별 표시 안내는 유지합니다.
- 표의 파일 내보내기는 XLSX·CSV·PNG·PDF, 그래프는 PNG·CSV와 현재 인쇄 가능한 SVG·PDF만 표시합니다. 표 파일 버튼 중복을 제거했습니다.
- JSON 저장·가져오기, 최근 설정 열기, 초기 상태 복원은 별도 `분석 설정` 메뉴로 분리했습니다. 두 메뉴는 같은 그룹으로 묶여 한 번에 하나만 열립니다.
- SVG·PDF 가능 여부는 서버 `export_preflight`에서 실제 인쇄 렌더러와 같은 데이터·종류·편집 스타일·해상도·제목/범례/출처 배치 검증을 사용합니다. 트리맵·원·도넛·상자·히스토그램, 지원하지 않는 혼합/보조축/구간 스타일 등에는 사용 불가능한 인쇄 형식을 표시하지 않습니다. 화면 PNG는 기존 Plotly 렌더러를 사용합니다.
- 공통 버튼 모서리·글자·간격·포커스·비활성 상태를 통일하고, 워크스페이스 메뉴·표/그래프 전환·편집 도구·채팅 버튼·파일 선택 버튼을 정리했습니다. 원형 탐색 아이콘과 색상/그래프 선택 도구의 의미는 유지합니다.

## 적용 범위

`StatBridge-local1`과 `StatBridge1/StatBridge-official`에 같은 공개 코드와 회귀 테스트를 적용했습니다. 실행 포트와 쿠키 설정, API 키, 계정 및 저장 분석은 복사하지 않았습니다. 이번 작업에서는 커밋·푸시하지 않았습니다.

## 검증

최종 실행 결과를 아래에 기록합니다. 평가와 임시 UI 검증 자료는 `.venv/cache`에 보관하며 공개 코드에 포함하지 않습니다.

- 실제 local1 UI: 원래 비교 질문 → 잔액 1회 선택 → 생산자물가 3개 중 선택 → 기간 입력 단계. 연결 실패 경고 없음.
- 실제 StatBridge1 UI: 저장 분석 복원 → 표 전용 내보내기 → CSV 다운로드, 그래프로 전환 → 트리맵 편집 → PNG/CSV만 표시 → PNG 다운로드. 실제 저장 데이터 사용; 외부 KOSIS 349개 전체 조회는 실행하지 않았습니다.
- 로그인/회원가입·홈·통계 탐색·선택 조건·보관함·편집/내보내기·채팅의 버튼 소스와 공통 스타일 확인. 데스크톱/좁은 화면 배치 확인은 별도 UI 기록에 남깁니다.

- 두 200문항 최종 실행 모두 평가 시작/종료 소스 해시 일치, 모델 호출 0, HTTP/실행 경계 위반 0입니다. 공개 AI 보조 골드이며 `human_approved=false`입니다. 공식 블라인드 성능 점수로 해석하지 않습니다.
- 정합 평가의 남은 1건은 기존 REPORTER30-V2.1-194: 질문은 잔액이나 골드는 신규취급액 표 DT_181Y007을 지정합니다. local1 카탈로그의 잔액 표 DT_181Y008을 유지합니다. 동결 골드나 의미를 점수에 맞춰 변경하지 않았습니다.
- 표 UI의 네 형식을 실제 다운로드했습니다. XLSX는 워크시트 XML, PDF는 PDF 시그니처, PNG ZIP은 실제 PNG 2개와 각각 2100×1350 크기를 확인했습니다. 그래프 트리맵 PNG 다운로드도 확인했습니다.
- 390×844 좁은 화면에서 페이지 가로 넘침 없음(문서 폭 375px); 내보내기 메뉴가 x=113~333px 안에 표시되어 가장자리 잘림을 해결했습니다. 임시 화면 크기 설정은 해제했습니다.
- 기존 500kB 번들 경고는 유지됩니다. 양쪽 서버 재시작 후 API/UI HTTP 200을 확인했습니다. 재시작으로 기존 브라우저 로그인 세션이 끝나면 같은 계정으로 다시 로그인해야 합니다.
- 변경 코드·테스트·문서 9개는 두 폴더 해시가 같습니다. 통계사전과 표 마스터의 해시도 같습니다. `git diff --check` 통과.
