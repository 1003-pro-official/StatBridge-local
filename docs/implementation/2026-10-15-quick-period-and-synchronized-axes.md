# 빠른 표시 기간과 좌우 축 동기화

- 그래프 상단에 1년/5년/10년/전체 버튼을 배치했습니다. 서버가 원본 세션 자료의 마지막 관측시점을 기준으로 기간을 계산합니다. 최근 구간을 표시한 뒤에도 전체 원자료로 복원할 수 있습니다. 데이터 재조회/임의 생성은 수행하지 않습니다.
- 기간 선택은 기존 filter_period DATA_EDIT를 사용하므로 표/요약/출력의 표시 자료에도 반영되고 편집 이력을 유지합니다. 전체는 현재 세션에서 확보한 범위 전체입니다.
- 같은 단위일 때 좌우 축 범위와 눈금 간격을 동기화할 수 있습니다. 다른 단위와 로그축은 거부합니다. 왼쪽 수동 범위/눈금 우선이며 수동 범위가 없으면 현재 표시 자료에서 공통 범위를 계산합니다. 막대 0 기준과 누적 높이를 포함합니다. 오른쪽 마지막 계열 해제 시 동기화도 해제합니다.
- Plotly 화면과 SVG/PDF 인쇄에 동일 계산을 사용합니다. 저장 ChartSpec과 undo/redo에 설정을 유지합니다.

검증: Python 관련 17개 통과(월/분기/연, 1/5/10/전체 복원, 원자료 보존, 이중축과 SVG 눈금 일치, 다른 단위 거부). 실제 QuickPeriodControls/WorkspaceProperties/PlotlyRenderer 컴포넌트를 Playwright로 실행하여 12/60/120/192개월 전환과 각 전환의 실제 렌더링 축 range/dtick 일치를 확인했습니다. 로그인 전체 세션/외부 통계 재조회 검증은 아닙니다.
