# 그래프 이미지 이모티콘 패치

작업 범위는 **StatBridge-local1**이며 StatBridge1과 원본 image 폴더는 수정하지 않았다. 기능 브랜치는 `feat/chart-sticker-library`이다. AI-assisted 작업이며 이 변경은 로컬 패치 상태다.

## 이미지와 사용 방법

사용자가 제공한 6개 이미지 시트를 기반으로 투명 배경 이모티콘 **148개**를 분리했다. 이미지 생성 도구로 시트를 정리하고, `scripts/build_sticker_assets.cjs`로 아이콘 영역을 잘라 개별 RGBA PNG와 목록을 생성했다. 분리 과정에서는 옆 아이콘의 잘린 조각과 작은 분리 잔여 픽셀을 제외하고 복합 아이콘의 구성 요소와 내부 투명 영역을 보존했다. 원본 파일은 유지했다.

| 카테고리 | 개수 |
|---|---:|
| 그래프 | 22 |
| 편집 | 24 |
| 스타일 | 30 |
| 축·배치 | 22 |
| 강조·주석 | 25 |
| 데이터·저장 | 25 |
| 합계 | 148 |

파일은 `src/agent/frontend/public/stickers/`에 저장하며 목록은 같은 폴더의 `catalog.json`이다. 런타임에서는 추가 이미지 처리 라이브러리가 필요 없다. 에셋을 재생성할 때는 sharp와 정리된 시트 6개의 경로가 담긴 JSON 배열이 필요하다. sharp 모듈 경로를 `STICKER_SHARP_MODULE`로 지정하거나 sharp를 설치하고 `node scripts/build_sticker_assets.cjs <입력 JSON>`을 실행한다.

수정이 → 그림판 편집 → 이미지 이모티콘을 열어 카테고리·검색으로 이미지를 선택한다. 그래프에서 드래그 이동, 모서리 크기 조절, 상단 회전 조절을 지원한다. 슬라이더와 숫자 입력으로 크기 2~100%, 각도 -360~360도를 조정하고 투명도를 미리 확인할 수 있다. 선택 삭제와 개별 PNG 다운로드도 제공한다. 적용 후 사이드바가 닫히며 재진입해 배치를 계속 수정할 수 있다. 그림판 표시 모드와 이모티콘 배치 모드는 입력을 서로 가로채지 않도록 전환한다.

## 저장과 렌더링

- `ChartSpec.stickers`가 이미지 ID, 위치, 크기, 회전, 불투명도를 저장한다. 그래프당 최대 40개다.
- `GET /api/stickers`는 허용 목록을 제공한다. 외부 이미지 URL과 임의 파일 경로를 받지 않는다.
- 기존 `POST /api/output/edit`에 `stickers` 배열을 추가했다. 원자료 재조회와 HCX 해석 없이 검증된 배치를 한 번에 적용한다. 텍스트·표시 편집과 혼합 요청은 거부한다.
- 편집 버전 충돌 검사, 실패 시 기존 상태 보존, 취소·다시 적용을 기존 편집 세션과 함께 사용한다. 기간 재조회 후에도 그래프 영역의 상대 위치를 유지한다. 표현 스타일 초기화는 이모티콘도 제거한다.
- PNG를 회전 여백이 있는 정사각형 SVG에 내장해 Plotly 이미지로 렌더링한다. 브라우저 미리보기와 PNG 내보내기가 같은 비율·회전을 사용하고 외부 이미지 URL에 의존하지 않는다.
- 기존 편집 세션과 동일하게 서버 메모리에 저장하므로 서버 재시작 후 복구는 제공하지 않는다. 위치는 관측값에 연결된 좌표가 아닌 그래프 영역의 상대 좌표다.

148개 파일 전체를 대상으로 PNG 시그니처, RGBA 형식, 투명 여백, 목록·파일 대응을 확인하고 흰 배경의 전체 미리보기도 시각 점검했다. 잘못된 이미지 ID·외부 URL·중복 ID·개수 초과·NaN/무한대·크기/각도/위치 범위 오류를 검증했다. 새 명령은 기존 모든 편집 명령 렌더링 테스트에도 추가했다.

실제 브라우저와 local1 코드를 실행한 별도 API/UI 포트에서 합성 통계 데이터로 검색, 화살표 추가, 이동, 크기와 회전 조절점, 수치 입력, 적용 후 자동 닫힘, 다시 열었을 때 값 복원, 이어서 재수정, 편집 취소·다시 적용을 확인했다. 실제 PNG 다운로드를 실행하고 저장된 이미지에 회전된 화살표가 포함된 것도 시각 확인했다. 테스트는 외부 KOSIS·HCX 호출 성능을 평가한 것이 아니며 이 기능은 해당 호출 없이 적용된다. 임시 검증 스크립트와 화면 기록은 `.venv/cache/`에 보관하고 공개 소스에는 포함하지 않는다.

## Windows 실행 위치

- 실행: `StatBridge-local1/scripts/windows/START_STATBRIDGE.cmd`
- 종료: `StatBridge-local1/scripts/windows/STOP_STATBRIDGE.cmd`

START 스크립트는 자신의 위치를 기준으로 local1 루트를 계산하고 Agent API와 프런트엔드를 실행한다. 실제 파일 존재와 경로 계산 코드를 확인했다.
