# 2026-10-19 StatBridge 동적 파생지표 작업 기록 (ai-assisted)

## 목적과 최종 범위
미리 정의한 지표 레시피 대신 사용자의 자연어 요청으로 GPT-5.4가 승인 한국은행 KOSIS 349개 통계표를 검색하고, 검증된 원자료 선택과 제한된 계산 DAG를 구성하도록 구현했습니다. Python이 계산하고 기존 OutputAgent·ChartSpec으로 그래프와 표를 출력합니다. 일반 조회와 기존 저장 분석 흐름을 보존했습니다.

## 오늘 진행한 작업
1. 현재 LangGraph·StatisticsService·OpenAI·OutputAgent 호출 구조를 조사하고 계산 트리 스키마와 엔진을 설계했습니다. 기본 연산 14개와 기간 비교용 period_change를 지원합니다. 표·항목·분류·주기·단위·기간·연산·깊이·작업량을 독립 검증하고 임의 코드 실행을 금지했습니다. 실제 API 출처와 관측값으로만 계산하며 분모 0·정의역·결측을 기록합니다.
2. 계획·조회·계산·출처·사용량을 불변 근거로 저장했습니다. 소유권을 검사하고 편집 시 이전 근거를 연결해 변경 노드와 후손을 재계산합니다. 산식·입력·조회기간·단위를 출력 UI에서 확인하도록 보완했습니다.
3. 300개 개발 평가 사례를 만들고 독립 Decimal 계산·보안·실패·편집을 평가했습니다. API 기반 항목/분류/주기/기간 검토와 실제 GPT 평가를 구분했고, 공급자 크레딧 소진은 성공으로 세지 않았습니다. 실패 10건 및 후속 8건을 원인별 패치하고 관련 사례를 재실행했습니다.
4. 실제 KOSIS TBL·ITM·PRD API로 승인 349개 표를 확인하는 인벤토리를 구현했습니다. 모델 검색 실패를 곧바로 데이터 부재로 간주하지 않도록 보완하고 API 장애와 미확보를 구분했습니다.
5. 엔진을 입력·출력 최대 12개 및 일별 D 자료까지 확장했습니다. 두 기간 변화율·환율 표시 방향·DXY 지수·평균 포함 범위를 구분하고 달력일·결측 정책을 유지합니다. **현재 승인 API 표의 일별 지원 여부와 엔진의 일별 계산 지원은 별개**입니다. 엔진이 지원해도 실제 자료가 없으면 API 확보로 표시하지 않습니다.
6. API와 파일을 결합하는 보완 작업을 구현했습니다. 필요한 자료명·기간·주기·단위·입수처 후보·계산법을 안내하고 CSV/JSON/TSV/XLSX 양식과 업로드·텍스트 입력을 제공합니다. 파일당 2MB·6,000행, 수식·매크로·외부 링크 실행 금지, 계정별 연결 및 출처 구분을 유지합니다. 자료 연결 후 재검증해 계산을 이어갑니다.
7. 조건 확인을 오류 카드 대신 확인 질문으로 표시하고 실제 부족 자료가 있을 때 파일 연결을 제공합니다. API가 하나라도 실제 최종 계산에 연결되면 외부 보완을 허용하고, 전부 외부 자료이거나 회사·개인 매출·급여·재고 요청이면 지원 범위와 질문 재작성 방법을 안내합니다. 임의의 API 계열을 끼워 지원 범위를 우회할 수 없도록 검사합니다.
8. 한국은행 간행물에서 정리한 1,766개 후보는 검색 참고 목록으로만 사용합니다. 검증된 레시피나 모든 계산 가능 목록으로 표시하지 않습니다. 실제 원자료 확보가 별도로 필요합니다.
9. 계획·메타데이터·파일 준비 중복 요청을 재사용하고 단순 조회·단일계열 변화율에 불필요한 사전 호출을 추가하지 않았습니다. 경제적 의미 검토는 유지합니다. 검색 한도 소진을 API 입력 0개로 단정하던 경로를 수정했습니다.
10. `2023년 1월부터 4월까지 … 2020=100`에서 기준연도를 종료연도로 읽던 공통 기간 오류를 수정했습니다. 월·일·분기의 생략된 연도를 이어받고 여러 비교기간은 임의 병합하지 않습니다. 비율·차이·합계·곱셈·실질화·가중평균·비교 요청은 API/업로드 같은 특별한 지시 없이 원자료 확인으로 진입합니다.
11. 두 실행 폴더의 코드·문서·테스트를 대조하고 환경 설정·계정·저장 분석·포트·원자료·실행 기록은 보존했습니다. 두 백엔드를 재시작해 실제 앱에 적용하고 사용자 원문으로 UI를 확인했습니다.

## 평가 결과를 읽는 방법
- v6 당시 실제 GPT 300건 실행은 292 통과·8 실패·미실행 0이었습니다.
- 후속 v7에서 요청된 실패 8건은 8 통과, 관련 150건은 150 통과했습니다. 나머지 150건을 v7에서 다시 실행하지 않았고, 이후에도 기능 변경이 있었으므로 **현재 코드의 실제 GPT 300/300 통과라고 주장하지 않습니다**.
- 평가 정답은 AI 보조 작성이며 경제학 전문가 승인은 미완료입니다. 수정에 사용한 분할은 회고적 평가이며 블라인드 홀드아웃 점수로 표시하지 않습니다. 공개 저장소의 비공개 정답 자료를 사용하지 않았습니다.
- 이전 단계의 전체 회귀 수치는 해당 시점 코드 결과입니다. 최종 자연어 공통 처리 관련 회귀는 두 폴더 각각 922 통과·실패 0·건너뜀 0이며, PR 복제본의 전체 검증 결과는 아래 별도 기록을 정본으로 삼습니다.
- 실제 GPT/KOSIS 대표 요청: PPI 2023년 1~4월은 4개 관측값 확보, CPI는 승인 범위 미확보로 입수처·업로드 안내. 수입물가/CPI 조합은 5개 관측값 확보 및 단순비율/백분율 확인 질문. 수출·수입물가 전년동월 상승률 차이 4개월은 실제 API 및 전년 이력으로 계산하고 Decimal 검산 오차 1e-10 %p 이내였습니다.
- 실제 CPI 파일을 이번 최종 점검에서 업로드하지 않았으므로 해당 조합의 최종 그래프 실증으로 보고하지 않습니다. 과거 파일 보완 E2E와 모의 데이터 검증은 실제 KOSIS 통합 검증과 구분합니다.
- 기존 계정·저장 분석·.env 해시를 보존했고 테스트 계정 저장 분석 7개 HTTP 복원에 성공했습니다. 인증 정보나 계정 DB는 PR에 포함하지 않습니다.
