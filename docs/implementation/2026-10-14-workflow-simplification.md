## 목표와 사용자 동선

질문 → 부족한 조건만 확인 → 조회와 기본 그래프 자동 생성 → 필요한 편집 → 분석 저장/파일 내보내기로 연결합니다. 원래 질문·카탈로그·수치·표/항목·기간 검증은 유지합니다.

- 조회 후 필수였던 그래프 생성 클릭과 ‘그래프 요청’ 재입력을 기본 경로에서 제거했습니다. 기존 API의 조회/출력 단계는 유지하면서 화면이 캐시된 조회 세션을 자동 출력으로 연결합니다.
- 마지막 역질문 선택에서 조건과 기간이 준비되면 곧바로 조회·출력합니다. 항목이 실제로 모호하거나 기간이 빠진 경우에는 여전히 확인합니다.
- `quick_output: true`인 기본 출력은 규칙 기반 차트 종류·배치·제목과 서버 계산 사실의 존댓말 요약을 생성합니다. 추가 출력 모델을 호출하지 않으며 명시한 지원 차트 종류를 보존합니다. 요청·출처·차트 적합성 검증은 유지합니다.
- 복합 차트 또는 표현 불가 요청은 조회 자료를 유지하고 지원 종류 선택으로 연결합니다. 기존 그래프가 있으면 유지합니다. 출력 재시도는 캐시된 출력 세션을 재사용합니다.
- 명확한 기본 색·HEX·유효한 RGB 요청은 재확인 없이 적용합니다. 알아서 색 선택·미지원 색·잘못된 RGB 등의 요청에는 색상 확인이 남습니다.
- ‘분석 저장’은 그래프를 계정에, 대화와 편집 기록을 이 브라우저에 보관합니다. ‘분석 보관함’은 계정 그래프와 브라우저 임시 분석을 같은 ID 기준으로 합쳐 표시하며 각각의 보관 위치를 설명합니다. 대화의 PC 간 자동 동기화는 추가하지 않았습니다.
- 새 채팅과 새 분석은 이전 분석을 브라우저에 임시 보관하고 진행합니다. 보관 실패 시 기존 화면을 유지합니다. 삭제는 보관함의 명시적인 사용자 선택으로만 수행합니다.
- JSON 등 파일 내보내기를 분석 저장에서 분리했습니다. 채팅창 중복 저장/새 채팅/목록 버튼과 진입할 수 없던 이전 MultiIntent 화면을 제거하고, 디자인 미리보기는 접힌 메뉴로 옮겼습니다.
- 마지막 후처리에서는 이전 미지원 지표 질문이 다음 출력 형식 오류와 함께 남지 않도록 상태를 정리했습니다.

## API·데이터 경계

`POST /api/output`에 선택 필드 `quick_output`을 추가했습니다. 기본값 false여서 기존 직접 API 호출 계약은 유지합니다. `/api/query`의 execute=false 계획 평가와 실행 경계, 표·분류·파라미터 선택 방식은 변경하지 않았습니다. 현재 LangGraph·MCP 경로와 편집 버전·원자료·실행 기록 검증도 유지합니다.

StatBridge1은 Git 저장소가 없는 로컬 보관본입니다. 공개 평가 실행기의 `--local-copy` 옵션은 Git 커밋을 만들거나 점수를 바꾸지 않고, 실제 소스·카탈로그·데이터셋·정책 해시를 실행 환경에 기록합니다. 동일한 원본 점수 함수·시간 제한·수치/출력 경계 가드를 사용합니다.

## 보존과 산출물

원시 결과와 스크린샷은 각 .venv/cache/evaluation_runs에만 보관합니다. 공개 커밋 대상에 평가 결과·원응답·개인 계정·API 키·CSV를 넣지 않습니다.

재현(기본 저장소 루트):

```powershell
.venv/Scripts/python.exe scripts/evaluate_reporter200_local.py --goldset-root ../StatBridge-local1-fork/eval/reporter-table-discovery-30/v2.1 --source-catalog ../StatBridge-local1-fork/src/agent/stat_dictionary/stat_language_dictionary.json --output-dir .venv/cache/evaluation_runs/workflow_recheck --offline
# StatBridge1에서는 자체 실행기를 사용하고 데이터셋/원본 카탈로그 경로를 절대 경로로 지정하며 --local-copy를 추가합니다.
```

현재 검증 결과는 첫 local1 기준선 workflow_simplify_before_20261014, 최종 local1 workflow_simplify_final_20261014, 최종 StatBridge1 workflow_final_copy_20261014에 있습니다. 평가 시 외부 모델을 차단하고 실제 수치·출력 실행을 가드하므로, 모델 비사용 계획 검증과 실제 UI 시험은 서로 다른 검증 범위입니다.
