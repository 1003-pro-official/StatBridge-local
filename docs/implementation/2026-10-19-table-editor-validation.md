위 수치는 서로 겹치는 회귀 검증을 포함하므로 합쳐서 독립 질문 수나 고유 평가셋 크기로 보고하지 않습니다. 참조 평가셋은 첨부 PDF 3개 페이지에서 발췌한 88개 원관측값이며, 22개 계산 셀을 독립 Decimal 수식으로 검증합니다. 원본 ZIP 46개 그림표 전체를 88개 질문으로 평가했다는 의미가 아닙니다.

전체 공개 회귀는 Python 소스·테스트 파일 해시가 실행 중 변하지 않은 상태로 93개 파일을 3개 독립 프로세스에서 실행했습니다. 291.04초가 걸렸습니다. 그 뒤 CSV 음수/양수의 숫자형 표시와 PNG 픽셀 예산 조기 중단 검증 2건을 추가하여, 최종 관련 평가 88건을 두 폴더에서 각각 다시 통과했습니다. 전체 1,964건은 마지막 2건 추가 전의 광역 회귀 결과이고, 이후 최종 내보내기 보완은 관련 88건과 두 정상 앱의 실제 파일 출력으로 검증했습니다.

## 오류와 수정

초기 전체 실행에서는 먼저 메모리에 로드된 이전 머리글 구조와 개발 도중 갱신된 내보내기 코드가 섞여 `format`/`markers` KeyError 10건이 발생했습니다. 머리글 서식 필드가 없는 이전 구조의 파일 출력도 지원하는 기본값을 추가하고, 코드 고정 상태로 전체 회귀를 재실행하여 10건을 모두 해소했습니다. 이전 구조 CSV/XLSX/PDF/PNG 회귀 4건도 추가했습니다.

실제 UI에서는 가로 스크롤 시 다단 머리글의 첫 하위 열까지 고정되는 충돌을 발견했습니다. 이름 열만 고정하도록 수정했고, 현재 행 이름과 비교 열을 함께 확인할 수 있습니다. CSV의 단순 음수/양수 숫자는 수식 이스케이프 문자 없이 유지하며, 실제 수식 문자열은 계속 차단합니다. PNG는 누적 픽셀 한도를 매 페이지 생성 후 확인해 큰 이미지를 끝까지 쌓기 전에 중단합니다.

## 첨부 표별 실제 검증

| 첨부 PDF 물리적 쪽 | 참조 자료 | UI 및 파일 검증 |
|---|---|---|
| 5쪽 | 3개 조사 시계 × 4개 응답 구간, 24개 관측값 | 다단 A/B/차이 36셀, 각주 추가, 실제 XLSX 다운로드. 오프라인 4종 출력·Decimal 검산 |
| 13쪽 | 가계신용/가계대출 연간·분기 14개 관측값 | 7개 연·분기 행 직접 배치와 실제 XLSX 다운로드. 서로 다른 주기를 합산하지 않음 |
| 18쪽 | 금액/건수 10개 계열 × 5개 반기, 50개 관측값 | 행 그룹·연도 머리글·증감(증가율), 셀 서식 편집·undo/redo·분리 계정 DB 저장, 실제 XLSX/CSV/PDF/PNG 다운로드 |

XLSX 계산근거 시트는 각각 36·14·60개 수치 셀을 보존하며, 실행 가능한 Excel 수식을 포함하지 않습니다. 계산값과 원자료 관측값·단위·주기·A/B 시점을 대조했습니다. 보고서 그림의 계산 결과를 정답으로 복사하지 않고 원관측값과 별도 수식으로 검산했습니다.

정상 앱 두 개에서도 기존 저장 분석을 열고 상세 표 편집과 실제 Excel 다운로드를 확인했습니다. local1에서는 실제 저장된 주택담보대출 관측값 1,354.3과 2,128.6의 차이 774.3을 새 비교 열로 생성하고 Decimal 검산·Excel/PDF 출력을 확인했습니다. 최종 재시작 후 두 앱 모두 4종 내보내기를 다시 실행했고, 표 편집 전후 그래프 관측값이 동일했습니다. 정상 앱의 기존 저장 분석 파일에는 테스트 편집을 덮어쓰지 않았습니다.

브라우저의 주 보관함은 두 앱 모두 5개였고, 기존 초과 15개는 별도 이전 기록에서 확인했습니다. 서버 최대 5개 저장 정책과 동시성 검증도 유지했습니다.

## LIMITATION / 미실시

- PDF 5·13쪽은 명시한 항목의 발췌 구조 검증입니다. 원본 25쪽과 ZIP 전체 그림표의 완전 재현·픽셀 일치 평가는 미실시입니다.
- 이번 표 편집 평가는 실시간 KOSIS 조회나 GPT 자연어 지표 해석 품질을 검증하지 않았습니다. 첨부 고정 관측값 및 기존 저장 관측값을 사용했습니다.
- 독립 통계 전문가 승인, 인쇄소의 교정쇄 품질 검수는 미실시입니다.
- 서식/주석/배치와 검증된 비교식만 편집하며 원자료 수치를 임의로 수정하지 않습니다. 큰 PNG는 예산 초과 시 PDF/Excel 출력을 안내합니다.
- Vite는 기존 대형 번들 크기 경고를 출력하지만 타입 검사와 빌드는 통과했습니다.

생성된 원본 백업·계정 DB·내보내기 파일·평가 로그는 .venv/cache에 두며 공개 커밋에 포함하지 않습니다. PR 생성이나 게시 작업은 이번 요청에서 수행하지 않았습니다.
