# 2026-10-14 스냅샷 기준 그래프 출력·편집 품질

ai-assisted 구현입니다. local1과 StatBridge1/StatBridge-official의 공개 기능 코드를 동기화했습니다. 계정·저장 그래프·API 키·포트·쿠키는 각 폴더 설정을 유지했으며 커밋·푸시는 실행하지 않았습니다.

## 확인한 원본과 적용 범위

[한국은행 금융·경제 스냅샷](https://snapshot.bok.or.kr/)의 금융기관 여수신 화면과 확대 그래프를 직접 확인했습니다. 얇은 선, 절제된 색상, 상단 범례, 좌우 축, 값 표시, 기간 조절, 출처와 주석의 분리 배치를 확인했습니다. 독립 참고 이미지는 실제 브라우저에서 다음 그래프를 캡처했습니다.

- [예금은행 가계대출금리, 862](https://snapshot.bok.or.kr/chart.html?id=862): 세 계열 선 그래프
- [가계대출 및 판매신용 증감액, 1174](https://snapshot.bok.or.kr/chart.html?id=1174): 양수·음수의 나란한 막대 그래프
- [예금은행 여수신 금리, 861](https://snapshot.bok.or.kr/chart.html?id=861): 두 선·한 막대와 좌우 축

사이트 전체의 모든 지표·지도·특수 시각화를 재현했다고 주장하지 않습니다. 사이트의 ECOS 수치나 지표명을 현재 KOSIS 조회 결과로 복사하지 않습니다. 이번 구현은 지원되는 현재 지표와 차트의 표현 품질을 개선하는 전용 디자인이며 한국은행의 공식 양식·공식 구현이 아닙니다.

## 변경한 기능

1. `스냅샷 보고서형` 디자인을 추가하고 새 기본 출력에 적용했습니다. 흰 배경, 파랑·갈색·청록 계열, 얇은 선, 점 없는 시계열, 절제된 격자와 한글 글꼴을 사용합니다. 기존 저장 명세에는 새 기본 디자인을 강제로 적용하지 않습니다.
2. `마지막 관측값만 표시` 옵션을 추가했습니다. 표시 수치는 조회한 마지막 관측값이며 가까운 값은 글자 위치만 분리합니다. 막대의 배치 계산에는 0 기준을 포함합니다. 원래 시점·값·지표·단위·주기는 그대로입니다.
3. 같은 표 이름이 반복되는 자동 제목과 범례를 정리했습니다. 실제 지표 이름과 사용자 이름은 보존하고 전체 원명은 hover/meta에 남깁니다. 복합축은 범례에 좌축·우축을 표시합니다. 막대 범례의 색상도 실제 막대 색을 사용합니다.
4. 월·분기 날짜를 읽기 쉽게 표시하고 여러 패널은 눈금 밀도를 줄입니다. 스냅샷 비교 패널은 최대 4열로 감싸며 내보내기도 선택한 열 수와 필요한 높이를 사용합니다. 좁은 실제 화면에서 발견한 마지막 두 날짜의 겹침은 화면 폭에 맞춘 표시 눈금 조정으로 수정했습니다. 모든 관측값은 유지하며 명시적인 눈금 간격은 유지합니다.
5. 사용자 선 모양을 테마의 기본 실선이 덮는 문제를 수정했습니다. 사용자가 지정한 높이는 명세에 보존하며, 제목·범례·각주·실제 출처가 길면 겹치지 않도록 출력 높이가 더 늘어날 수 있습니다.
6. SVG·PDF 인쇄에 실제 선/막대·좌우 축 연결을 유지합니다. 오른쪽 선을 막대로 바꾸지 않습니다. 보조축의 불필요한 테두리와 막대가 선을 덮는 문제를 수정했습니다. 원자료 출처는 `KOSIS` 등 사용자용 이름으로 표시합니다.
7. VLM이 읽은 `series_types`와 `secondary_axis_indices`를 검증해 현재 실제 계열에 연결합니다. 계열 수가 다르면 연결할 지표를 요청합니다. 없는 금리차·증가율·추정값을 생성하지 않습니다. 기본 종류 변경은 계열별 종류 설정보다 먼저 적용합니다. 한 번의 전체 형식 요청에서 반복 스타일 패치와 동일한 축·범례 명령만 정리하며 일반 편집의 12개 명령 한도는 유지합니다.
8. 잘못된 첨부의 오류 응답에서 이미지 base64 원문이 그대로 채팅에 반환되던 문제를 수정했습니다. 작은 오류 응답을 반환하고 위치는 `참고 그래프`로 안내합니다. 실제 JPEG 캡처에는 JPEG MIME을 사용하도록 하네스도 보완했습니다.

## 실제 모델과 파일 출력 검증

`eval/chart-reference/snapshot-v1/cases.json`에 공개 출처, 현재 카탈로그 조회 조건과 기대 구조를 기록했습니다. 실행 방법은 [스냅샷 진단 안내](../../eval/chart-reference/snapshot-v1/README.md)에 있습니다.

실제 GPT-5.4를 사용해 각 그림을 첨부하고 `이렇게 그려줘`를 요청했습니다. 자료는 현재 KOSIS의 기업대출·대기업대출·중소기업대출 금리, 2024년 1월~2025년 12월, 3계열 72개 관측값입니다. 참고 그림의 가계대출·금리차·증감액 데이터와 같은 내용이 아닙니다. 곡선과 막대의 모양을 원본 수치에 억지로 맞추지 않았습니다.

| 실행 | local1 | StatBridge1 | 범위 |
|---|---|---|---|
| 파일 내보내기 포함 세 사례 반복 | 선·막대 통과, 복합축은 오른쪽 축 누락 | 3종 통과 | 실제 HTTP 편집, 관측값·원행 hash, 기본/수정 후 PNG·SVG·PDF |
| 시각 구조 연결 보완 후 복합축 재검증 | 통과, 36.625초 | 통과, 26.078초 | 실제 두 선·한 막대·오른쪽 축, 관측값·원행 보존, 3형식 파일 |

세 사례 반복의 local1 편집 시간은 21.047/34.484/27.953초, StatBridge1은 22.359/19.500/43.469초였습니다. 각 사례는 모델 해석·검토 요청 2회를 사용했습니다. 성공한 호출만 묶어 일반적인 VLM 성공률을 만들지 않습니다. 최초에는 캡처의 실제 JPEG 형식과 PNG MIME이 달라 모델 호출 전에 실패했고, 이어 복합축 명령 개수 초과와 축 누락을 실제로 확인해 보완했습니다.

하네스는 실제 `/api/query` → `/api/output` → `/api/output/edit` → `/api/report/export`를 사용합니다. 계정 DB는 실행 폴더에 격리합니다. 통계 계약·계열 종류·좌우 축·실제 그리기 영역을 자동 검사하며, 겹침·색·글꼴·읽기 쉬움은 출력 그림을 직접 확인합니다. 두 축이 겹쳐 있는 한 그래프와 실제 여러 패널은 별도로 판정합니다. 원본과 같은 픽셀·같은 곡선의 재현 점수가 아닙니다.

마지막 테두리·범례·출처 보완 후에는 저장된 실제 모델 명령과 실제 조회 관측값을 최종 렌더러로 다시 PNG·SVG·PDF로 출력했습니다. 관측값이 변하지 않는지 다시 비교했습니다. 이는 새 모델 호출이 아닙니다. PDF 한 페이지의 한글·축·범례·출처를 렌더해 확인했습니다. Poppler의 Unicode 설치 경로 때문에 Bulgarian/Greek/Thai 매핑 경고가 있었으나 확인한 한글 본문은 정상입니다.
