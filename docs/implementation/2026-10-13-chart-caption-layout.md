# 차트 종류와 출처 배치 수정 (ai-assisted)

워크스페이스의 차트 종류는 현재 데이터에 대해 서버가 검증한 supportedChartTypes만 표시합니다. 원·도넛·트리맵은 최소 본체 높이와 범례 공간을 확보하며, 차트 전환 후 Plotly resize가 완료된 다음 렌더링 완료를 표시합니다.

출처·각주·구성비 설명은 화면에서 X축과 분리된 하단 영역에 표시합니다. 서버의 일반 그래프와 보고서 그래프에는 축 눈금·축 제목·하단 범례·출처 순서로 공간을 예약합니다. 여러 패널은 행 간격을 확보하고 가로 배치는 패널별 최소 폭과 수평 스크롤을 사용합니다. 사용자가 직접 배치한 주석은 이동시키지 않습니다.

검증: 두 프런트엔드 타입 검사/빌드 및 Node 75개 통과. 전체 백엔드 회귀 local1 855개, StatBridge1 846개 및 각각 355 subtests 통과 후, 보고서 경로 추가 수정에 대한 관련 회귀는 각각 188개 통과했습니다. 일반/보고서 출처 배치 새 검사는 87개입니다. 실제 앱 렌더러의 합성 수치 브라우저 87개 사례(1~10개 계열, 결합/세로/가로/격자, 원/도넛/트리맵, 보고서)를 검사했으며 축과 출처 간 최소 간격은 55px 이상입니다. 실제 KOSIS 결제통화 네 계열에서 지원 목록과 원/도넛 4조각, 트리맵 4개 범주 표시를 확인했습니다. 내보내기 레이아웃은 명세 검사로 검증했으며 모든 출력 파일 형식의 실물 검사는 포함하지 않습니다.

두 CMD로 최종 서버 재시작 및 건강 상태 확인. 새 의존성/실행 파일 수정은 필요하지 않습니다. 설정·계정·저장 데이터는 복사하지 않았습니다.
