# 조회 관측값에 한정한 존댓말 보고서 요약

## 변경 이유

기존 모델 입력은 시작·끝·최솟값·최댓값으로 제한되어 최근 변화 흐름을 충분히 설명하지 못했습니다. 기본 요약에도 반말 종결이 남아 있었습니다.

## 참고 자료와 적용 범위

- [한국은행 2025년 7월 금융기관 가중평균금리](https://www.bok.or.kr/portal/bbs/B0000501/view.do?menuNo=201264&nttId=10093183): 최신 금리 수준과 전월 대비 변화를 함께 서술합니다.
- [한국은행 2026년 8월 금융기관 가중평균금리](https://www.bok.or.kr/portal/bbs/B0000501/view.do?menuNo=201264&nttId=11065098): 수준 유지와 상승을 구분하고 금리 차이는 %p로 표시합니다.
- [한국은행 통화신용정책보고서 2026년 3월](https://www.bok.or.kr/portal/bbs/B0000156/view.do?menuNo=200067&nttId=10096935): 관측 동향과 전망·경제적 평가를 구분합니다. 본 앱에는 조회값에서 확인되는 동향 서술만 적용합니다.

보고서 전체를 학습하거나 런타임 검색 자료로 제공하지 않았습니다. 참고 자료의 실제 수치·원인·전망을 사용자 그래프에 재사용하지 않습니다.

## 구현

`report_summary.py`가 원자료에서 최신 수준, 직전 기간과 전년동기 차이, 조회 시작 시점 대비 차이, 연속 변화와 방향 전환, 변화폭 확대·축소를 계산합니다. 월·분기·연간 간격을 검사하며 결측 시점을 메우지 않습니다. 음수·0 기준값에서도 차이만 계산하며 근거 없는 증가율은 생성하지 않습니다. 서로 다른 단위의 계열을 합산하거나 직접 크기 비교하지 않습니다.

GPT에는 현재 조회 관측값과 서버가 계산한 근거 문장만 전달합니다. 응답은 문장 ID 목록으로 제한하며 서버에서 존재 여부, 중복, 필수 최신값과 비교 문장, 계열별 문장 수를 검증합니다. 모델의 새로운 숫자·문장·인과·전망은 출력할 수 없습니다. 잘못된 응답은 기본 근거 문장으로 대체합니다. 모델 내부 사고 자체를 통제하는 방식은 아니며 출력 가능한 주장과 입력 자료를 제한하는 방식입니다.

현재 자료 경로는 KOSIS 조회와 기존 원자료 CSV를 유지합니다. 요약은 해당 조회 결과만 사용하며 외부 문헌이나 사용자 제목을 사실 근거로 추가하지 않습니다. 요약에 사용된 문장 ID와 관측 근거는 `outputSpec.explanation.factIds/facts`로 확인할 수 있습니다. 그래프 변환 전 원자료를 표시 기간으로 제한해 설명합니다. 근거가 동일한 스타일 수정은 기존 요약을 유지합니다.

변경 대상은 StatBridge-local1입니다. 다른 checkout은 변경하지 않았습니다.

## 검증

새 테스트는 존댓말, 최근 변화폭, 결측 간격, 분기·전년동기·%p, 0·음수·단일 관측·복수 단위, 모델 자유 문장 거절, 그래프 변환과 원자료 구분, 스타일 수정 요약 유지와 연간 주기를 다룹니다. 기존 모델 mock은 ID 선택 계약에 맞췄습니다.

- 출력·요약 관련 테스트: 최종 52 passed, 1 deselected (전체 질의 HTTP 테스트 1건 제외).
- 공개 v4.1 자료 검증: VALIDATION OK.
- 프런트엔드 build: 성공. 기존 대형 bundle 경고가 있습니다.
- git diff --check: 통과.
- 실제 KOSIS 경제심리지수 원계열 `DT_513Y001`, `objL1=13102134473ACC_CD.E1000`, 202501~202512: 12개 관측값 조회. GPT-5.4가 latest/previous/pace 근거 ID를 선택했습니다. 최신 관측값 93.5, 전월 관측값 94.5, 1 하락 및 하락폭 확대 문장이 반환되었습니다. 처음 분류 ID를 생략한 호출은 KOSIS 오류였으며 정본 분류를 포함한 호출로 확인했습니다.
- 전체 766개 테스트는 실행했으나 `test_catalog_dimension_codes_survive_period_step`의 HTTP 요청에서 완료되지 않아 중단했습니다. 전체 통과로 보고하지 않습니다. 이번 작업에서는 해당 API 대기 문제를 수정하지 않았습니다.

실제 브라우저 UI와 전체 질의→출력 HTTP 흐름은 이번 작업에서 검증하지 않았습니다. 기존 실행 중인 서비스를 변경하거나 재시작하지 않았습니다.
