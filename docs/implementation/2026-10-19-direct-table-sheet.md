# 첨부 표를 바탕으로 한 셀 직접 편집

## 재검토한 자료와 결정

사용자가 업로드한 한국은행_표그래프_팀공유_20261019.zip의 PDF 25쪽과 XLSX 12개를 재검토했다. 기존 추출 PDF와 ZIP 내부 PDF의 SHA256을 비교했고, 엑셀의 병합 범위·배경색·굵은 글자를 조사했다. 첨부 파일은 참조 자료이며 코드나 지시문으로 실행하지 않았다.

- PDF 5쪽: 조사 시계별 가로 병합과 A/B/차이 하위 열.
- 7·8·13쪽: 긴 표와 계층형 머리글, 세로 방향 구분.
- 17쪽: 표 일부의 녹색 채우기.
- 18쪽: 금액/건수 행 묶음, 최신 열 강조, 구분선과 증감·증가율 복합 셀.

정해진 템플릿만으로는 임의 위치의 편집 요구를 충족하지 못하므로, 기존 고급 설정을 보존하면서 셀 격자 직접 편집을 첫 화면에 배치했다.

## 사용 방법

1. 분석 결과에서 **표**를 선택한다. 기존 표에 직접 편집이 꺼져 있으면 **셀 직접 편집 시작**을 누른다.
2. 마우스 드래그 또는 Shift+클릭으로 범위를 선택한다. 행 번호·열 문자로 전체 행·열을 선택할 수도 있다.
3. **셀 병합** / **병합 해제·분할**, 색상 팔레트·사용자 색, 글자색·굵게·크기·정렬·테두리를 적용한다. 우클릭 메뉴도 제공한다.
4. 열 문자 오른쪽 경계와 행 번호 아래쪽 경계를 드래그하여 크기를 바꾼다. 경계에 키보드 포커스를 주고 방향키로도 조절한다.
5. 머리글·행 제목은 더블클릭 또는 F2로 문구를 수정한다. Enter 또는 다른 셀로 이동하면 반영되고 Esc는 취소한다.
6. 기존 되돌리기/다시 실행, 분석 저장/복원, XLSX·PDF·PNG·CSV 내보내기를 사용한다.

표 모드에서는 데이터·속성·편집 대화를 접어 격자 공간을 확보한다. 각각 다시 열 수 있다. 그래프 모드의 편집 기능은 유지한다.

## 데이터와 이력 보호

병합은 범위 안에 있던 모든 표시 내용을 줄바꿈으로 함께 표시한다. 합산하거나 왼쪽 위 값 이외의 값을 버리지 않는다. 분할하면 원래 위치와 수치가 복원된다. 관측 수치는 직접 덮어쓰지 못한다. 숫자를 바꾸려면 검증되는 계산식/원자료 경로를 사용한다. Excel의 수식 입력·임의 행/열 삽입까지 구현한 것은 아니다.

표시 격자(sheetRows)만 변경하고 원본 series/layoutRows와 수치·출처를 유지한다. 서버가 병합 사각형, 존재하는 행/열, 구역 경계, 중복·부분 겹침, 텍스트 길이·서식 자원 한도를 검증한다. 실패 시 기존 표와 편집 버전을 유지한다. 기존 계정별 권한·편집 이력·분석 보관함 경로를 재사용한다.

XLSX는 병합·색상·행열 크기와 계산근거 시트를 저장한다. PDF/PNG는 같은 격자에서 그리며, 여러 페이지에 걸친 병합은 해당 페이지에 해당하는 원래 내용만 출력한다. CSV는 셀 텍스트와 빈 피복 셀을 내보내며 색상·병합 속성은 CSV 형식상 보존하지 않는다. 내보낸 문자열은 수식 주입을 방지한다.

## 구현과 검증 범위

- table_cell_grid.py: 공유 셀 격자·병합/분할·범위 서식 검증.
- table_sheet_image.py: 공유 격자의 PDF/PNG 출력.
- TableSheetEditor.tsx / tableSheetSelection.ts: 직접 선택·서식·크기·키보드 편집.
- tests/test_table_sheet.py: 새 직접 편집 회귀, 기존 tests/test_table_layout.py: 첨부 5·13·18쪽과 독립 Decimal 검산.
- tools/run_table_edit_eval.py: 외부 HTTP를 전송 전에 차단하는 관련 평가.

관련 평가는 첨부 고정 관측값을 사용하며 실시간 KOSIS나 GPT 계획 품질 평가로 보고하지 않는다. 셀 직접 편집과 이 평가의 GPT 호출은 0회다. 실제 실행 결과와 UI/파일 증거는 별도 검증 문서에 기록한다.
