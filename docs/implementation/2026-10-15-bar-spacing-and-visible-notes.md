# 막대 편집과 설명 표시 보완

- 막대가 있는 차트에서 막대 두께(20~100%), 같은 시점의 막대 간격(0~80%)을 편집합니다. 적용/얇은 막대/기본값 복원 버튼을 제공합니다.
- Plotly bargap/bargroupgap와 벡터 인쇄의 막대 폭을 같은 비율로 계산합니다. 두께는 시점별 전체 막대 영역의 비율이며 개별 막대는 계열 수에 따라 나뉩니다. 픽셀 고정 두께가 아닙니다.
- 별도 영역 설명은 ID를 유지한 채 paper y=0, 음수 yshift로 저장됩니다. 반응형 화면에서 이를 일반 주석으로 분류해 아래 여백을 줄이면서 숨기던 문제를 수정했습니다. 이제 HTML 출처/설명 영역으로 분리합니다. 기존 저장 설명도 새로고침하면 표시됩니다.

검증: Python 14개, 프런트엔드 111개 통과. 실제 WorkspaceProperties 컴포넌트를 Playwright로 실행해 얇은 막대, 슬라이더 적용, 선 차트에서 제어 숨김을 확인했습니다. 전체 로그인 세션 검증과 외부 통계 재조회는 실행하지 않았습니다. 두 폴더 빌드 확인; 기존 청크 크기 경고가 있습니다.
