# 한국은행 E2E v2 기반 제품 수정과 검증

ai-assisted · 2026-10-21. 공개 개발 평가이며 사람 승인 전이다.

## 범위와 기준

사용자가 제공한 `bok-e2e-v2.zip`을 원본 변경 없이 `.venv/cache/kosis-bok-reproduction/evaluation-v2/bundle/`에 추출했다. 패키지 검증 결과 ready=true, 오류 0건, 144개 후보 중 runnable 112건·blocked 32건이다. 차단 32건은 원자료 단위 등의 근거 부족이며 분모에서 숨기거나 임의로 해제하지 않는다. 두 표현과 두 출력의 조합이므로 112개 독립 통계 주제라는 뜻은 아니다.

고정 메타데이터·CSV를 사용하는 별도 DB와 테스트 계정에서 실제 `/api/query` → `/api/output` → `/api/table/export` 경로를 실행한다. 모델과 외부 API는 이 개발 평가에서 비활성화했다. 제품에는 정답을 전달하지 않고, 관측 파일을 저장·해시 고정한 다음 별도 채점 프로세스에서만 오라클을 연다. API/수치/파일 검사와 실제 브라우저 검사는 구분한다. 유료 모델 프로필 비교나 144개 전체 브라우저 검증이라고 부르지 않는다.

## 제품 변경

- 월·일·분기 기간 표현이 숫자 분류값으로 해석되지 않도록 했다. 예를 들어 12월 때문에 1~2% 구간이 추가되지 않는다. 명시적으로 요청한 숫자 구간과 향후1년이라는 자료명은 유지한다.
- 통계표 ID는 표 범위를 제한하고 여러 요청 분류는 모두 유지하도록 했다.
- 정적 언어 사전에서 잘린 분류값을 승인 메타데이터로 보완한다. 이미 사용하던 동일 이름의 코드 우선순위는 보존하되 명시 코드 선택을 위한 전체 값은 유지한다.
- 표 이름에 있는 단어를 추가 분류로 오인하지 않도록 했다. 원화기준·기관·기업규모 등은 같은 메타데이터 선택 경로에서 확인한다.
- 게시된 매출액증가율·교역조건지수와 이용금액 합계의 단순 조회를 새 계산 요청과 구분했다. 실제 계산 명령과 회사·개인 자료 제한은 유지한다.
- 예금취급기관은 기관 조건이며 별도 예금 수신 지표가 아니다. 실제 선택한 분류가 같은 이름의 다른 표에 대한 언급을 충족하는지도 확인한다. 명시적으로 다른 기준의 표를 요청한 경우에는 누락을 계속 차단한다.
- 카탈로그 선택을 질의와 전체 메타데이터 해시에 묶어 메모리에서 최대 64개 재사용한다. 호출자가 결과를 수정해도 저장된 선택에 전파되지 않고 메타데이터 변경 시 무효화한다. 관측값·분석 화면·계정 상태를 캐시하지 않으며 실제 원자료 조회는 다시 실행한다.

경제적 의미 검증, 파생 연산 검증, 기간·단위·출처 검증을 통과 처리로 바꾸거나 생략하지 않았다.

## 채점기 수정

패키지의 원본 채점기는 그대로 보존했다. 공개 소스 사본을 `eval/bok-reproduction/v2/scripts/evaluate.py`에 두고 XLSX 기간 머리글 인식만 수정했다. 원본은 `월별 · 2023-01 ~ 2025-12`라는 설명까지 개별 시점 머리글로 인식해 올바른 파일도 ambiguous로 처리한다.

수정본은 셀 전체가 단일 월·분기·연도인 경우에만 머리글로 인식한다. 여러 계열을 각 구역에 배치한 파일은 반복 머리글에 대응하는 숫자 셀 좌표를 모으되 같은 셀을 중복 집계하지 않는다. 범위 설명 제외, 유효한 파일 통과, 기간 머리글 교환 시 실패, 머리글 누락 시 실패와 잘못된 값 거부를 회귀 검사했다. 계열·시점 중복을 딕셔너리 인덱싱으로 숨기는 경우도 명시적으로 차단한다. 숫자·단위·계열·시점 허용 오차나 정답은 변경하지 않았다. 원본 점수와 수정 채점 결과를 혼합하지 않는다.

## 실제 UI 확인

Computer Use로 평가 전용 포트(8092/5192)의 앱에 로그인해 기대인플레이션율 질문을 제출했다. 1개 계열·36개월 출력, 표 전환과 XLSX 다운로드를 확인했다. 실제 내려받은 파일의 36개 관측 셀은 독립 정답과 일치했다. 원본 채점기의 범위 설명 오탐은 별도로 기록했고, 수정한 머리글 판별을 적용하면 통과하며 머리글을 서로 바꾸면 실패한다.

화면·실행·파일·채점 산출물은 ignored 평가 캐시에만 저장한다. 기존 두 프로젝트의 `.env`, 실제 계정 DB, 저장 분석, 원자료, 기본 포트를 복사하거나 삭제하지 않았다. 변경한 소스와 회귀 테스트만 두 폴더에 동기화한다.

실제 UI에서는 추가로 국제수지 경상수지의 1개 월별 계열 출력과 예금취급기관 제조업 산업별대출금의 1개 분기별 계열·12분기 표 자동 표시를 확인했다. 표 이름과 같은 총계 분류는 구체적인 다른 분류를 명시하지 않은 경우에 보존한다. 이 규칙의 양성·음성 검사도 포함했다.
