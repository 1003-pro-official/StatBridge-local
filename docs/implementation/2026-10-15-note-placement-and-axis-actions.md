# 축 제목 버튼과 설명 배치 개선

- 축 제목 적용/기본값 복원을 도움말 아래 별도 행에 배치했습니다.
- 설명 배치: 그래프 아래 별도 영역(신규 기본값), 그래프 안 직접 위치 조절.
- 기존 저장 설명은 inside 기본값으로 좌표를 보존합니다. 아래 배치 설명은 X축/범례/출처와 별도 픽셀 레인을 확보하고 그림 높이를 늘립니다. 설명 ID를 유지해 선택/수정/삭제가 가능합니다.
- 벡터 인쇄도 별도 설명을 각주 영역에 포함합니다. 저장/복원은 placement 필드를 유지합니다.
- 기존 mixed chart overlay와 패널 배치는 별도 기능입니다. 이번 변경은 혼합 차트 그룹 모델을 새로 추가하지 않습니다. separate 배치는 계열별 세로 패널을 지원하며 보조축을 먼저 해제해야 합니다.

검증: 실제 WorkspaceProperties를 Playwright로 330px 편집창에서 실행해 버튼 순서/동일 행, 설명 위치 변경 명령과 안쪽 위치 조절 숨김을 확인했습니다. 합성 상태를 사용한 컴포넌트 검증이며 로그인된 전체 사용자 세션 검증은 아닙니다.

검증 결과: Python 관련 52개 통과. 프런트엔드 110개 통과. 두 폴더 빌드 성공(기존 500kB 청크 경고 있음). diff --check 통과. 별도 편집 설명 회귀 검증 실행.
