# 실행 근거 창 레이아웃 수정

- 많은 기록이 flex 컨테이너 안에서 버튼 높이를 압축하여 보조 텍스트가 버튼 밖으로 넘치던 문제를 수정했습니다. 기록 카드 flex-shrink를 막고 제목/시간을 내용 높이에 맞게 표시합니다.
- 대화상자는 뷰포트 안의 고정 높이이며 헤더/안내는 유지합니다. 목록과 상세 내용만 각각 스크롤합니다. 모바일에서는 가로 기록 목록과 세로 상세 영역을 사용합니다.
- 선택 기록을 목록 안에 표시하고, 기록 변경/창 재열기 시 상세 내용을 맨 위로 이동합니다. 선택 상태 스타일을 전역 버튼 스타일보다 우선 적용합니다.

검증: 실제 ExecutionEvidence 컴포넌트에 합성 기록 50개와 긴 상세 내용을 넣고 Playwright로 960x540, 1440x1000, 390x740을 확인했습니다. 버튼 안 시간 텍스트 수용, 모달 외부 스크롤 없음, 상세 영역 스크롤/선택 시 초기화, 닫기를 검증했습니다. 로그인된 사용자 세션과 API 처리 내용은 변경하거나 재검증하지 않았습니다.
