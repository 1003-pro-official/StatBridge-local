# 버튼 디자인 통일

2026-10-15 · ai-assisted

## 변경

- 12개 화면 컴포넌트의 버튼 선언 125곳과 관련 CSS를 확인했습니다. 동적 목록이 있으므로 실제 버튼 개수와는 다릅니다.
- 마지막에 읽는 `buttonTheme.css`에서 공통 높이·모서리·색상·글꼴·호버·키보드 포커스·비활성 상태를 관리합니다.
- 분석·전송·표 적용은 주요 실행, 되돌리기·메뉴·닫기는 보조 작업, 삭제는 경고 색상으로 구분합니다.
- 그래프/표 탭과 조건 선택의 선택 상태, 도구 모음 메뉴의 정렬, 보관함 버튼을 정리했습니다.
- 브랜드·상단 탐색·범례·색상 견본·캐릭터 버튼은 기능에 필요한 형태를 보존합니다.
- 좁은 화면에서는 도구 모음과 조건 선택이 줄바꿈됩니다. API·데이터·조회 로직은 변경하지 않았습니다.

## 검증

- TypeScript 검사 및 Vite 빌드 성공. 기존 500kB 초과 번들 경고가 있습니다.
- 기존 프런트엔드 테스트 109개 통과.
- 변경한 추적 파일의 `git diff --check` 통과.
- 실제 공통 CSS와 같은 버튼 마크업을 사용하는 독립 확인 화면에서 도구 모음·내보내기 메뉴·탭·조건 선택·표 적용·보관함·비활성 버튼을 시각 확인했습니다.
- 데스크톱과 폭 390px에서 확인 화면을 점검했습니다. 좁은 화면에서 문서 가로 넘침이나 화면보다 넓은 버튼은 관측되지 않았습니다.
- 검증 브라우저와 사용자 로그인 세션이 달라 실제 분석 화면의 모든 상태는 재현하지 않았습니다. 확인 화면에는 계정·분석 데이터·API 호출이 없습니다.
- CSS 및 버튼 역할 표시 변경으로 백엔드 전체 테스트·골드셋·외부 API 평가는 재실행하지 않았습니다.

이번 변경은 local1에 적용했습니다. StatBridge1 보관본과 기존 GitHub PR은 수정하지 않았습니다.
