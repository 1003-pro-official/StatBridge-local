# 한국은행 KOSIS 349개 범위의 동적 파생지표 검증 예시 (ai-assisted)

이 문서는 실행 레시피나 전체 조합 목록이 아니다. 실행기는 이 목록을 읽지 않는다.
2026-10-19에 사용자의 자연어를 GPT-5.4가 각각 해석하여 실제 항목·분류를 검색하고
계산 트리를 생성한 사례만 기록한다. 다른 지표는 매 요청 시 카탈로그·원자료를 다시 검증한다.

349개 표 모두의 자료를 미리 조회하거나 조합을 전부 계산하지 않았다. 위 표의 기간은
이번에 **실제 확인한 구간**이며 각 통계표의 전체 제공기간을 뜻하지 않는다.
브라우저의 독립 요청에서는 DT_404Y015(특수분류)의 총지수가 선택되어 같은
202301–202412 전년동월 상승률 24점이 출력되었으며, 해당 출처를 화면에 표시했다.

## 수치 검산

실제 API 응답 문자열을 Decimal(정밀도 50)로 별도 읽어 원래 식을 직접 계산했다.
엔진의 중간값을 기준값으로 사용하지 않았다. 허용 절대오차는 1e-10이었다.

| 검산 대상 | 관측 수 | 최대 절대오차 | 결과 |
|---|---:|---:|---|
| 생산자물가 전년동월 상승률 | 24 | 1.1366e-14 | 통과 |
| 수출·수입물가 상승률 차이 | 24 | 3.1175e-14 | 통과 |
| 생산자물가 재지수화 | 24 | 2.0803e-14 | 통과 |
| 재지수화 후 3개월 평균 | 24 | 1.9133e-14 | 통과 |

예: 202301 생산자물가 전년동월 상승률은 약 5.0882564841%,
202301 수출·수입물가 상승률 차이는 약 -3.1216379384%p였다.
