# 동적 파생지표 설계 (ai-assisted)

## 현재 호출 구조와 적용 범위

`bridge_api.query → StatBridgeAgent.run → StatBridgeWorkflow`가 질의를 해석하고,
`resolve_request → execute_statistics → prepare_output` 순서로 동작한다.
HCX-003은 기존 통계언어 정규화에 사용된다. `OpenAIChartClient.request`는 기본
GPT-5.4 Responses 연결을 제공한다. `McpToolGateway`는 같은 프로세스의
`StatisticsService`를 호출한다. OutputAgent는 KOSIS 행을 ChartSpec으로 변환한다.
현재 MetadataStore의 표는 349개다. 메타데이터에는 단위가 비어 있는 항목도 있어
모델이 적은 단위를 신뢰하면 안 된다. StatBridge1 실행 코드는 StatBridge-official에 있다.

## 계산 계약

계획은 버전, 경제학적 정의, 입력 선택, 노드 목록, 출력 목록으로 구성한다.
노드 입력은 원자료 alias 또는 선행 노드 ID다. 중첩 트리를 위상 정렬된 DAG로
직렬화하여 동일 하위 계산을 재사용한다. 코드·URL·자유 수식·관측값은 입력받지 않는다.
상수는 power 지수, lag 길이, rolling 창, 기준기간 등 연산별 제한된 매개변수만 허용한다.

허용 연산: add, subtract, multiply, divide, pct_change, yoy_pct, difference,
rolling_mean, cumulative_sum, rebase_100, lag, inverse, log, power.
최대 입력 8개, 노드 48개, 깊이 12, 입력당 20,000점, 중간 셀 500,000개,
계산 작업 2,000,000회, JSON 128KiB로 제한한다. 실제 작업량은 rolling 창까지 계산한다.

## 계획·검증·실행

GPT가 승인 목록 내 검색어를 제안하고 서버가 해당 목록에서 검색한다. 후보의 실제
항목·분류·주기만 GPT에 전달한다. 필요한 자료가 없으면 required_data와 검색 근거를
남기고 계산을 중단한다. 검색 무결과는 API 자체의 자료 부재를 뜻하지 않는다.
분류가 불분명하면 추가 질문을 반환한다. 의미 검토는 별도 모델 판정과 서버의
단위·주기·조정 여부 검사로 보완한다. 일반 경제학 의미를 완전히 증명하는 장치는 아니다.
검토가 불확실하면 실행하지 않는다.

서버는 349개 목록, 기관 301, 항목/분류/주기, 기간, 노드 참조/개수/깊이/매개변수를
먼저 검사한다. 실제 KOSIS만 prefer_local=False, allow_fallback=False로 조회한다.
응답의 출처·표·항목·분류·주기를 다시 확인하고 달력 키로 결합한다.
결측을 0으로 채우지 않으며 누락된 비교기간과 분모 0은 근거와 함께 보고한다.
실제 관측 단위로 계산식을 재검증한다. 기간 연장은 중첩된 시차·창을 합산한다.

## 출력·수정·근거

결과를 기존 KOSIS 행 계약에 맞추어 OutputAgent에 전달하고 계산 계획/원자료/노드 결과/
결측/요청기간과 조회기간/모델 사용량을 별도 근거로 보존한다. 기존 원자료 조회 경로는
유지한다. 시각적 편집은 기존 ChartSpec 경로를 사용한다. 계산 편집은 노드 ID와
교체 매개변수를 검증한 뒤 해당 노드와 후손을 다시 계산한다. 이전 근거 파일은 불변이다.
복원/실패는 기존 그래프와 입력을 보존해야 한다.

실제 구현에서는 파생 요청을 START의 `classify_analysis_intent`로 분기하여 GPT 계획자로
직접 전달한다. 기존 HCX 정규화와 `resolve_request` 경로는 일반 조회에 그대로 남긴다.
검색·검토가 여러 번 필요한 파생 분석은 화면에서 최대 120초를 기다리며, 일반 조회는
기존 20초 전체 대기 한도를 유지한다. 기간 확대는 부족한 앞/뒤 구간만 추가 조회한다.
작업량/중간 셀 수는 메모리의 보수적인 논리 한도이며 OS 차원의 RSS 격리는 아니다.
일·주 단위 주기 변환과 자동 월/분기 집계는 현재 지원하지 않는다.

## 검증 경계

가상 원자료 단위/통합 테스트와 실제 GPT/KOSIS 호출은 구분한다. 카탈로그의 가능한
계산 예시는 실행 레시피가 아니며 실제 API 관측 확보 전에는 계산 가능 확정으로 쓰지 않는다.
비용은 실제 usage만 기록하고 단가를 추정하지 않는다.
