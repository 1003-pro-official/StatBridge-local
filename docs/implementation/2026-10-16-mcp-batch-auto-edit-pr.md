# MCP 배치 조회와 편집 자동 반영

확정된 여러 계열을 MCP의 단일 배치 호출로 전달하고, 표·그래프·보고서 편집은 별도 적용 버튼 없이 반영합니다.

## 조회

공개 도구는 검색·메타데이터·단일 조회·배치 조회의 4개입니다. 운영용 상태·전체 검증 함수는 CLI/Python에 보존했습니다. 배치는 최대 20개 요청, 작업자 3개, 전역 대기열 제한, 요청 내 중복 제거를 사용합니다. 카탈로그·항목·주기·분류·기간을 검사하고 반환 표 ID가 다르면 거절합니다. 일부 실패 시 요청한 계열과 원인을 보존하고 다른 표로 대체하지 않습니다. 관측값 결과 캐시는 추가하지 않았습니다.

배치 대기 예산은 20초입니다. KOSIS 분당 호출 제한 대기를 예산 안에 소화할 수 없으면 busy와 재시도 권고 시간을 반환하고, HTTP에도 남은 예산을 전달합니다. 진행 중 네트워크의 즉시 강제 취소를 보장하지는 않습니다.

## 편집

변경 후 약 350ms 동안 입력이 멈추면 자동 반영합니다. 같은 설정의 연속 입력을 합치고 요청을 순서대로 처리하며, 세션 전환 시 이전 설정을 다른 분석에 보내지 않습니다. 표 옵션, 축 제목·위치·범위, 계열 스타일, 막대 간격, 기존 설명·기간 강조, 보고서 옵션·스티커 편집의 적용 버튼을 제거했습니다. 새 설명·기간 강조 추가, 저장·내보내기는 별도 작업입니다. 불완전한 숫자·JSON은 유효해질 때까지 입력을 보존합니다.

## 검증 범위

별도 공개 PR 작업공간에서 기존 가상환경을 읽기 전용으로 재사용합니다. 생성 평가 결과·키·원자료는 복사하지 않습니다. 이번 PR 작업공간에서 외부 API나 200문항 평가를 재실행한 것으로 주장하지 않으며 최종 검사 결과는 PR 본문에 기록합니다. 사람의 검토·승인이 필요하고 자동 머지는 하지 않습니다.
