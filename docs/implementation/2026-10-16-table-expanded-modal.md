# 표 확대 화면 잘림·채팅 겹침 수정

기존 표 확대는 workspace-center의 overflow/contain/isolation 안에서 fixed 요소를 배치했습니다. 조상 영역에 의해 잘리거나 별도 채팅 레이어와 겹칠 수 있어 화면 최상위의 native dialog로 분리했습니다. React portal로 body 아래에 표시하고 showModal로 배경 상호작용을 차단합니다.

- 표 본문만 독립 스크롤하며 상단의 확대 중지 버튼은 계속 보입니다.
- 확대 중지 버튼과 Esc 모두 작동하며 종료 후 확대 버튼으로 포커스를 복원합니다.
- 확대 중 배경 스크롤을 잠그고 종료할 때 기존 설정을 복원합니다.
- 표 데이터·수치·편집 설정과 다운로드 내용은 변경하지 않았습니다.

Chrome에서 실제 ReportTable 컴포넌트와 40행·80개 시점의 합성 표로 검증했습니다. 1366×768, 390×844, 1024×400에서 모달의 화면 경계, 극단적으로 높은 z-index 채팅의 배경 차단, 가로/세로 스크롤 후 종료 버튼, Esc, 재열기, 포커스·스크롤 잠금 복원을 확인했습니다. 이는 컴포넌트 검증이며 로그인된 계정의 모든 저장 표 조합을 재실행한 검증은 아닙니다.
