# PM 검토 문서 기반 UI 수정

2026-10-14 · ai-assisted · local1·StatBridge1 프런트엔드 UI 반영

## 기준과 범위

PM의 [PR #30 검토 문서](https://github.com/1003-pro-official/StatBridge-local/pull/30/files)의 F01~F12를 최신 로컬 화면과 대조했습니다. 이전 작업의 미커밋 변경을 유지한 `fix/pm-ui-review` 브랜치에서 UI 코드·UI 회귀 테스트·이 기록만 수정했습니다. 백엔드·조회 계획·카탈로그·수치·평가 자료는 변경하지 않았습니다. 최초 UI 작업은 local1에서 진행했고, 후속 요청으로 아래 StatBridge1 동기화를 수행했습니다. 기존 PR #35는 업데이트하지 않았습니다.

## 반영 사항

| 항목 | UI 반영과 한계 |
|---|---|
| F04 | 실제 관측 기간·주기·계열·출처를 상시 표시합니다. 제목의 연도 범위가 실제 기간과 다른 경우 경고합니다. 자동·수동 제목 구분 및 자동 제목 재생성은 서버 작업으로 남습니다. |
| F05 | 역전된 공통 제공 기간에는 날짜 선택과 조회 제출을 차단하고 통계표 재선택·개별 조회를 안내합니다. 역전 원인을 만드는 조회 계획은 변경하지 않았습니다. |
| F06 | ‘제목을 ... 바꾸고 선 색상을 ...’ 문장을 동작별로 분리해 선 색상을 제목 색상으로 묻지 않습니다. 원래 복합 지시는 그대로 보존합니다. 모델이 최종 복합 편집을 수행하는 단계는 별도 검증이 필요합니다. |
| F08 | 입력·기간·인증·연결·서버·요청 제한 오류를 구분합니다. 입력 오류에 런처 실행이나 지원 데이터 없음 안내를 붙이지 않고, 재시도는 연결·서버·요청 제한 오류에만 제공합니다. |
| F09 | 관측값 기반 요약은 기본 화면에 유지하고, 처리 로그·실제 편집 변경 기록은 실행 근거 영역으로 옮깁니다. 자료 제약 안내는 기본으로 펼칩니다. |
| F10 | 현재 관측치와 원래 주기에서 기간 입력값을 계산합니다. 생성·기간 편집·저장 복원 후 입력값을 동기화하며, 저장 그래프를 열면 질문 입력도 복원합니다. |
| F12 | 저장 목록에 실제 saved_at과 저장 당시 자료 안내를 표시합니다. 표 ID가 같은 출처 카드는 합치되 서로 다른 항목·단위를 유지합니다. 실행 근거 버튼의 모달 열림을 확인했습니다. CSV·이미지 출력 계약과 조회 시점 기록 생성은 변경하지 않았습니다. |

F01 표·분류 선택, F02 혼합 주기 좌표, F03 경제적 구성 관계 기반 차트 적합성, F07 서버 기간 해석, F11 출력 패널별 축 단위는 서버·렌더러 작업으로 분리했습니다. 이 항목들을 수정 완료로 표시하지 않습니다.

## 검증

- 프런트엔드 전체 Node 회귀 테스트 88개 통과(이번 회귀 15개).
- `pnpm --dir src/agent/frontend build`: TypeScript·Vite 성공. 기존 번들 500 kB 초과 경고가 남습니다.
- 공개 v4.1 검증기: VALIDATION OK, dev/test/holdout = 50/70/30. 공식 평가 점수·합격률이 아닙니다.
- `git diff --check`: 오류 없음.
- 실제 local1 UI(5173)의 공개 테스트 계정에서 날짜 역전 오류 안내, 저장 시점 표시, 저장 그래프 질문·기간 복원, 보고서 요약·관측 조건 표시, 실행 근거 모달, 복합 요청의 ‘차트’ 색상 확인 UI를 확인했습니다.
- 데스크톱 1280×900과 기본 좁은 화면에서 관측 조건 카드의 줄바꿈·워크스페이스 배치를 확인했습니다.
- HTTP 422/500/503/429·통신 실패는 프런트엔드 회귀 입력으로 검증했으며, 실제 서버 장애를 발생시킨 시험은 아닙니다.
- 외부 KOSIS·NCP·OpenAI 호출, 전체 CSV 조회, 백엔드 전체 Python 테스트는 이번 UI 변경에서 재실행하지 않았습니다. 저장된 실제 자료 화면을 이용했으며, 새 수치나 조회 시점을 만들지 않았습니다.

스크린샷·임시 진단 결과는 로컬 캐시에만 보관하며 공개 커밋 대상에서 제외합니다. 커밋·푸시·새 PR 생성은 이번 요청에서 수행하지 않았습니다.

## 후속 요청: StatBridge1 동일 UI 반영

사용자의 ‘statbridge1도 같이 수정해줘’ 요청에 따라 `StatBridge1/StatBridge-official`에 같은 UI 코드·테스트 13개 파일과 이 작업 기록을 반영했습니다. StatBridge1은 로컬 보관본으로 유지하며 Git 커밋·푸시를 하지 않았습니다.

- 대상 프런트엔드 Node 테스트: 88개 통과.
- API 8001 설정의 TypeScript·Vite 빌드 성공. 기존 번들 크기 경고는 동일합니다.
- 대상 런처가 기록한 서비스만 재시작했고, API 8001·UI 5174의 정상 응답을 확인했습니다.
- 실제 5174 화면에서 날짜 역전 오류의 ‘기간 수정/질문 수정’ 안내, 자체 저장 목록의 saved_at 표시, 저장 그래프 복원과 입력 날짜(2021-01-01~2025-12-31)가 관측 기간과 일치함을 확인했습니다.
- 13개 반영 파일은 local1과 바이트 단위로 일치합니다.
- StatBridge1 전용 START_STATBRIDGE.cmd(8001/5174·statbridge_session_statbridge1), .env, 계정·저장 그래프 DB, 기존 벡터 DB는 복사 대상에서 제외했고 해시 보존을 확인했습니다.
- 이번 동기화에 백엔드·카탈로그·수치·평가 산출물은 포함하지 않았습니다.
