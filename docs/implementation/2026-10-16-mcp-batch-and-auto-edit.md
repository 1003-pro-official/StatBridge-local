# MCP 배치 조회와 표·그래프 자동 반영 (2026-10-16)

## 구현

- 공개 MCP 도구: search_tables, get_table_metadata, get_statistics, get_statistics_batch. healthcheck/validate_tables_batch/validate_all_tables는 모델 등록에서 제외하고 기존 Python·CLI 운영 경로는 보존했습니다.
- 확정된 여러 조회 계획을 한 배치로 전달합니다. 동일 조건은 배치 안에서 합치고 최대 3개 작업을 동시에 실행하며 전역 대기열도 제한합니다. 최대 20개 요청을 지원합니다.
- 지원 카탈로그·주기·항목·분류 값과 기간을 조회 전에 검증합니다. 응답 표 ID가 다른 자료는 거절합니다. 요청 순서·실패 지표를 보존하고 키 노출을 차단합니다. 실패를 다른 표로 대체하지 않습니다.
- 배치 대기는 최대 20초입니다. 이미 시작한 HTTP 요청의 강제 취소를 보장하지 않으며 기존 네트워크 타임아웃까지 실행될 수 있습니다. 결과 수치 캐시는 추가하지 않았습니다.
- 표·그래프·보고서 설정, 색상, 막대 간격, 축 제목·배치·범위, 기존 설명·기간 강조, 스티커 편집을 변경 후 약 350ms에 자동 반영합니다. 같은 설정의 연속 입력은 합치고 편집 요청은 순서대로 처리합니다. 분석 세션이 바뀌면 이전 세션의 대기 설정을 보내지 않습니다.
- 적용 버튼을 제거했습니다. 새 설명·기간 강조 추가, 되돌리기·다시 실행, 결과 저장·내보내기는 별도 작업으로 유지합니다. 불완전한 숫자·JSON 입력은 유효해진 뒤 반영됩니다.
