# 계열 수에 따른 그래프 화면 크기 (ai-assisted)

1~2개 계열의 기존 크기를 유지합니다. 한 그래프에 3~4개 계열을 표시할 때 본체 높이는 520px, 5개부터는 760px이며 이후 계열당 60px씩 늘립니다(상한 1500px). 제목·범례는 본체 밖에 별도 공간을 사용합니다. 여러 패널은 기존 패널별 공간과 계열 수 기준 중 큰 값을 사용합니다.

큰 결합 그래프에서는 작업 영역이 내용 높이에 맞춰 늘어납니다. 데스크톱 데이터·편집 패널과 채팅은 별도의 화면 높이를 유지하며 페이지 스크롤 중 고정됩니다. 모바일에서는 기존 스크롤 영역을 유지하고 그래프 본체만 확대합니다. 그림판·스티커 좌표는 스크롤 바깥의 전체 그래프 캔버스를 기준으로 유지합니다. 중복된 보조 trace와 숨긴 계열은 중복 집계하지 않습니다.

검증: 두 프런트엔드 타입 검사·빌드, Node 테스트 73개. 실제 StatBridge1 결제통화 네 계열 화면의 본체 높이 520px, local1 여섯 계열 화면의 본체 높이 820px을 DOM과 화면에서 확인했습니다. 데스크톱 채팅 입력창의 아래쪽은 720px 화면 안에 위치했습니다. 이번 변경은 화면 렌더링에 적용되며 다운로드 파일의 서버측 레이아웃 계약은 변경하지 않습니다. 새 의존성이나 CMD 수정은 필요하지 않습니다.
