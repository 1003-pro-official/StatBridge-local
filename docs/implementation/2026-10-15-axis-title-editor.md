# X축·Y축 제목 편집

- 왼쪽 그래프 편집의 독립된 `축 제목` 항목에 X축(가로축)·Y축(세로축) 입력란, 적용 버튼, 기본값 복원을 추가했습니다. 각각 최대 80자입니다.
- 두 값을 하나의 기존 `set_axis_labels` 명령으로 적용하며, 되돌리기·다시 실행·편집 기록은 기존 경로를 사용합니다. 빈 제목은 데이터별 기본 제목으로 복원합니다. 축 선택 시 해당 제목 입력란으로 이동합니다.
- 프런트엔드 명령 타입에 축 제목 필드를 추가했습니다. PDF/SVG 인쇄 렌더러도 사용자 지정 Y축 제목을 적용하도록 수정했습니다. X축 제목은 산점도 인쇄에서도 동일하게 반영합니다.
- local1과 StatBridge1/StatBridge-official의 변경 파일을 일치시켰습니다. 각 폴더의 키·계정·저장 분석·포트는 복사하거나 변경하지 않았습니다.

## 검증

- Python 출력·워크스페이스·혼합 차트·보고서 관련 52개 통과(44.36초). 새 회귀 검사는 실제 출력 편집을 거쳐 Plotly 제목, SVG 제목, 원자료 보존, 기본값 복원을 확인합니다.
- 양쪽 TypeScript/Vite 빌드와 프런트엔드 검사 각각 110개 통과. 기존 번들 크기 경고가 있습니다.
- 실제 WorkspaceProperties 컴포넌트를 합성 자료로 마운트하여 Playwright에서 두 입력란·적용 명령·기본값 복원을 확인했습니다. 로그인한 운영 계정의 전체 UI 통합 시험은 아닙니다.
- 전체 Python 검사와 외부 KOSIS/LLM 호출은 이번 UI 변경에서 재실행하지 않았습니다.

AI-assisted 로컬 변경이며 커밋·원격 게시 작업은 하지 않았습니다.
