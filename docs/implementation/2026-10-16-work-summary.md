# 2026-10-16 StatBridge 작업 요약

local1과 StatBridge1/StatBridge-official에 반영한 오늘 작업을 정리했습니다. 관측값·출처를 유지하면서 여러 지표 탐색, 계산, 그래프·표 편집, 실패 후 재시도를 이어가는 데 집중했습니다. AI-assisted 기록입니다.

## 오늘 변경한 내용

1. **MCP 배치 조회 및 대기 제한**: 공개 업무 도구를 검색·메타데이터·단일 조회·배치 조회 네 개로 정리했습니다. 확정된 계획을 최대 세 작업으로 병렬 처리하며, 같은 요청은 배치에서 합칩니다. 호출 제한 대기는 요청 예산을 넘기기 전에 재시도 안내로 연결합니다. 실행 중인 외부 HTTP의 즉시 강제 종료를 보장하지는 않습니다.
2. **그래프·표 편집 즉시 반영**: 색·두께·축 제목/방향/위치·표 정밀도/양식 등 설정 변경을 자동 반영하고 설정용 적용 버튼을 제거했습니다. 연속 입력은 합치고 세션별 요청 순서를 유지합니다. 추가·삭제·저장·내보내기는 별도 작업입니다.
3. **워크플로우 복구**: 편집·저장·다운로드에도 시간 제한을 적용하고 기존 입력·첨부·그래프를 보존합니다. 버전 충돌은 최신 상태 확인으로, 호출 제한은 재시도로 이어집니다. 이미지 편집은 중복 참고 스크린샷과 불필요한 추가 모델 호출을 줄였습니다.
4. **표 확대**: 최상위 dialog에 표를 표시해 채팅 겹침과 잘림을 줄였습니다. 확대 중지 버튼·Esc·포커스 복원과 배경 스크롤 잠금을 연결했습니다.
5. **비교 지표 누락 방지**: 일부 표만 찾고 성공으로 처리하던 경로에서 요청 전체의 표·항목 범위를 다시 검사합니다. 긴 정본 표명과 분류의 범위를 보호하고, 과거 생산자물가 표와 각주가 있는 항목명 선택도 보완했습니다.
6. **원자료와 전년동기 계산**: 같은 표의 잔액과 증가율을 두 계열로 출력합니다. 전년 같은 달·분기의 실제 값을 사용하고, 금리 차이는 %p로 계산합니다. 누락·분모 0·금리 증가율 기준 불명은 값을 꾸미지 않고 역질문합니다. 비교용 추가 조회기간과 산식을 근거에 기록합니다.
7. **이중축 선택 UI와 자동 구성**: 차트 종류의 이중축 선·막대 혼합차트와 상단 Y축 구성 메뉴를 추가했습니다. 계열별 모양·좌우 축을 즉시 바꿀 수 있습니다. 명시적인 이중축 질의와 수준+계산 증가율의 자동 구성을 연결하고, 보고서 축과 편집 상태·PDF 출력의 일관성을 보완했습니다.
8. **작은 화면의 빈 그래프**: 중앙 패널이 267px, 그래프 프레임이 141px까지 줄어 제목·범례만 보이던 현상을 실제로 재현했습니다. 한두 계열도 그래프 본문 420px 이상을 확보하고 전체 그래프를 스크롤로 볼 수 있도록 수정했습니다.
9. **최신 main 통합**: 원본 PR #39·#40의 병합 결과를 보존하면서 오늘 변경을 3-way로 합쳤습니다. 기간 source·basis·후속 맥락 context와 기존 테스트 정리·사전 정본 변경을 유지해 두 로컬 폴더에도 반영했습니다. 환경변수·포트·계정·저장 결과는 복사하지 않았습니다.
