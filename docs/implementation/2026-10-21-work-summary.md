# 2026-10-21 작업 종합 기록

ai-assisted. local1 소스와 당일 구현 기록을 기준으로 작성하였다. 기존 원본 저장소 main의 PR #44 이후 차이를 별도 클론에서 정리하였다. 사람의 전체 diff 검토와 승인은 아직 필요하다.

## 1. 모델 역할과 보고서 대화

주 모델 기본값을 GPT-6.1 Sol로 변경하고 선택적인 저비용 텍스트 역할을 GPT-6 Luna로 분리하였다. 파생 계산 계획과 경제적 의미 검증, 복잡한 편집·참고 파일 해석은 강한 모델을 유지한다. 보고서 질문 계획에는 실제 JSON schema를 제공한다. 검증된 계획 재사용과 결정적 후속 질문 처리를 유지하며 수치는 최신 서버 자료로 검산한다. 실제 키·환경파일은 공개하지 않는다. 합성 30건의 opt-in 모델 역할 평가 도구를 추가하고 과거 evidence 검증 도구 두 개는 기대 모델 인자를 받되 기존 GPT-5.4 기본값을 유지한다. 역사적 기록을 새 모델 성과로 바꾸지 않는다.

당일 기록에서는 실제 Sol 파생 계획·경제 의미 검증 두 generation의 Langfuse 수신, Luna 개발 30건, 두 앱 후속 질문에서 불필요한 모델 호출 생략을 확인하였다. 이는 이번 PR 준비 중 외부 모델을 다시 호출했다는 의미가 아니다. 예전 보고서 초안 관련 모델 검사는 기능 삭제 이전의 이력이다.

상세: [모델 이관](2026-10-21-openai-model-migration.md).

## 2. 그래프 편집 UI와 미사용 기능 정리

왼쪽 속성에서 그래프 변경 선택을 항상 보이도록 복구하였다. 허용된 차트 종류와 기존 검증 편집 경로를 그대로 사용한다. 불필요한 관측 요약 안내와 문장별 근거 컴포넌트를 제거하였다. TypeScript 미사용 선언·인자 검사를 활성화하고 연결되지 않는 코드와 속성을 정리하였다.

별도 보고서 초안 버튼·컴포넌트·생성 및 내보내기 API·전용 테스트를 삭제하였다. 보고서 작성 대화, 이전 맥락, 답변 MD 모으기·미리보기·내려받기, 공용 그래프 크기 및 표 내보내기는 유지한다. 공용 숫자 표시 함수는 report_summary로 옮겼다. 남은 미사용 업로드 복구 컴포넌트와 사용하지 않는 데이터 스냅샷 모듈도 제거하였다.

당일 두 앱 실제 UI에서 선→막대→선 변경과 데이터 불변, 삭제 버튼 부재를 확인하였다. 계정·저장 분석·환경·원자료는 삭제하거나 서로 덮어쓰지 않았다. 과거 기록 문서는 보존한다.

상세: [그래프 선택 복구](2026-10-21-chart-selector-ui-cleanup.md), [초안 제거](2026-10-21-remove-report-draft.md).

## 5. 카탈로그·기간·분류와 조회 성능

기간 숫자가 지표의 숫자 분류로 오해되지 않도록 하였으며 명시한 숫자 구간과 자료명은 유지한다. 표 ID로 범위를 좁히더라도 요청한 여러 분류는 보존한다. 승인 메타데이터의 전체 분류값으로 잘린 언어 사전을 보완하고 기존 동일 이름 코드 우선순위를 유지한다. 표 제목 자체의 단어와 실제 분류 조건, 기관 이름과 별도 지표, 게시 지표 조회와 새 파생 계산을 구별하였다. 명시적으로 다른 기준을 요구한 계열의 누락은 계속 차단한다.

질의와 전체 메타데이터 해시에 묶인 최대 64개 선택 결과만 깊은 복사와 잠금으로 재사용한다. 관측값·계정·분석 상태를 캐시하지 않는다. 경제적 의미, 단위, 기간, 출처 검증을 우회하지 않는다.

## 6. XLSX 채점기와 실제 검증 범위

원본 패키지는 그대로 보존하였다. 공개 채점 소스 사본에서 단일 기간 셀과 기간 범위 설명을 구별하고 여러 구역의 반복 머리글을 허용하되 관측 셀 중복 집계를 막았다. 잘못된 값, 교환·누락된 기간 머리글, 중복 계열·시점은 실패하는 음성 검사를 추가하였다. 정답과 허용 오차는 변경하지 않았다.

당일 고정 CSV 실행 결과는 API 수치·계열·단위·시점 112/112, 실제 XLSX 56/56이다. 별도의 실제 UI에서는 기대인플레이션율 그래프·표·XLSX, 국제수지 그래프, 산업별대출금 분기 표를 확인하였다. 관련 Python 회귀는 local1 166건, StatBridge1 핵심 102건 통과하였다. 이 실행의 외부 모델 호출은 0회였다.

32건은 근거 부족으로 차단 상태를 유지한다. 위 결과는 112건 전체 브라우저 검증, 실시간 KOSIS 정확도, 유료 모델 프로필 E2E 또는 전체 144건 공식 100%가 아니다. 로컬 실행 중앙값 4.69초·95백분위 8.36초이며 외부 서비스 성능 보장은 아니다.
