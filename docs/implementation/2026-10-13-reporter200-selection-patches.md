## 문제와 수정

공개 reporter200 문항을 local1에 실행했을 때 분류에 있는 지표의 표 탐색, 공통 수식어를 가진 복수 항목, 분모·분자, 금액/물량·신규취급액/잔액 기준, 제외 품목과 원화 기준이 누락되거나 인접한 표로 연결됐습니다. 현재 카탈로그의 제목·분류에서 근거를 찾는 선택기를 추가하고 기존 명시적 표·ID 선택 경로를 보존했습니다. 요청 순서와 실제 지원 주기·지역 조건을 검증하며, 동명이표는 local1의 통계표 계보에서 신규취급액과 잔액을 구별합니다.

지원 목록에 해당 측정 대상이 없으면 API는 `no_match`를 유지하고 `requiresQueryRefinement`와 `refinementQuestion`을 반환합니다. UI에는 정확한 지표명이나 표명을 보완하는 입력란을 표시하며 기존 그래프와 편집 기록을 유지합니다. 보완된 질문은 기존 확정 필터를 잘못 적용하지 않도록 새 요청으로 보냅니다. 실제 호출 오류의 재시도와 지표 보완은 별도로 처리합니다.

실행 코드에는 평가 문항이나 정답 ID를 넣지 않았습니다. 새 테스트는 공통 수식어, 복수 기준, 독립 항목, 제외 품목, 미지원 대상, 동명이표 계보, 비교 선택의 보존을 확인합니다. 실행 테스트의 기존 수작업 최소 계획은 현재 서버에서 생성한 전체 조회 계획으로 교체해 실제 MCP 실행 동작을 계속 검증합니다.

## 검증

- 최종 소스를 고정한 실제 API 200문항 + 계층별 반복 20문항 평가: local1 분류명 정합 기준 199/200, 반복 20/20. 모델 비사용 경로도 동일합니다.
- 원본 동결 정답 그대로 비교: 187/200. 수정 전 82/200. 12문항의 분류명/ID 연결 차이는 별도 매핑 목록으로 남겼습니다.
- 194번은 잔액 요청인데 원본 정답이 신규취급액 표를 지정합니다. 원본을 수정하지 않고 local1 계보와 파라미터의 정정 제안을 별도 JSON에 보관했습니다. 정정 제안 적용 진단은 200/200이며 사람 승인 전 정식 골드 점수로 취급하지 않습니다.
- 실제 브라우저: 취약차주 요청의 보완 질문, 질문 수정 후 실제 KOSIS 96개 관측치·금리 2계열의 그래프 생성, 이후 미지원 질문에서도 기존 그래프 보존을 확인했습니다.
- 마지막 서버 재시작 후 기업대출 금리와 가계대출 금리의 공통 신규취급액 기준 요청이 불필요한 금리 기준 역질문 없이 실제 데이터 2계열을 조회하고 그래프 선택 단계로 진행함을 확인했습니다.
