# 경상수지 기간 재입력과 보고서 PDF 다운로드

ai-assisted 변경. 기능 브랜치에서 검증하며 사람 검토 전이다.

## 경상수지

첫 조회에서는 `경상수지(계절조정)`을 선택했지만, 같은 질문과 상태를 보내 기간을 선택하면 이전 계획의 표 이름을 질의에 다시 붙였다. 이 과정에서 정본 표 참조가 중복 확장되어 최종 검증이 실패하고 UI가 `no_match`를 표시했다. 기간 값 자체의 인식 실패가 아니었다.

같은 질문은 이전 계획을 사전과 원래 요청에 재검증한 뒤 그대로 유지한다. 클라이언트가 바꾼 분류 코드는 이 경로에서 신뢰하지 않는다. 명시한 원계열 조건이나 표 ID에 반하는 괄호 생략 표 이름도 암묵적 요청으로 추가하지 않는다. `경상수지 원계열`은 국제수지의 경상수지 항목으로 연결된다.

첨부한 간행물 그림은 상품수지·서비스수지·본원 및 이전소득수지의 막대와 경상수지·무역수지의 선을 합친 연간 그림이다. 2026·2027년 `e)`는 전망치다. 이번 수정은 월별 단일 관측값을 해당 연간·전망 복합 그림으로 자동 대체하는 기능이 아니다.

## PDF

기존 `인쇄 · PDF 저장`은 브라우저 인쇄창만 열었다. PDF 목적지 선택을 사용자가 해야 하므로 직접 파일 다운로드와 달랐다.

`PDF 저장`과 `인쇄`를 분리했다. PDF 버튼은 현재 화면에서 생성한 PNG와 서버가 보관한 초안 ID를 전송하며, 서버가 그래프와 설명을 합친 실제 A4 PDF를 응답한다. HTML 저장은 유지한다. 새 외부 라이브러리 설치 없이 기존 Matplotlib/Pillow/PDF 경로를 사용한다.

- 서버 초안은 편집 버전별 최대 3개만 보관한다. 모델 응답을 다시 생성하거나 클라이언트의 문장으로 바꾸지 않는다.
- 로그인 소유권, 최신 그래프 버전, 초안 ID 및 버전을 확인한다. PDF 작성 중 버전이 변경되면 파일을 반환하지 않는다.
- PNG만 받고 8MB·32메가픽셀을 제한한다. 그래프 명세와 이미지 비율을 대조한다.
- 그림은 동일 배율로 축소하며 PDF에 원본 픽셀을 보존한다. 긴 설명은 다음 페이지로 이어진다.

## 확인한 결과

- 경상수지·원계열·정식 표 ID·계절조정 표 명시와 같은 질문 재전송, 클라이언트 분류 위조를 검사했다.
- PDF 단위/API 검증에서 A4 실제 PDF, 한국어 설명·출처·그림 포함, 원본 픽셀 보존, 형식/비율 거절, 로그인·소유권·버전·초안 ID를 검사했다.
- 실제 KOSIS 조회에서 `경상수지 원계열`은 `DT_301Y013`으로 선택되고 기간 재입력 후 `need_output_config`로 진행했다.
- Chromium에서 7개 확인: 독립 PDF/인쇄 버튼, `%PDF-` 파일 내용과 다운로드 이름, PDF 클릭 시 인쇄창 미실행, 인쇄 버튼 실행, 미리보기 비율 및 API 오류 없음.
- 다운로드된 파일은 실제 1쪽·62,461바이트 PDF였다. 그래프 PNG 1400×634의 비율 2.208202와 PDF 내부 배치 비율 2.208202가 일치했다. 렌더링한 PDF에서 제목·그래프·출처·한국어 설명을 시각 확인했다.
- 전체 Python 회귀: 1,556 passed, 355 subtests passed (833.54초). 명령은 `PYTHONPATH=src/backend;src/agent` 환경의 `.venv\Scripts\python.exe -m pytest -q tests eval/table-discovery/v4.1/tests`이며 Windows 권한 제약으로 저장소 내부의 전용 임시/캐시 경로를 지정했다.
- 프런트엔드 126개 테스트와 `npm.cmd run build`, v4.1 검증기가 통과했다. pnpm이 없어 동일한 package.json 빌드 스크립트를 npm으로 실행했다. 기존 번들 크기 경고는 남아 있다.
