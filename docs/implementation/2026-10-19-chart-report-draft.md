후속 보완: [경상수지와 PDF 다운로드](2026-10-19-current-account-and-pdf-download.md)에서 인쇄창과 별개인 실제 PDF 파일 다운로드를 추가했다. 아래 초기 구현의 `인쇄 · PDF 저장` 설명은 당시의 브라우저 인쇄 방식에 대한 기록이다.

## 구현

- `report_caption.py`: 현재 표시 자료의 계산 가능한 사실로 짧은 설명을 구성한다. 모델은 계열별 비교 근거 ID를 고른다. 계열 누락·중복·알 수 없는 ID·자유 서술이 오면 기본 선택으로 복원한다.
- `/api/report/interpret`의 `mode=chart_brief`: 로그인 소유권과 작성 전후 버전을 검증한다. 그래프·변환된 관측값·출처는 동일한 서버 스냅샷에서 가져온다. 기존 `mode=evidence` 및 기본 동작은 유지한다.
- UI: 제목을 `보고서 초안`으로 변경하고 그래프 → 자료 출처 → 짧은 설명 순서로 표시한다. 생성이 완료된 이미지와 설명을 HTML에 함께 저장하며 브라우저 인쇄/PDF 저장을 제공한다.
- 이미지에는 `width:auto; height:auto; max-width:100%; object-fit:contain`을 적용한다. 인쇄용 최대 높이에 맞추는 경우에도 비율을 유지한다. 화면의 반응형 레이아웃을 픽셀 그대로 복제하는 기능은 아니다.
- 180초 제한은 API 응답 본문과 PNG 준비를 포함한다. 편집 버전 변경이나 컴포넌트 해제는 진행 요청을 취소하고 오래된 결과를 표시하지 않는다. 완성 전까지 기존 초안은 유지한다.

## 검증 범위

합성 관측값으로 증감률/%p, 결측 시점, 다중 계열, 모델 실패, API 로그인·버전 충돌을 검사한다. 실제 Chromium에서 생성 이미지, 본문 순서, 저장 HTML, 표시 크기 변화 시 이미지 비율을 확인한다. 브라우저의 PDF 저장은 인쇄 대화상자에서 사용자가 선택하는 기능이며 서버의 그래프 전용 PDF 내보내기와 구분한다.
