# 계정 UI, 다중 그래프, 실행 근거 개선 (2026-10-13, ai-assisted)

## 변경

- 로그인/회원가입을 메인과 같은 남색·파란색 테마의 소개 패널/입력 카드로 구성했습니다. 모바일에서는 세로로 배치합니다. 기존 인증·입력 검증·계정 저장 범위는 유지합니다.
- 내 저장 그래프/로그아웃에 아이콘, 계정 표시, 저장 개수 배지를 적용하고 상단 계정 바를 고정했습니다.
- 여러 패널 그래프는 원래 필요한 높이를 유지하며 행당 여유를 확보합니다. 중앙 스크롤 영역 안에 별도 캔버스를 두어 그래프 제목과 실제 데이터 영역이 겹치지 않으며 그림판 좌표도 전체 캔버스를 기준으로 계산됩니다. 단일 그래프의 보조축은 별도 패널로 오인하지 않습니다.
- 워크스페이스는 데스크톱 화면의 가용 높이에 맞추고 채팅 기록만 스크롤합니다. 첨부를 접을 수 있게 하여 입력/전송 영역을 확보했습니다.
- 전체 실행 근거 보기 버튼과 워크스페이스의 실행 흐름 버튼을 실제 상세 창에 연결했습니다. 현재 데이터의 표 ID, 기간, 계열/관측치 수를 함께 표시합니다.

## 실행 기록의 범위

API의 executionRuns 필드는 실제 워크플로 결과의 orchestration.path와 편집 결과의 editAgent.path를 사용합니다. 조회 실행과 출력 선택 후 prepare_output 실행을 각각 구분합니다. 직접 설정/되돌리기/복원은 LangGraph를 거치지 않는 직접 처리로 표시합니다. 성공한 편집 기록은 버전/적용 결과와 함께 누적하며 실패한 수정은 기존 세션을 변경하지 않습니다. 한 그래프에는 최근 200개 실행 기록을 보관합니다. 시간은 기록 생성 시각이며 노드별 지연 시간은 아닙니다. API 키, provider 원문, 첨부 파일 및 모델 내부 추론은 기록하지 않습니다.

서버에 그래프를 저장하면 실행 기록도 함께 저장됩니다. 이전 버전의 저장 그래프에 기록이 없으면 임의 경로를 만들지 않습니다. 새 분석/편집부터 실행 기록을 확인할 수 있습니다.
