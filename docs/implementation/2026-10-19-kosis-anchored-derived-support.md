# KOSIS 입력 포함 여부에 따른 파생지표 지원 정책 (ai-assisted, 2026-10-19)

## 적용 기준

| 필요한 실제 입력 | 처리 |
| --- | --- |
| 전부 승인 한국은행 KOSIS API 자료 | 기존 동적 계획·DAG 검증·API 조회·계산·출력 |
| 승인 API 자료가 하나 이상이며 추가 외부 자료 필요 | 실제 API 관측값 확보 후 부족 자료명·기간·주기·단위·입수처·파일 업로드 안내 |
| 승인 API 입력이 없고 전부 외부·파일 자료 | 지원 범위 밖 안내 및 질문 재작성, 업로드 작업 미생성 |
| API 장애·빈 응답·선택 미확정 | 지원불가로 단정하지 않음. 자료 확인 재시도, 확인 전 업로드 미개방 |

승인 KOSIS 입력은 최종 출력 DAG에서 도달 가능한 입력이어야 한다. 단순히 KOSIS를 언급하거나 계산에 연결되지 않은 API 계열을 추가해도 지원 조건을 충족하지 않는다. 실제 메타데이터의 표·항목·분류와 원자료 응답을 다시 검증한다. 기존의 사내·개인 자료 금지 정책, 허용 연산·단위·주기·자원 제한, 계정별 파일 접근권한을 유지했다.

## 첨부 목록의 처리

사용자 CSV 1,766건을 미검증 분석 후보 검색 참고 자료로 연결했다. 후보 ID 1,766개는 고유하며 참조 표 349개는 모두 현행 승인 목록 안에 있다. 표 ID가 없는 후보는 22개다. 이 사실은 항목·분류·주기·기간·산식이 검증됐다는 의미가 아니다.

첨부 상태 문서는 해당 목록을 간행물 원문 도표 전수 추출본이 아닌 후보 목록이라고 설명한다. 따라서 간행물별 그림·표를 확인한 것으로 보고하지 않으며, 후보의 계산식을 실행 코드·지표 레시피로 등록하거나 1,766개 지표를 선계산하지 않았다. 검색 참고의 표 ID도 실제 승인 목록으로 필터링하며 실제 메타데이터 확인을 생략하지 않는다.

## 주요 변경

- `derived_support_policy.py`: API 입력 포함·혼합·범위 밖·확인 미완료 판정과 최종 DAG의 API 의존성 검증.
- `derived_indicator_planner.py` / `derived_indicator_runtime.py`: 파일만 사용하는 계획 차단, 부족 자료 요청 허용, 검증된 부분 계획 재사용.
- `derived_supplement.py`: 실제 API 원자료가 확보된 작업만 업로드 개방. 모든 외부 입력, 미확정 API, 과거 파일 전용 작업의 재계산 우회 차단. 과거 파일·계산 근거는 삭제하지 않는다.
- `DerivedAvailabilityPanel.tsx`: API 입력 0개에는 지원 범위 밖 안내, 업로드 버튼 미표시. 혼합 요청에만 파일 연결 표시.
- `derived_publication_reference.py`: 미검증 후보명/승인된 표 ID를 검색 참고로 사용. 산식 실행 기능 없음.
- 실제 확보 확인 결과의 항목·기간을 파일 준비 단계에 전달해 GPT 재계획을 생략한다. 파일 준비는 API 재확인·스키마 검증을 계속 수행한다.

## 실제 앱 검증

- local1: 2023년 1~4월 PPI/CPI 비율 요청. 실제 DT_404Y014 총지수 관측값 4개를 확보했고 CPI 총지수만 부족 자료로 안내했다. 실제 파일 업로드 영역·입수처·CSV/JSON/TSV/XLSX 안내를 확인했다.
- 혼합 요청 원자료 확인은 실제 GPT-5.4 호출 2회. 확인 결과에서 파일 준비로 이동할 때 추가 모델 호출 0회. 실제 확보 응답 source는 `kosis_api`다.
- StatBridge1: 2024-11-05~2025-02-24 ICE DXY만 사용한 요청은 실제 승인 메타데이터 범위에서 확보 0개로 확인되어 지원 범위 밖으로 안내했다. 업로드 버튼이 없음을 UI에서 확인했다. GPT 호출 1회.
- 승인 349개 메타데이터는 당일 13:58:09의 실제 API 검증 스냅샷을 재사용했다. 이번에 1,047개 메타데이터 호출을 다시 한 것으로 보고하지 않는다. 선택한 생산자물가 관측값은 실제 API로 조회했다.
- 두 서버의 API 자료만 사용하는 PPI 전년동월비 요청은 실제 GPT·KOSIS로 계산됐다. `need_output_config`로 출력 준비가 완료됐고 추가 파일 요청은 없었다. 응답 시간은 local1 약 12.9초, StatBridge1 약 16.3초(각 1회 관측)다.
- 실제 혼합 사례의 CPI 파일은 제공하지 않았으므로 이 사례의 최종 그래프나 계산을 완료했다고 보고하지 않는다. 합성 자료를 사용하는 혼합 업로드·재계산 테스트와 실제 API 검증을 구분한다.
- 두 앱 정상 런처로 재시작. 원래 계정·저장 분석·환경 파일의 해시 보존, 기존 테스트 계정 저장 분석 7건의 실제 복원 성공을 확인했다.
