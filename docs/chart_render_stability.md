# 재편집 렌더링 및 보고서 주석 교체

2026-10-12 · ai-assisted · local1만 수정.

## 수정

작은 중앙 영역에 인쇄용 제목·부제·긴 범례까지 넣고 Plotly 높이를 줄이면 제목이 잘리고 범례가 겹쳤다. 화면용 제목·부제·범례를 그래프 위의 별도 줄바꿈 영역으로 분리했다. 해당 줄은 현재 편집 상태와 동일한 제목·색상·글자 크기를 사용하며 제목·범례 클릭 선택도 유지한다. 인쇄 및 파일 내보내기 명세는 별도로 유지한다.

중앙 영역에는 최소 그래프 높이를 확보했다. 데스크톱 작업 영역은 내용에 맞춰 높이가 늘어나며 작은 창에서는 페이지를 스크롤해 전체 그래프와 대화 입력을 볼 수 있다. 제목·범례를 다시 그래프 안으로 압축하거나 대화 위에 덮지 않는다. 브라우저 1360×650에서 중앙 내용 높이 479px과 실제 영역 높이가 동일하여 아래쪽 계열·축까지 잘리지 않음을 확인했다.

Plotly 갱신과 크기 변경을 순서대로 처리하고 이전 편집의 비동기 렌더링이 최신 화면을 덮지 않도록 했다. 매 수정 때 그래프를 purge하던 방식도 제거하고, 이벤트를 정리하여 반복 클릭 리스너가 누적되지 않도록 했다. 실제 마운트 해제 후 자원을 정리한다.

## 148종 삭제와 새 기호

운영 public/stickers의 기존 PNG 148개를 삭제했다. 한국은행 공식 [통화신용정책보고서(2026년 9월)](https://www.bok.or.kr/portal/bbs/B0000156/view.do?menuNo=200067&nttId=11064613)의 PDF 17쪽(인쇄 5쪽), 그림 I-4에서 초록색 상승·붉은색 하락 화살표를 실제 확인했다. 그 기본 표기를 참고하여 투명 배경 화살표 두 개를 새로 그렸다. 공식 배포 이미지 또는 별도 공식 이모티콘 세트라고 표시하지 않는다.

화면에서는 `보고서 주석 기호 · 2종`으로 표시한다. 기존 위치·크기·각도·투명도 편집 기능으로 적용한다. 이전 저장 그래프의 삭제된 이미지 ID만 제거하는 명세 마이그레이션도 추가했다. 통계값·제목·선·강조 등은 보존하며 알 수 없는 임의 이미지 ID를 허용하지 않는다. 제거된 ID 목록에는 이미지가 아닌 과거 식별자만 남긴다.
