# 한국은행 자료 작성 업무형 평가 질의 설계

## 목표

한국은행 자료 작성 담당자가 기존 보도자료·표·그림을 재현하거나 최신 관측값으로 갱신할 때 실제로 할 법한 요청을 공개 BOK 평가셋에 구성한다.

## 접근 방식

1. 자동 문장 템플릿에 통계명만 넣는다. 형식은 일관되지만 질의가 부자연스럽거나 정답과 다른 계열을 가리킬 수 있어 제외한다.
2. 실제 담당자의 운영 프롬프트를 수집한다. 현실성이 높지만 자료 확보와 개인정보 검토가 선행돼야 하므로 이번 범위에서는 제외한다.
3. 공개 원본 자료, 감사 기록, 기존 기대 계약에 근거해 사례별로 업무 질의를 직접 작성한다. 공개 통계명과 실무 목적은 자연스럽게 사용하되 내부 코드·분류 ID·정답 내부 카탈로그 라벨은 노출하지 않는다. **이번 설계의 권장안이다.**

## 질의 설계

- 중심 사용자는 한국은행 보도자료·통계표·그림을 작성하거나 갱신하는 담당자다.
- 파일럿 질의에는 담당 업무의 목적, 공개 통계 용어, 필요한 기간과 요청 작업을 포함한다. 차트 형식은 해당 업무에서 필요한 경우에만 지정한다.
- 원래 파일럿 12건의 정답 계열·기간·단위 계약은 유지한다. 그 계약에 어긋난 8건의 활성 질의는 질의를 정답 통계 주제에 맞춰 다시 쓴다.
- 기간 확장 6건은 유지한다. 상대기간 질의는 “자료에 이용 가능한 최신 3개 관측월”이라는 기준을 입력 메타데이터와 계약에 명시한다.
- 보완 질의는 초기 화면·대화 맥락·기대 계약·오라클이 같은 실무 과제를 가리키도록 정렬한다. 특히 대기업·중소기업 대출금리 차이 요약은 두 대출금리 계열과 그 차이를 검증하는 독립 오라클을 사용한다.
- 기존 canonical v1 12건은 비교 보존용으로 유지하고, 갱신된 입력 42건의 기존 사람 검수는 승계하지 않는다.

## 검증

- 모든 질의가 공개 원본 주제, 기대 계열과 기간에 의미상 맞는지 사례별 매핑표로 확인한다.
- 후속 질의는 필요한 선행 질문·현재 화면이 입력에 분명히 들어 있는지 확인한다.
- 테스트는 파일럿 질의의 주제-계열 연결, 기간 명시 방식, 보완 입력·기대 계약·오라클 정합성을 검사한다.
- 평가 도구 테스트와 v1.1 validator를 실행하고 manifest 해시를 갱신한다.
- 유료 모델, 실제 KOSIS, 비공개 평가 자료는 사용하지 않는다.

## 범위 밖

P5–P9 분석 제안은 승인 대상이므로 이번 설계에서도 구현하지 않는다. 원본 46건 감사 목록, 공개 원자료 메타데이터, canonical v1 계약은 질의 재작성만을 위해 변경하지 않는다.
