## 진행 기록

### 2026-09-26 · Notion 정리본 확인

- [자연어 입력](<../../design/input/입력-에이전트.md>): 자유 입력, 원문 보존, 다음 단계 전달과 입력 화면 요소를 설계했다.
- [질의 해석 · Query Planning](<../../design/query-planning/질의-해석-흐름.md>): 의도·조건 추출, 개념 정규화, 모호성 확인, 도구 실행계획과 단계별 산출물을 설계했다. [개념 후보 구성](<../../design/query-planning/통계-개념-후보-구성.md>)과 [역질문](<../../design/query-planning/역질문-설계.md>)도 별도 문서로 정리했다.
- [통계표 탐색](<../../design/retrieval/통계표-탐색-흐름.md>): 카탈로그 후보 검색, 메타정보 기반 적합성 확인, 결과별 분기를 설계했다.
- [평가 기준](<../../evaluation/질의-탐색-평가-기준.md>): 입력부터 통계표 탐색까지 단계별 정량 지표·초기 통과선, 1~5점 정성 채점표, 비교 실행 규칙의 초안을 작성했다.
- [권장 도구](<../../design/도구-선정.md>): LLM·검색·리랭커·KOSIS MCP 연계 후보와 비교 방향을 정리했다.
- [한국은행 통계표 목록](../../data/한국은행-통계표-목록.md): 349개 표의 분류·수집 여부와 347개 CSV의 행 수·주기·수록 시점 범위를 정리했다.
- [한국은행 데이터 EDA 보고서](../../data/한국은행-데이터-EDA-보고서.md): 실행된 노트북의 분류·주기·분류 차원·단위·점검 결과를 검색과 골든셋 작업으로 연결했다.

### 남은 작업

- PM / Evaluation: 평가 기준 초안을 팀과 합의하고, 실제 질문·허용 표 ID·기대 결과가 담긴 골든셋 12~15건을 작성한다. 현재 문서는 골든셋의 구성 원칙과 지표를 정의하지만 평가 사례 목록은 없다.
- Backend · Data · MCP: 표 목록과 EDA 보고서를 작성했다. 미수집 2개 표의 조회 가능 여부와 단위 열이 없는 53개 CSV의 메타정보 확인 경로를 점검한다.
- Agent · LLM · Frontend: 설계 문서의 입력/출력 구조 중 이번 주 구현 범위를 정하고 파트 간 형식을 합의한다. 화면·에이전트의 구현 완료 여부는 문서만으로 확인되지 않는다.
