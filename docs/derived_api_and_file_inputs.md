# 실제 API 확인과 사용자 파일을 결합하는 파생지표

후속 확장: CSV 외 JSON·TSV·XLSX 업로드와 자료 입수처 안내를 추가했습니다. 최신 파일 계약과 화면은 [다중 형식·자료 안내](derived_file_formats_and_sources.md)를 참고하세요. 아래 CSV 검증 사례는 기존 v6 실행 기록입니다.

## 출처 경계

한국은행 KOSIS API 조회는 승인된 기관 301의 349개 표로 제한합니다. 표별 실제 `TBL`, `ITM`, `PRD` 메타데이터를 호출하고 항목 ID, 분류 ID, 주기, 공표 기간을 검증합니다. 로컬 등록 정보는 승인 목록과 검색에 사용하고, 실제 선택 검증은 API 응답을 사용합니다. API 장애를 자료 부재로 단정하거나 로컬 값으로 대체하지 않습니다.

2026-10-19 직접 호출은 349 × 3 = 1,047건 모두 성공했습니다. DT_511Y001의 로컬 분류 ID 3개가 실제 API와 달랐습니다. 원본 카탈로그를 일괄 덮어쓰지 않고 실제 API 메타데이터로 선택을 검증합니다. 응답은 `eval/derived_api_metadata_349_records/`, 비교 결과는 `eval/derived_api_metadata_349.json`에 보관합니다. 상세 응답이 아닌 공표 범위가 필요한 PRD에는 detail=N을 사용합니다. [KOSIS 개발 가이드](https://kosis.kr/openapi/devGuide/devGuide_060101List.do)를 따릅니다.

사용자 파일은 최신 요청에서 허용한 별도 입력입니다. `USER_FILE:<alias>`로 표시하고 KOSIS 통계나 기관 301의 자료로 위장하지 않습니다. 일반 API 전용 계산 경로에서는 USER_FILE을 허용하지 않습니다. 파일에 대한 단위와 출처는 사용자 선언이며 공식 통계의 진위 보증이 아닙니다.

## 요청과 보완 흐름

1. 기존 GPT-5.4 연결로 요청을 해석하고 실제 메타데이터로 필요한 API 항목을 확인합니다.
2. 확인 가능한 모든 API 입력을 먼저 조회합니다. 로컬 fallback 없이 실제 응답을 보관합니다.
3. 부족한 자료의 이름, 사유, 주기, 기간, 과거 관측 필요량과 알려진 단위를 안내합니다. 해당 기간을 채운 빈 CSV 양식을 제공합니다. 숫자는 만들어 넣지 않습니다.
4. UI의 CSV 파일 선택 또는 CSV 내용 붙여넣기로 입력합니다. 검증 후 같은 작업에서 다시 계산합니다. 정상 조회한 API 자료는 재사용합니다.
5. GPT는 메타데이터와 허용한 파일 정보로만 DAG를 생성합니다. 파일의 원시 관측값을 GPT가 산출하지 않습니다. 기존 독립 검증기와 Python 실행 엔진으로 계산하고 기존 OutputAgent/ChartSpec으로 표와 그래프를 출력합니다.
6. 실패해도 원본 그래프와 파일을 보존합니다. 파일 수정은 새 파일과 해시로 저장하며 이전 그래프는 이전 파일에 고정됩니다. 0으로 나누는 파일을 수정한 뒤 같은 작업에서 재개할 수 있습니다.

`POST /api/derived/supplement`로 작업을 시작하고, `GET /api/derived/supplement/{id}/template/{alias}`, `POST .../{id}/upload`, `POST .../{id}/resume`를 사용합니다. 모든 경로는 기존 계정 인증과 작업 소유권을 확인합니다. 다른 계정은 404를 받습니다. 일반 질문의 자료 부족/조회 실패 경로도 같은 보완 UI에 연결합니다. 공급자 크레딧 오류는 모델 장애로 안내합니다.

## CSV 계약

UTF-8 CSV, 열은 정확히 `period,value,unit,frequency,source`입니다. M/Q/S/Y 주기를 지원하며 한 파일의 단위와 주기는 일정해야 합니다. 월별 period는 202301 형태입니다. 파일당 2MB, 6,000행, 작업당 입력 8개, 작업 저장량 20MB, 계정당 작업 20개로 제한합니다. 템플릿의 빈 value는 사용자가 채워야 합니다.

결측, 중복 시점, 비유한 숫자, 수식 문자열, 잘못된 주기·단위·기간과 경로 문자를 차단합니다. 사용자 코드, 매크로, Python 또는 외부 URL을 실행하지 않습니다. API·파일의 출처, 실제 메타데이터 해시, 파일 SHA-256, DAG, 원자료, 계산 결과, 이전 계산 ID를 불변 근거로 남깁니다. 자원 제한은 논리 셀·연산 예산이며 OS 수준 메모리 격리는 별도입니다.

## 검증 범위와 제한

실제 GPT-5.4와 KOSIS API, 명시적으로 합성한 비용지수 CSV로 4개 관측값의 그래프·표, 날짜 변경, 되돌리기·다시 실행, 저장·복원, 원자료 열람을 브라우저에서 검증했습니다. 계산 7개 값을 Decimal로 독립 비교했습니다. 합성 파일을 실제 공식 자료로 보고하지 않습니다. 네이티브 파일 선택창은 미실행이며 CSV 붙여넣기와 인증된 업로드 HTTP 경로를 검증했습니다.

349개 메타데이터와 평가 질문 300개의 ID/분류/주기/기간 검토는 실제 API 응답에 근거합니다. 모든 질문의 경제학적 정답에 대한 전문가 승인은 아직 PENDING입니다. 300개 계획 평가는 실제 관측값 300개 종단 계산 검증과 동일하지 않습니다. 최신 평가의 실패를 `eval/derived_failure_analysis.md`에 공개합니다.
