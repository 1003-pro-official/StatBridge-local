# 그래프 편집 워크스페이스

2026-10-12, ai-assisted. 적용 폴더는 StatBridge-local1이며 StatBridge1·StatBridge3 원본은 수정하지 않았다.

## 고정 구조

사용자가 첨부한 3열 편집 화면과 18%/57%/25% 비율을 기준으로 구현했다. 데스크톱의 기본 열 비율은 데이터 18, 그래프 57, 속성 25이며 최소 너비를 적용한다. 양쪽 패널은 독립적으로 스크롤하고 접을 수 있다. 중앙 그래프와 아래 자연어 입력창을 같은 작업 프레임에 유지한다. 작은 화면에서는 그래프를 먼저 표시하고 패널을 접어 사용할 수 있다.

- 상단: 작업 제목, 편집 항목 찾기, 되돌리기·다시 실행, 설정 저장, 파일 다운로드·열기.
- 왼쪽: 사용 중인 데이터·기간·단위, 통계 항목 자동 변경, 분류와 기간을 확인한 데이터 추가, 표시 제외·다시 표시, 기간 재조회.
- 중앙: 조회한 실제 자료를 사용하는 Plotly 그래프, 편집 처리 상태. 선·관측점·제목·축·범례·설명·기간 강조 선택을 속성 패널과 연결한다.
- 오른쪽: 차트 종류, 디자인 6종과 적용 전 간략 미리보기, 제목·부제·범례, 선택 데이터의 색·선, 축·격자, 기간 강조, 기준선·설명. 고급 차트·출처·인쇄와 기존 그림판·이모티콘은 접는 영역에 유지한다.
- 아래: 상시 자연어 편집 입력창, 저장되는 대화 기록, 필요한 경우 색과 불투명도 확인.

기존 캐릭터를 눌러 별도 수정 챗봇을 여는 동선은 기본 편집 화면에서 제거했다. 기존 자연어 해석·RGB 확인·그림 표시·이모티콘 기능은 재사용한다.

## 사용 흐름

1. 기존 검색 또는 통계 탐색에서 통계표·조건·기간을 확인해 그래프를 만든다.
2. 기본 속성은 오른쪽에서 바꾼다. 제목 입력은 잠깐 멈추면 적용하고 차트 종류·디자인 선택은 바로 적용한다. 처리 중에는 상태를 표시한다.
3. 그래프 선을 선택하면 해당 데이터의 속성을 편집한다. 겹치는 선이나 선택하기 어려운 요소는 오른쪽의 항목 목록을 사용한다.
4. 자연어로 추가 수정한다. 서버의 현재 버전을 기준으로 적용하며 원본 복원은 필요 없다.
5. 되돌리기·다시 실행으로 최근 20개 수정 이력을 이동한다. 제목·개별 데이터 색만 이전 상태로 되돌리거나 특정 강조·설명·기준선을 삭제할 수도 있다.
6. 설정 저장은 서버 디스크에 현재 자료·상태·이력을 저장하고 JSON 파일도 내려받는다. 화면 재진입·새로고침은 같은 편집 세션의 최신 상태를 다시 읽는다. 서버를 재시작했으면 저장한 작업을 디스크에서 복원한다.
7. PNG·SVG·PDF·CSV를 다운로드한다. 벡터 출력이 지원되지 않는 종류와 스타일은 이유를 알려 주며 조용히 다른 그래프로 대체하지 않는다.

데이터 교체는 원자료를 고치는 작업이 아니다. 새 통계표를 실제 조회하고 검증한 뒤 기존 세션 안에서 데이터셋을 교체한다. 제거된 항목에 연결된 설정은 정리하고, 단위·주기가 바뀌면 해당 축 이름·범위를 재설정한다. 사용자 제목은 유지하므로 새 데이터에 적합한 제목인지 확인해야 한다. 서로 다른 단위·주기의 추가 데이터는 비교 패널로 분리한다.

## 저장 및 한계

JSON 파일은 8MB, 서버 저장은 압축 전 64MB 제한이다. 서버 저장 경로는 `.venv/cache/chart_workspaces/`이며 키·인증 필드는 제외한다. 저장 자료의 fingerprint를 검사하고 손상된 파일은 거절한다. 저장 당시 통계 자료를 복원하는 것이므로 최신 수치가 필요하면 기간을 다시 조회한다. 저장한 JSON을 다른 데이터셋에 임의 적용하지 않는다.

자연어 편집은 외부 서버 처리 시간이 필요하다. 429와 일부 일시적 서버 오류에는 최대 두 번 재시도하며 실패 시 현재 그래프·입력은 유지된다. 단순 스타일 편집에서 불필요한 통계 서술 생성 호출을 제거했다. 입력이 모호하거나 제공되지 않은 전망·구간 자료가 필요하면 확인을 요청한다.

사람을 대상으로 한 사용성 조사와 모든 기기·브라우저 검증은 아직 수행하지 않았다. 실행 증거와 지원 구분은 `chart_ui_validation_report.md`, `chart_e2e_evidence.md`를 따른다.
