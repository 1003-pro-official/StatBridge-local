# 데이터조회 정확도 재평가 결과

ai-assisted · 실행 당시 공식 응답 본문 보존 · 2026-10-23

**통과 5/20 · 미통과 15/20 · 25점**

## 평가 범위와 조건

349개 승인 표를 후보로 사용하는 데이터조회 20문항이다. 서로 다른 표 20개, 월간 12·분기 3·연간 5문항이며 정답 관측값은 58개다. 질문 앞의 한국은행 자료로는 없다. 기존 사용자 검토 정답을 유지하고 제품 코드는 e45ed41 기준으로 실행했다. 이 점수는 규칙·모델·Agent·MCP·실시간 KOSIS 조회를 포함한다. 실제 브라우저 로그인·UI 편집·다운로드 평가는 수행하지 않았다.

첨부한 60문항 예시는 문항별 조건·결과·근거, 실패 유형, 재현 방법, 검증 한계를 명시하는 보고서 구성에 반영했다. 그 평가의 고정 응답 재생이나 60/60 점수를 이 평가에 합치지 않는다.

메타데이터 전수 확인 캐시는 빈 전용 폴더에서 시작했다. 문항마다 독립 요청 1회이며 후속 답변·재시도에 정답을 사용하지 않았다. 모델·검색 호출 간격은 최소 15초다. 일부 요청은 규칙 경로만 사용한다.

## 정답 분리와 채점

입력 스키마(id/query만), 질문 파일만 있는 입력 폴더, 정답 경로 읽기 차단 시험의 3개 검사를 모델 실행 전에 통과했다. 실행 후 정답 접근 시도는 0회다. 실행 프로세스 종료를 확인한 뒤 별도 네트워크 차단 채점기로 정답을 읽었다. 이 격리는 Python 감사 훅 방식이며 OS 보안 격리는 아니다.

API 호출·기관/표·항목·분류·주기/기간·단위·수치 7개 모두 통과해야 최종 통과다. 누락·확인 대기·조회 오류도 미통과다. API 호출은 실제 요청과 최종 조회 성공을 함께 요구한다. 단일 계열 정답에 불필요한 계열을 더하면 미통과다. 수치는 Decimal로 비교하며 A/Y 연간 별칭은 인정한다. 확인 증거가 없어서 미통과한 항목을 서로 독립된 일곱 원인으로 해석하지 않는다.

## 실행 증거

execution/raw_responses에는 이번 실행 당시 받은 KOSIS·모델·검색 응답 본문이 있다. 실행 중 저장한 요청 ID·문항 ID·인자·시각·HTTP 상태·본문 해시를 execution/http.jsonl에 연결했다. API 키와 인증 헤더는 포함하지 않았다. 본문은 HTTP 압축 해제 후 requests.Response.content 바이트이며 TLS 패킷은 아니다.

실제 요청 집계: {'model': 18, 'kosis_data': 23, 'other': 0}. HTTP 상태: {('kosis_data', '200'): 23, ('model', '200'): 16, ('model', '429'): 2}
