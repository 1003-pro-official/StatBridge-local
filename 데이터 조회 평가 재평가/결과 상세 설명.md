## 표 선택과 조회 실패

선택 오류와 API 조회 실패는 동시에 발생할 수 있다. HTTP 200이어도 KOSIS 본문 오류 30은 해당 조건의 데이터 부재다. 표 전체가 없거나 통신 장애라는 뜻은 아니다.

### DA3-03

예금은행 수신금리(신규취급액 기준): 조회 실패: DT_121Y002
정답 표 DT_121Y006; 선택 표 ['DT_121Y002', 'DT_121Y006', 'DT_121Y006']

03·04번에서 수신금리를 추가했다면 요청 범위 오류다. 추가한 분류 조합이 오류 30을 받았다면 실제 조회도 실패한 것이다. 이번 문항별 원문 표에서 성공한 가계대출 응답과 실패한 다른 계열을 함께 확인할 수 있다. 배치의 한 요청이 실패하면 최종 관측 행을 반환하지 않는 코드 경로가 있어 중간 성공과 최종 성공을 구분한다.

DA3-20: 승인된 349개 표의 실제 KOSIS 메타데이터를 확인하고 있습니다 (0/349). 자료 부재 판정이 아닙니다. 잠시 후 같은 요청으로 확인을 이어가 주세요.

공식 분류명의 합계가 파생계산 판별에 걸리면 전체 메타데이터 확인을 요구하는 경로로 들어갈 수 있다. 빈 확인 캐시에서 대기를 반환한 경우 원자료 부재나 HCX-003의 오답으로 단정하지 않는다. 문항별 모델 호출 기록을 확인해야 한다. 60문항 예시의 E12·E13은 조건이 부족해 확인 질문이 정답인 경우지만, 여기서는 조회 조건이 주어졌으므로 대기만 반환하면 미통과다.

## 지역 조건 누락과 불필요한 계열 추가

07번의 부산 가계대출 정답은 DT_151Y003이다. DT_151Y002를 선택하면 지역 조건을 충족하지 못한다. 10번에서 원계열과 계절조정 계열을 함께 반환하면 필요한 표를 포함했더라도 불필요한 계열이 추가된 것이다. 전자는 다른 표로 대체한 오류이고 후자는 정답에 다른 계열을 섞은 오류다. 이번 실제 선택은 문항별 보고서에서 확인한다.

## 증거 보완과 해석의 한계

이전 실행은 KOSIS 응답 전체를 저장하지 않았다. 이번 실행은 수신 즉시 원문을 저장했고 최종 반환 수치가 실제 공식 응답에 포함되는지도 오프라인으로 검증한다. 정답의 독립 검증용 응답은 별도 gold_verification 폴더에 두고 실행 증거와 혼용하지 않는다.

이 평가는 349개 전부의 정확도나 특정 LLM 단독 지능 점수가 아니다. 20문항의 제품 조회 흐름 평가다. 규칙·기간 파서·캐시 준비·외부 서비스 상태까지 영향을 준다. 실제 UI 평가와 다운로드 파일 검증은 이번 범위에 없다. 검토된 개발 문항이므로 미공개 블라인드 일반화 성능으로 주장하지 않는다.
