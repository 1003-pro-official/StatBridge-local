# GS-0001~GS-0020 독립 검토 제안

검토일: 2026-09-23. 20건 모두 사람 검토 전 초안이며 최종 승인 0건. 제안: 수정 16건, 보류 4건, 승인 0건, 제외 0건. 보류: GS-0001, GS-0003, GS-0013, GS-0015.

## 확인 범위

- 원문 대화 20건은 모두 단일 턴이며 선행 맥락/사용자 답변 분기는 없다. `cases.jsonl`의 A~I 단계, `schema.json`, `plan_validation_cases.jsonl`, 원본 `review.xlsx` 구성, `catalog_manifest.json`, `schemas/mcp_tools.json`을 확인했다.
- 2026-09-14 한국은행 프로젝트 카탈로그 349개 표의 manifest와 `hankook_tables.json`, 로컬 요약 CSV 및 해당 20건 주 후보 CSV를 대조했다. 후보 68개 표의 저장된 KosisClient `getMeta(PRD/ITM)` 응답 중 해당 표를 확인했다. **이번 검토에서 실시간 KOSIS API와 KOSIS 전체 카탈로그 검색은 수행하지 않았다.** 저장된 내보내기에서 주석과 완전한 계열 정의는 확인되지 않는다.
- `review.xlsx`는 원본을 읽기 전용으로 확인했고 공식 검토 결정 칸에는 입력하지 않았다. 파일 수정 제안의 점 표기 경로는 `gold`를 루트로 하는 후속 사람 적용 제안이며 정본에 적용되지 않았다.

## 오류 유형과 사람 확인 사항

| 유형 | 사례 | 검토 결과 |
|---|---|---|
| 개념 오매핑 | GS-0002, GS-0011~0013, GS-0016, GS-0018~0020 | 원문 지표 대신 표명을 슬롯에 넣거나 지표·차원 조건을 누락. GS-0011/0018은 업종코드만으로 BSI 종류가 정해지지 않는다. |
| 상대 기간 오류 | GS-0001~0011, GS-0014, GS-0018~0020 | 상대 표현과 기준일은 유지됐지만 종료 관측시점은 표마다 2026-07 또는 2026-08이다. 시작점은 조회 계열의 실제 마지막 수록월에서 5년 창으로 계산해야 한다. 지금은 최종 기간을 고정하지 않는다. |
| 절대 기간 원문 손실 | GS-0012, GS-0013, GS-0015~0017 | `source_text`가 `202001`/`2015` 같은 변환값이다. `2020년 이후`/`2015년 이후`로 원문을 복원해야 한다. 분기는 2020년 1분기 또는 2015년 1분기부터다. |
| 역질문 분기 누락 | GS-0001, GS-0013 | 원계열/순환변동치 및 명목/실질·주기가 미지정인데 PROCEED. 사람은 질문과 답변별 슬롯 갱신을 확정해야 한다. GS-0003/0015도 후보 정의를 확인하기 전 단일 후보 승인 보류. |
| 도구 계약 불일치 | GS-0001~0020 | 도구명·필수 인자·검색→메타→데이터 순서는 계약과 맞는다. 다만 모든 사례의 `conditionally_allowed_tools`에 계획 상태의 `merge_datasets`/`render_chart`가 들어 있다. 실행 도구 목록에서 분리하고 계획 상태로 표시한다. `fetch_data`의 `frequency`, `start_period`, `end_period` 등은 메타 확인 후 허용 인자로만 사용한다. |
| 메타정보 부족 | GS-0001~0020 | 저장된 PRD/ITM 및 로컬 CSV는 항목·분류·주기·기간과 일부 계열 단위를 확인한다. 주석·완전한 계열 정의, 최신 개정 여부는 미확인. 특히 GS-0016은 표 요약의 혼합 단위 대신 10101 계열의 십억원을 사용해야 한다. |
| 잘못된 NO_MATCH | 해당 없음 | 배정 20건에는 NO_MATCH가 없다. 전체 15건은 이 검토 범위 밖이며 승인 제안하지 않는다. |

## 제안 판단

- GS-0001: ESI 원계열과 순환변동치 중 미지정. 답변별 계열 선택과 handoff를 사람이 확정한다.
- GS-0003: 생산자물가지수 기본/특수 분류 총지수의 정의·동일성 확인 전 단일 ID 승인 보류.
- GS-0013: 민간최종소비지출의 명목/실질 및 연간/분기 미지정. 명목 연간 `DT_200Y113`과 다른 후보를 비교할 답변이 필요하다.
- GS-0015: 기관 총계만으로 통화/만기/시장 축 중 단일 계열이 정해지지 않는다. 축 조합과 중복 집계를 확인한다.
- 나머지 16건의 표 ID는 원문과 저장된 항목/분류·기간이 맞는 **제안**이다. 사람은 주석·완전한 계열 정의와 최신 수록, 각 수정값을 확인한 뒤에만 정본 승인 여부를 결정한다.
