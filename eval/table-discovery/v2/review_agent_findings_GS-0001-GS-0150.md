# 골든셋 v2 · 150건 AI 검토 의견

검토 기준: 2026-09-14 한국은행 349표 카탈로그, 로컬 CSV, 저장된 KOSIS PRD/ITM 메타정보. 실시간 API 및 전체 KOSIS 검색은 실행하지 않았다. **이 문서는 사람의 정답 승인이나 평가용 확정 골든셋이 아니다.** `cases.jsonl`의 `gold`와 `annotation.review_status`는 변경하지 않았다.

## 우선 발견한 오류

- `CANDIDATES`인데 `acceptable_table_ids`가 빈 사례 50건: 별칭 10건, 조건 20건, 대화 후속 20건. 단일/복수 표 점수의 정답 기준이 비어 있다.
- GS-0088~GS-0095의 허용 표 집합에는 앞선 질의의 무관한 표 ID가 연속으로 섞여 있다. 보고서와 Excel에는 제거할 ID와 남길 후보 집합을 제안했다.
- 조건 질의 GS-0102·GS-0108은 표명과 요청한 말잔/평잔이 충돌한다. 후속 질의에도 선행 대화와 어긋나거나 이미 주어진 조건을 반복하는 사례가 있다.
- 모든 사례의 승인 상태는 `review_required`이며, 저장된 메타정보만으로 주석·완전한 계열 정의는 검증할 수 없다. `NO_MATCH` 15건은 프로젝트 349표 범위의 후보 판단이며 사람 확인 전 확정하지 않는다.

## 판정의 의미

- **유지 후보:** 현재 방향이 카탈로그·CSV와 대체로 맞는다는 검토 의견. 승인 아님.
- **수정 제안:** 슬롯·후보·상태 또는 대화 맥락에서 구체적 수정이 필요함.
- **판정 보류:** 중요한 개념·계열·기간 또는 근거가 부족해 정답을 확정할 수 없음.

검토 의견 집계: 유지 후보 28건, 수정 제안 86건, 판정 보류 36건, 제외 제안 0건. 공식 승인 0건.

## 실행계획 구조 점검

150건의 도구 이름·필수 인자를 동결된 `schemas/mcp_tools.json`과 대조했다. 구현 전인 `merge_datasets`·`render_chart`는 실행 가능 도구가 아닌 계획 도구로 기록되어 있고, 계약 필수 인자 불일치·미구현 도구의 실행 허용·`ASK_USER`와 handoff 상태 불일치는 각 0건이었다. 이는 **구조 점검 결과**이며, 질의별 역질문 필요성·표 정답·도구 계획의 의미적 적합성 승인은 아니다. 기존 GS-0001~GS-0020 검토 문서의 지적 사항도 사례별 판단에 참고했다.
