작성일: 2026-10-08. 페르소나: 한국은행 보고서를 취재·해설하는 기자. 사용자 목표: 기사에 사용할 구체적인 데이터 그래프와 데이터에 근거한 해석.

질문은 research의 실제 보고서 그림·표 주제를 바탕으로 새로 작성했다. 보고서 원본 그림의 복제 요청이나 직접 인용문이 아니다. 보고서의 조사국 시산·다른 기관 자료·발간 당시 전망을 현재 지원 사전의 관측 데이터와 같다고 가정하지 않았다. 연구 문서의 자동 추정 필드를 정답 근거로 사용하지 않았다.

구성: 단일 계열 8개 / 한 표의 복수 계열 10개 / 여러 표의 복수 계열 12개. 모든 질문은 기간·대상·측정 기준·요청 계열·그래프 배치·해석 목적을 명시한다. 반복적인 기사 소개 문장은 query에서 제외하고 persona와 editorial_context에만 보관한다. 기사 주제는 정답 계열을 추가하는 근거가 아니다.

정답: 질문 해석의 의미 슬롯과 사전 v5.1에서 독립적으로 지정한 통계표 ID 집합·항목·분류 코드 조합. 원문 질문에는 표 ID를 넣지 않았다. 2023~2024년 전체를 사용하며 월별 24개/분기별 8개 시점을 요청한다. 분기 API 코드 YYYY01~YYYY04를 사용한다.

추가 필드 workflow_gold: query_interpretation(지표·대상·측정값·기준·세부 조건·기간·주기·비교), table_discovery(표 이름/ID 집합), item_selection(표별 항목 코드), classification_and_plan(정확한 계열별 분류·기간·주기), resolution(상태·표 수·계열 수·역질문 여부). 같은 뜻의 자연어는 허용하지만 데이터 범위·측정 기준·코드는 바꾸면 안 된다. null은 추가로 명시한 조건이 없다는 뜻이다.

검증: 30개 질문/ID의 유일성, 구성 비율, 정답 표·항목·모든 분류 코드의 존재, 사전 기간 범위에 2023~2024년 포함 여부, 연구 자료의 해당 제목·결과물ID를 확인했다. 시스템 예측 성능은 측정하지 않았다. 원자료의 결측·개별 계열 수록기간·단위는 실제 조회에서 추가 확인해야 한다.

판정: 질문 해석 → 표 선택 → 항목 선택 → 분류/조회 계획 → 탐색 완료를 각각 채점한다. 표 ID 집합과 계열 코드 조합은 순서 없이 정확 일치해야 하며 일부 누락·추가 계열은 실패다. UI의 기간/출력 설정 확인은 통계 의미를 묻는 역질문과 구분한다. 실제 자동 채점기는 아직 구현하지 않았다. 그래프·해석 요구사항은 다음 단계로 분리하며 현재 정량 E2E Gold는 아니다. 원자료 스냅샷과 수치 정답은 추가 확정해야 한다.
