# v1.4 평가 지표 및 채점 기준

2026-10-27 · ai-assisted · 제안안 · 사람 검수 전 · 공개 개발 회귀 평가

## 목적과 범위

50개의 독립 질의로 사용자의 요구가 한국은행 통계의 올바른 계열 조회, 필요한 계산, 표와 그래프까지 전달되는지 평가한다. 네 유형은 일반 12, 복수 지표 일반 8, 단순 파생 18, 복잡 파생 12문항이다. 50문항 모두 표와 그래프가 요구된다. 이 세트는 모호한 요청과 자료 부족 상황을 의도적으로 평가하지 않으며, 문항에 없는 대화 기억·다운로드·편집·보고서 본문 작성의 성능도 평가하지 않는다.

**현재 상태:** 전체 기간의 수치 정답과 참고 표·그래프는 별도 로컬 출력으로 생성했으나 사람의 검수와 오라클 동결은 완료되지 않았다. 아래는 채점 설계이지 측정 결과가 아니다. 정답의 출처와 수치·결측·개정 기준, 시각 정답 및 사람이 승인한 판정 기준이 준비되기 전에는 전체 100점이나 최종 통과율을 산출하지 않는다. 별도 로컬 참고 출력은 전체 기간을 포함하지만 사람 승인된 오라클이 아니다.

## 평가 절차와 증거

1. 실행자에게는 [질문 파일](질문_50문항.md)의 ID와 질의만 주고, 매 문항을 새 세션에서 시작한다. 정답 파일과 수치 오라클을 모델 입력이나 도구 출력에 주입하지 않는다.
2. 실제 화면에서 요청부터 표·그래프 생성까지 실행한다. 제품 버전, 실행일시·시간대, 데이터 기준일, 모델·설정, 데이터 소스, 실행 상태를 기록한다. 외부 데이터가 개정되면 동일 스냅샷으로 재현하거나 변경 사실을 명시하고 정답과 재검토한다.
3. 표의 표시값과 가능한 기계 판독 수치, 그래프의 계열별 시점·값·축, 산식·원자료·출처, 화면 캡처를 보존한다. 그래프 내부 값에 접근할 수 없다면 화면만으로 판별 가능한 항목만 평가하고 해당 값 일치는 `not_observed`로 둔다. 실제 제출 가능한 표·그래프가 모두 있어야 한다.
4. 채점자는 정답과 증거를 비교하고 항목별 점수·상태와 근거 위치를 기록한다. 모델 또는 규칙 채점은 보조 수단으로 사용하며, 최종 정성 및 치명 오류 판정은 사람이 확인한다. 검수자 간 이견은 보류 후 해소한다.
5. 관측 불가, 외부 장애, 문항·오라클 오류, 시스템 실패를 구분해 기록한다. 사후에 기준이나 대상 문항을 임의로 바꾸지 않고 수정한 문항은 재검토한다.

## 점수표: 문항당 100점

| 항목 | 일반·복수 지표 일반 | 단순·복잡 파생 | 평가 대상 |
|---|---:|---:|---|
| A. 계열·출처 | 25 | 20 | 기관, 통계표·항목, 분류, 원계열·계절조정, 평잔·말잔, 명목·실질 등 요청 기준 |
| B. 기간·주기 | 20 | 15 | 전체 표시 시점, 월·분기·연간 주기와 정렬; 파생은 선행 입력의 정확성 포함 |
| C. 원자료·파생 계산 | 20 | 30 | 수치·단위·결측, 산식 및 중간 계산. 일반 문항은 원자료 수치만 |
| D. 표 결과 | 20 | 20 | 요청한 열·시점·계열·값·단위·출처와 읽을 수 있는 표 |
| E. 그래프 결과 | 15 | 15 | 그래프 계열·시점·값·축·단위·범례·출처와 가독성 |
| 합계 | **100** | **100** | |

이 배점은 설계상의 제안값이며 통계적으로 보정된 가중치가 아니다. 기준 변경 시 이 버전의 과거 점수와 비교하지 않고 배점과 산식을 함께 기록한다.

### 공통 부분점수

각 항목에는 아래 세 수준 중 하나를 적용한다. 항목별로 비중을 다시 임의 분할하지 않는다. 다음 절의 필수 실패는 부분점수와 별개로 판정한다.

- **100%:** 해당 항목의 모든 필수 조건이 충족되고 증거가 있다.
- **50%:** 핵심 선택·수치·기간은 맞지만, 해당 항목의 부가 표시가 일부 빠졌거나 경미한 가독성 문제가 있다. 예: 계열과 값은 모두 맞고 표의 출처 표기만 빠짐.
- **0%:** 해당 항목의 핵심 조건이 틀리거나 요구 결과가 없다. 예: 지정한 계열 누락, 값 오류, 필요한 그래프 누락.
- **미판정:** 정답 미확정, 외부 장애, 증거 부족으로 확인할 수 없다. 0점이나 50%로 바꾸지 않는다. 일부만 보이는 그래프의 수치 일치도 이에 해당한다.

점수 = Σ(항목 배점 × 수준). 다섯 항목이 모두 판정된 문항만 100점 만점으로 계산한다. 일부 미판정인 경우 항목별 확정 판정은 기록하되, 가용 항목만으로 100점 환산하거나 통과 처리하지 않는다. 동일 결함이 복수 항목에 실제 영향을 미칠 때 각 항목에 반영할 수 있으나, 한 항목 내부에서 반복 감점하지 않는다.

### 항목별 판단

**A. 계열·출처.** 한 계열이라도 다른 표·분류를 사용하거나 비교 계열을 빼면 0점이다. 원천의 식별이 가능하고 선택이 모두 맞지만 단순 출처 표기 위치 등이 부족하면 50%다. 표 또는 그래프의 출처 누락은 해당 표시 항목 D 또는 E에서도 평가한다. 출처가 위조되거나 오인되면 필수 실패다.

**B. 기간·주기.** 지정된 모든 표시 시점과 주기가 맞고 계열 사이 정렬이 맞아야 한다. 전년동기·전기 계산에 필요한 선행 시점이 실제 계산에 사용됐는지도 확인한다. 선행 자료를 조회하는 것 자체는 출력 기간 초과가 아니다. 시점 누락, 월·분기 혼동, 선행값 미사용은 0점이다. 날짜 축의 일부 눈금 생략처럼 값의 시점이 확인 가능한 가독성 문제는 50%다.

**C. 원자료·파생 계산.** 일반 유형은 지정된 원자료 수치와 단위를 확인한다. 파생 유형은 원자료·산식·결과를 모두 확인한다. 예컨대 금리 차이는 `%p`, 전년 대비 증가율은 `%`를 사용하고 중간 반올림을 하지 않는다. 전년 값이 없거나 분모가 0인 증가율은 결측으로 유지한다. 검증된 원자료나 결과 중 하나라도 수치·부호·단위 또는 산식이 틀리면 0점이다. 값과 산식은 정확하지만 계산 근거의 설명이 일부 부족하면 50%다. 정답 숫자가 검증되지 않았다면 값 일치는 미판정이다.

**D. 표 결과.** 모든 요청 계열과 기간, 필요한 원자료·계산 결과, 단위·출처가 표에 정확히 표시되는지 확인한다. 질의가 원자료와 계산값을 함께 표로 요청하면 두 값을 같은 표에 표시해야 한다. 비교시점 원자료 열은 질의가 명시하지 않았다면 같은 표나 별도의 계산 근거 중 어느 곳에서 확인해도 된다. 값이 잘못되거나 필수 행·열이 없으면 0점이다. 핵심 데이터는 맞지만 출처 표시 누락이나 가독성 개선이 필요하면 50%다. 화면의 표시값과 내보낸 값이 같은지 여부는 사용자가 다운로드를 요구하지 않은 이 세트의 필수 항목이 아니다.

**E. 그래프 결과.** 요청한 시점과 계열, 그래프 종류, 값의 시점 매핑, 단위·축, 필요한 범례·출처를 확인한다. 질의가 기준선을 명시하지 않은 경우 0 기준선은 권고이며 필수 채점 조건으로 사용하지 않는다. 서로 다른 단위를 구분하지 않거나 잘못된 축으로 관계를 오도하면 0점이다. 복합 문항의 별도 패널과 좌우축은 정답이 둘 다 허용한 경우 어느 쪽도 가능하다. 핵심 데이터와 축은 맞고 일부 눈금·범례 가독성만 미흡하면 50%다. 색상·서체·범례 위치 또는 픽셀 일치는 요구하지 않는다.

## 통과·실패와 치명 오류

문항 통과는 **모든 항목이 판정되었고, 총점 80점 이상이며, 아래 필수 조건을 모두 충족한 경우**다. 80점은 운영 전 검토가 필요한 제안 기준이다. 정답이 미확정이거나 증거가 부족한 문항은 점수와 관계없이 `pending`이다.

필수 조건: 모든 요청 계열과 기간·주기를 정확히 선택하고, 검증된 모든 원자료·파생 수치와 산식·단위가 일치하며, 요구한 표와 그래프가 모두 존재하고 서로 같은 시점·값을 나타내야 한다. 파생 계산의 선행 입력, 결측과 0 분모 처리도 맞아야 한다. 표와 그래프는 화면 전환으로 각각 확인해도 된다. ME14-17은 잔액과 거래를 별도 패널로 표시한다. 차트 축이나 출처가 의미를 왜곡해서는 안 된다. 이 중 하나라도 어기면 점수가 80점 이상이어도 `fail`이다.

다음은 치명 오류로 별도 집계하며 문항 실패다: 다른 통계 계열을 정답처럼 제시, 원자료나 계산값을 만들어 냄, 계산 방향 또는 단위를 바꿔 결과를 왜곡, 표와 그래프의 값이 불일치, 부호·축 또는 잘못된 출처로 결과를 오도. 외부 API가 실패했다는 사실만으로 치명 오류라 하지 않는다. 오류 발생과 정답 확인 불가를 구분한다.

### 수치 비교

- 고정된 승인 오라클과 비교할 때 원자료 및 파생값의 기본 절대오차는 `0.000001`, 상대오차는 0이다. 원천 값의 정밀도와 계산 근거를 함께 보존한다.
- 화면에 반올림 표시된 값은 표시 자릿수의 반 단위까지 허용한다. 예를 들어 소수 둘째 자리 표시라면 절대차 `≤ 0.005`를 허용하되, 표기 자릿수와 반올림 규칙을 기록한다. 내보낸 원수치가 있으면 원수치도 기본 오차로 비교한다.
- 요청 단위와 다른 배율로 표시할 경우 단위 변환이 명시적이고 정확하며 질의 조건에 어긋나지 않을 때만 동일 기준 단위로 환산하여 비교한다. `%`와 `%p`, 잔액과 거래, 지수와 증가율은 환산 가능한 동일 단위가 아니다.
- 누락, 결측, `0`, API 오류, 미판정은 서로 다르다. 오라클도 결측으로 검증된 경우에만 출력 결측을 정답으로 인정한다.

## 정량 지표 및 분모

각 문항에 최종 상태를 **통과, 실패, 평가 대기, 외부 환경 장애, 미실행, 사전 제외** 중 하나로 기록한다. 배타적인 상태이며 실행 실패 사유를 별도 필드에 쓴다. 제품이 오작동한 경우는 실패다. 외부 장애는 요청 증거로 입증하고, 문항·오라클 오류에 따른 사전 제외는 사유와 최초 실행 전 결정 시각을 기록한다. 오류 발견이 실행 후라면 사후 제외 사실과 원래 결과를 모두 보존한다.

- **최종 통과율:** 통과 / (통과 + 실패) × 100. 오라클 완성과 증거 확인 후만 산출한다. 환경 장애·평가 대기·미실행·제외는 분모 밖에 두고 개수를 함께 제시한다.
- **전체 문항 대비 통과 비율:** 통과 / 50 × 100. 미실행 등을 성공으로 취급하지 않으며, 완전한 평가의 통과율과 혼동하지 않는다.
- **실행률:** 실제 제품에 질의를 제출한 고유 문항 수 / 실행 대상 문항 수 × 100. 외부 장애로 끝난 제출도 실행에 포함한다. 사전 제외 수와 전체 50개 대비 실행 수도 함께 표시한다.
- **평가 완료율:** (통과 + 실패) / 실행 대상 문항 수 × 100. 오라클 미완성으로 평가 대기인 문항은 포함하지 않는다.
- **유형별 통과율:** 각 유형의 통과 / 해당 유형의 (통과 + 실패) × 100. 분모와 미평가 건수를 함께 적고 n=0이면 `산출 불가`다.
- **항목별 평균 충족률:** 확정 판정된 문항에서 각 항목의 실제 점수 합 / 해당 항목의 배점 합 × 100. 일반과 파생의 배점이 다르므로 반드시 실제 배점 합을 분모로 사용한다. 항목별 판정 문항 수·미판정 수를 함께 기록한다. 잠정 진단 지표이며 최종 통과율을 대체하지 않는다.
- **치명 오류율:** 치명 오류 문항 수 / (통과 + 실패) × 100. 같은 문항의 여러 치명 오류는 문항 기준 1건으로 세고 오류 유형별 건수는 별도로 제시한다.
- **표·그래프 일치율:** 표와 그래프의 해당 값·시점·단위가 모두 검증 가능했던 문항 중 양자가 일치한 문항 / 비교 가능한 문항 × 100. 비교 불가 건수도 함께 기록한다. 두 출력이 서로 일치해도 오라클과 모두 틀릴 수 있으므로 정확도와 별개다.

반복 실행은 첫 실행 결과와 재시도 결과를 분리한다. 임의 재시도로 가장 좋은 결과만 선택하지 않는다. 지연 시간은 실행 환경·외부 호출의 영향을 받으므로 관측한다면 중앙값·분포·타임아웃을 별도 보고하며 승인된 시간 기준이 없으면 통과 조건으로 쓰지 않는다.
