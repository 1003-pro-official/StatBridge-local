## 기록을 읽는 기준

- 모든 점수는 **기존 실행의 보존 기록**이다. 최초 실행·수정 후 실행·사전 지정 부분 재실행을 합쳐 새로운 단일 전수 실행 점수로 표시하지 않는다.
- v2는 모델/API·파일 구성요소 평가이며 실제 UI 60문항 전수 평가가 아니다. v2.1의 조회·역질문은 API 경로, 유형 분류는 로컬 제품 함수 평가다. v1과 v1.4의 UI 실행 기록과 평가 범위가 다르다.
- 사람의 정답 승인과 제품 출력의 정성 승인, 공개 개발 평가와 블라인드 성능을 구분한다. v1.4의 참고 정답·그래프·채점 기준 승인 범위는 전달본의 `승인_기록.md`를 보존한다. 다른 버전의 사람 검토 대기 표기도 유지한다.
- v1.1·v2.1의 원본 안내와 manifest에 남아 있는 `미실행`/`not_run`은 **평가셋 작성 당시 상태**다. 이후 실행은 각 `records/`에서 확인한다. 원본의 수치·라벨·해시를 이번 업로드에 맞춰 소급 변경하지 않았다.
- 실행용 질문과 채점자용 정답은 분리한다. 공개 정답·난이도·후속 단계·기존 판정은 제품이나 모델의 입력으로 사용하지 않는다.

## 보존 범위와 출처

이번 공개는 사용자가 명시적으로 요청한 공개 개발셋·질의·정답·기존 평가 기록에 한정한다. `publication-20261028.json`은 복사한 85개 파일의 출처, 원본과 공개본 각각의 크기·SHA-256을 기록한다. 저장소 규칙에 따라 CRLF를 LF로 정규화하고 Markdown 끝의 추가 빈 줄을 정리했다. 질문·정답·수치·판정은 바꾸지 않았다. 과거 manifest와 동결 해시의 값은 원본 파일에 대한 기록으로 보존했다. 공개본의 LF 해시와 원본 해시는 업로드 manifest에서 연결한다.

평가 보고서가 참조하는 모든 로컬 실행 산출물을 옮긴 것은 아니다. 계정 DB·인증 정보·임시 파일·전체 원응답·스크린샷·생성 다운로드 파일은 기존 로컬 실행 디렉터리에 남는다. 기록의 원실행 경로와 동결 해시는 당시 산출물의 식별 정보이며, 모든 경로가 GitHub에서 열리는 링크라는 뜻은 아니다. 과거 보고서의 `evaluation_runs/` 재현 명령과 v2 원본 `verify.py`의 상대 경로는 당시 실행 디렉터리를 기준으로 한다.

비공개 평가 저장소와 holdout 정답은 점검·복사하지 않았다. 다른 계열인 `statbridge-golden/v1·v2`, `end-to-end/v1·v2`, `reporter-table-discovery-30/v1·v2·v2.1`, `bok-reproduction/v1·v2`의 공개 자료는 이미 main에 있었다. 이들 버전이나 점수를 위 최소 E2E 계열과 합치지 않는다.
