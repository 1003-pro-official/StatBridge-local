# v1.1 질의와 정답 40문항

ai-assisted · 공개 개발 평가셋 · 원본 역질문 라벨의 사람 승인 대기 · 노션 복사용 3열 표

추가 평가 항목인 [질의 유형 분류 정확도 20문항](질의_유형_분류_정확도_20문항.md)은 별도 문서에서 관리합니다. v1.1 전체 구성은 [60문항 안내](README.md)를 참고하세요. 이 문서와 기존 UI 결과의 대상은 아래 40문항입니다.

이 세트는 데이터 조회 정확도 20개와 역질문 적절성 20개입니다. 데이터 조회는 기관·표·항목·분류·주기·기간·단위·수치를, 역질문은 독립 질문의 첫 응답에서 필요한 조건만 확인하는지를 평가합니다. 편집·다운로드 정합 및 다중 턴 기억 성능을 측정하는 세트는 아닙니다.

각 문항은 로그인 후 새 채팅으로 시작합니다. 실행자에게는 id/query만 제공하고 아래 정답·계산식·후속 답변은 제공하지 않습니다. 원본 질의 40개와 필요/불필요 10:10 라벨을 유지했습니다. 기존 합의가 본문에 포함된 CQ1-12/13/19는 본문 해석 평가이며 실제 세션 기억 평가로 해석하지 않습니다.

데이터 조회 수치는 원본 패키지의 공식 응답 스냅샷 기준입니다. 이번 UI 실행은 실제 KOSIS API를 호출하며, 공식 개정치가 확인되면 제품 오류와 구분해야 합니다. 원자료 수치 비교 절대오차는 0.000001, UI 반올림은 별도로 허용합니다. Q의 YYYY01~YYYY04는 1~4분기이고 연간 A/Y는 같은 의미입니다. 모든 필수 조건을 충족해야 문항 통과이며 미실행·외부 오류는 성공으로 처리하지 않습니다.

역질문은 참고 응답의 문구 일치가 아니라 required_slots의 의미로 판정합니다. 이미 확정된 조건을 새 결정으로 다시 요구하거나, 확인 없이 미확정 계열을 임의 조회하면 실패입니다. API 장애·메타데이터 준비 대기와 사용자 의도 모호성은 구분합니다. 후속 사용자 답변은 첫 응답 평가에 입력하지 않습니다.

CQ1-16의 누락된 최신월 근거는 평가 시작 전 공식 KOSIS API로 보완했습니다. 원본 스냅샷 최신월은 202608, 이번 live 사전 확인은 202609입니다. CQ1-17/20 계산 참고값은 공급된 원자료에서 독립 계산했으며 실행 모델에 전달하지 않았습니다.
