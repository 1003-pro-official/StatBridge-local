# v1.1 질의 유형 분류 정확도 20문항

2026-10-27 · ai-assisted · 공개 개발 평가셋 · 정답 라벨 사람 검토 대기 · 평가 미실행 · 노션 복사용 3열 표

기존 [조회·역질문 40문항](질의와_정답_40문항.md)에 추가하는 독립 평가 항목이다. 일반 질문 10개, 파생지표 요청 10개로 구성하며 모든 문항의 난이도는 **기본(easy)**이다. 기존 40문항의 질의·정답·관측 결과는 그대로 유지한다.

## 분류와 채점 기준

- **일반 질문 (`general`)**: 이미 제공되는 통계값·계열을 조회하거나 표·그래프로 표시하는 요청. 이 평가에서 일반 질문은 통계 조회를 뜻하며 일상 대화나 개념 설명은 다루지 않는다. 지표 자체가 지수·금리이거나 실질·계절조정 계열이어도 제공된 값을 조회하면 일반 질문이다.
- **파생지표 요청 (`derived`)**: 원자료에 새로운 연산을 적용해 차이·합계·비율·평균·증감률 등의 값을 만드는 요청. 계산 결과를 표로 달라는 표현도 파생지표 요청이다.
- 문항별 **관측 분류가 정답과 같으면 통과(1), 다르면 미통과(0)**. 부분 점수는 없다. 정답 열의 근거는 검토용이며 근거 문구의 일치 여부는 채점하지 않는다.
- 실행했지만 유형을 하나로 결정하지 못하거나 유효한 분류를 반환하지 않으면 미통과(0)로 기록하고 `분류 누락`, `복수 라벨`, `실행 오류` 등 사유를 함께 남긴다. 실행하지 않은 문항은 `미실행`으로 구분하고 통과로 간주하지 않는다.
- 20문항을 모두 실행한 뒤 **질의 유형 분류 정확도 = 통과 수 / 20 × 100**으로 산출한다. 일반 질문과 파생지표 요청도 각각 통과 수 / 10으로 보고한다. 미실행 문항이 있으면 최종 정확도를 확정하지 않고 실행 수와 미실행 수를 기록한다.
- 통계표 선택, 원자료 확보, 계산 수치, 역질문, 그래프 품질은 이 항목의 채점 대상이 아니다. 분류가 관측된 이후의 API·계산 오류는 해당 분류 점수를 바꾸지 않는다. 다른 평가 항목과 합산한 점수를 분류 정확도로 제시하지 않는다.

## 실행 방법

각 문항은 이전 대화·선택 상태가 없는 새 세션에서 독립 실행한다. 평가 대상에는 문항 ID와 질의만 전달하며, 정답·아래 근거·문항 배열에서 추측한 유형을 입력하지 않는다. 실제 실행 순서는 섞고 ID로 결과를 연결한다.

분류기 단독 평가에서는 `general` 또는 `derived` 중 하나를 예측하도록 한다. 현재 제품의 로컬 분기 확인 지점은 `src/agent/derived_indicator_planner.py`의 `is_derived_request(query)`이며 `False`는 `general`, `True`는 `derived`에 대응한다. 이 함수만 실행한 결과는 로컬 분기 평가로 명시하고 모델 또는 UI 전체 성능으로 부르지 않는다. UI 평가에서는 실제 분기 기록을 관측하며, 그래프 출력 여부나 최종 답변 문구만으로 분류를 추정하지 않는다.

결과 기록은 `id`, `predicted_label`, `판정`, `사유`, `실행 방식`을 포함하고 별도 실행 기록 경로에 보관한다. 이 파일은 정답 초안이며 실제 예측·통과 결과를 포함하지 않는다.

## v1.1과 향후 v2.1의 난이도 경계

v1.1은 단일 턴, 명시된 지표·기간·기준, 직접적인 조회 또는 계산 표현으로 제한한다. 같은 주제의 조회와 계산을 짝지어 지표 이름만으로 유형을 외우지 못하게 하되, 정답을 결정하기 위해 전문 산식 추론이나 이전 대화 복원이 필요하지 않게 한다. 기간 평균·증감률 같은 계산의 구현 난이도가 아니라 **질의에서 계산 의도를 식별하는 난이도**를 기본으로 설정했다.

향후 v2.1 고난도 문항에는 아래 요소를 별도 구성한다. 이번 20문항에 포함하거나 v2.1 문항을 미리 작성하지 않는다.

- 계산 동사 없이 간접적으로 표현된 파생 요청과 다단계·복합 의도.
- 공식 지표명에 포함된 증가율·합계·비중과 새 계산 요구의 미묘한 구분.
- 부정·인용·정정 표현, 계산 용어가 포함된 제목 변경 같은 시각 편집.
- 앞선 대화의 계열·기준을 생략한 후속 질문과 기준 변경.

v2.1에서도 정답이 하나로 합의되는 문항만 채택한다. 단순히 정보가 부족해 정답을 정할 수 없는 질문을 고난도로 간주하지 않는다. 두 버전의 정확도는 난이도별로 따로 보고한다.
