총 60문항이다. 새 분류 항목은 기본 난이도의 일반 질문 10개와 파생지표 요청 10개로 구성한다. 유형 일치는 통과(1), 불일치는 미통과(0)이며 세부 기준과 향후 v2.1 고난도와의 경계는 해당 문서에 정의한다.

`FULL_UI_REPORT.md`의 기존 40문항 관측은 신규 분류 20문항의 결과를 포함하지 않는다. 평가 항목별 점수를 따로 보고하며, 분류 정확도의 분모는 20이다. 새 문항의 정답은 제품 실행 결과에 맞춰 변경하지 않는다. 사람 검토 전 라벨과 공개 개발셋 결과는 공식 또는 블라인드 성능으로 주장하지 않는다.
