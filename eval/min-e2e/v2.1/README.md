# min-e2e v2.1 고난도 평가셋

2026-10-27 · ai-assisted · 공개 개발용 · 사람 검토 대기 · 평가 미실행

v1.1의 60문항을 각각 한 문항씩 다시 작성했다. 지표·기간·핵심 정답과 채점 목적을 유지하면서 자연어 표현과 조건 해석의 부담을 높였다. 각 문항은 새 세션에서 질문 하나로 실행한다. 실제 이전 대화나 숨겨진 선택 상태를 요구하지 않는다.

| 항목 | 문항 | 정답 구성 |
|---|---:|---|
| 데이터 조회 정확도 | DA21-01~20 | v1.1 DA3-01~20과 동일한 계열·기간·수치 정답 |
| 역질문 적절성 | CQ21-01~20 | 필요 10개·불필요 10개; v1.1 CQ1-01~20 대응 |
| 질의 유형 분류 정확도 | QT21-01~20 | 일반 10개·파생 10개; v1.1 QT1-01~20 대응 |
| 합계 | 60 | 모든 문항 설계 난이도 hard |

## 파일과 입력 분리

- [질의와 정답 60문항](질의와_정답_60문항.md): 읽기·검토용 3열 표와 1:1 대응·난이도 근거.
- [cases.jsonl](cases.jsonl): 채점자용 정본. 질의·정답·원본 ID·난이도 요소·근거 구절·검토 상태를 포함한다.
- [questions.jsonl](questions.jsonl): 실행용 60문항. `id`, `query`만 포함하며 고정 seed 20261027로 순서를 섞었다. 이는 같은 공개 문항의 입력 사본이며 별도 holdout이 아니다.
- [manifest.json](manifest.json): 문항 수, 버전, 원본과 산출물의 SHA-256, 검토·실행 상태.
- [scripts/validate.py](scripts/validate.py): 문항 수·비율·대응·입력 분리·문서 일치·해시 검증기.

실행 대상에는 `query` 문자열만 전달한다. `id`는 실행기가 결과 연결에 사용한다. 정답 파일, 원본 대응, 난이도 태그, 문항 간 비교 정보는 입력하지 않는다. 예측을 저장하고 해시를 확정한 뒤 별도 단계에서 채점한다. 예측·실행 로그·채점 결과는 Git 제외 경로 `evaluation_runs/`에 보관한다.

`cases.jsonl`의 공통 필드는 `id`, `baseline_id`, `category`, `difficulty`, `query`, `difficulty_factors`, `difficulty_rationale`, `expected`, `review`, `evaluation_status`다. `expected.answer`는 사람 채점 기준이며, 유형 분류에는 `label`, 역질문에는 `clarification_required`와 `required_slots`가 추가된다. `required_slots`는 아래 의미의 조건을 뜻하며 응답에 영문 키를 출력할 필요는 없다.

| required_slots | 확인해야 하는 조건 |
|---|---|
| loan_rate_basis | 신규취급액 / 잔액 |
| m2_balance_basis | 평잔 / 말잔 |
| m2_adjustment | 원계열 / 계절조정 |
| gdp_price_basis | 명목 / 실질 |
| gdp_adjustment | 실질 원계열 / 실질 계절조정 |
| currency_basis | 원화 / 달러 / 계약통화 |
| esi_series | 원계열 / 순환변동치 |
| start_month, end_month | 조회 시작월과 종료월 |
| change_comparison_basis | 전월 대비 / 전년 동월 대비 등 비교 기준 |
| annual_aggregation_method | 단순평균 / 연말값 등 대표값 집계 방식 |

## 난이도 기준

각 문항에 아래 요소 중 서로 다른 2개를 적용하고, 실제 해당 구절을 `difficulty_factors.evidence`에 기록했다. 두 요소가 다른 해석 과제를 만드는지 `difficulty_rationale`에서 설명한다.

| 코드 | 요소 | 요구하는 해석 |
|---|---|---|
| P | 일상어·우회 표현 | 평균잔액→평잔, 그달 새로 받은 대출→신규취급액 등의 연결 |
| D | 조건 통합·적용 범위 | 흩어진 조건, 공통 기본값과 개별 예외, 자료 확보 기간과 표시 기간의 구분 |
| N | 제외·정정·우선순위 | 부정된 연산·제외 계열·폐기 조건을 반영한 현재 요청 결정 |
| Q | 인용·참고 문맥 | 제목·메모·후보 목록의 단어와 실제 요청을 구분 |
| I | 간접 계산·연산 정의 | 계산 명칭 없이 비례·간격·가중치·중앙 위치 등으로 표현된 산출 의도 파악 |
| M | 메타데이터 판단 | 확정된 표의 메타데이터로 조건을 결정 |

길이·전문용어·태그 수만으로 난이도가 입증되지는 않는다. 현재 hard는 **설계상 분류**이며 실제 성능 차이는 미측정이다. 사람은 ① 핵심 정답 유지, ② 의미가 다른 두 해석 과제, ③ 현실적인 표현, ④ 정답의 명확성을 검토해야 한다. 조회·유형 분류 문항은 판단 정보를 제공하고 역질문 필요 문항은 의도한 조건만 남겨 둔다. 제품의 현재 정규식에 맞춰 정답을 바꾸거나 일부러 실패하는 표현만 골라내지 않는다.

## 채점 기준

### 데이터 조회 정확도

기관·표·항목·분류·주기·기간·단위·수치의 필수 조건을 모두 충족하면 통과(1), 하나라도 불충족하면 미통과(0)다. 요청하지 않은 다른 계열로 대체하거나 정정 전 기준을 사용하면 미통과다. v1.1과 같은 원자료 절대오차 0.000001을 적용하고 UI 반올림은 별도로 허용한다. 분기 코드 YYYY01~YYYY04는 1~4분기이며 연간 A/Y는 같은 주기다.

수치 정답 20개는 **v1.1 공개 문서의 스냅샷 정답을 그대로 계승**했다. 원자료를 새로 수집하거나 관측값을 생성하지 않았다. 실제 API 실행에서 공식 개정치가 확인되면 그 근거를 별도로 남기고 제품 오류와 구분한다. v1.1과 v2.1의 난이도 영향을 비교할 때는 같은 원자료 버전·실행 조건을 사용한다.

### 역질문 적절성

첫 응답만 평가한다. 필요 문항은 `required_slots`의 미확정 조건을 의미상 모두 확인하고, 확정된 조건을 다시 요구하거나 사용자 답변 전에 미확정 계열로 최종 결과를 내지 않아야 통과다. 불필요 문항은 명시된 조건·기본값·예외 또는 지정 표의 메타데이터로 진행하고 불필요한 확인을 필수 진행 조건으로 요구하지 않아야 통과다. 원본 참고 응답과 문장 표현이 같을 필요는 없다.

CQ21-16은 v1.1의 과거 실행 종료월을 고정하지 않고 **실행 시 경제심리지수 원계열의 실제 최신 관측월**을 확인한다. 이 정책 차이는 원본의 최신월 선택 의도를 유지하기 위한 것이다. CQ21-17/20의 수치와 출력 위치는 v1.1에서 계승한 참고 정보다. 이 항목의 점수는 역질문의 적절성만으로 판단한다. API 장애·메타데이터 준비 대기를 사용자 의도의 모호성으로 처리하지 않는다.

### 질의 유형 분류 정확도

`general`은 제공된 통계값의 조회·표시, `derived`는 원자료에 새 연산을 적용한 값의 산출 요청이다. 지표명·제목·부정문 속 계산 단어를 실제 연산 지시와 구분한다. 정답 `label`과 일치하면 통과(1), 다르면 미통과(0)다. 부분 점수는 없으며 이유 문구의 일치는 요구하지 않는다.

실행했으나 분류가 누락되거나 복수 라벨·실행 오류로 하나의 유형을 결정하지 못하면 미통과로 사유를 기록한다. 분류 이후의 자료 확보·계산 오류는 분류 점수를 바꾸지 않는다. `is_derived_request()`만 실행했다면 로컬 분기 평가로, 실제 UI를 실행했다면 UI에서 관측한 분기 평가로 표시한다. 두 방식을 섞어서 같은 성능으로 제시하지 않는다.

각 항목의 정확도는 통과 수 / 20이며, 역질문 필요/불필요와 일반/파생도 각각 통과 수 / 10을 보고한다. 미실행은 통과로 처리하지 않고 별도 집계하며 항목별 20개 실행을 마친 뒤 최종 정확도를 확정한다. 세 항목의 점수를 각각 보고한다. 이 공개 개발셋과 다른 평가 계열의 버전·점수는 합치지 않는다.

## 검증과 실행 상태

저장소 루트에서 Windows 명령:

```powershell
.\.venv\Scripts\python.exe -X utf8 eval/min-e2e/v2.1/scripts/validate.py
.\.venv\Scripts\python.exe -m pytest -q tests/test_min_e2e_v21_dataset.py
```

검증기는 분류기·API를 실행하지 않는다. 문항의 실제 성능 평가와 사람 정답 검토는 아직 진행하지 않았다. v1.1 실행 이력과도 구분한다. 문항이나 정답을 수정하면 검증기·문서·질문 전용 사본을 함께 확인하고 `manifest.json`의 해당 해시를 갱신한다.
