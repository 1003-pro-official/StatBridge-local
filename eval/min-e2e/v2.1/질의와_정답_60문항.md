v1.1의 60문항과 1:1 대응한다. 조회 20개, 역질문 20개(필요/불필요 10:10), 질의 유형 분류 20개(일반/파생 10:10)이며 모두 독립된 단일 턴이다. 난이도는 설계상 hard이며 성능 저하로 검증한 등급은 아니다.

실행 대상에는 [질문 전용 파일](questions.jsonl)의 query만 전달한다. 이 문서와 [정답·설계 원본](cases.jsonl)은 채점자용이다. 세부 채점 기준과 수치·최신월 취급은 [README](README.md)를 따른다.

데이터 조회의 수치 정답은 기존 v1.1 공개 스냅샷을 그대로 계승했다. 새 API 관측값이 아니다. 역질문 계산 참고값도 기존 참고값이며, CQ21-16의 최신월은 실행 시 해당 계열에서 확인한다.
