# 민 담당 E2E 추가 골드셋 v2 · 난이도 상향 60문항

2026-10-27 · ai-assisted · 공개 개발 평가셋 · 사람 정답 승인 대기.

v1을 대체하지 않는 신규 60문항이다. ID는 v1과 겹치지 않게 E21~E40, F21~F40, D21~D40으로 부여했다. 지표별 20문항이며 각 행의 모든 단계를 수행해야 한 문항이다. 난이도 상승은 복합 조건·후속 정정·여러 revision·연산 순서·달력 이력 확보에 둔다. 완전히 새로운 기능 지원 여부를 평가하지 않는다.

## 기준 데이터와 시작 방법

A=예금은행 저축성수신(금융채 제외) 신규취급액 금리. B=예금은행 가계대출 신규취급액 금리. 월간, 연리%. 아래는 v1에서 보존한 고정 API 응답 fixture의 평가값이며 오늘 실시간 API 재수집 값이 아니다.

기관301. A=DT_121Y002, B=DT_121Y006. 정확한 item_id와 objL 분류는 함께 제공한 cases.json의 sources를 적용한다. 두 입력은 신규취급액이며 잔액 기준으로 바꾸지 않는다.

편집·파일 문항은 각각 독립 세션에서 다음 기준 그래프를 실제 조회·출력·UI 설정으로 만든다: 1~6월 두 계열 모두 선·실선·두께2, A=#2563EB, B=#F97316, 제목 ‘2025년 상반기 금리 비교’·크기20, 범례 위, 출처 ‘자료: KOSIS · DT_121Y002, DT_121Y006’. 최초 상태 복원은 이 기준 그래프의 최초 생성 스냅샷을 뜻한다. 준비 실패를 제외하고 쉬운 상태로 대체하지 않는다.

파생 문항은 독립적인 새 질의에서 시작하며 A/B의 정의를 질의 안에 포함했다. 기초값은 API 응답 공급 경계에서만 고정하고 실제 사용자 질의→local1 경로는 그대로 평가한다. 생성된 정답 계획(plan)이나 기대 결과를 에이전트 프롬프트·API에 주입하지 않는다. cases.json은 채점자 전용이다. 별도 입력은 questions.jsonl을 사용한다.

실시간 API 평가를 선택하면 공표값 수정 여부를 먼저 확인하고, 실행 전에 새로운 근거 스냅샷과 수치 정답을 확정해야 한다. 이 파일의 고정 수치와 무조건 비교하거나 실행 뒤 정답을 바꾸면 안 된다. API 호출 실패·자료 결측·계열 선택 오류는 각각 기록하고 대체 자료로 통과시키지 않는다.

## 공통 판정 규칙

- 각 단계가 끝난 뒤 관측한다. 최종 상태만 우연히 같으면 통과시키지 않는다. 요청하지 않은 계열·원자료·단위·스타일·기간은 직전 정상 상태를 유지한다.
- ‘[UI]’와 ‘[UI 표시]’는 실제 버튼·선택·저장·다운로드 조작이다. 채팅으로 대신 실행하지 않는다. mark 표시는 지정한 구간을 선택해 각 설명 입력란에 해당 지시를 넣는다. 실행 순서는 ①→②→…이다.
- 각 단계의 처리 완료를 기다린 뒤 다음 요청을 보낸다. 저장·재개 문항은 같은 계정·동일한 백엔드 실행을 유지한 채 저장 목록에서 다시 여는 범위다. 서버 재시작 후의 이력 복구는 평가 대상이 아니다. 표 선택은 그래프의 범례 클릭이나 숨김과 별개인 표 표시 계열 UI를 사용한다.
- 문항별 검증 대상은 지표 열의 행동이다. E는 응답 해석과 편집 적용/이력, F는 실제 파일 다운로드 및 다운로드 당시 revision의 화면과 파일 일치, D는 선택한 입력·연산 순서·출력 월·숫자·단위를 본다.
- 구간의 시작·끝은 포함한다. 점 편집과 구간 편집을 혼동하지 않는다. 색상 HEX는 대소문자만 무시한다. 파일은 내려받은 바이트가 비어 있지 않고 실제 형식으로 디코딩되어야 한다.
- PNG/PDF/SVG는 제목·축·범례·출처·계열·기간·스타일·기준선·메모의 의미상 일치를 요구한다. 픽셀 완전 일치는 요구하지 않는다. 잘림·읽기 어려운 겹침은 실패다. 메모 좌표 허용오차는 정규화 좌표 각 축0.03, 화면과 파일은 같은 기준을 적용한다.
- CSV는 long/wide 모두 허용하되 월·계열로 정규화한다. XLSX는 화면 표 순서와 숫자 셀을 확인한다. 색상·선 패턴을 CSV에 요구하지 않는다. 숨긴 그래프 계열이 데이터 파일에서도 제외된다고 가정하지 않고, F의 계열 제외는 명시적 표 선택으로만 평가한다.
- 수치 절대오차 0.000001, 상대오차0. 화면 반올림은2~6자리 허용하되 차트 데이터·파일 원본은 위 수치 오차를 따른다. 표의 정답은9자리로 표시하고 cases.json은 고정밀 원값을 보존한다. 중간 반올림·보간·0 대체 금지.
- 월별 단순평균은 공표 금리의 산술 계산이다. 거래금액 가중금리나 공식 분기/연간 금리라고 해석하지 않는다. 금리차는%p, 재지수화는지수(기준=100), 두 지수 차이는포인트, B/A는배, 상대 증감률은%이다.
- 미실행·환경 차단·정답 판정 불가를 성공에 포함하지 않는다. 아래 검증은 정답/지원 범위의 준비 검증이며 60문항 실제 UI 성공률이 아니다. 전체 UI 실행은 아직 하지 않았다.
