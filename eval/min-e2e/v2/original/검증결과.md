# v2 평가셋 준비 검증 결과

검증일: 2026-10-27. 대상: 현재 `StatBridge-local1`. AI-assisted, 공개 개발 평가셋, 사람의 최종 정답 승인 대기.

## 판단

**local1의 기존 기능 범위에서 실행할 수 있도록 구성한 신규 60문항이다.** 편집 요구 정합성 20개(E21~E40), 화면/파일 정합성 20개(F21~F40), 파생지표 20개(D21~D40)로 나눈다. v1의 기존 문항 60개는 변경하지 않았다. 노션용 본문은 각 문항을 `지표 | 질의 | 정답` 한 행으로 제공한다.

단, ‘소화할 수 있다’는 지원 기능·연산·입력 자료가 존재하고 정답이 정의된다는 뜻이다. 새 복합 질의를 편집 모델이 항상 정확히 처리한다는 보증은 아니다. 이 파일은 60/60 UI 통과 보고서가 아니다. 새 문항의 실제 UI 평가와 실패 패치는 아직 수행하지 않았다.

## 계산 정답을 명확히 한 사례

- D32: 월별 B/A를 세 개 구한 다음 평균한다. D33: B 세 값의 평균을 A 세 값의 평균으로 나눈다. 같은 계산으로 취급하면 실패다.
- D35: A와B를 각각2월=100으로 만든 뒤 A지수에서 B지수를 뺀다. 단위는%p가 아니라 포인트다.
- D37: B−A 금리차를 기준=100 지수로 바꾼 후 그 지수의 전월 상대 증감률을 구한다. 결과는%다. 금리차 자체의 전월차(%p)와 다르다.
- D39: 6월 결과1개는 `(1.64+1.62+1.66)/3=1.64 %p`. 1~6월 전체 금리차 평균1.62와 다르다.
- D40: 1~6월 월별 비율의 평균은 `1.582137215… 배`. 대출 평균/수신 평균으로 대체하면 안 된다.

## 평가 실행 조건

1. **고정 API 응답 재생 모드**를 기본으로 사용한다. v1에서 사용한12개 원금리와 같은 계열 식별자를 공급 경계에서 제공한다. 실제 사용자 질의와 UI 조작은 그대로 실행한다. 이는 새로운 실시간 공표값 검증이 아니다.
2. 편집·파일 문항은 각각 독립된 기준 그래프에서 시작한다. 준비 실패도 해당 문항의 실패/차단으로 기록한다. 대명사는 동일 문항 안에서만 문맥을 이어간다.
3. 저장·재개는 같은 계정·동일한 백엔드 실행을 유지한 상태에서만 평가한다. 서버 재시작 후 최초 스냅샷이나 이력 복구를 요구하지 않는다.
4. D의 표시 기간을 입력 이력과 분리한다. 6월만 출력하더라도 이동평균에 필요한4~5월 또는1~5월을 조회해야 한다. 보간·0 대체·월 누락 압축 금지.
5. 고정값 대신 실시간 KOSIS API로 평가하려면 실행 전에 응답을 수집해 자료 개정 여부를 확인하고 새로운 정답 스냅샷을 확정한다. 사후에 결과를 보고 정답을 바꾸지 않는다.
6. 실제 평가에는 `questions.jsonl`만 입력하고 `cases.json`은 채점 측에 둔다. 이 폴더에 별도 브라우저 실행기는 포함하지 않았다. 현재 `verify.py`는 오프라인 준비 검사다.

## 파일 사용법

- `질의와_정답_60문항.md`: 노션에 붙여 넣을3열 표와 공통 시작 상태·판정 규칙.
- `questions.jsonl`: 정답 없는60개 입력. UI 단계는 문자열 안에 순서대로 명시되어 있다.
- `cases.json`: 채점자용 정답, 원자료12개, 정확한 원자료 식별자, 파생 계획·고정밀 숫자·단위·이력 범위. 제품 입력용이 아니다.
- `verify.py`: 현재 local1에서 문항 구조·입력 분리·카탈로그·질의 분기·기간·20개 계산 결과를 재검사한다.

local1 루트 PowerShell에서:

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:PYTHONDONTWRITEBYTECODE='1'
.\.venv\Scripts\python.exe eval/min-e2e/v2/verify.py
```

검사 결과는 `status=PASS`, `cases=60`, `catalog_plan_period_route_numeric_verified=20`, `ui_e2e_executed=false`, `human_review=pending`이다.

v2만 추가했다. 제품 코드·기존 v1/v1.1·개인 설정·저장 분석·StatBridge1은 이번 생성 작업에서 수정하지 않았다.
