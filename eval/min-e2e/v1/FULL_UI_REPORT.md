파일은 PNG 14건, PDF 1건, SVG 1건, CSV 3건, XLSX 1건입니다. CSV/XLSX는 날짜·계열·값을 독립적으로 읽어 정답과 비교했고 XLSX 값의 숫자 셀 여부도 확인했습니다. PDF/SVG는 별도 도구로 다시 렌더링했습니다.

E12/E13은 요청을 임의로 해석해 편집하는 대신 필요한 대상을 질문해야 통과합니다. D20도 제외 문항이 아닙니다. 평가 공급 응답에서 202503 한 행을 제거한 조건에서 부족 월을 화면에 명시하고, 계산값·그래프를 생성하지 않아야 통과합니다.

## 실제 UI 실행 방식

- 최종 코호트는 `release-final`입니다. 편집·파일·파생 각 20문항을 동일 빌드의 별도 서버/DB에서 병렬 실행했습니다. 각 문항은 새 Chrome 컨텍스트에서 로그인부터 시작합니다.
- UI 실행기는 분리한 `inputs.jsonl`만 읽습니다. 정답 명령·정답 DAG·기대 상태를 모델이나 화면에 주입하지 않습니다. 채점기가 관측 후 정답을 읽습니다.
- 실제 화면의 분석하기·편집 전송·대상/시점 선택·그림 표시·되돌리기·표 선택·분석 저장/재열기·다운로드 버튼을 사용했습니다. 앱 상태 이벤트나 API 편집 요청으로 UI 단계를 대체하지 않았습니다.
- 서버 시작 시 주입한 편집 세션은 0개입니다. 계정·보완 자료·근거·저장 파일은 평가 전용 경로를 사용했습니다.
- 실제 모델은 `gpt-6.1-sol`입니다. 원자료 공급 경계는 공개 KOSIS 응답의 고정 재생이며, **60문항 전체 실시간 KOSIS 평가를 의미하지 않습니다.** 이전 별도 원자료 IO 검증과도 구분합니다.
- 최신 세 서버의 소스 해시가 동일하고 실행 중 변경되지 않았음을 확인했습니다. 런타임·입력·프런트엔드 산출물 해시를 저장했습니다.

그래프 패널은 스크롤 영역입니다. 캡처가 화면 밖 제목/출처 일부를 담지 못한 경우에는 전체 DOM 텍스트·범례 위치·실제 Plotly trace와 다운로드 문서를 함께 검수했습니다. CSS 화면 크기와 파일 픽셀 크기의 동일성은 요구하지 않고 명세의 의미 일치 기준을 적용했습니다.

## 발견한 실패와 제품 패치

| 관측 | 원인 | 수정 |
|---|---|---|
| E04·E07·E19: 서로 다른 계열/표시가 같은 색으로 편집됨 | UI가 명시 색들을 하나의 가상 `차트` 색 선택으로 합쳐 원래 지시보다 우선시함 | 실제 색상표를 사용한 경우에만 최종 색상 덮어쓰기 안내를 전송. 명시 색은 원래 문장과 표시별 맥락을 보존 |
| E14: 범례를 다시 보여 달라는 요청에서 위치만 바뀜 | 위치와 표시 여부가 별도 필드인데 모델이 위치 명령만 반환 | 명확한 재표시+위치 요청은 두 상태를 모두 반영. 위치만 변경하거나 숨김 유지 요청에는 임의로 표시하지 않음 |
| F13·F14: PDF/SVG에 기본 X축 제목 누락 | 화면의 기본 `시점` 제목을 인쇄 렌더러가 적용하지 않음 | 시계열 문서에도 기본 축 제목 적용. 명시 축 제목과 비시계열 축 의미는 보존 |
| D18: 실제 UI에서 분석 대기 종료 | 기호 뺄셈 질의가 일반 조회의 20초 분류에 남았고 계산은 약 20.6초에 완료됨 | 기호 산식·명시 계산·산술평균을 기존 파생 120초 예산에 연결. 20문항의 21개 질의를 전수 대조해 유사 표현 6문항도 보완. 일반 조회의 기존 20초는 유지하고 단순 스타일 질의를 파생 계산으로 확장하지 않음 |
| 전체 회귀가 첨부 오류 응답 검사 종료에서 정체 | 종료된 Langfuse 클라이언트를 재사용해 이미 멈춘 소비자 큐의 flush를 다시 대기 | 종료 전에 클라이언트를 원자적으로 분리하고 중복 종료를 안전하게 처리 |

UI 사전 점검에서는 그림 표시가 없을 때도 대상·시점을 직접 선택할 수 있게 했고, 여러 그림 표시마다 설명을 입력할 수 있게 보완했습니다. 평가 실행기의 버튼 접근성 이름·표 속성 패널 열기·서버 준비 대기도 수정했습니다. 실행기 문제를 제품 실패로 합산하지 않았습니다.

핵심 변경 파일은 `Sujeongi.tsx`, `ChartSketchEditor.tsx`, `derivedDeadline.ts`, `chart_edit_agent.py`, `chart_edit_intents.py`, `report_export.py`, `statbridge_mcp/observability.py`입니다. 회귀에는 실제 TypeScript 대기 분류, 불완전한 범례 모델 계획, 실제 PDF/SVG 문서 텍스트, 종료된 exporter 재사용 방지 검사를 추가했습니다.
