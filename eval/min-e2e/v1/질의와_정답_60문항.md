## 모든 문항의 판정 규칙

- 요청하지 않은 데이터·스타일·단위·출처는 직전 정상 상태와 같아야 합니다. expected_delta는 변경할 부분만 나타냅니다. 목록형 정답은 전체 기대 목록입니다.
- 별칭 a/b는 위 실제 계열에 연결합니다. 부분 구간의 시작·끝은 양 끝을 포함합니다. 선택 밖 선·점은 유지합니다.
- 요청 누락·범위 밖 변경·설명만 변경은 실패입니다. 확인 질문 문항은 구체적 필요 정보를 묻고 차트와 revision을 유지해야 합니다.
- 수치 절대오차 0.000001, 상대오차 0. 날짜 집합·계열·단위는 정확해야 합니다. 중간 반올림·0 대체·보간은 금지합니다.
- 화면 표시는 소수점 2~6자리 반올림 허용. 다운로드 원본 수치는 수치 허용오차 적용.
- 파일은 같은 revision의 화면과 비교합니다. PNG/PDF/SVG는 의미·스타일·배치를 비교하며 픽셀 완전 일치는 요구하지 않습니다. 제목·축·범례·출처의 잘림과 읽을 수 없는 겹침은 실패입니다.
- CSV는 long/wide 모두 허용하고 월·계열로 정규화합니다. XLSX는 표시 순서와 숫자 셀을 검사합니다. 색상은 CSV/XLSX의 공통 판정 항목이 아닙니다.
- UI action은 버튼·선택 동작입니다. 이를 편집 모델 질의로 대체하지 않습니다. 자연어 편집은 실제 모델 또는 제품의 규칙 경로로 실행하고 경로를 기록합니다.
- 모든 필수 조건을 만족해야 문항 성공입니다. 미실행·미검수·관측 불가·환경 차단은 성공에 포함하지 않습니다.

세부 사전 상태·좌표·파일 기준은 아래 표와 문항별 상세 명세를 함께 적용합니다. 실행 결과와 검증 범위는 FULL_UI_REPORT.md에 기록되어 있습니다.

## 노션 붙여넣기용 · 지표 / 질의 / 정답

지표 열에는 평가 영역과 해당 질의로 확인하는 행동을 함께 적었습니다. 각 행이 한 문항이며, 화살표로 연결한 단계는 같은 세션에서 차례대로 수행합니다. `[ui_...]` 및 UI 선택·저장·다운로드·되돌리기는 채팅 질의가 아닌 실제 UI 조작입니다.

공통 전제: A는 위 수신금리, B는 위 대출금리이며 A1~A6/B1~B6는 각각 2025년 1~6월 공표값입니다. 모든 편집·파일 문항은 위 기준 그래프에서 독립적으로 시작합니다. 정답에 적지 않은 상태는 유지해야 합니다. 파생지표는 명시한 결과 월과 단위가 정확해야 하며 절대오차 0.000001을 적용합니다. 파일 문항은 실제 다운로드·디코딩 성공 및 같은 revision의 화면과 파일 일치를 모두 요구합니다. PNG/PDF/SVG는 제목·축·범례·출처와 스타일의 의미상 일치 및 잘림·읽기 어려운 겹침 없음을 확인하며, CSV/XLSX는 색상이 아닌 날짜·계열·수치·단위를 비교합니다.
