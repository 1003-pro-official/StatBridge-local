## 정성평가에서 확인한 주요 사항

- Q05·Q06: 최초 실행에는 표·그래프가 없었습니다. 수정 후 각각 48개월·10년의 원자료와 계산 결과를 출력했습니다.
- Q04: 공통 y축에서 서울·부산의 규모 차이 때문에 부산 추이를 읽기 어렵다는 관찰이 그래프 2점의 근거입니다.
- Q10: 초기 화면에는 아래 패널이 모두 보이지 않지만, 내부 스크롤로 증가율 패널·축·기간·출처를 확인했습니다. 생성 누락이나 영구 잘림으로 판정하지 않습니다.
- 계산 근거의 내부 별칭·코드형 식, 복수 기준연도·단위 표기와 근거 위치 분산이 남은 개선 사항입니다.
- 표 하단 출처 줄, 선택 열, 권장 0 기준선의 부재 자체는 감점 조건으로 적용하지 않았습니다.

## 정확성 검증 범위

- 최초 실행에서 출력된 8문항: 필수 표·그래프 값 1,620개를 동결 참고값 및 독립 산식 재계산과 비교해 일치했습니다.
- 수정 후 Q05·Q06: 표·그래프 값 174개를 별도로 비교해 일치했습니다.
- 비교 수는 표와 그래프의 중복 표현을 포함하며 고유 질문 수나 독립 표본 수를 뜻하지 않습니다.
- 계열·분류·기간·주기·단위·선행 입력을 확인했습니다. 그래프 축 단위 자동 검사는 v2 검증 코드에 추가됐습니다.
- 허용 오차는 값 자체 단위에서 abs(actual - expected) <= 1e-6 + 1e-10입니다.
- 2026-10-27 동결 참고 원자료와 11월 2일 제품이 받은 원자료를 대조했습니다. 별도 공식 API 재조회 검증은 수행하지 않았습니다.
- 화면의 반올림 표시값과 화면에 보이지 않은 요약문 수치는 정확성 검증 범위에서 제외했습니다.
