## v3에서 확정한 사항
1. **선택 열:** Q08 '전월 차이', Q09 '전년 동월 값', Q10 '전년 동기 값'은 선택 사항이며 없어도 감점하지 않습니다.
   - 같은 조건에 있던 원자료·계산 결과·단위는 필수로 분리했습니다: Q08 C6a, Q09 C5a, Q10 C5a.
   - Q05~Q07의 비교시점 값 열도 같은 근거로 선택(C5b)으로 표시했습니다. answers.md가 "같은 표 또는 계산 근거"로 규정하고, score_v2.py에서도 필수 열이 아니기 때문입니다. 비교시점 값을 확인할 수 있는지는 필수(C5c)로 남겨 '근거 확인의 용이성'에서 평가합니다.
2. **기대 형태와 관측 형태:** case-index.json의 행 수·계열 수는 `observed_shape`로 옮겨 실행 연결 파일에만 둡니다.
   - 기대 기간·계열은 질문 원문에서 달력 계산으로 따로 도출했습니다. 도출 결과 시점 수는 48·24·48·48·48·10·60·60·60·48이며, 참고 표 행 수와 일치합니다.
   - 정확성 A2는 필수 계열마다 누락·중복·표시 기간 밖 시점·순서를 확인합니다. 총 행 수는 기록만 합니다.
3. **실행 분리:** 실행 정보·증거 경로·캡처 범위는 실행 연결에서만 가져옵니다. 관측 불가 사항은 해당 실행의 캡처 범위만 따릅니다.
4. **앞서 확정한 기준 유지:**
   - 출처는 모든 문항에서 근거 확인의 용이성으로 평가합니다. 명시 요청 문항(Q01·Q02·Q04·Q05·Q06·Q07)은 요구 반영도 확인합니다.
   - 0 기준선은 권장 사항입니다.
   - Q08 '기준 차이'는 두 금리의 구별과 조건 식별 여부로 판단합니다.
   - 정성평가와 정확성 검증은 분리합니다.
