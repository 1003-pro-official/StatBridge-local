최종 사람 승인 절차를 평가 통과 조건에서 제거했습니다. 사람 승인 여부를 조작하거나 일괄 승인한 것이 아닙니다. 규칙 충족은 PASS, 명백한 불일치는 FAIL, 자료 부족은 EVIDENCE_GAP으로 기록합니다. 기존 사람 검토자의 이미지 판정 18건은 증거로 유지합니다. CQ 의미 검토는 AI가 직접 수행하고 검토 주체·원시 응답 해시·이유를 기록했습니다.

CQ21-08: 기간 확인 질문 자체는 맞지만 실제 응답 observability에 statistics.execute completed가 있습니다. 이전 관측기에서 bool(output)만으로 실행 여부를 결정하여 놓쳤습니다. 이번에 실제 trace까지 확인하여 ‘답변 전 실행 금지’ 실패로 정정했습니다. 출력 그래프가 없다고 데이터 실행도 없었다고 판단하면 안 됩니다.

CQ21-16: 원계열 E1000만 202401~202609 표시, 가용 종료월 202609와 일치하고 현재월 202610을 채우지 않았습니다. 다만 원래 계약이 요구한 예측 전 독립 최신월 동결 기록은 없습니다. 그 과거 기록을 지금 만들어 채우지 않으며 최신성 부분만 증거 부족으로 둡니다. 다음 실행은 모델 호출 전에 선택 원계열의 공식 가용 종료월·유효 관측값·시각·해시를 따로 동결해야 합니다. 사람 승인 요청은 필요하지 않습니다.

CQ21-02/04/05: 일반적인 질문 문구만 보지 않고 선택지까지 함께 판정했습니다. 선택지에서 각각 평잔/말잔, 명목/실질, 원계열/계절조정 차이가 드러나므로 확인 대상은 적절합니다. ID 중복과 전문 용어는 사용성 개선 후보이며 곧바로 의미 오답으로 처리하지 않았습니다. 불필요한 조회 주기·기간 변경이 없고 실행 전 선택을 기다리는지 별도로 확인했습니다.

## D23 수치와 원문

| 월 | 원시 금리차 B−A (%p) | 당월·직전월 평균 (%p) |
|---|---:|---:|
| 2025-01 | 1.57 | 선행월 |
| 2025-02 | 1.55 | 1.56 |
| 2025-03 | 1.68 | 1.615 |
| 2025-04 | 1.64 | 1.66 |
| 2025-05 | 1.62 | 1.63 |
| 2025-06 | 1.66 | 1.64 |

실제 요약의 첫 문장: ‘금리차의 당월의 2025년 6월 관측값은 1.64 %p입니다.’ 표·제목·계산 계획은 2개월 평균이므로 이 요약 지표명이 잘못됐습니다. ‘Judge가 평균이라는 원문을 당월로 바꿨다’는 앞선 보고서 설명을 철회합니다. 실제 응답과 Judge 입력은 바이트 해시로 연결되고 원문도 동일함을 확인했습니다.

원래 Judge 8개 주장 중 5개는 잘못 명명한 당월 지표의 값/변화를 설명하므로 모순, 2개 추세는 지지, 1개 조회 시작은 표시 시작(2월)과 선행 조회 시작(1월)의 범위가 모호합니다. 조회 시작 한 문장을 fetch_start만으로 거짓 처리한 판단은 근거가 부족합니다. 원래 RAGAS 0.25와 평균 0.952586은 그대로 보존했습니다. 이번 직접 판정은 표준 RAGAS 재호출 결과나 새로운 Faithfulness 점수로 가장하지 않습니다.

제품 패치는 요약 지표명을 실제 output label에서 보존하고, 평균/당월/변화율을 임의 축약하지 않으며, 긴 부동소수점 표시를 정리하는 방향이어야 합니다. 정답을 당월 금리차로 바꾸는 것은 잘못된 패치입니다.
