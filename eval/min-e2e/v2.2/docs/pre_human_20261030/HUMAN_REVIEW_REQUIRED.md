# 사람 검토 필요 항목

보고서에서 사람 검토 대기인 10문항은 F21, F22, F23, F25, F28, F29, F33, F35, F36, F38이다. 이 10개에 PNG/PDF 14개가 있으며 실패 문항 F26/F27/F34/F37의 4개를 포함하면 총 18개다. 전체 파일의 사람 승인 원자료가 없어 모두 미승인으로 보존한다.

[나란히 비교 양식](human_review/side_by_side.html)과 [18개 파일 체크리스트](human_review/artifact_checklist.json)를 제공한다. 실제 파일·화면이 없어 오른쪽은 미수신 상태이며 비교 완료를 주장하지 않는다. 파일/화면 SHA-256, 동일 revision, 검토자, 승인 날짜, 일치/불일치, 근거를 입력해야 한다. AI 검토는 human 승인으로 인정하지 않는다. 하나의 파일에 확정 불일치가 있으면 다른 파일이 대기여도 문항 실패를 보존한다.

120개 gold의 원 승인도 보고서 주장만 있으며 서명 manifest가 없다. 04_정답_사람검토_120문항.md에서 이름·날짜·계약 해시를 확인한다. E40/F34의 바뀐 계약은 원 승인과 별도 승인해야 한다. 이는 실행 질문을 다시 쓰거나 점수를 높이기 위한 승인이 아니다.

3인 분담: 1인은 지표·단위·계산 의존성을, 1인은 화면·실제 파일을, 나머지 1인은 독립 교차 검토 및 불일치 조정을 맡는다. 본인이 작성한 변경 계약은 다른 사람이 승인한다. 검토 전에는 PASS를 부여하지 않는다.
