# 한국은행 간행물 기반 골든셋

2026-09-28 기준, [manifest.json](manifest.json)에 고정한 한국은행 간행물 6종의 최신 공개본 2개씩을 사용합니다. 범위는 통화신용정책보고서, 금융안정보고서, 경제전망보고서, 기업경영분석, 지급결제보고서, 지역경제보고서의 본문·표·그림과 공식 그림 데이터 첨부파일입니다. 간행물은 질문 소재이며, 정답 통계표 ID는 프로젝트의 로컬 카탈로그에서 별도로 확인합니다. 미래 전망치는 관측 수치의 정답으로 쓰지 않습니다.

## 구성

- 총 150개: 간행물 유래 135개, 범위 밖 요청 15개
- 질문 유형: 단일 표 30, 별칭 25, 조건 25, 유사 표 구분 20, 다중 지표 20, 역질문 15, 범위 밖 15
- 그래프 평가 30개: 고정 CSV에서 항목·분류 ID와 주기까지 선택한 관측값 fixture
- 개발 50개, 보류 평가 100개; 검색 정답 표 ID는 두 분할에 중복되지 않음
- 정답 통계표 ID 78개

새 사례는 공식 PDF의 주제어가 등장하는 쪽수를 `source.locator`에, PDF 주소와 SHA-256을 출처 기록에 남깁니다. 해당 쪽은 질문 주제의 근거이며 특정 통계표 ID를 보고서가 직접 지정했다는 뜻이 아닙니다. 기존 36개는 게시물의 장·주제 수준 위치를 사용합니다. 일부 사례의 질문 표현은 보고서 문구를 그대로 옮긴 것이 아니라 사용자의 자연어를 재구성한 것입니다.

## 평가

프로젝트 루트에서 실행합니다.

```bash
.venv/bin/python tools/evaluate_golden_set.py
PYTHONPATH=src/backend:src/agent .venv/bin/python -m pytest tests/test_golden_set.py tests/test_search_stack.py -q
```

검색은 필수 계열 그룹별 Recall@5, MRR, Top-1을 기록합니다. 역질문은 필요한 선택지가 실제 카탈로그 표로 제시됐는지, 범위 밖 요청은 결과가 비었는지 확인합니다. 그래프 30개는 네트워크 없이 명시적으로 로컬 저장본을 선택하여 같은 서버 분석 경로를 실행하고, 시점·값·단위·주기가 fixture와 정확히 일치하는지 비교합니다. 축 가독성 등 시각 항목은 수동 점검 대상입니다.

실제 UI는 KOSIS 조회를 기본으로 하고, 실패 시 로컬 저장본을 자동으로 섞지 않습니다. 고정 fixture 수치는 `data/tables/` 보유본에서 추출했으며, 각 파일의 SHA-256과 행별 변경일을 기록합니다.

**평가 해석:** 이번 구현에서는 100개 보류 평가 질문을 보면서 검색 규칙을 수정했습니다. 따라서 현재 100개 점수는 회고적 점수입니다. 출시용 블라인드 성능을 주장하려면 새 미공개 질문을 별도로 수집해 같은 기준으로 측정해야 합니다.
