## 준비한 내용

- 공개 스키마·검증기·채점기·실행기·검수 도구를 복사하고 파일별 해시를 고정하는 인계 도구.
- 질문·정답·fixture 수치·실패 결과 없이 공개 연구 결과물/원본 위치/계열-시점 중복 제외 목록.
- 지원 기능·API 순서·세션 연결·오프라인 한계를 명시한 feature-contract.json.
- 비공개 전용 ID/split 어댑터와 18건의 모드·세부 구성 검사.
- 근거·공급자 정합성, 독립 승인 역할, 승인 해시, 구현 노출 기록, 제품 버전 고정 검사.
- 승인 전 실행 금지, 승인 후 변경 차단, 결과 덮어쓰기 방지, 상세 정보 없는 집계 보고.
- 네 모드의 합성 데이터·가짜 API transport 실행과 실제 OutputAgent/채점기 검사.

실제 제품 응답이나 후보 holdout을 실행해 질문·정답을 선택하지 않았습니다.
초기화·제작·승인·평가 명령은 [holdout_support/README.md](holdout_support/README.md)에 있습니다.
