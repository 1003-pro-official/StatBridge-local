# UI 정합성 수정

ai-assisted. 사람 승인 0건. 2026-10-07 개정본입니다.

## 변경 이유

서비스에는 파일 업로드가 없습니다. 따라서 “첨부한 자료”를 사용자 입력으로 둔
사례는 제품의 공개 평가로 사용할 수 없었습니다. UI는 새 질문마다 이전 결과를
지우므로 이전 지표·기간을 자동 기억한다고 가정한 사례도 수정했습니다.

## 수정 범위

- SBV2-0055~0066: 지원 KOSIS 계열을 실제 조회한 뒤 그래프·수치·해석을 검사합니다.
- SBV2-0067~0072: 조회 → 실제 출력 → 실제 편집 API 순서로 실행합니다.
- SBV2-0022, 0023, 0032~0035: 이전 대화 없이 지표·기간·기준을 명시한 독립 질문입니다.
- 첫 질의 execute=True, 반환 세션 연결, 실제 편집 전후 원자료·조회 횟수 관측을 적용했습니다.
- 전년 대비 사례 0072는 2023~2024년 24개월 원자료로 2024년 12개월을 계산합니다.

공개 dev 30·test 42건과 네 모드의 건수는 유지했습니다. e2e 구성은 단일 24·복수 6으로
변경했습니다. 외부 첨부 6건 이상이라는 초안 목표는 미구현 기능을 가정하므로 철회했습니다.
이는 지원 기능 범위로 좁힌 평가이며 연구의 다양한 외부 자료까지 검증했다는 뜻이 아닙니다.
실제 채택 연구 결과물은 14개(통화신용정책 8·금융안정 2·경제전망 4)입니다.

## 이전 자료 보존

기존 첨부 18건은 internal/components/cases.jsonl과 해당 fixture·claims에 보존했습니다.
공개와 동일 ID를 쓰지만 별도 평가 계열입니다. 점수나 승인 결과를 합치지 않습니다.
수정 전 작업 파일은 로컬 results/before-ui-revision-20261007T063705078870Z/에 보존했습니다.
루트의 이전 첨부 registry·input fixture는 초판 재현용이며 현재 공개 입력에서 사용하지 않습니다.

같은 ID라도 내용이 달라졌으므로 이전 골든 승인·응답 해석 검수·관측은 재사용하지 않습니다.
입력 해시가 다르면 채점기가 거부합니다. 새 관측은 dev-ui/test-ui/pilot-ui로 구분합니다.
노트북은 새 전체 관측만 기본 표시하며 과거 HARDENING/VERIFICATION 기록은 당시 결과입니다.

## 남는 평가 경계

오프라인은 실제 앱 경로와 고정 수치 공급자를 사용합니다. 실서비스 KOSIS/NCP 호출과
브라우저 조작을 수행했다는 뜻이 아닙니다. 편집 명령 재생은 계산·렌더링을 검사하지만
자연어 편집 분류 성능은 검사하지 않습니다. 해석 자동 통과도 사람 검수가 없으면
pending_review입니다. 사람 승인이나 공식 평가 성공으로 기록하지 않습니다.

최신 관측·테스트 결과는 로컬 results/UI_REVISION_REPORT.md에서 확인합니다.
