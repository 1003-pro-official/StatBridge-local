# v2 설계와 제작 기준

## 무엇을 검증하는가

골든셋은 모범 문장 모음이 아니라 **입력, 관측 가능한 정답, 원본 근거**의 계약입니다.
프로그램에는 input만 전달합니다. expected/evidence/review는 검증·채점·사람 검수에만 사용합니다.
모드는 운송 경로를 결정하며 질문의 정답을 알려주지 않습니다.

discovery 24건은 선택 가능 12·역질문 8·미지원 4입니다.
e2e 30건은 단일 24·복수 6입니다. 이전 대화를 자동 유지하는 기능을 가정하지 않습니다.
output 12건은 실제 지원 계열의 조회 이후 그래프 종류·배치·수치·해석을 평가합니다.
혼합·외부 첨부 과제는 공개 제품 평가에서 제외하고 internal/components/에 보존합니다.
edit 6건은 제목 2·범례 1·기간 1·전기 대비 1·전년 대비 1입니다.

## 근거와 숫자

후보는 경제전망 1,016·금융안정 1,425·연차 394·지급결제 178·통화신용정책 1,014개입니다.
이는 연구 마스터의 결과물 수이며 고유 검증 원본 수가 아닙니다.
채택한 고유 연구 결과물은 통화신용정책 8·금융안정 2·경제전망 4개입니다.
보고서별 균등 분포로 위장하지 않습니다. 지급결제·연차는 이번 초판에 채택하지 않았습니다.

관계는 두 종류로 구분합니다.

1. attachment_subset: XLSX의 표시 데이터에서 선택한 행·열을 직접 추출합니다.
2. purpose_reconstruction: 원본 그림의 분석 주제에 관련된 지원 KOSIS 계열로 새 질문을 작성합니다.
   보고서의 증가율·전망·공급 부문 분해를 그대로 복제했다는 뜻이 아닙니다.

미지원 사례는 research에 해당 주제가 있어도 첨부 없이 한국은행 KOSIS만으로 조회하라는 요청입니다.
자동 추정된 분석 목적·차트 종류는 정답에 사용하지 않습니다.
PDF 페이지의 실제 주제를 확인하고, XLSX의 제목·출처·기간·단위를 원본에서 읽습니다.
출처에는 연구 ID, 파일 SHA-256, 그림/페이지 또는 시트/셀 범위, 추출 규칙이 있습니다.
공개 수치 정답은 별도로 해시를 기록한 KOSIS 로컬 export에서 추출합니다.
attachment_subset은 보존된 내부 테스트에만 사용합니다.

M2 로컬 export가 2004년 9월에서 끝나므로 dev는 2003년, test는 2004년 1~9월입니다.
그 밖의 조회 사례는 dev 2023년·test 2024년입니다. 기간을 늘리려면 새 원본을 독립 검증해야 합니다.
범위값인 '0.5~1.25'는 대표값으로 바꾸지 않고 제외했습니다.
빈 셀은 null로 보존합니다. 일·주·월·분기 주기를 구분하며 주간 자료를 월간으로 바꾸지 않습니다.

기본 수치 오차는 0.0000001, 계산 결과는 0.000001입니다.
이는 원본 표시 자릿수보다 엄격한 JSON 숫자 반올림 허용치이며 단위 변환 허용치가 아닙니다.
fixture에서 단위나 표시 자릿수를 바꿀 경우 사람 검수와 오차 재설정이 필요합니다.
같은 계열·시점, 중복 계열, 누락·추가 값, 결측 보간은 실패입니다.
증감률은 (현재/기준-1)*100, 전기 lag 1, 전년 lag 월 12·분기 4·연 1입니다.
0 분모와 결측은 null이며 주기가 끊긴 자료에 인접 관측치 기준 계산을 적용하지 않습니다.

## 분리와 정답 형식

동일 원본 그림 및 같은 계열·시점의 파생 사례는 연결 성분으로 묶어 한 split에만 둡니다.
외부 계열은 자료 ID 대신 의미상 계열명·단위·주기·기간도 비교합니다.
공개 dev/test는 회귀 진단용입니다. 공개 test 점수는 비공개 holdout 성능이 아닙니다.

acceptable_table_sets의 각 원소는 하나의 완전한 답안입니다.
예를 들어 [[A,B],[C]]는 A와 B를 모두 선택하거나 C를 선택해야 한다는 뜻입니다.
[A]나 [A,C]는 실패입니다. series_selection은 항목·분류·주기·단위까지 고정합니다.
공개 질문은 지표·기준·절대 기간이 완결된 독립 질문입니다. prior_turns는 비어 있습니다.
응답에서 받은 state/session ID만 재사용하고 정답으로 세션을 구성하지 않습니다.

## 실행 경로와 관측

오프라인 공개 네 모드는 실제 FastAPI TestClient와 실제 resolver/workflow를 사용합니다.
첫 요청은 UI와 동일하게 execute=True이며 응답에서 필요할 때만 기간 확인을 진행합니다.
외부 수치 공급자는 고정된 전역 registry를 실제 table/item/classification/frequency/period로 조회합니다.
사례 ID나 expected를 보고 답을 골라 반환하지 않습니다.
등록되지 않은 요청은 오류로 남깁니다. 잘못 고른 표에 정답 수치를 붙이지 않습니다.
NCP를 비활성화한 실제 클라이언트의 사전 기반 fallback을 사용하고 HTTP 외부 호출을 차단합니다.
따라서 HCX/JEV/벡터 검색 성능이나 실시간 KOSIS 연결을 측정한 결과가 아닙니다.

공개 output/edit는 조회에서 받은 세션으로 /api/output을 호출합니다.
edit는 실제 출력에서 발급된 세션으로 /api/output/edit를 호출합니다.
expected.data.source_fixture는 계산 검증용 원자료 정답이며 프로그램 입력으로 전달하지 않습니다.
보존된 내부 첨부 사례만 fixture 행을 OutputAgent에 직접 전달합니다.
오프라인 offline_edit_command는 input에 있는 사용자 명세를 재생합니다.
실제 변환·ChartSpec·렌더러는 실행하지만 자연어 수정 분류기는 평가하지 않습니다.
이 경계는 관측 결과의 edit_parser 및 실행 manifest에 표시합니다.
live의 NCP 수정 분류와는 점수를 합치지 않습니다.

API 상태·HTTP 오류·단계별 응답·시간·실제 통계 요청을 기록합니다.
이전 단계가 실패해도 이미 받은 응답 trace를 보존합니다.
그래프는 실제 Plotly trace 종류·이름·시점·숫자·subplot 배치를 검사합니다.
제목·범례 수정은 실제 figure 상태도 검사하고, 원자료·출처 보존과 조회 재실행 여부를 기록합니다.
이번 사례에서 사용하는 line/bar/area/stacked_bar 외 종류는 채점기가 자동 통과시키지 않습니다.

## 완료와 승인

제작 완료는 72건 원본 연결·기계 검증·검수 자료 준비입니다.
공식 평가 준비 완료는 사람의 골든 정답 승인과 별도 운영 승인 이후입니다.
현재 사람 승인 0건이며 ready_for_review입니다.
해석은 fixture의 첫/마지막 값·극값·차이·단위·주기·결측 사실로 검수합니다.
자동 검사와 사람 해석 검수는 분리합니다. 미검수는 pending_review,
미실행은 not_executed, 식별 관측 불가는 unobserved이며 모두 성공에서 제외합니다.

실행 결과는 의도적으로 제작 완료 기준의 만점 조건이 아닙니다.
실패를 없애려고 정답을 현 구현의 잘못된 출력으로 바꾸지 않습니다.
원본·질문·명세 문제와 제품 결함은 사람이 근거를 보고 구분합니다.
