# 파생지표 평가 명세와 실행 기록의 경계

`derived_goldset_300.jsonl`과 v2~v5는 2026-10-19 단계별 개발에 사용한 **작성된 질문·기대 계약의 역사적 버전**입니다. 모델 예측 결과나 비공개 평가 저장소의 정답이 아닙니다. 분할 이름이 holdout이더라도 개발 중 실패 분석에 사용했으므로 블라인드 성능으로 보고하지 않습니다. 경제학 전문가 승인도 대기 상태입니다.

최초 명세 이후 일별·12계열·파일 보완·지원 범위 정책·자연어 분류가 변경됐습니다. 과거 정답을 현재 제품의 모든 요청에 대한 최신 승인 정책으로 해석하지 마세요. 특히 현재는 최종 계산에 실제로 연결되는 승인 API 원자료가 하나 이상이어야 하며, 회사·개인 자료와 전부 외부 입력인 계산은 지원하지 않습니다. 과거 파일 보완 실험이 이 정책을 확대하는 근거가 되지 않습니다.

현재 제품 계약은 `tests/test_derived_support_policy.py`, `tests/test_derived_private_inputs.py` 등 회귀 테스트와 [전체 작업 기록](../docs/implementation/2026-10-19-complete-derived-worklog.md)을 함께 확인하세요. 과거 모델 출력에서 정답을 추출해 최신 정답으로 덮어쓰지 않습니다.

생성된 모델 출력·API 관측값·평가 JSON/TXT/XML·스크린샷·계정·런타임 근거는 PR에 포함하지 않습니다. 도구에서 참조하는 로컬 실행 기록은 별도 생성해야 하며, 파일이 없다고 검증 성공으로 간주하지 않습니다. 실제 API 검증에는 해당 실행의 서버측 KOSIS 키, 실제 GPT 평가에는 OpenAI 설정이 필요합니다. 모델 장애·API 장애·미확보를 구분하세요.

오프라인 제품 회귀는 `python tools/run_derived_regression.py`, 전체 Python 및 공개 표 탐색 회귀는 `python tools/run_derived_regression.py --full`입니다. 이 명령은 자식 프로세스의 공급자 키를 비활성화하고 별도 테스트 계정 DB를 사용합니다. 실제 공급자 품질 검증과 구분합니다.

공개 표 탐색 `eval/table-discovery/`와 파생지표 개발 평가의 버전·점수를 합치지 않습니다. 최신 코드에서 실제 GPT 300건 전체를 재평가한 기록은 아직 없으며, 과거 292/300 및 후속 8/8·150/150을 단순 합산해 최신 300/300으로 표시하지 않습니다.
